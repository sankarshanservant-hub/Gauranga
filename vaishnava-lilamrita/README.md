Перевод идёт в отдельном чате по комплекту `../oriya-pilot/KIT-README.md`; порции приходят через папку Диска
(файлы `VL-CC-FROM-TO-{src,full,ru,en}.md`) и вносятся сюда по главам:
- `src/CC.md` — текст ория (по изображениям скана изд. Б. Ч. Ачарьи, 1986);
- `full/CC.md` — ория + транслитерация + пословный RU/EN + уверенность A/B/C;
- `ru/CC.md`, `en/CC.md` — литературный перевод со сносками;
- `review/reports-CC.md` — отчёты порций (вопросы к специалисту, неясные чтения) и проверка координатора.
Пилот (гл. 4, ст. 28–81) — `../oriya-pilot/vaishnava-lilamrita/`; метод — `../oriya-pilot/METHOD.md`.
