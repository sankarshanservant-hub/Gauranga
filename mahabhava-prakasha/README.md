# Канаи Кхунтиа, «Махабхава-пракаша» (ория, XVI в.) — перевод на русский и английский

Автор — служитель храма Джаганнатхи (кхунтиа), современник и спутник Шри Чайтаньи. Источник — изд. Факир Мохана Даса
(Барипада, 1965; IA `sri-mahabhabaprakash-1965`), текст неполный, 22 страницы (печ. с. 1–22) в два столбца, без
нумерации. Скан: `../sources/oriya/kanai-khuntia-mahabhava-prakasha/`. Предисловие, примечания и приложение
редактора не переводятся.

Перевод — в отдельном чате по комплекту `KIT-README.md` (архив: `sh mahabhava-prakasha/tools/make_kit.sh <zip>`);
порции `MP-CC-FROM-TO-{src,full,ru,en}.md` — через папку Диска BR-exchange; приём —
`python3 -I tools/intake.py . <папка> MP-CC-FROM-TO`. Структура как в `../vaishnava-lilamrita/`:
`src/`, `full/`, `ru/`, `en/`, `review/`.
