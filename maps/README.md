# Карты лил — план и журнал поиска

Цель (решение пользователя, 2026-10-11): вкладка сайта с картографией лил Шри Чайтаньи и спутников —
точные карты Бенгалии, Ориссы, Враджа, Южной Индии с названиями всех селений, городов, рек и святынь, где
происходили лилы (по тегам мест `#…` из `lila-db/PLACES.md`, у каждой лилы — свои места). Карта должна быть
интерактивной и **без ошибок**: каждая точка проверена по старой топокарте и по писаниям.

## Что есть сейчас
- `lila-db/PLACES.md` — 169 тегов: ~131 точка на земле, 9 областей, 7 рек, 15 мест внутри городов (дома, кунды,
  храмы), 7 неземных обителей. Координат в базе пока нет.
- `places-candidates.json` — **предварительные** координаты по OpenStreetMap (Nominatim, 2026-10-11):
  найдено 90 из 131, не найдено 41. Все со статусом `unverified`. Среди найденных есть явные промахи
  (`#dandeshvara` → храм в Мумбаи, `#fatehabad` → Фаридпур, `#narayanapura` → Чандпур, `#devghar`, `#teliya-budhari`,
  `#gopalapura`, `#shrihatta`/`#chandradvipa` → центры областей) — сверка обязательна.
  Скрипт: `tools/geocode_candidates.py` (≤ 1 запроса/с, дописывает файл после каждого места).
- `src/ams-u502/nf-45-03.jpg` — пробный лист топокарты (см. ниже), «Бурдван»: 23°–24° с. ш., 87°00'–88°30' в. д. —
  Навадвипа, Шантипур, Кална, Катва, Шрикханда, Яджиграм, Бурдван, Вишнупур.
- `check/nf-45-03-navadvipa-candidates.jpg` — проба сверки: кандидаты OSM нанесены на лист 1955 г. по грубой
  (линейной) привязке рамки; расхождение ~1–1,5 км — это погрешность привязки, точную делать по сетке 15'.

## Основа: точные старые карты в общественном достоянии
1. **AMS Series U502, India and Pakistan 1:250 000** (U.S. Army Map Service, 1955–; работы правительства США —
   общественное достояние). 188 листов на всю Индию: https://maps.lib.utexas.edu/maps/ams/india/
   Подписаны тысячи деревень, реки и старые русла до современной застройки; сетка градусов через 15'.
   Главный источник для точек и названий. Нужные листы (номенклатура 1:1 000 000 → 16 листов по 1°×1,5°):
   Бенгалия — NF 45, NG 45 (и NF/NG 46 для Шрихатты, Восточной Бенгалии); Орисса — NE 45, NF 45; Врадж — NG 43;
   Бихар/Гая/Каши — NG 44; Юг — ND/NE/NC 43–44.
2. **Natural Earth** (общественное достояние): береговая линия, крупные реки, рельеф — для общего вида и мелких
   масштабов: https://www.naturalearthdata.com/
3. Для исторической географии XVI в. (русла, названия, область Гауды) — **Rennell, Bengal Atlas (1779–1781)**
   и **Imperial Gazetteer of India, Atlas (1909)** (DSAL, Чикаго: https://dsal.uchicago.edu/maps/gazetteer/) —
   старше и ближе к эпохе; для сверки названий, не для координат.

## Как сделать (предложение)
1. **Привязка листов AMS**: по пересечениям сетки 15' на каждом листе (≈ 35 опорных точек) — полиномиальная
   привязка (numpy; GDAL не обязателен). Проверка: известные храмы/города должны ложиться с точностью ≤ 200 м.
2. **Сверка каждой точки**: кандидат OSM → находим подпись на листе AMS → координата по подписи → статус
   `verified` + ссылка на лист и источник лилы. Где имя неоднозначно — решаем по писаниям (маршрут, соседние места)
   и отмечаем `note`. Где места больше нет или отождествление спорно — `disputed` с вариантами.
3. **Святые места внутри городов** (Маяпур — дома Джаганнатхи Мишры, Шривасы; Пури — Гамбхира, Гундича,
   Нарендра-саровара; Вриндаван/Говардхан — кунды): отдельные крупные планы по планам городов.
4. **Исторические русла**: Ганга (Бхагиратхи) у Навадвипы сместилась. Место явления Господа — **Шридхам Маяпур**
   на восточном берегу, по Шриле Бхактивиноде Тхакуру и Шриле Бхактисиддханте Сарасвати (авторитет толкования
   для проекта); нынешний город Набадвип — на западном берегу. На карте: Маяпур как место лилы; иные мнения —
   только в примечании.
5. **Формат для сайта**: GeoJSON (точки, линии маршрутов, области) + векторная подложка, стилизованная под
   старую бумагу (цвета свитка), на MapLibre/Leaflet; плитки из листов AMS — как слой «старая карта» по желанию.
   Каждая точка → список лил (из `lila-db`), каждый спутник → свои места и маршруты.
6. **Маршруты**: путь в Гаю, в Пури, по Югу, во Вриндаван — линиями по последовательности мест в лилах.
