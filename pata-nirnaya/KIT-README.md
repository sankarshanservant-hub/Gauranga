## 2. Что переводится, что — нет
- **Только тексты PN, PP, ASN**: двустишия, санскритские цитаты в начале PN («তথাহি…»), подписи авторов, хронограмма
  PN, колофоны («ইতি…»).
- **Не переводить**: вступительную заметку Амбикачарана Брахмачари на pdf 116 (над текстом PP, до «পাট পরিক্রমা যে
  যে করিবার হয়»), его подстрочные сноски, колонтитулы журнала, надпись «Scanned by TapScanner», шапки Кишори Даса
  («[ শ্রীখণ্ড নিবাসী শ্রীরামগোপাল দাস বিরচিত ]» — это его подзаголовок: передать одной курсивной строкой не нужно).
- Современные переводы и пересказы не использовать.

## 3. Как читать
- PN: в печати Кишори Даса **одно двустишие = одна строка** («… । … ॥»). PP и ASN в журнале 1911 г. — по две строки.
- **Нумерации в изданиях нет.** Нумеруй сам, с 1 в каждом тексте; единица — двустишие или санскритская шлока;
  «তথাহি» и колофоны — без номера.
- PP: читать по журналу 1911 г.; где чтение журнала и печати Кишори Даса расходятся по существу (имя, село) —
  переводи по журналу и дай вариант в сноске.
- **Имена сёл** — главное в этих текстах. Передавай по `ref/PLACES.md`; нового нет — транслитерация по правилам
  проекта (как в `PLACES.md` и `GLOSSARY.md`: Кумарахатта, Кхардаха, Шрикханда, Амбика-Кална), и в
  REPORT — список «Новые места» с бенгальским написанием латиницей. Не «осовременивай» и не отождествляй с
  современными городами в тексте; современное имя/округ — только в сноске и только если уверен.
- Неясное: наиболее вероятное чтение + сноска «чтение неясно». **Никогда не угадывай молча** имя или село.

## 4. Формат (как в `sample/ru.md`)
```
# «Шри Пата-нирная» Рамагопалы Даса

*Одна курсивная строка о содержании — своими словами.*

**1.** Шри Кришна Чайтанья — это нисхождение для игр;
с ангами, упангами и спутниками Он распространился по миру.
```
- Номер — `**N.**`; двустишие — две строки; пустая строка между единицами; санскрит — курсивом.
- Подпись автора — обычное двустишие, переводить по тексту.
- Сноски `[^N]` — сквозные внутри каждого текста; определения — в конце файла.

## 5. Стиль, имена, богословие
- Перевод **точный, построчный, без рифмы, без пересказа**. Ясный язык; EN — естественный литературный английский.
- **Имена лиц** — по `GLOSSARY.md` и `ref/PERSONS.md`. Термины: «পাট» — «шрипат» / "shripat"; «মহাপাট» —
  «великий шрипат (махапат)» / "great shripat (mahapat)"; «ধাম» — «дхама» / "dhama"; «পরিক্রমা» — «парикрама»
  (обход) / "parikrama". Первое употребление — со сноской.
- **Отождествления с обитателями Враджа** («пурве Судама», «Ранга-деви» и т. п.) — точно, как в тексте; если
  расходятся с «Гаура-ганоддеша-дипикой» — краткая сноска.
- **Местоимения**: о Господе, Нитьянанде, Адвайте — с заглавной; о спутниках — строчными.
- **Богословие** (авторитет — Шрила Бхактисиддханта Сарасвати): Божество — «Божество» / "Deity" (не «статуя»,
  «идол»); уход — «уход» / "disappearance" (не «смерть»).
