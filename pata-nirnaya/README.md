# «Пата-нирная», «Пата-парьятана», «Шакха-нирная Абхирамы» — перечни шрипатов

Статус: **комплект для перевода готов, перевод не начат** (2026-11-19). Для тегов мест `#…` в `lila-db/`.

- **«Шри Пата-нирная»** Рамагопалы Даса из Шрикханды (ученик Ратипати Тхакура; автор также «Радха-Кришна-раса-
  калпавалли», 1595 Шаки — по сведениям издателя). Окончена в чайтру 1597 Шаки (≈1675) — хронограмма «সাত অঙ্ক শর ব্রহ্ম» в конце текста
  (в предисловии Кишори Даса ошибочно «1517»). ≈55 двустиший + 4 санскритские цитаты; 24 (в одной рукописи 25)
  шрипата и 12 махапатов. Рукописи: Бангия Сахитья Паришат № 1439 (переписана 1216 Б.С.), Калькуттский ун-т № 3464,
  3648. Впервые напечатана Кишори Дасом Бабаджи (в «Гаудия-вайшнава-тиртха-парьятане»; в скане 5-го изд. на
  archive.org полного текста нет, только цитаты); текст — по 6-страничной фотокопии archive.org
  `path-nirnaya-path-paryatan` (`img/kdb-*`).
- **«Пата-парьятана»** Абхирамы Даса — «извлечение» из «Пата-нирнаи», ≈50–55 двустиший; и **«Шакха-нирная
  Абхирамачандры»** того же автора, ≈25 двустиший. Изданы по рукописи Амбикачараном Брахмачари в «Сахитья-паришат-
  патрике», 1318 Б.С. (1911), № 2 — **общественное достояние**: DLI `dli.bengal.10689.2880`, pdf 116–121 (`img/spp1318-*`).
  Рукопись PP — Сахитья Паришат № 1440. Маджумдар использует PP в своём указателе спутников (сокращение «অভি»).
