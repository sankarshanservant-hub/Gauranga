# Рубрикатор «Как это было» — что должно быть кликабельно

Цель (решение пользователя, 2026-11-23): **кликабельно всё** — каждый предмет, жест, блюдо, обычай. Ниже — перечень
вопросов по категориям; у каждого — файл карточек (`items/*.yaml`), где он раскрывается. Отметка: ✅ есть карточки,
🔶 частично, ⬜ нет. Поле `rubric` карточки — одна из рубрик в скобках.

## 1. Еда и кухня (`kitchen`) — items/kitchen.yaml, items/food.yaml
- 🔶 блюда эпохи поимённо (шукта, мочар-гханта, дал, бара, пайас, пиштака…) — что это, из чего, как готовят
- ⬜ **рецепты блюд, которые любил Господь** (по житиям + старые PD-кулинарные книги; помечать реконструкцию)
- ⬜ продукты по сезонам (бенгальский календарь: 6 сезонов, 12 месяцев), что когда созревает
- ⬜ пряности, масла, сахар (гур, кханда, мисри), соль; чего ещё не было (чили, картофель, томат, табак, чай)
- 🔶 из чего ели (лист, чашки, канса, камень), **чем ели** (рукой — правой; ложки-половники для раздачи)
- ⬜ **когда ели** (распорядок дня, число трапез, пост экадаши, кто ест первым/последним)
- 🔶 правила чистоты (уччхишта, омовение рук и рта, кто кому может подать пищу)
- 🔶 молочное, сладости; ⬜ напитки (вода, кокос, пахта, панака, шарбат)
- ⬜ еда в пути и у паломников, подаяние (бхикша санньяси)

## 2. Одежда, ткани, облик (`dress`) — items/dress.yaml
- 🔶 мужская/женская одежда, детская; ⬜ одежда санньяси (каупина, бахирвас, шафран), вдовы, царя, мусульманина-кази
- ⬜ **ткани: из чего** (хлопок, шёлк — тасар, мурга, пат; джут; лён?), как пряли, ткали, красили (индиго, марена, куркума,
  лак), муслин Бенгалии
- 🔶 украшения (золото, серебро, раковина, железо, лак, бусы туласи), ⬜ причёски, ⬜ косметика (сурьма, алта — красный
  лак для стоп, масла, амлаки для волос), ⬜ обувь (кхарам, босиком), ⬜ зонты, посохи
- ⬜ тилака, чётки (туласи-мала), знаки вайшнава

## 3. Климат, тело, здоровье (`home`/`town`)
- ⬜ **как согревались** (стёганые одеяла-кантха, шали, огонь, солнце), **как охлаждались** (опахала-пакха, вода, тень,
  сон на веранде/крыше, шитал-пати), муссон (зонты из листьев, сушка одежды)
- ⬜ гигиена: омовение, чистка зубов (веточка нима), масло для тела, мыло-заменители, стирка (прачки), туалет
- 🔶 врачи-вайдьи, аюрведа, болезни (лихорадка, холера?), змеи и укусы

## 4. Дом и быт (`home`) — items/home.yaml
- 🔶 из чего строили, ⬜ **сколько хижин/комнат, кто где жил** (мужская/женская половина, кухня, коровник, кладовая)
- ⬜ **кто ещё жил при семье** (родня, вдовы, слуги — Ишана, Дукхи; приживалы, ученики)
- ⬜ **домашние животные** (коровы, быки, собаки, кошки, попугаи-шука, майна, обезьяны?), вредители (крысы, змеи)
- 🔶 мебель (пиди, сундуки, полки, циновки, ложе, подвесные сетки-шика), освещение, хранение, замки
- ⬜ уровень жизни: бедный брахман / зажиточный / знать / двор султана — что у кого
