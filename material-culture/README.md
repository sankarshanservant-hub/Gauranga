# «Как это было» — материальная культура эпохи Шри Чайтаньи

База проверяемых карточек о быте Бенгалии и Ориссы конца XV — первой трети XVI в. Назначение: кликабельные предметы
игры «Гаура-лила» (кодекс «Быт»), сайт, комментарии к житиям. Задание — `TASK.md`.

## Устройство

- `items/<рубрика>.yaml` — карточки (рубрики: home, kitchen, dress, rites, town, music, nature, puri, travel).
- `SOURCES.md` — библиография; `SEARCH-LOG.md` — журнал поиска (и тупики); `research/` — выписки исполнителей
  (`pd-texts.md` — факты из книг в общественном достоянии; `images.md` — изображения и лицензии).
- `img/` — только свободные изображения (PD, CC0, CC-BY, CC-BY-SA, Open Access), до 2 МБ.
- `tools/hgrep.py` — поиск реалий в наших переводах житий; `tools/check.py` — проверка карточек
  (`--json` → `export/items.json`).

## Формат карточки

```yaml
- id: mc-banana-leaf-plate        # не меняется
  title: {ru: "…", en: "…"}
  rubric: kitchen
  era_evidence: hagiography       # epoch | later-reconstruction | hagiography — главный тип свидетельства
  evidence_note: {ru: "…", en: "…"}   # что именно засвидетельствовано и чем; что реконструкция
  text: {ru: "2–5 фраз своими словами", en: "…"}
  hagiography: ["ЧЧ Мадхья 3.43–44", …]   # по нашим переводам
  sources: ["…"]                   # PD-книги (стр.), музеи (номер экспоната)
  images: [{file: "material-culture/img/…", license: "CC0", author: "…", url: "…"}]
  game: {model: "…", where: ["mishra-house/kitchen"], codex: hs_handi, notes: "…"}
  todo: "что проверить"            # необязательно
```

**era_evidence**: `epoch` — есть свидетельство самой эпохи помимо житий (надписи, датированные памятники,
современные тексты вроде «Манаса-мангала» 1494 г.); `hagiography` — известно из житий (указать, раннее или позднее);
`later-reconstruction` — восстановлено по данным XVII–XIX вв. и этнографии. Смешанные случаи разбираются в
`evidence_note`.

**game.codex** — ключ предмета в черновом кодексе игры (`game/web/data/codex.json` на ветке игры), который карточка
заменяет/проверяет. **game.where** — места на карте (`mishra-house/courtyard|kitchen|sutika-ghar|thakur-ghar|
cowshed|backyard|pond|fence|lane`, `ganga-ghat`, `navadvipa/...`).

## Правила

Свои слова; современные книги не цитировать. Гаудия-вайшнавский взгляд: быт — служение, Божество — не «статуя».
Не переносить поздние реалии (чхана-сандеш, перец чили, картофель, блузка-чоли к сари и т. п.) на эпоху без пометки.
