# Реестр именных тегов

Формат тега: `@` + латиница в нижнем регистре без диакритики, слова через дефис, по самому употребительному имени
(`@srivasa`, `@jagannatha-mishra`). Одно лицо — один тег; другие имена — в столбце «Также». Тёзки различаются
уточнением (`@gopinatha-acharya`, `@gopinatha-deity-puri`). Добавлять новые строки в конец своего раздела.
