# План базы лил

Решение пользователя: база — технический файл для будущего сайта/приложения; формат свободный, удобный для поиска.

1. СДЕЛАНО (180 событий, все 255 записей с verses/event/метками). Проверить по тексту ЧЧ/ЧБ соответствия `cc`/`cb`,
   данные по памяти (список сомнительных — в отчёте исполнителя, коммит «База лил: разметка Лочана»).
   Было: (после завершения Лочана) В `lilas/lochana-cm.yaml`: `verses` (точные стихи) и `event` (завести события) для
   всех записей; поля поиска: themes, bhava, teaching, scriptures,
   calendar, years/age где источник даёт опору, cc/cb, divergence.
2. Свести в базу уже переведённые тексты, по одному источнику, в порядке изложения, сразу со всеми полями:
   Мурари Гупта (murari-kcc), затем Джаянанда, «Према-виласа», Говинда Дас (D), «Адвайта-пракаша» (D),
   «Нитьянанда-вамша», «Гаура-ганоддеша-дипика» (отождествления), «Чайтанья-чандродая» и др.
3. Заводить события (`events.yaml`) по мере появления второго источника о той же лиле; привязывать записи.
4. Отдельная работа (обсудить с пользователем): датировка событий — сверка указаний источников (возраст, месяц,
   титхи, годы Шаки), уточнение `years`/`age`/`date_conf`/`date_basis` на уровне событий.
