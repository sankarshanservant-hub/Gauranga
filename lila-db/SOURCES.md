# Источники и их авторитетность

Шкала: **A** — каноничен для гаудия-вайшнавов (признан ачарьями, свидетель или прямой ученик, принят Бхактисиддхантой);
**B** — традиционно принят, но с особенностями (поздние вставки, местная традиция, поэтическая вольность);
**C** — используется с оговорками (неканоничен, много расхождений, поздний); **D** — сомнителен (подлинность оспаривается).
Уровень записи по умолчанию = уровень источника; отдельную запись можно понизить (вставка, явное расхождение).
