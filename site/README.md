# Сайт «Гаура-лила» — прототип

Статический сайт (без сервера): лента лил Шри Чайтаньи и окно чтения стихов из наших переводов. Замысел — `SPEC.md`.

## Состав
- `index.html`, `style.css`, `app.js` — страница, оформление, логика (лента, список, окно-свиток, слои, RU/EN).
- `data/timeline.json` (эпизоды, лилы, перечни писаний) и `data/verses/<эпизод>-<n>.json` (стихи порциями ≤ 800 КБ,
  подгружаются при чтении) — генерируются (не править вручную); хранятся в git, чтобы сайт открывался прямо из ветки.
- `assets/src/` — исходники пользователя (фоны, макет); `assets/img/` — подготовленные слои (не править вручную).
- `tools/build_data.py` — собирает `data/lilas.json` из `lila-db/export` и файлов переводов
  (слои оригинал / транслитерация / пословный / перевод / примечания; RU и EN).
- `tools/prep_assets.py` — режет фоны: прозрачный край свитков, бесшовная плитка ленты, части вертикального свитка.

## Сборка
```
python3 lila-db/build.py
python3 site/tools/build_data.py
python3 site/tools/build_library.py
python3 site/tools/prep_assets.py   # только если менялись исходники фонов
cd site && python3 -m http.server 8000   # открыть http://localhost:8000
```

## Вкладки
«Писания» — читалка: все наши переводы целиком, по главам, RU/EN (`tools/build_library.py` + разбор разметки
`tools/mdhtml.py`; данные `data/library/`). Кнопки слоёв: оригинал / транслитерация / пословный / перевод / примечания.
Адрес главы — `#lib/<книга>/<номер>`. Из окна стихов на ленте — «Читать главу целиком →» (к стиху).
**Не публикуется** «Чайтанья-бхагавата» (`chaitanya-bhagavata/ed`): это изданный современный перевод
(Шри Чайтанья Сарасват Матх, 2006), не наш (правило CLAUDE.md) — ни в читалке, ни в ленте лил (`EXCLUDE_SOURCES`
в `tools/build_data.py`), пока пользователь не подтвердит права.
«Лилы» — лента; «Карта» — места лил (клик → лилы места; слой топокарты 1955 г.); «Спутники» — все участники лил
по группам с поиском (клик → описание, все лилы спутника, «Места на карте» — его места и путь по порядку лил).
Адреса: `#map`, `#people`, `#<id лилы или эпизода>`. Подложка и места — см. `maps/README.md`.

## Участники лил
Кнопка «Участники лилы» (в раскрытой лиле, над писаниями) и «Участники эпизода» (под раскрытым эпизодом) открывают
тот же свиток: сверху — кнопки с именами, ниже — описание выбранного. Кто участвует — из тегов `persons` записей
базы лил (без Самого Господа, Кришны и Радхи как Его бхавы, аллегорических лиц, авторов писаний и поэтов пад).
Имена — `lila-db/PERSONS.md`; описания — жизнеописания из `parshadas/ru|en/*.md` (сводные по T/M/B, 48 лиц;
данные `data/parshadas/<тег>-<lang>.json`, даты и места явления/ухода — `parshadas/export/persons.json`); у кого
жизнеописания ещё нет — временный текст из `content/persons.yaml`; плюс стихи «Гаура-ганоддеша-дипики».

## Музыка
«Prema Dhama» (исходник 156 МБ — на Google Диске пользователя, в git не хранится): `assets/audio/prema-dhama-1…8.mp3`,
части по 10 мин, 80 кбит/с; играют подряд по кругу. Кнопка в шапке; звук начинается с первого нажатия на странице.

## Иллюстрации лил
Исходник — `assets/src/lila/<id>.png` (виньетка на белом или с прозрачностью); `tools/prep_assets.py` убирает белый
фон и пишет `assets/img/<id>.webp`; привязка — `IMAGES` в `app.js` (ключ — id лилы `ev-…` или эпизода `ep-…`).
Промпты — `PROMPTS.md`. Готово: явление Шри Гауранги (`ev-gaura-appearance`); у остальных — заглушки.
