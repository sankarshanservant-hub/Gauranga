# Сайт «Гаура-лила» — прототип

Статический сайт (без сервера): лента лил Шри Чайтаньи и окно чтения стихов из наших переводов. Замысел — `SPEC.md`.

## Состав
- `index.html`, `style.css`, `app.js` — страница, оформление, логика (лента, список, окно-свиток, слои, RU/EN).
- `data/timeline.json` (эпизоды, лилы, перечни писаний) и `data/verses/<эпизод>-<n>.json` (стихи порциями ≤ 800 КБ,
  подгружаются при чтении) — генерируются (не править вручную); хранятся в git, чтобы сайт открывался прямо из ветки.
- `assets/src/` — исходники пользователя (фоны, макет); `assets/img/` — подготовленные слои (не править вручную).
- `tools/build_data.py` — собирает `data/lilas.json` из `lila-db/export` и файлов переводов
  (слои оригинал / транслитерация / пословный / перевод / примечания; RU и EN).
- `tools/prep_assets.py` — режет фоны: прозрачный край свитков, бесшовная плитка ленты, части вертикального свитка.

## Сборка
```
python3 lila-db/build.py
python3 site/tools/build_data.py
python3 site/tools/prep_assets.py   # только если менялись исходники фонов
cd site && python3 -m http.server 8000   # открыть http://localhost:8000
```

## Публикация
Сайт: https://sankarshanservant-hub.github.io/Gauranga/ (GitHub Pages из ветки `gh-pages`).
Обновить: `sh site/tools/publish_pages.sh` (кладёт содержимое `site/` без исходников в корень `gh-pages`).

## Музыка
«Prema Dhama» (исходник 156 МБ — на Google Диске пользователя, в git не хранится): `assets/audio/prema-dhama-1…8.mp3`,
части по 10 мин, 80 кбит/с; играют подряд по кругу. Кнопка в шапке; звук начинается с первого нажатия на странице.

## Иллюстрации лил
Исходник — `assets/src/lila/<id>.png` (виньетка на белом или с прозрачностью); `tools/prep_assets.py` убирает белый
фон и пишет `assets/img/<id>.webp`; привязка — `IMAGES` в `app.js` (ключ — id лилы `ev-…` или эпизода `ep-…`).
Промпты — `PROMPTS.md`. Готово: явление Шри Гауранги (`ev-gaura-appearance`); у остальных — заглушки.
