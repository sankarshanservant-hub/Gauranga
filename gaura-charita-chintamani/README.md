# Нарахари Чакраварти, «Гаура-чарита-чинтамани» — перевод на русский и английский

Аштакалия-лила Шри Гауры в «киранах» («лучах»), стихами множества размеров и падами на раги; бенгали с брадж-були.
Источник — изд. Харидаса Даса (Навадвип, 1947; первая часть, рукопись обрывается):
`../sources/narahari-chakravarti/gaura-carita-cintamani/`. Предисловие и подстрочные сноски редактора не переводятся.

Перевод — в отдельном чате по комплекту `KIT-README.md` (архив: `sh gaura-charita-chintamani/tools/make_kit.sh <zip>`;
33 МБ — пользователю отправлялся в двух частях: стр. 6–100 и 101–200); порции `GCC-KK-FROM-TO-{ru,en}.md` — через
папку Диска BR-exchange; приём — `python3 -I tools/intake.py . <папка> GCC-KK-FROM-TO` (REPORT → `review/reports-KK.md`).
Номера `**K.N.**`: K — кирана, N — номер строфы издания. База лил — `lila-db/lilas/gaura-charita-chintamani.yaml` (C).
