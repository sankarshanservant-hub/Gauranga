# Кирана 4 — отчёты переводчика и приёмка

## Порция GCC-04-001-011

Порция: кирана 4, 1–11 (pdf 51–55 + начало pdf 56, печ. с. 46–51). Кирана 4 начинается на pdf 51 после колофона кираны 3 (3.12–3.13 и колофон — в GCC-03-012-013-*). 4.11 начинается на pdf 55 и кончается на pdf 56 «॥১১॥» — переведена целиком (бриф § 3a); следующая порция начинается на pdf 56 строфой 4.12 («পুনঃ বেলোয়ার — রজনী প্রভাত প্রভাকর সম অদ্বৈত মহাশয়…»). Колофон кираны 4 — на pdf 60 после 4.22 (по OCR, подтверждено изображением при малом увеличении).
Размеры и раги порции: подзаголовок «পুনঃ প্রাতঃকালে নিজাঙ্গনোপবিষ্টস্য সৌন্দর্য্যাদি-বর্ণনং—» (без номера); чатурбханги(?)-ч. (4.1, дандака; название выцвело); рага лалита (4.2, с припевом); ятхарага (4.3; 4.4 с припевом); тривикрама-ч. (4.5, дандака); судхамукхи-ч. (4.6); читра-ч. (4.7, дандака); «বেলাবলী» (4.8, с припевом); «বেলোয়ার» (4.9; 4.10 — первая строка по центру без «ধ্রু»); «রাগ বেলোয়ার» (4.11, с припевом).
Неясные чтения: 4.1 — первая строка почти стёрта (pdf 51), название размера *ca…ṅgī*; *ratna*, *dattācārya*, деление имён; 4.3 *kirata*, *phutakāri*; 4.5 *prakāśāja*, *barabadānanda*, *dara na nirata*; 4.7 *kuruthe*; 4.8 *prasanna baraṇe abanāgi*; 4.11 *jaga-vañcana*, *barikhe/baribe*.
Пропуски/повторы нумерации издания: нет (4.1–4.11 подряд).
Новые имена: в 4.1 — длинный перечень спутников (Шриман Пандит / Shriman Pandita, Хиранья / Hiranya, Шригарбха / Shrigarbha, Пурандара / Purandara, Садашива / Sadashiva, Шриман Сен / Shriman Sena, Гангадас / Gangadasa, Нанданачарья / Nandanacharya, Ратна(?) / Ratna, Видьянанда / Vidyananda, Ванинатха / Vaninatha, Шаштхивара / Shashthivara, Гопиканта / Gopikanta, Ишана / Ishana, Нарада / Narada, Шринатха / Shrinatha, Рамадас / Ramadasa, Шубхананда / Shubhananda и др.); Падмавати / Padmavati (мать Нитьянанды); Шеша / Shesha; Шарада / Sharada; Ананга / Ananga; Тривени / Triveni. Размеры: чатурбханги(?) / chaturbhangi(?), тривикрама / trivikrama, судхамукхи / sudhamukhi, читра / chitra. Раги: лалита, белавали / belavali, велоара / veloara.
Подписи автора: Гханашьяма (4.1, 4.7, 4.9), Нарахари (4.2–4.5, 4.8, 4.11), Нарахари Дас (4.10).
Богословские сноски: 14 — гаура-нагари-вада (первая в киране 4; здесь гипербола о Нитьянанде, 4.11); 11 — Нитьянанда-Баларама, Гаура — Кришна в настроении Радхи; 13 — милость Гауры через Нитьянанду.
Строка содержания — по 4.1–4.11 (дальше в киране, по OCR, — Адвайта, 4.12, и другие спутники; при необходимости уточнить).

## Порция GCC-04-012-022

Порция: кирана 4, 12–22 и колофон кираны 4 (pdf 56–60, печ. с. 51–55). pdf 56 начинается с продолжения 4.11 (переведена в GCC-04-001-011) — пропущено. Кирана 4 кончается на pdf 60 колофоном после 4.22; кирана 5 начинается на pdf 61 («পুনঃ প্রাতঃকালে বৃদ্ধগণানাং প্রেমোৎকর্ষঃ—», রাগ বিভাষ) — на моих страницах её нет.
Размеры и раги порции: «পুনঃ বেলোয়ার» — снова велоара (4.12); рага ятхарага (4.13–4.15, 4.17–4.21; 4.13, 4.17–4.21 — с припевом, первая строка по центру, вторая с «ধ্রু»); рангамала-ч. (4.16); шобха-ч. (4.22).
Неясные чтения: 4.12 *diśā(!) jayakṛta*, *lahu bahu*, *sughara lobha rijha āra*, *pahuka parābhava*; 4.13 *na rahala pora*, *?āraṇa*, *śravaṇa-gata*, *ko adhikāra hīna karu*; 4.14 *bhora/tora*; 4.15 *śoṇa*, *kuladala laye/naye*; 4.17 *pari*, строка о шрути; 4.18 *susadṛśa adṛśa*; 4.20 *kañja-caraṇa*; 4.21 *su?āra*, *goṅāba(?)*.
КОЛОФОН — РАСХОЖДЕНИЕ: по изображению ×7 ясно «ভক্তাবলী-বেষ্টিতাদি» (-ādi, без র-ফলা), а не «-বেষ্টিতাদ্রি» (OCR), на котором основано название кираны в GCC-04-001-011 (# Кирана 4 … «описание горы, окружённой рядами преданных», сноска 1). Колофон переведён по изображению («Описание [Гауры], окружённого рядами преданных, и прочего»), расхождение — в сноске 26. Координатору: согласовать заголовок кираны 4 и сноску 1.
Пропуски/повторы нумерации издания: нет (4.12–4.22 подряд).
Новые имена: Сита / Sita (Ситапати — Адвайта); Ачьюта(нанда) / Achyuta(nanda); Харидас / Haridasa (Тхакур?); Нарахари Саркар / Narahari Sarkara (Тхакур), Шрикханда / Shrikhanda; Гададхара Дас / Gadadhara Dasa; Мадхумати / Madhumati (в сноске); Ананга / Ananga. Размеры: рангамала / rangamala, шобха / shobha. Рага: велоара / Veloara.
Подписи автора: Нарахари (4.12–4.14, 4.16, 4.17, 4.19–4.22), Гханашьяма (4.15, 4.18). В 4.18 «Шри Нарахари» — Нарахари Саркар (герой строфы), не подпись.
Богословские сноски: нет новых сносок о гаура-нагари-ваде (женщин в порции нет; первая в киране — сноска 14). Сноски 21–22, 24: Гададхара — Радха, Нарахари Саркар — Мадхумати, Гададхара Дас — сияние Радхи (ГГД); прежние настроения — лила Враджи.
Содержание: спутники вокруг Гауры во дворе Шачи: ликование Адвайты (хлопает по подмышкам, усаживает Гауру в сердце, «Я победил!») и красота Адвайты; Гададхара Пандит, Нарахари Саркар, Шриваса, Гададхара Дас — каждый в своей преме; итог — все спутники пьют нектар лица Гауры.
