# «Расика-мангала» Гопиджана-валлабхи Даса — комплект для перевода в отдельном чате (без доступа к GitHub)

Ты переводишь бенгальскую поэму **Гопиджана-валлабхи Даса «Шри Расика-мангала»** (1658–1660) — житие
**Расикананды (Расика-Мурари, 1590–1652)**, главного ученика Шьямананды Прабху, — на **русский и английский**.
Поэма в четырёх вибхагах (Пурва, Дакшина, Пашчима, Уттара) по 16 лахари («волн»); автор — сын Расамайи, ученика
Расикананды. Это завершение житийного цикла Шьямананды и его линии (после «Бхакти-ратнакары», «Према-виласы»,
«Нароттама-виласы»). Готовые порции ты отдаёшь файлами; пользователь кладёт их в папку Google Диска, Claude в
основном чате проверяет, вносит в репозиторий, собирает книгу и ведёт базу лил.

Прочитай этот файл целиком перед началом и перечитывай § 4–7 перед каждой порцией.

## 2. Что переводится, что — нет
- **Только текст поэмы**: паяры, трипади, пады с рагой и «гхошей» (припевом), санскритские шлоки, подписи автора,
  колофоны лахари.
- **Только перевод** (RU и EN параллельно, одинаковая нумерация и сноски); бенгальского оригинала и пословного в
  выходных файлах нет.
- **Не переводить и не пересказывать** аппарат изданий 1941 и 1997 гг.: предисловия, оглавление с изложением
  содержания лахари (pdf 1–36), **проза редактора под чертой внизу страниц** (бенгальский перевод санскритских шлок
  и пояснения) и его сноски (помечены `*` и т. п.), список опечаток (шуддхи-патра —
  можно использовать для исправления чтения, но не переводить), рекламу.
- Современные переводы и пересказы не использовать.

## 3. Как читать текст
- Основа — OCR полного издания; **каждую строку сверяй с изображением**, если в OCR что-то странное (искажённые
  конъюнкты, শ্রী → «জী», «প্রী», «গ্ী»; «৷৷» вместо «॥»; лишние буквы латиницей). Пурва и Дакшина — ещё и по
  OCR 1997 г.
- **Нумерация — по изданию**: двустишия внутри каждой лахари пронумерованы «॥ N ॥»; это и есть наш номер. Если номер
  в издании пропущен или повторён — отметь в сноске и REPORT, нумерацию издания сохраняй (повтор — `46a.`).
- Пада (песня с рагой): строка «রাগ …» и «ঘোষা/ধুয়া» (припев) — курсивом без номера в начале пады; строфы пады — по
  номерам издания.
- Неясное: наиболее вероятное чтение + сноска «чтение неясно» с бенгальским словом латиницей. **Никогда не угадывай
  молча** имя, число, дату, название места.
- Язык — бенгальский XVII в. с ория-влиянием (Мединипур, Уткал): формы вроде করিলা, আইলা, হৈল, কৈল, মুঞি — нормальны.

## 4. Формат файла (как в `sample/ru.md`)
```
# Пурва-вибхага. Лахари 1. <название по колофону лахари>        ← только в первой порции лахари

*<одна курсивная строка краткого содержания лахари — своими словами>*

**1.** *Санскритская шлока — курсивом, строки как в оригинале.*[^1]

**2.** Первая строка двустишия.
Вторая строка двустишия.
```
- Номер — `**N.**`; двустишие — две строки; пустая строка между единицами. Санскрит — курсивом.
- **Подпись автора** в конце лахари («শ্যামানন্দ-পদদ্বন্দ্ব করিয়া ভূষণ। আনন্দে রচিল রসময়ের নন্দন ॥» и её варианты) —
  обычное двустишие, всегда одной формулой:
  RU: «Украсив себя стопами Шьямананды, / сын Расамайи с радостью сложил [эту песнь].»
  EN: "Adorning himself with Shyamananda's feet, / the son of Rasamaya joyfully composed [this]."
- **Колофон** лахари («ইতি শ্রীরসিকমঙ্গলে … লহরী») — курсивом отдельным абзацем.
- **Сноски** `[^N]` — сквозная нумерация **внутри лахари** (с 1 в каждой лахари); определения — в конце файла порции.

## 5. Стиль, имена, богословие
- Перевод **точный, построчный, без рифмы, без пересказа**; каждое слово оригинала должно отразиться. Ясный
  литературный язык без архаизмов («сей», «дабы») и без просторечия. EN — естественный литературный английский.
- **Имена** — по `GLOSSARY.md`, затем `ref/prema-vilasa-GLOSSARY.md`: Расикананда (Расика, Расика-Мурари), Шьямананда,
  Хридаянанда (Хридая-Чайтанья), Дамодара, Расамайя, Ачьюта, Бхавани, Шьямадаси, Радхананда, Гопиваллабхапур,
  Дхаренда, Ремуна, Суварнарекха, Нрисимхадева (гаджапати), Ахмед Бег… Новое имя — по тем же правилам, в список
  «Новые имена».
- **Местоимения**: о Господе, Нитьянанде, Адвайте — с заглавной; о Шьямананде, Расикананде и других спутниках —
  строчными (даже если автор называет их «Прабху»).
- **Богословие** (глазами гаудия-вайшнава; авторитет — Шрила Бхактисиддханта Сарасвати). Божество — «Божество» /
  "Deity" (никогда «статуя», «изваяние», «идол», "idol", "statue"); уход Господа и спутников — «уход», «сокрытие» /
  "disappearance" (не «смерть», "death"; «оставил тело» — если так в тексте); Господь не подвластен майе — «йогамайя»;
  према — не «страсть», "passion", "lust". Где автор расходится с гаудия-вайшнавским учением или с ЧЧ/БР (напр.,
  Шьямананда — «Сама Радхика» в мангала-шлоке, Расикананда как воплощение, чудеса и «керамати», отношения с гаджапати),
  — **точный перевод** и короткая сноска с пояснением (кто есть кто по традиции, расхождения с «Бхакти-ратнакарой»,
  таранга 15). Не исправлять автора в тексте.
- **Сноски** — кратко: лица, места Уткала и Мединипура, раги, реалии, источники шлок (если уверен), расхождения с
  БР 15 / «Према-виласой» / «Шьямананда-пракашей», неясные чтения. Ссылки на ЧЧ/ЧБ — главой.

## 6. Что выдавать после каждой порции
Два файла (`V` — вибхага: 1 Пурва, 2 Дакшина, 3 Пашчима, 4 Уттара; `LL` — лахари двумя цифрами; `FROM`–`TO` — номера
двустиший трёхзначными):
- `RM-V-LL-FROM-TO-ru.md`
- `RM-V-LL-FROM-TO-en.md`

В конце **RU-файла** — служебный блок (Claude его уберёт):
```
<!-- REPORT
Порция: Пурва 1, 1–40 (pdf 37–40).
Неясные чтения (сверено по изображению / осталось неясным): 12 «…» — …
Пропуски/повторы нумерации издания: …
Новые имена: … → RU / EN.
Богословские сноски: 1, 5.
Последняя сноска: [^7].
-->
```
Если интерфейс не даёт скачать файлом — выведи каждый файл блоком кода с его именем в первой строке.

## 7. Порции и самопроверка
- Порция — **40–60 двустиший** (лахари в 40–90 двустиший можно делить на две порции; пады и шлоки — меньше).
- После 4–6 порций — новый чат: стартовое сообщение + архив + последние файлы (RU и EN).
- Перед выдачей:
  - [ ] каждое двустишие порции переведено, номера издания подряд; ни одной строки не пропущено (сверено с изображением);
  - [ ] RU и EN: одинаковые номера, одинаковые сноски; все метки имеют определения;
  - [ ] сноски и аппарат редактора не переведены и не пересказаны;
  - [ ] имена — по глоссарию; подпись автора — по формуле § 4;
  - [ ] нет стоп-слов: статуя, изваяние, идол, смерть (о Господе и спутниках), страсть (о преме); statue, idol,
        death, passion, lust;
  - [ ] блок REPORT заполнен.
