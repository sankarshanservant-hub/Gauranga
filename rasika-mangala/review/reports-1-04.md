# «Расика-мангала» 1-04 — отчёты переводчика

## Порция RM-1-04-001-037

Порция: Пурва 4, заголовок «চতুর্থ লহরী», рага, гхоша и двустишия 1–37 (pdf 50–51, печ. с. 14–15). Лахари 4 начинается на pdf 50 сразу после колофона лахари 3. Мангала-шлок нет — сразу рага Каруна-шри, гхоша (две строки) и песнь с ॥১॥; § 7 брифа не применялся. Строка «Четвёртая лахари» — курсивом, как в лахари 1–3.
Название — по колофону на pdf 55: «রসিক-জন্মলীলা-বর্ণন-নাম চতুর্থ-লহরী» → «Описание лилы рождения Расики» / "Description of the Pastime of Rasika's Birth" (лахари кончается на ॥132॥).
Стык: pdf 51 кончается ровно на ॥37॥, двустишие на pdf 52 не переходит; но фраза о дате рождения (36–37) продолжается в ॥38॥ на pdf 52 («শুক্ল প্রতিপদ রবিবার শুভক্ষণে…») — следующей порции.
Страница pdf 51 — в две колонки (4–20 слева, 21–37 справа); OCR смешал порядок (19, 20 вверху) — порядок восстановлен по скану, номера идут подряд.
Неясные чтения (сверено по скану): 31 «পটী»; 34 «দণ্ডতামী» (смысл предположителен; глосса редактора «তাম্রী, তান্ত্রিক»); 1 «রসিকশেখর-প্রিয়-প্রাণ» — двоякое понимание.
Пропуски/повторы нумерации издания: нет.
Новые имена: Рага Каруна-шри (уже было); Дипа-ятра / Dipa-yatra; дандатами / dandatami.
Богословские сноски: нет. Шьямананда здесь не возвышается до «Самой Радхики» (при необходимости — ссылка на лахари 1, сноска 2).
Последняя сноска: [^8].

## Порция RM-1-04-038-127

Порция: Пурва 4, двустишия 38–127 (pdf 52–54, печ. с. 16–18), без заголовка — продолжение RM-1-04-001-037. Начало: ॥38॥ (продолжение даты рождения из 36–37). Конец: pdf 54 кончается ровно на ॥127॥, двустишие на pdf 55 не переходит; ॥128॥–॥132॥ и колофон лахари 4 — на pdf 55 (следующая порция). Новая лахари на моих страницах не начинается.
Раскладка: все три страницы в две колонки. На pdf 53 посередине — рамка редактора «জন্ম-পত্রিকা» (гороскоп Расикананды с санскритской датой) — не переводится; она делит колонки: слева 73–80 | рамка | 81–82, справа 83–90 | рамка | 91–92. «Скачки» OCR (73…80, 83…90, рамка, 81, 82, 91, 92) — только раскладка; номера издания идут подряд, порядок подтверждён изд. 1997 г.
Пропуски/повторы нумерации издания: нет. OCR-ошибки номеров: ১৭৮ → ১০৮, ৯১৩ → ১১৩ (по скану).
Неясные чтения (сверено по скану): 58 «সুশঙ্ক» (глосса ред. সুগঠিত; 1997 গঠিত); 91 «ষষ্ঠী ছটী ঘর» (смысл предположителен); 97 «মার্কণ্ডেয় !» (звательный по изданию или «долголетие Маркандеи»); 102 «দয়াল-দাসী» — имя (ниже দয়ালদাসী ঠাকুরাণী); 119 «বেতবিষাণে» («бета» неясна); 121 «কার্ষ্ণজন» (OCR/1997 искажены); 81 OCR «কুজবৃদ্ধ» → скан কুলবৃদ্ধ.
Новые имена: Даяладаси / Dayaladasi; Шаштхи / Shashthi; Маркандея / Markandeya; Прахлада / Prahlada; хулахули / hulahuli; дхаи (повитуха) / dhai (midwife); чхати-гхара / chhati-ghara; рама-кадали / rama-kadali; инструменты мурали, рабаб, вену, шинга, бета, вишана.
Богословские сноски: 11 (Уткал не знал санкиртаны — о крае автора; Пури, ЧЧ), 17 (Прахлада, Бхаг. 7.7).

## Порция RM-1-04-128-132

Порция: Пурва 4, двустишия 128–132 (pdf 55, печ. с. 19) — конец лахари, без заголовка; продолжение RM-1-04-038-127 (pdf 54 кончается ровно на ॥127॥, стыка нет). Подпись автора (132) — по формуле README § 4; колофон по скану: «ইতি শ্রীরসিকমঙ্গল-পূর্ব্ববিভাগে রসিক-জন্মলীলা-বর্ণন-নাম চতুর্থ-লহরী সম্পূর্ণ» — название совпадает с заголовком лахари. Pdf 55 вверху в две колонки (128–130 слева, 131–132 и колофон справа).
Неясные чтения (сверено по скану): 128 «তাঁর» — чей достаток (видимо, Ачьюты); OCR «সম্পত্তি বহুত» = скан. 1997: «সম্পৃত্ৰি», «নরনিধি» — ошибки OCR.
Пропуски/повторы нумерации издания: нет.
Новые имена: сиддхи / siddhis; нидхи / nidhis.
Богословские сноски: 21 (сиддхи — образ благоденствия; преданные к ним не стремятся, Бхаг. 11.14.14).
