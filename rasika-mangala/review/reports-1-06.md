## Порция RM-1-06-001-009

Порция: Пурва 6, заголовок, шлока, рага, гхоша и двустишия 1–9 (pdf 57, печ. с. 21). Pdf 57 кончается ровно на ॥৯॥; ॥১০॥ («হেনমতে অন্ন-প্রাশন-সময় হৈলা») — первое на pdf 58, стыка нет. Следующая порция — с двустишия 10, сноски с [^4].

Курсивная строка содержания составлена по всей лахари (pdf 57–60, по OCR с беглой сверкой по сканам).
§ 7 брифа: перед раговой песнью одна санскритская шлока без номера (॥ без цифры) — обозначена **S1.** со сноской; двустишия — по изданию с 1.
Раскладка pdf 57: шлока, рага, гхоша, 1–3 — левая колонка; 4–9 — правая.

Неясные чтения (сверено по скану): S1 «কলিবারণে» — двоякое понимание (слон / сдерживание); 6 «পাণ্ডোই», «কঠাউ» — по глоссам издания; 7 «আনে কাহে কোলে» — «приносит [и кладёт] кому-нибудь на колени» (предположительно).

## Порция RM-1-06-010-104

Порция: Пурва 6, двустишия 10–104 (pdf 58–60, печ. с. 22–24) — до конца лахари, без заголовка; продолжение RM-1-06-001-009 (pdf 57 кончается ровно на ॥9॥, стыка нет). Подпись автора (104) — по формуле README § 4; колофон по скану: «ইতি শ্রীরসিকমঙ্গল-পূর্ব্ববিভাগে বাল্যলীলা-বর্ণন-নাম ষষ্ঠ-লহরী সম্পূর্ণ» → «Описание детских игр», как в заголовке RM-1-06-001-009. После колофона на pdf 60 начинается лахари 7 — отдельные файлы RM-1-07-001-003.
Раскладка: все три страницы в две колонки (pdf 58: 10–26 | 27–43; pdf 59: 44–61 | 62–79; pdf 60: 80–92 | 93–104 и колофон).
Пропуски/повторы нумерации издания: нет. Номер 37 на скане отпечатан с дефектом (похоже на «৩০») — по порядку 37 (сноска 12).
Неясные чтения (сверено по скану): 24 «দ্বিজভাগে» (двоякое понимание, сноска 9); 70 «সুপক্ক অমৃত পানি» (сноска 16); 94 «চউড়া» → по шуддхи-патре «চউরা» (сноска 19); 92 «নিছানি» — по смыслу и глоссе ред. (сноска 18); 100 «উপসন» = উপসন্ন, «пришёл, оказался»; 23 — эллиптическая строка: сели и мать, и отец (переведено «мать [и] отец»). Многочисленные искажения OCR (латиница вместо слов) исправлены по скану — см. read/RM-p058-060.txt.
«বাপু» передано «дитя» / "child", как в RM-1-06-001-009, 6.
Новые имена/реалии: аннапрашана / annaprashana; гхата / ghata; альпана / alpana; горочана / gorochana; кшира, питха, пакканна / kshira, pitha, pakkanna; пинди / pindi; ашваттха, дхатри / ashvattha, dhatri; сара / sara.
Богословские сноски: 11 (горожане называют Расику «аватарой» — по гаудия-вайшнавскому пониманию он вечный спутник, не аватара Господа), 13 (восемь саттвика-бхав, БРС 2.3).
