# Шри Адвайта-пракаша (Ишана Нагара) — русский перевод

Источник: OCR-текст (djvu.txt) хинди-издания «श्रीश्री अद्वैतप्रकाश»
(ред. Лакшминараяна Дас, Радхакунда). В издании оригинальные бенгальские
двустишия-паяры Ишаны Нагары (XVI в.) даны деванагари, за каждым следует
современный хинди-пересказ.

Принцип перевода: переводится **только оригинальный бенгальский текст**
Ишаны Нагары (общественное достояние), напрямую на русский, с сохранением
нумерации стихов. Современный хинди-комментарий издателя не переводится
целиком — он лишь используется для сверки понимания.
