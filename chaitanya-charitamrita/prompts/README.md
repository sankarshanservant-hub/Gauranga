# Шаблоны заданий исполнителям (субагентам)

Координатор не пишет задания с нуля, а собирает их из шаблонов:

    python3 tools/coord/prompt.py prompts/sheets.md CH=Adi16 PAGES=268–276 VERSES=111 NOTE="…"

Подстановки `{{ИМЯ}}`. Общие (ставятся автоматически): `{{W}}` — рабочая папка (`$CC_WORK`, по умолчанию
`/tmp/cc-work`), `{{BRANCH}}` — текущая ветка, `{{TRAILER}}` — строки в конце сообщений коммитов (переменная
окружения `COMMIT_TRAILER`; в Claude Code — строки атрибуции, которые даёт системное напоминание сессии).
Остальные — в командной строке; незаполненная подстановка — ошибка.

| Шаблон | Модель | Когда |
|---|---|---|
| `sheets.md` | Sonnet | сразу после `prep_chapter.sh` (параллельно с комментариями) |
| `commentary.md` | Opus | сразу после `prep_chapter.sh`; ≤ 15–20 страниц скана на исполнителя |
| `commentary-part.md` | Opus | длинная глава: два исполнителя параллельно, деление по номеру стиха |
| `stageA.md` | Opus | после `sheets.md` (нужны правки бенгальского по скану); ≤ 250–300 стихов |
| `check.md` | Sonnet | после слияния комментариев (может идти параллельно с этапом А) |

`{{EXTRA}}` в каждом шаблоне — особые указания по главе (что нашёл координатор при подготовке, решения
пользователя по спорным местам). Если нечего добавить — `EXTRA=""`.
