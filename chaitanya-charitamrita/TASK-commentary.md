# Перевод комментариев главы (проход 2 по WORKFLOW.md) — постоянное задание

Прочитать один раз: `STYLE-commentary.md` (**обязательно**), `CLAUDE.md` (корень), `TASK-full-edition.md` § 4 и «Решения пользователя», `GLOSSARY-vcd.md` (§ 2, 5, 6),
`ed/GLOSSARY-commentary.md` (если есть). Издание — последнее прижизненное (4-е, 1928) = скан `src/CC_SS.pdf`.

## Вход (готовит координатор)
`<scratch>/comm/<Глава>/`: для каждой страницы `pNN-L1.png`, `pNN-L2.png` (левая колонка, верх/низ), `pNN-R1.png`,
`pNN-R2.png` (правая), `pNN.txt` — черновой OCR тех же колонок. Порядок чтения: L1 → L2 → R1 → R2 → следующая страница.
Перевод стихов (ВЧД) — `ed/vcd/CC_<Глава>.md`.

## Что переводить
- **«Амрита-праваха-бхашья»** (Бхактивинода; под заголовком অমৃতপ্রবাহ ভাষ্য): вступление к главе (কথাসার и т. п.) →
  `## 0`; абзацы к стихам → `## N` (или `## N–M`, как в издании).
- **«Анубхашья»** (Бхактисиддханта; под заголовком অনুভাষ্য) → `## N` (или `## N–M`).
- **Подзаголовки разделов** (мелкая строка над стихами, напр. «শ্রীকৃষ্ণচৈতন্যের মহাবদান্যতা-বর্ণন—») → в файл
  «Анубхашьи», в раздел стиха, перед которым стоят: первой строкой `> Подзаголовок: …`.
- Стихи ЧЧ на странице не переводить (они уже переведены). Колонтитулы, номера страниц — пропускать.

## Выход (только свои файлы)
- **Два языка за один проход:** каждый раздел сразу по-русски и по-английски, оба — с бенгальского
  (`ed/ru/…` и `ed/en/<Глава>-apb.md`, `ed/en/<Глава>-anu.md`; заголовки EN: `# Amṛta-pravāha-bhāṣya on Ādi 1`,
  `> Subheading: …`). Разделы `## N` в RU и EN — один к одному.
- `ed/ru/<Глава>-apb.md`, `ed/ru/<Глава>-anu.md`: первая строка `# «Амрита-праваха-бхашья» к <Лила> <N>` / `# «Анубхашья» к …`,
  далее разделы `## N` по порядку. Редакторские сноски — `[^N-k]` в тексте и определения в конце файла.
- `ed/GLOSSARY-commentary.md` — дополнять: термин → принятый перевод/написание **RU и EN** (+ раздел «Нельзя»).
- **Сохранение (дёшево, часто):** каждые 3–5 разделов (≈ полстраницы) — дописать в файл и сразу, **той же одной
  командой**, `git add <файлы> && git commit -q -m "…" -- <файлы> && git pull -q --rebase origin <ветка> && git push -q origin <ветка>`
  (без --autostash; если pull отказывает из-за чужих несохранённых изменений — просто `git push`). Отдельных шагов
  только ради сохранения не делать. При обрыве теряется максимум несколько абзацев.
- **Продолжение после обрыва:** посмотреть последний раздел `## N` в своих файлах (`grep '^## ' … | tail -3`) и
  продолжить со следующего; уже переведённое не перечитывать.
- **Объём на одного исполнителя:** не больше ~15–20 страниц скана (качество и цена шага падают с ростом контекста).
  Короткие главы координатор объединяет, длинные делит на части.

## Как переводить
- Смотреть изображение колонки (оно главное), OCR — подсказка: он ошибается в сочетаниях согласных, теряет চন্দ্রবিন্দু.
  Каждое изображение смотреть один раз; бенгальский текст **не переписывать** (экономия; чистовой бенгальский не нужен).
  Неразборчивое место — редакторская сноска «Неясное место скана: …».
- Полно и точно: каждая мысль оригинала есть в переводе, лишнего нет; длинный период можно разбить на 2–3 предложения,
  сохраняя связи («поэтому», «ибо», «то есть»). Литературный русский в манере ВЧД — не калька.
- Глоссы к словам (анвая) — **как в издании**: связной строкой, пояснение в скобках после слова: `**таттва-видах̣** (знатоки истины) **тат** (именно это) …` (STYLE § 2).
- Стиль — `STYLE-commentary.md`: главное в конце фразы, пояснение после поясняемого, одна мысль — одно предложение,
  глоссы — анваей в строку, как в издании; каждый абзац перечитать один раз перед сохранением.
- Цитаты: перевод в “лапках” (EN: “…”, reference in parentheses, e.g. (Śrīmad-Bhāgavatam 1.2.11)), ссылка в скобках, как в издании: «“…”. (Шримад-Бхагаватам, 1.2.11)» — полное название
  (Бхагавад-гита, Шримад-Бхагаватам, Бхакти-расамрита-синдху…). Если в издании источник не указан, но он **точно**
  известен (проверено), — короткая редакторская сноска «Мундака-упанишада, 3.1.1–3» (EN: “Muṇḍaka Upaniṣad 3.1.1–3”);
  если не уверен — не указывать.
  Санскрит/бенгальский оригинал цитат в русский текст не переносить (только перевод).
- Стих ЧЧ, который комментатор цитирует или пересказывает, — дословно переводом ВЧД из `ed/vcd/` со ссылкой «(ЧЧ, Ади 1.5)».
- Богословие не «вычитывать» и не смягчать: переводить точно. Следить только, чтобы русское слово не внесло чужого
  смысла (Божество — не «статуя», йогамайя — не «иллюзия», према — не «страсть», уход — «сокрытие»).
- Где Бхактивинода понимает стих иначе, чем перевод ВЧД, — сноска «В переводе стиха — иначе: …». Богословских сносок от
  себя не давать.

## Отчёт
5–10 строк: что сделано (страницы, разделы), сколько неясных мест, вопросы. Подробности — в файлах.
