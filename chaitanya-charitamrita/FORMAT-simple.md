# Формат перевода «Шри Чайтанья-чаритамриты» — коротко и по делу

Глава переводится в **семь файлов**. Никаких «черновиков по шаблону»: весь исходный текст уже лежит в папке
(список ниже). Имена глав: `Madhya01` … `Madhya25` (две цифры). По-русски в тексте — «Мадхья 1».

## 0. Откуда брать текст (всё уже есть)
| Что | Где |
|---|---|
| Бенгальский текст стиха + транслитерация + перевод ВЧД (Вриндавана Чандры даса) | `vcd/txt/CC_Madhya01.txt` → после `python3 tools/prep_vcd.py Madhya01` — `ed/vcd/CC_Madhya01.md` |
| Скан издания Гаудия Матха 1928 (главный авторитет: бенгальский стихов и оба комментария) | `src/CC_SS.pdf`; страницы глав — `MADHYA-NOTES.md` (Мадхья 1 — с. 305–330) |
| Комментарии на бенгальском: картинки колонок + черновой OCR | после `bash tools/coord/prep_chapter.sh Madhya01 305 330` — `../cc-work/comm/Madhya01/pNNN-L1.png …` и `pNNN.txt` |
| Образцы готовых глав (смотреть и делать так же) | `ed/vcd/CC_Adi13.md`, `ed/en/work/Adi13.txt`, `ed/ru/Adi13-apb.md`, `ed/ru/Adi13-anu.md`, `ed/fixes/Adi13.txt` |

**Нельзя** править `ed/vcd/CC_*.md` и `ed/en/CC_*.md` руками — они **генерируются** скриптами. Все изменения перевода стихов —
только строками в `ed/fixes/<Гл>.txt` (п. 1), английский — в `ed/en/work/<Гл>.txt` (п. 2).

## 1. Перевод стихов на русский: `ed/fixes/Madhya01.txt` (правки к переводу ВЧД)
Перевод ВЧД **не переписываем**: только опечатки, пунктуация, ошибки смысла (со сноской) и недостающий пословный.
Каждая правка — одна строка: `@номер поле: было => стало  # причина`.

```
@5 bn: ভক্ত চন্দ্রগণ => ভক্ত পূর্ণচন্দ্রগণ  # скан с. 245            ← бенгальский по изданию ГМ
@5 tl: бхакта чандра-ган̣а => бхакта пӯрн̣ачандра-ган̣а  # по бенгальскому  ← транслитерация
@12 tr: Каранадокашайи => Каранодакашайи  # опечатка                    ← русский перевод
@33 ww: Чайтаньи  сандалии => Господа  подушка для стоп  # ошибка ВЧД     ← пословный
@2 addww: джайа джайа ш́рӣ-кр̣ш̣н̣а-чаитанйа гаурачандра => слава  слава  Шри Кришна Чайтанье  Гаурачандре
@33 note: => У ВЧД — «сандалии Господа»; «пада-упадхана» — подушка для стоп.  # ошибка ВЧД   ← сноска к стиху
```
- `было` — короткий **точный** фрагмент, скопированный из `ed/vcd/CC_<Гл>.md`.
- **Пословный (`addww`) в Мадхье у ВЧД отсутствует — его нужно составить для каждой строки транслитерации:**
  слева — начало строки транслитерации (как в файле), справа — русские значения слов **в порядке бенгальских слов**,
  слова разделены **двумя пробелами**.
- Ошибка смысла у ВЧД → `@N tr:` (исправленный перевод в стиле ВЧД) **и** `@N note:` («У ВЧД — «…»; …»).
- После правок: `python3 tools/prep_vcd.py Madhya01 && python3 tools/check_ed.py Madhya01` → «ошибок 0», нет
  «не применена», нет «нет пословного».

Как выглядит итог (это делает скрипт, не вы):
```
জয় শ্রীচৈতন্যচন্দ্রের ভক্ত পূর্ণচন্দ্রগণ ৷
সবার প্রেম-জ্যোৎস্নায় উজ্জ্বল ত্রিভুবন ॥ ৫ ॥

джайа ш́рӣ-чаитанйачандрера бхакта пӯрн̣ачандра-ган̣а
слава  Шри  Чайтанье-луне  преданных  полным лунам
саба̄ра према-джйотсна̄йа уджжвала три-бхувана
всех их  любви  светом  озарены  три мира

(5) Вся слава всем этим полным лунам — преданным Золотой Луны — Шри Чайтаньячандры. …[^5]
```

## 2. Английский перевод стихов: `ed/en/work/Madhya01.txt` (наш, с бенгальского)
```
@title The Pastimes of Śrī Caitanya        ← название главы, один раз в начале

@1                                          ← номер стиха (группа — @18-19)
may He  be gracious  Caitanya-              ← английский пословный: по строке на каждую строку транслитерации,
-deva  whose  by the grace                     слова через два пробела, в порядке бенгальских слов
= May Śrī Caitanyadeva be gracious to me: … ← «= » и перевод стиха одной строкой
```
Переводить с бенгальского, не с русского и **не** с BBT/Прабхупады (их не открывать). Термины — IAST (Kṛṣṇa, prema).
Проверка: `python3 tools/build_en.py Madhya01` → «переведено N из N».

## 3. Комментарии: 4 файла
`ed/ru/Madhya01-apb.md` и `ed/en/Madhya01-apb.md` — «Амрита-праваха-бхашья» (Бхактивинода);
`ed/ru/Madhya01-anu.md` и `ed/en/Madhya01-anu.md` — «Анубхашья» (Бхактисиддханта). RU и EN — **одинаковые списки разделов**.

```
# «Анубхашья» к Мадхье 1                   ← заголовок (EN: # Anubhāṣya on Madhya-līlā 1)

## 1                                         ← номер стиха, к которому комментарий (по нумерации издания)

> Подзаголовок: По милости Гауры даже падший становится способен описывать Его игры —

**йасйа** (Шри Кришна Чайтаньядевы) **праса̄датах̣** (по состраданию) … — глоссы к шлоке связной строкой, как в издании

Текст комментария абзацами…[^1-1]

## 18–19                                     ← общий комментарий к нескольким стихам — после разделов этих стихов

*Так заканчивается первая глава “Анубхашьи”.*    ← колофон в конце (названия книг в тексте комментария — в “…”)

---

[^1-1]: Текст сноски (сноски редакции: «В издании — …», «В переводе стиха — иначе: «…»», неясное место).
```
- В «Амрита-праваха-бхашье» первым идёт `## 0` — **Краткое содержание** главы.
- Подзаголовки «Анубхашьи» (строки над стихами в издании) — `> Подзаголовок: … —` в разделе своего стиха,
  даже если самого комментария к стиху нет.
- Переводить **всё**, что напечатано, ничего не пропуская и не добавляя от себя; смотреть **картинку** колонки,
  OCR — только подсказка.

## 4. Обязательные правила (на этом уже ошибались)
1. **Аваграха ঽ в издании печатается как «হ»**: «নাত্মা হশ্রুতেঃ» = nātmā ’śruteḥ — отрицание не терять.
   Каждую санскритскую цитату сверять по картинке.
2. Старые дроби: «১॥০» = 1½, «১।০» = 1¼, «২।৩» = 2–3.
3. Уход Господа и Его спутников — «уход», «ушёл из этого мира», «день ухода»; **не** «смерть», «умер», «сокрытие».
4. Божество — не «статуя/идол»; йогамайя — не «иллюзия»; према — не «страсть»; Купидон → Мадана.
5. Имена — как в `ed/GLOSSARY-commentary.md` (Гададхара, Рагхунатха дас, Шривас, Харидас, Шивананда Сен);
   деревни — транслитерацией бенгальского, без осовременивания.
6. Цитаты из ещё не переведённых глав ЧЧ — переводом ВЧД из `vcd/txt` (только опечатки).
7. Где комментатор понимает стих иначе, чем перевод ВЧД, — сноска «В переводе стиха — иначе: «…»».
8. Стиль — `STYLE-commentary.md`: живой литературный русский/английский, не подстрочник; длинный период можно
   разбить на 2–3 предложения.
