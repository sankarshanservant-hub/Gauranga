# Глоссарий переводчика комментариев (Бхактивинода, Бхактисиддханта)

Дополняет `GLOSSARY-vcd.md`. Термин → принятый перевод/написание. В тексте — транслитерация без диакритики;
при первом появлении в главе — краткое пояснение в скобках.

## Названия и оформление
- অমৃতপ্রবাহ ভাষ্য → «Амрита-праваха-бхашья»; অনুভাষ্য → «Анубхашья»; কথাসার → **Краткое содержание.**
- মঙ্গলাচরণ → мангалачарана (благословляющее вступление).
- স্বরূপগোস্বামিকড়চা → дневник Сварупы Госвами (как у ВЧД: «дневник Сварупы Дамодары»).
- Подзаголовки разделов → в «Анубхашью», `> Подзаголовок: …`, с тире в конце, как в издании.
- Стихотворные вступления комментаторов (мангалачараны) → раздел `## 0`, свободный перевод по строкам
  (пара русских строк на полустишие), без рифмы.

## Термины
- তত্ত্ব → таттва (истина); তত্ত্ববস্তু → Истина (о предмете книги).
- ঈশ → Иша (Всевышний); ঈশভক্ত → иша-бхакта (преданный Господа); ঈশতত্ত্ব → иша-таттва (истина о Всевышнем).
- দীক্ষাগুরু / শিক্ষাগুরু → дикша-гуру (учитель, давший посвящение) / шикша-гуру (наставляющий учитель).
- সিদ্ধ / সাধক → сиддха (достигший совершенства) / садхака (идущий путём садханы).
- স্বয়ংরূপ → сваям-рупа (изначальный облик); কায়ব্যূহ → кайа-вьюха (экспансия тела Господа).
- প্রকাশ → пракаша (проявление); বিলাস → виласа.
- অংশাবতার, গুণাবতার, শক্ত্যাবেশাবতার → амша-аватара, гуна-аватара, шактьявеша-аватара.
- আবরণতত্ত্ব → аварана-таттва (окружение Господа).
- শক্তি / শক্তিমান্ → энергия (шакти) / обладатель энергии.
- অচিন্ত্যভেদাভেদতত্ত্ব → ачинтья-бхедабхеда-таттва (истина о непостижимом единстве и различии).
- স্বরূপ (о природе) → сварупа (истинная природа); имя — Сварупа (Дамодара).
- মহিষী (Двараки) → царицы.
- মহাভাগবত → маха-бхагавата; হরিভজন → служение Хари; হরিজন → слуга Хари.
- উচ্ছিষ্ট → остатки (трапезы/милости).

## Имена
- Бхактивинода; Бхактисиддханта; Гауракишора (Шри Гауракишора); Вишванатха (Чакраварти); Джаганнатха (дас Бабаджи);
  Баладева; Рамачандра; Шринивас; Нароттама; Кави Карнапура; Шивананда; Гопала Бхатта; Рагхунатха дас;
  Рагхунатха Бхатта; Шри Вамшивадананда; Сарвабхаума; Рамананда (Рай); Шри Джива.
- শ্রীবার্ষভানবী → Шри Варшабханави (Радха, дочь Вришабхану).

## Нельзя
- Божество — не «статуя/идол»; йогамайя — не «иллюзия»; према — не «страсть»; уход Господа — «сокрытие».
