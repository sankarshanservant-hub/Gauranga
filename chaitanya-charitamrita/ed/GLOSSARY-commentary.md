# Глоссарий переводчика комментариев (Бхактивинода, Бхактисиддханта)

Дополняет `GLOSSARY-vcd.md`. Термин → принятый перевод/написание. В тексте — транслитерация без диакритики;
при первом появлении в главе — краткое пояснение в скобках.

## Названия и оформление
- অমৃতপ্রবাহ ভাষ্য → «Амрита-праваха-бхашья»; অনুভাষ্য → «Анубхашья»; কথাসার → **Краткое содержание.**
- মঙ্গলাচরণ → мангалачарана (благословляющее вступление).
- স্বরূপগোস্বামিকড়চা → дневник Сварупы Госвами (как у ВЧД: «дневник Сварупы Дамодары»).
- Подзаголовки разделов → в «Анубхашью», `> Подзаголовок: …`, с тире в конце, как в издании.
- Стихотворные вступления комментаторов (мангалачараны) → раздел `## 0`, свободный перевод по строкам
  (пара русских строк на полустишие), без рифмы.

## Термины
- তত্ত্ব → таттва (истина); তত্ত্ববস্তু → Истина (о предмете книги).
- ঈশ → Иша (Всевышний); ঈশভক্ত → иша-бхакта (преданный Господа); ঈশতত্ত্ব → иша-таттва (истина о Всевышнем).
- দীক্ষাগুরু / শিক্ষাগুরু → дикша-гуру (учитель, давший посвящение) / шикша-гуру (наставляющий учитель).
- সিদ্ধ / সাধক → сиддха (достигший совершенства) / садхака (идущий путём садханы).
- স্বয়ংরূপ → сваям-рупа (изначальный облик); কায়ব্যূহ → кайа-вьюха (экспансия тела Господа).
- প্রকাশ → пракаша (проявление); বিলাস → виласа.
- অংশাবতার, গুণাবতার, শক্ত্যাবেশাবতার → амша-аватара, гуна-аватара, шактьявеша-аватара.
- আবরণতত্ত্ব → аварана-таттва (окружение Господа).
- শক্তি / শক্তিমান্ → энергия (шакти) / обладатель энергии.
- অচিন্ত্যভেদাভেদতত্ত্ব → ачинтья-бхедабхеда-таттва (истина о непостижимом единстве и различии).
- স্বরূপ (о природе) → сварупа (истинная природа); имя — Сварупа (Дамодара).
- মহিষী (Двараки) → царицы.
- মহাভাগবত → маха-бхагавата; হরিভজন → служение Хари; হরিজন → слуга Хари.
- উচ্ছিষ্ট → остатки (трапезы/милости).

## Термины (добавлено по Ади 1, «Анубхашья» и проч.)
- অভিধেয় / সম্বন্ধ / প্রয়োজন → абхидхея (средство, путь) / самбандха (связь с Господом) / прайоджана (цель).
- আশ্রয়বিগ্রহ / বিষয়বিগ্রহ → ашрая-виграха (воплощение прибежища, вместилище любви) / вишая-виграха (объект любви).
- মন্ত্রগুরু, শ্রবণগুরু, শিক্ষাগুরু, চৈত্ত্যগুরু, মহান্তগুরু → мантра-гуру, шравана-гуру (гуру, у которого слушают),
  шикша-гуру, чайтья-гуру (гуру в сердце), маханта-гуру; গুরুব্রুব → гуру-брува (лжегуру);
  পারমার্থিক গুরু → гуру, наставляющий в высшей цели (парамартхика-гуру).
- শ্রদ্ধা, রুচি, নিষ্ঠা, আসক্তি, ভাব/রতি, প্রেমা → шраддха (вера), ручи (вкус), ништха (твёрдость), асакти, бхава / рати, према.
- অনর্থ → анартхи; সুকৃতি → сукрити (благие заслуги); অনুগ্রহ → ануграха (милость; = посвящение в мантру).
- অন্বয়-ব্যতিরেক → анвая-вьятирека (прямой и косвенный путь; предписания и запреты).
- আভাস → абхаса (отражение); তমঃ → тамас (тьма); মায়াবৈভব → майическое проявление (не «иллюзорное богатство»).
- চিৎ / জড় → духовный, чит / материальный, джада; অপ্রাকৃত → трансцендентный.
- নির্ব্বিশেষ → нирвишеша (лишённый качеств, безличный); নির্ব্বিশেষবাদী → нирвишешавадин.
- কৈতব → кайтава (обман); তমোধর্ম্ম → тамо-дхарма (свойства тьмы); স্বধর্ম্ম → свадхарма (изначальная природа).
- তদীয় → тадия («Его собственный»); অন্তর্য্যামী → Антарьями (Внутренний Владыка); চৈত্য → чайтья.
- সিদ্ধসেবক → сиддха-севака; ঐশ্বর্য্য / মাধুর্য্য → айшварья (величие) / мадхурья (сладость); পরব্যোম → Паравьома.
- স্বয়ংপ্রকাশ → сваям-пракаша; প্রাভববিলাস → прабхава-виласа; তদেকাত্মরূপ → тад-экатма-рупа.
- বৈধ / রাগানুগা সাধনভক্তি → вайдхи- / рагануга-садхана-бхакти.
- সম্ভোগ / বিপ্রলম্ভ → самбхога / випраламбха; দাস্য, সখ্য, বাৎসল্য, শৃঙ্গার → дасья, сакхья, ватсалья, шрингара.
- প্রিয়নর্ম্মসখী → прия-нарма-сакхи (дорогая наперсница).
- উদয়াচল → Удаячала (гора восхода); তত্ত্ববাদ → таттвавада; সাম্প্রদায়িক → [ачарьи] сампрадай.
- Двойная ссылка «ЧЧ, Ади 10.85»: «আদি ১০ম পঃ ৮৫ সংখ্যা» → «см. Ади 10.85».

## Оформление «Анубхашьи»
- Анвая-глоссы (санскр. слово + (пояснение)) → `**транслит.** — пояснение` подряд в абзаце, через «;» или «—»;
  транслитерация — как в пословном ВЧД этого стиха; дополнения издания в скобках без слова-глоссы — в (скобках).
- Комментарий к группе стихов (১-১৪, ৩৭-৪৩…) → отдельный раздел `## 1–14` сразу после раздела последнего стиха;
  подзаголовки стихов группы — в своих `## N`.
- Краткие инципиты стихов, на которые ссылается Бхактивинода, — транслитерацией в «ёлочках» + перевод в скобках.

## Нельзя
- Божество — не «статуя/идол»; йогамайя — не «иллюзия»; према — не «страсть»; уход Господа — «сокрытие».
