# Новые термины и написания — Madhya01, часть 2 (стихи 102–287), «Амрита-праваха-бхашья» и «Анубхашья»
Формат: бенгальское / RU / EN.

## Места
- কূর্ম্মস্থান, কূর্ম্মক্ষেত্র → Курма-стхана, Курма-кшетра / Kūrma-sthāna, Kūrma-kṣetra.
- জিয়ড়-নৃসিংহ → Джияда-Нрисимха / Jiyaḍa-Nṛsiṁha.
- বিদ্যানগর → Видьянагар / Vidyānagara (на Годавари — Мадхья 8; в Гауде — Мадхья 1.150: дом Видья-вачаспати).
- ত্রিমল্ল (তিরুমলয়) → Трималла (Тирумалая) / Trimalla (Tirumalaya); ত্রিপদী (তিরুপতি) → Трипади (Тирупати) / Tripadī (Tirupati); ব্যেঙ্কটাচল → Венкатачала / Veṅkaṭācala; বালাজী → Баладжи / Bālājī.
- অহোবল (অহোবিলম্) → Ахобала (Ахобилам) / Ahobala (Ahobilam); নবনৃসিংহমন্দির → Нава-нрисимха-мандир / Nava-nṛsiṁha-mandira; কর্ণূল → Курнул / Kurnool.
- শ্রীরঙ্গক্ষেত্র → Шри Ранга-кшетра / Śrī Raṅga-kṣetra; ঋষভ পর্বত → гора Ришабха / Ṛṣabha Mountain.
- ভট্টথারি → бхаттатхари / Bhaṭṭathāri (в бенг. списках ভট্টমারি — бхаттмари / bhaṭṭamāri); নম্বুদ্রি → намбудри / Nambudri; মালাবার → Малабар / Malabar.
- ত্রিবান্দ্রম → Тривандрам / Trivandrum; অনন্ত-পদ্মনাভ → Ананта-Падманабха / Ananta-Padmanābha; জনার্দ্দন → Джанардана / Janārdana; বর্কালা → Варкала / Varkala.
- সেতুবন্ধ, রামেশ্বর → Сетубандха, Рамешвара / Setubandha, Rāmeśvara.
- আলালনাথ (ব্রহ্মগিরি) → Алаланатха (Брахмагири) / Ālālanātha (Brahmagiri); অনবসর → анавасара / anavasara.
- কুলিয়া → Кулия / Kuliyā; চিনাডাঙ্গা → Чинаданга / Cināḍāṅgā; কোলের গঞ্জ → Колер-ганджа / Koler-gañja.
- কানাইর নাটশালা → Каная-Наташала / Kānāi's Nāṭaśālā (Каная — по ВЧД «Канай Наташала»); তিনপাহাড় → Тинпахар / Tinpahāṛ; রাজমহল → Раджмахал / Rājmahal.
- রামকেলি → Рамакели / Rāmakeli; গৌড় → Гауда / Gauḍa; শান্তিপুর → Шантипур / Śāntipura; পাণিহাটি → Панихати / Pāṇihāṭi; ভদ্রক → Бхадрака / Bhadraka.
- ঝারিখণ্ড → Джарикханда / Jhārikhaṇḍa; দশাশ্বমেধঘাট → Дашашвамедха-гхат / Daśāśvamedha-ghāṭa; দ্বাদশকানন → двенадцать лесов (двадаша-канана) / the twelve forests.
## Имена
- বিদ্যাবাচস্পতি → Видья-вачаспати / Vidyā-vācaspati; বিশারদ → Вишарада / Viśārada.
- দবির খাস → Дабира-кхас / Dabira-khāsa; সাকর মল্লিক → Сакара-маллик / Sākara-mallika.
- হুসেনসাহা বাদসাহ → падишах Хусейн Шах / the emperor Husain Shāh.
- ক্ষত্রিয় কেশব → кшатрий Кешава / the kṣatriya Keśava.
- রামসেবক বিপ্র, রামদাস বিপ্র → брахман Рамасевака, брахман Рамадас / the brāhmaṇa Rāmasevaka, Rāmadāsa; কৃষ্ণদাস → Кришнадас / Kṛṣṇadāsa.
- রঘুবর্য্যতীর্থ → Рагхуварья Тиртха / Raghuvaryatīrtha; নরহরি তীর্থ → Нарахари Тиртха / Narahari Tīrtha.
- শিখি-মাহিতি → Шикхи Махити / Śikhi Māhiti.
## Термины
- তত্ত্ববাদী → таттвавади / Tattvavādī; বড়গলই / তেঙ্গলই → вадагалаи / тенгалаи / *vaḍagalai* / *teṅgalai*.
- মারণ, উচ্চাটন, বশীকরণ → марана («убийство»), уччатана («изгнание»), вашикарана («подчинение») / *māraṇa*, *uccāṭana*, *vaśīkaraṇa*.
- মায়াসীতা → иллюзорная Сита (майя-Сита) / the illusory Sītā (*māyā-Sītā*).
- নামাভাস → намабхаса / *nāmābhāsa*; কূর্পর → курпара («локоть») / *kūrpara* (“elbow”).
- শৌক্র / সাবিত্র্য / দৈক্ষ্য → шаукра (по семени), савитрья (по Савитри), дайкшья (по посвящению) / *śaukra*, *sāvitrya*, *daikṣya*; শৌক্র-বিপ্র / অশৌক্র-বিপ্র → шаукра-випра (брахман по рождению) / ашаукра-випра / *śaukra-vipra* / *aśaukra-vipra*.
- বাক্যদণ্ড → «наказание словами» (вакья-данда) / “punishment in words” (*vākya-daṇḍa*).
- শক্তিসঞ্চার → вложение силы (шакти-санчара) / infusion of power (*śakti-sañcāra*).
- ক্ষেত্রসন্ন্যাস → кшетра-санньяса / *kṣetra-sannyāsa*.
- নামপ্রসাদ → имя-прасад (имя как милость) / name-*prasāda*; প্রাকৃত সহজিয়া → пракрита-сахаджии / *prākṛta-sahajiyās*.
- কনিষ্ঠাধিকারী (বৈধ) → каништха-адхикари на ступени вайдхи / *kaniṣṭha-adhikārī* at the *vaidhī* stage.
- কৃষ্ণচরিত্র-লীলা → Кришна-чаритра-лила / *Kṛṣṇa-caritra-līlā*.
