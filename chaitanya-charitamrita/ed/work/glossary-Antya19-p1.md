# Новые термины — Антья 19, комментарии, часть 1 (стихи 0–55; RU / EN)

#### Термины
- তর্জ্জাপ্রহেলী (АПБ 0); তরজা-প্রহেলী (стих 18) → загадка-тарджа (тарджа-прахели) / a riddle in the form of a *tarjā* (*tarjā-prahelī*); প্রহেলিকা (подзаг. 18, 25) → загадка (прахелика) / riddle (*prahelikā*) — ср. общий глоссарий (Мадхья 16).
- অপ্রকট হইবেন (АПБ 0) → «уйдёт из этого мира» / “will depart from this world” (не «сокроется»).
- লীলা সঙ্গোপন (подзаг. 20) → «свернуть игры» / “wind up His pastimes” (не «сокрытие»).
- মধূদ্যান (стих 1, АПБ 1, Ану 1) → весенний сад (мадхудьяна) / the spring garden (*madhūdyāna*); বাসন্তিকবিহারকানন → роща весенних игр / the grove of spring pastimes.
- মাতৃভক্তশিরোমণি → венец всех, кто предан своей матери / the crown jewel of those devoted to their mothers.
- বাৎসল্যোক্তি (подзаг. 5) → слова (несравненной) нежности / words of (incomparable) tenderness; অপ্রাকৃত বাৎসল্যপ্রেম → трансцендентная родительская любовь (ватсалья-према) / transcendental parental love (*vātsalya-prema*).
- ভক্তবৎসল → любящий Своих преданных (бхакта-ватсала) / who loves His devotees (*bhakta-vatsala*).
- গোপবেশ (Ану 12) → наряд пастушка (гопа-веша) / dress as a cowherd boy (*gopa-veśa*).
- বাউল / আউল (стихи 20–21, АПБ, Ану 20–21) → баул (безумец) / аул; «аул» = атура (охваченный [чувством], исполненный любви), также «расслабленный», «бессвязный», нишкинчана, арта, атура / *bāul* (madman) / *āul*; *āul* = *ātura* (overwhelmed, full of love), also “slack,” “incoherent,” *niṣkiñcana*, *ārta*, *ātura*. В стихах (перевод) — «безумец».
- উচ্ছৃঙ্খলতা (Ану 21) → беспорядок / disorder.
- আবাহন, নিরোধন, বিসর্জ্জন (АПБ 26–27) → призыв Божества (авахана), удержание Божества (ниродхана), отпускание Божества (висарджана) / invoking the Deity (*āvāhana*), keeping the Deity present (*nirodhana*), sending the Deity away (*visarjana*). দেবতা здесь — Божество (не «идол»).
- মহাযোগৈশ্বর্য্যশালী → обладатель великого могущества йоги / the possessor of great mystic power.
- প্রণয়রোষ (подзаг. 51) → любовный гнев (пранайа-роша) / loving anger (*praṇaya-roṣa*).
- দুরদৃষ্ট, নিজাদৃষ্ট-ধিক্কার → укор собственной (злой) судьбе / reproaching one's own (ill) fate.
- শিখিচন্দ্রক → перо павлина (шикхи-чандрака) / the peacock feather (*śikhi-candraka*); সুরেন্দ্রনীল, ইন্দ্রনীলমণি → сапфир (сурендра-нила, индранила) / sapphire (*surendra-nīla*, *indranīla*).
- তাণ্ডব (Ану 35) → танец (тандава) / dance (*tāṇḍava*).
- সর্ব্বসম্পৎপ্রসূ (Ану 35, о «нидхи») → источник всех богатств / the source of all riches.
- কুমুদিনী → кувшинка (кумудини) / night-blooming lotus (*kumudinī*); কাম (гопи; АПБ 38, Ану 38) → любовное желание (кама) / loving desire (*kāma*) — не «страсть».
- কর (игра слов «руки / лучи», Ану 38) → «кара» — руки или лучи / *kara*, hands or rays.
- বকপাঁতি → ряд, вереница цапель / a line of herons.
- আম্র-আঠা → смола мангового дерева / the sap of the mango tree; সেয়াকুলের কাঁটা → колючка сеякулы / a thorn of the *seyākul* bush.
- কলানিধি → вместилище 64 искусств; [о луне] полный во всех 16 долях (калах) / the reservoir of the 64 arts; [of the moon] full in all 16 digits (*kalās*).
- বিড়ম্বন → обман, надувательство / deceit, trickery.
- দত্তাপহার → даттапахара (отнять подаренное) — грех, требующий искупления (праяшчитты) / *dattāpahāra* (taking back what was given), a sin requiring atonement (*prāyaścitta*).
- অপ্রাপ্তভোগ (Ану 45) → ещё не вкусившие счастья [встречи] / not yet having tasted the happiness [of union].
- চিত্রজল্প → читра-джалпа / *citra-jalpa* (как в общем глоссарии); উদ্ঘূর্ণা → удгхурна / *udghūrṇā*.

#### Имена, места, источники
- শচীদেবী → Шачидеви / Śacīdevī; শ্রীজগন্নাথদেব → Шри Джаганнатхадева / Śrī Jagannāthadeva.
- শ্রীজগন্নাথবল্লভ-উদ্যান → сад Шри Джаганнатха-валлабха / the garden of Śrī Jagannātha-vallabha.
- শ্রীঅক্রূর → Шри Акрура / Śrī Akrūra.
- ললিতমাধব, ৩য় অঙ্ক, ২৫ শ্লোক → «Лалита-мадхава», 3.25 / *Lalita-mādhava* 3.25.
