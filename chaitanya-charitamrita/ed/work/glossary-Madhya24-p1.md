# Новые термины — Мадхья 24, часть 1 (комментарии, стихи 0–137)

Согласовано с `glossary-Madhya24-p2.md` (стойкость/дхрити, брахмамая, прапта-брахма-лая, прапта-сварупа, самуччая).

- Значения слова আত্মা (по «Вишва-пракаше»), § 11: দেহ → тело / body; মন → ум / mind; ব্রহ্ম → Брахман / Brahman; স্বভাব → природа (свабхава) / nature (*svabhāva*); ধৃতি → стойкость (дхрити) / steadfastness (*dhṛti*); বুদ্ধি → разум (буддхи) / intelligence (*buddhi*); যত্ন → усилие (ятна) / effort (*yatna*).
- আত্মারাম → атмарама / *ātmārāma*; আত্মারামতা → состояние атмарамы, приверженность безличному Брахману (по «Анубхашье» к 123) / being an *ātmārāma*.
- নির্ (приставка): নিশ্চয়, ক্রম, নির্মাণ, নিষেধ → уверенность, последовательность, созидание, запрет / certainty, sequence, construction, prohibition; গ্রন্থ: ধন, সন্দর্ভ, বর্ণসংগ্রথন → богатство, сочинение, соединение букв в слова / wealth, a literary work, the stringing of letters into words.
- ক্রম → шаг; сила, последовательный порядок (парипати), движение, трепет / step; power, orderly arrangement (*paripāṭī*), movement, trembling.
- উভয়পদী ধাতু → корень, принимающий обе формы спряжения (убхаяпади) / a root that takes both voices (*ubhayapadī*); আত্মনেপদ / পরস্মৈপদ → атманепада / парасмайпада / *ātmanepada* / *parasmaipada*; স্বরিত স্বর → ударение сварита / the *svarita* accent; ঞ ‘ইৎ’ → показатель «н̃» (ит) / the indicatory letter *ñ* (*it*).
- পাতক, উরুপাতক (так в издании), মহাপাতক, অতিপাতক → патака, урупатака, махапатака, атипатака / *pātaka*, *urupātaka*, *mahāpātaka*, *atipātaka*.
- Значения «ча» (§ 63): অন্বাচয়, সমাহার, অন্যোন্য, সমুচ্চয়, যত্নান্তর, পাদপূরণ, অবধারণ → анвачая (присоединение второстепенного), самахара (объединение в целое), аньонья (взаимность), самуччая (соединение), ятнантара (иное усилие), пада-пурана (восполнение стопы стиха), авадхарана (уверенность) / *anvācaya*, *samāhāra*, *anyonya*, *samuccaya* (conjunction), *yatnāntara*, *pāda-pūraṇa*, *avadhāraṇa*.
- Значения «апи» (§ 64): সম্ভাবনা, প্রশ্ন, শঙ্কা, গর্হা, সমুচ্চয়, যুক্তপদার্থ, কামচারক্রিয়া → самбхавана (возможность), прашна (вопрос), шанка (сомнение), гарха (порицание), самуччая (соединение), юкта-падартха (уместное применение), камачара-крия (действие по своей воле) / *sambhāvanā*, *praśna*, *śaṅkā*, *garhā*, *samuccaya*, *yukta-padārtha*, *kāmacāra-kriyā*.
- বৃহত্ত্ব, বৃংহণত্ব → брихаттва (всепроникаемость), бримханатва (способность взращивать и питать) / *bṛhattva*, *bṛṁhaṇatva*; আততত্ব → атататва (всепроникаемость) / *ātatatva*; মাতৃত্ব → способность порождать всё / being the progenitor of all; বিস্তৃতত্ব, প্রসবিতৃত্ব → вистритатва (протяжённость), прасавитритва (способность порождать) / *vistṛtatva*, *prasavitṛtva*.
- কেবল-ব্রহ্মোপাসক → кевала-брахмопасака (поклоняющийся одному Брахману) / *kevala-brahmopāsaka*; মোক্ষাকাঙ্ক্ষী → мокша-аканкши (стремящийся к освобождению) / *mokṣākāṅkṣī*; কেবল-ব্রহ্মজ্ঞানী → знаток одного лишь Брахмана / one who knows Brahman alone.
- অবরোহ-পন্থী / আরোহ-পন্থী → идущий нисходящим путём (авароха) / восходящим путём (ароха) / the descending (*avaroha*) / ascending (*āroha*) path; মুক্তাভিমানী → мнящий себя освобождённым / one who imagines himself liberated.
- শ্রৌতপন্থী → идущий путём шрути / one who follows the path of the Śruti.
- সগর্ভ (см. ч. 2); নৈর্গুণ্য → запредельность гунам (наиргунья) / transcendence of the *guṇas* (*nairguṇya*).
- অপ্রাকৃত বাউল → трансцендентный безумец (баул) / a transcendental madman (*bāula*).
- গোপবধূ → пастушки Враджа (гопа-вадху) / the young cowherd maidens of Vraja (*gopa-vadhūs*).
- দুঃসঙ্গ → дурное общение / bad association; সৎসঙ্গ → общение со святыми / the company of saintly devotees; সাধুসঙ্গ → общение с садху / the company of sādhus.
- নিরোধ, মুক্তি; অনুশয়ন → ниродха, мукти; погружение в покой (анушаяна) / *nirodha*, *mukti*; lying down to rest (*anuśayana*).
- প্রারব্ধ / অপ্রারব্ধ (পাপ) → начавшие приносить плоды (прарабдха) / ещё не начавшие (апрарабдха) / *prārabdha* / *aprārabdha*.
- রঙ্গক্ষেত্র → ранга-кшетра / the *raṅga-kṣetra*; বৃষ্ণিপত্তন → Вришни-паттана (Дварака) / Vṛṣṇi-pattana.
- নব-যোগেন্দ্র (জায়ন্তেয়) → девять Йогендр (сыновья Джаянти) / the nine Yogendras (the sons of Jayantī); পর্ব্বতমুনি → мудрец Парвата / the sage Parvata.
- Источники: “Вишва-пракаша” / *Viśva-prakāśa*; “Хари-бхакти-судходая” / *Hari-bhakti-sudhodaya*; толкование автора “Сарвагья-бхашьи” (приведено Шридхарой к Бхаг. 10.87.21) / the author of the *Sarvajña-bhāṣya*; “Ригведа”, мандала 1, сукта 154 / *Ṛg Veda*; Панини (Аштадхьяи, 1.3.72) / Pāṇini (*Aṣṭādhyāyī* 1.3.72); БРС, Пашчима-вибхага, «Шанта-бхакти-лахари», «Прити-бхакти-лахари» / *Bhakti-rasāmṛta-sindhu*, Paścima-vibhāga, “Śānta-bhakti-laharī,” “Prīti-bhakti-laharī.”
