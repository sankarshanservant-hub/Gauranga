# Новые термины — Мадхья 19, часть 2 (комментарии, стихи 151–257)

## Термины
- ভক্তিলতা, ভক্তিলতা-বীজ → лиана бхакти, семя лианы бхакти / the creeper of devotion, the seed of the creeper of devotion (*bhakti-latā-bīja*).
- মালী → садовник / gardener; সেচন, সেকজল → полив, вода для полива / watering.
- উপশাখা → побочные побеги (упашакха) / side shoots (*upaśākhā*) — у ВЧД в стихе «сорняки» (сноска).
- মূলশাখা → главный побег / the main shoot.
- কৃষ্ণানুরাগ → кришнанурага (привязанность к Кришне) / *kṛṣṇānurāga* (attachment to Kṛṣṇa).
- চিদ্‌বৃত্তি → духовная природа, чид-вритти / *cid-vṛtti*, the soul's spiritual nature.
- ক্রমপন্থা → путь шаг за шагом / the step-by-step path.
- আশ্রয়জাতীয় ভগবৎস্বরূপ → проявление Бхагавана из разряда ашраи / a manifestation of Bhagavān of the *āśraya* category.
- অনুগ্রহ-মন্ত্র → мантра милости (ануграха-мантра) / the mantra of grace (*anugraha-mantra*); ভক্তিমার্গ → путь бхакти / *bhakti-mārga*.
- দেবীধাম, ইতরব্যোম → Деви-дхама, «иное небо» (итара-вьома) / Devī-dhāma, the “other sky” (*itara-vyoma*).
- ব্রহ্মময় বৈকুণ্ঠ → духовная (брахмамайя) Вайкунтха / the wholly spiritual (*brahma-maya*) Vaikuṇṭha.
- সখ্যার্দ্ধ; গৌরব-সখ্যার্দ্ধ / বিশ্রম্ভ-সখ্যার্দ্ধ → половина сакхьи; половина сакхьи, исполненная почтения (гаурава) / доверия (вишрамбха) / half of *sakhya*; half of *sakhya* marked by reverence (*gaurava*) / by complete confidence (*viśrambha*).
- নিষিদ্ধাচার, কুটীনাটী, জীবহিংসা, লাভ, পূজা, প্রতিষ্ঠা → запретное поведение (нишиддхачара), кутинати (лицедейство, двуличие), джива-химса, лабха (выгода), пуджа (почитание), пратиштха (положение) / forbidden conduct, *kuṭīnāṭī* (duplicity), *jīva-hiṁsā*, *lābha* (gain), *pūjā* (worship), *pratiṣṭhā* (position).
- আত্মপ্রসাদ → удовлетворённость в себе (атма-прасада) / inner contentment (*ātma-prasāda*).
- শৌক্র-বংশ-মর্য্যাদা → происхождение по семени / status by seminal lineage; কলির স্থানপঞ্চক → пять мест, которые Парикшит отдал Кали / the five places Parīkṣit gave to Kali.
- নির্জ্জন-ভজনানন্দী → тот, кто «наслаждается уединённым бхаджаном» / one who “delights in solitary worship”; চিজ্জড়-সমন্বয়বাদ → учение о соединении духа и материи / the doctrine that reconciles spirit and matter; অদৈব বর্ণাশ্রম → небожественная варнашрама / ungodly *varṇāśrama*; অশুক্ল-বৃত্তি → нечистые способы (заработка) / impure means.
- বিদ্ধভজন → смешанный (виддха) бхаджан / mixed (*viddha*) worship; ভক্ত্যাভাস → подобие бхакти (бхакти-абхаса) / a semblance of devotion (*bhakty-ābhāsa*).
- ঐকান্তিকী / অহৈতুকী ভক্তি → исключительная (айкантики) / беспричинная (ахайтуки) бхакти / exclusive (*aikāntikī*) / causeless (*ahaitukī*) devotion.
- আত্যন্তিক-ভক্তিযোগ → абсолютная бхакти-йога (атьянтика) / absolute *bhakti-yoga* (*ātyantika*).
- তটস্থ-লক্ষণ / স্বরূপ-লক্ষণ → внешний признак (татастха-лакшана) / признак сущности (сварупа-лакшана) / marginal characteristic / characteristic of essence.
- অনুশীলন → развитие [служения], анушилана / cultivation (*anuśīlana*); বিশেষণ / উপলক্ষণ → вишешана (определяющий) / упалакшана (побочно указывающий) / *viśeṣaṇa* (defining) / *upalakṣaṇa* (incidental).
- পিশাচী → ведьма (пишачи) / witch (*piśācī*).
- মসৃণতা → мягкость (сердца) / softness; মমতা → мамата (чувство «Он мой») / *mamatā*.
- স্থায়িভাব, বিভাব (আলম্বন: বিষয়, আশ্রয়; উদ্দীপন), অনুভাব, সাত্ত্বিক, ব্যভিচারী / সঞ্চারী → стхайи-бхава, вибхава (аламбана: вишая, ашрая; уддипана), анубхава, саттвика, вьябхичари / санчари / *sthāyi-bhāva*, *vibhāva* (*ālambana*: *viṣaya*, *āśraya*; *uddīpana*), *anubhāva*, *sāttvika*, *vyabhicārī* / *sañcārī*.
- উদ্ভাস্বর → удбхасвара (сияющие) / *udbhāsvara* (radiant).
- Анубхавы (13): танец, катание по земле, пение, громкий плач, потягивание тела, рёв (хункара), зевота, учащённое дыхание, пренебрежение мнением людей, слюнотечение, громкий смех, головокружение, икота / dancing, rolling on the ground, singing, loud crying, stretching the body, roaring (*huṅkāra*), yawning, heavy breathing, disregard for public opinion, drooling, loud laughter, reeling, hiccups.
- গুড়, খণ্ডসার, শর্করা, সিতা-মিছরি, উত্তম-মিছরি → патока (гур), кхандасара, шаркара, сита-мисри, лучший мисри / molasses (*guḍa*), *khaṇḍasāra*, *śarkarā*, *sitā-misri*, the finest *misri*.
- মুখ্যরস / গৌণরস; আগন্তক → главные / второстепенные расы; приходящие (агантука) / principal / secondary *rasas*; visitors (*āgantuka*).
- হাস, বিস্ময়, উৎসাহ, শোক, ক্রোধ, ভয়, জুগুপ্সা (ঘৃণা) রতি → хаса-, висмая-, утсаха-, шока-, кродха-, бхая-, джугупса- (гхрина-) рати / *hāsa-*, *vismaya-*, *utsāha-*, *śoka-*, *krodha-*, *bhaya-*, *jugupsā-* (*ghṛṇā-*) *rati*.
- প্রেয়োরস → прейо-раса / *preyo-rasa*; প্রিয়তা → прията / *priyatā*; অযন্ত্রণা → аянтрана (свобода от уз) / *ayantraṇā* (freedom from constraint).
- সম্ভ্রম-দাস্য / গৌরব-দাস্য → самбхрама-дасья (с благоговением) / гаурава-дасья (с почтением к старшему) / *sambhrama-dāsya* (with awe) / *gaurava-dāsya* (with reverence for a superior).
- ঐশ্বর্য্যজ্ঞানমিশ্রা / কেবলা রতি → рати, смешанная с сознанием айшварьи / кевала-рати / *rati* mixed with awareness of majesty / *kevalā-rati*.
- পালক / পাল্য, পালন → опекун / опекаемый, опека (палана) / protector / the one to be protected, nurturing (*pālana*); আত্মসম → равный себе (атма-сама) / equal to oneself (*ātma-sama*).
- নিরপেক্ষ-ভাব → безучастное (нирапекша) отношение / a detached (*nirapekṣa*) attitude.
- নিজাঙ্গ-দানরূপ সেবা → служение, в котором отдают своё тело / the service of giving one's own body; কান্তাভাব → настроение возлюбленной (канта-бхава) / the mood of a beloved (*kāntā-bhāva*).
