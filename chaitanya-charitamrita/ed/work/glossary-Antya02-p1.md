# Новые термины — Антья 2, часть 1 (стихи 0–95)

RU → EN. В общий глоссарий не внесено (решает координатор).

- প্রকৃতি-সম্ভাষণ (বৈরাগীর) → беседа (отрёкшегося) с женщиной / a renunciant's speaking with a woman.
- ছয়রূপে বিলাসকারী (Махапрабху) → являет Свои игры в шести обликах / displays His pastimes in six forms.
- সেবারতা প্রেষ্ঠালি → самые дорогие подруги, занятые служением / dearest friends absorbed in service.
- পরমগুরু, পরাৎপরগুরু → парама-гуру, паратпара-гуру / *parama-guru*, *parātpara-guru*.
- সাবরণ পার্ষদ → окружение — приближённые / entourage of associates.
- সখি-মঞ্জরী → сакхи и манджари / *sakhīs* and *mañjarīs*.
- আম্বুয়া-মুলুক; মুলুক; তহশিল-কাছারি → Амбуя-мулук; мулук (округ); податная управа (тахсил-качари) / Āmbuyā-muluk; *muluk* (district); revenue office (*tahśil-kāchāri*).
- অম্বিকা, কালনা, বর্দ্ধমান, প্যারীগঞ্জ → Амбика, Кална, Бардхаман, Пияригандж (по общему глоссарию) / Ambikā, Kālnā, Barddhamāna, Piyārīgañja.
- নবখণ্ড: ঐন্দ্র, কশেরু, তাম্রপর্ণ, গভস্তিমৎ, কুমারিকা, নাগ, সৌম্য, বারুণ, গান্ধর্ব্ব → Аиндра, Кашеру, Тамрапарна, Габхастимат, Кумарика, Нага, Саумья, Варуна, Гандхарва / Aindra, Kaśeru, Tāmraparṇa, Gabhastimat, Kumārikā, Nāga, Saumya, Vāruṇa, Gāndharva.
- গৌরবাদী / কেবল কৃষ্ণবাদী → почитатели Гауры (гаура-вади) / те, кто признаёт одного лишь Кришну (кевала-кришна-вади) / those devoted to Gaura (*gaura-vādīs*) / those who hold to Kṛṣṇa alone (*kevala-kṛṣṇa-vādīs*).
- গৌরগোপাল-মন্ত্র → Гаура-Гопала-мантра (как у ВЧД) / Gaura-Gopāla-mantra.
- ঘরভাত; আমানী / প্রসাদী (Уткал) → «гхара-бхата» (домашний рис); «амани» (приготовленное из сырого, не остатки Джаганнатхи) / «прасади» / *ghara-bhāta* (“home rice”); *āmānī* / *prasādī*.
- বিদ্ধ কেবলাদ্বৈতবাদ → смешанная (виддха) кевала-адвайта / mixed (*viddha*) *kevalādvaita*.
- পূর্ণপ্রজ্ঞভাষ্য, পারিজাত-সৌরভ-ভাষ্য, সর্ব্বজ্ঞ-ভাষ্য, শ্রীভাষ্য → “Пурнапрагья-бхашья”, “Париджата-саурабха-бхашья”, “Сарваджня-бхашья”, “Шри-бхашья” / *Pūrṇaprajña-bhāṣya*, *Pārijāta-saurabha-bhāṣya*, *Sarvajña-bhāṣya*, *Śrī-bhāṣya*.
- চতুঃসন-সম্প্রদায়, রুদ্র-সম্প্রদায় → сампрадая Чатух-сана, Рудра-сампрадая / Catuḥ-sana-sampradāya, Rudra-sampradāya.
- সেব্যসেবকভাব → отношение слуги к Тому, Кому он служит (севья-севака-бхава) / the relationship between the servant and the one he serves (*sevya-sevaka-bhāva*).
- সৎসম্প্রদায় → истинные сампрадаи (сат-сампрадаи) / genuine *sampradāyas* (*sat-sampradāyas*).
- কুমতবাদ → ложное учение (кумата-вада) / false doctrine (*kumata-vāda*).
- নিখিল-বৈষ্ণব-গুরু শ্রীদামোদর-স্বরূপপ্রভু → Шри Дамодара-Сварупа Прабху, гуру всех вайшнавов / Śrī Dāmodara-svarūpa Prabhu, the guru of all Vaiṣṇavas.
- ছোট-হরিদাস → Чхота Харидас (по общему глоссарию; у ВЧД в заглавии «Младший Харидас») / Choṭa Haridāsa.
