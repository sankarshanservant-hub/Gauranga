# Новые термины — Мадхья 18, часть 2 (стихи 101–229)

- বাউল (в подзаголовке к 102) → «баул» (безумец) / “*bāul*” (madman).
- জঙ্গম-নারায়ণ → джангама-нараяна (Нараяна, наделённый способностью двигаться) / *jaṅgama-nārāyaṇa* (Nārāyaṇa endowed with the power to move).
- নিত্যবশ্য → вечно подвластный / eternally subordinate.
- স্থাণু → стхану (дерево без листьев) / *sthāṇu* (leafless tree).
- বিবর্ত্তবুদ্ধি → заблуждение (виварта-буддхи) / delusion (*vivarta-buddhi*).
- প্রতীতি-বৈষম্য → различие в восприятии / difference in perception.
- স্বতঃপ্রকাশত্ব (স্বরূপের) → сварупа проявляется сама собой / the *svarūpa* reveals itself of its own accord.
- তটস্থ-লক্ষণ / স্বরূপ-লক্ষণ → косвенный признак (татастха-лакшана) / признак сущности (сварупа-лакшана) / marginal characteristic (*taṭastha-lakṣaṇa*) / essential characteristic (*svarūpa-lakṣaṇa*).
- অচ্যুতত্ব (Упаричара Васу) → остался непоколебим / remained unshaken.
- সর্ব্বজ্ঞসূক্ত → «Сарваджня-сукта» / *Sarvajña-sūkta*; শ্রীবিষ্ণুস্বামী → Шри Вишнусвами / Śrī Viṣṇusvāmī.
- উপরিচর-বসু → Упаричара Васу / Uparicara Vasu; বিষ্ণুধর্ম্ম → “Вишну-дхарма” / *Viṣṇu-dharma*.
- পঞ্চগৌড় / পঞ্চদাক্ষিণাত্য ব্রাহ্মণ → пять гауда-брахманов (панча-гауда) / пять южных брахманов (панча-дакшинатья) / the five Gauḍa brāhmaṇas (*pañca-gauḍa*) / the five southern brāhmaṇas (*pañca-dākṣiṇātya*); কান্যকুব্জ, সারস্বত, গৌড়, মৈথিল, উৎকল; আন্ধ্র, কর্ণাট, গুর্জ্জর, দ্রাবিড়, মহারাষ্ট্র → Канъякубджа, Сарасвата, Гауда, Майтхила, Уткала; Андхра, Карната, Гурджара, Дравида, Махараштра / Kānyakubja, Sārasvata, Gauḍa, Maithila, Utkala; Āndhra, Karṇāṭa, Gurjara, Drāviḍa, Mahārāṣṭra.
- ভিক্ষা-দৌরাত্ম্য → назойливые приглашения на трапезу / pressing invitations to meals.
- সোরোক্ষেত্র, সোরো → Соро-кшетра, Соро (как в ч. 1) / Soro-kṣetra, Soro.
- কাড়িয়ে; পঁচসি; গড়বড়ি; বাটওয়ার/বাটোয়ার; আশোয়ার; সিক্‌দার; অবঁহি; ঘোড়া-পিড়া; ফুকারি; শেলধার → кадийе (уведём); панчаси (полнолуние, искаж. панчадаши); гадабади (суматоха); батоар (разбойник); ашоар (конное войско); сикдар; авахи (сейчас); гхора-пира (кони с сёдлами); пхукари (подав сигнал рожком); шеладхара (остриё дротика) / *kāḍiye*; *pāṅcasi*; *gaḍabaḍi*; *bāṭoyāra*; *āśoyāra*; *sikdār*; *abahi*; *ghoḍā-piḍā*; *phukāri*; *śeladhāra*.
- মৌলানা; পীর; সুফি; অনলহক্; এবাদৎ; নমাজ; খোদা / বান্দাহ → маулана; пир; суфии; «ана-л-хакк»; ибадат; намаз; «Худа» (Бог) / «банда» (слуга) / *maulānā*; *pīr*; Sufis; *anal-ḥaqq*; *ibādat*; *namāz*; “*Khodā*” (God) / “*bandā*” (servant).
- নির্ব্বিশেষ / সবিশেষ ব্রহ্ম → безличный (нирвишеша) Брахман / Брахман, наделённый признаками (савишеша) / featureless (*nirviśeṣa*) Brahman / Brahman with attributes (*saviśeṣa*); সাকার / নিরাকার → сакара / ниракара (бесформенный) / *sākāra* / *nirākāra* (formless).
- রামদাস (имя пира) → Рамдас (как у ВЧД) / Rāmadāsa; পাঠান-বৈষ্ণব → патханы-вайшнавы / Paṭhān Vaiṣṇavas; যুক্তপ্রদেশ → Соединённые провинции / the United Provinces.
- ভদ্রকালী → Бхадракали / Bhadrakālī; শ্রীগৌরবিগ্রহ → Божество Шри Гауры (Шри Гаура-виграха) / the Deity of Śrī Gaura (Śrī Gaura-vigraha).
- দিগ্দর্শন → общие очертания / a general outline.
