# Новые термины — Мадхья 17, часть 1 (комментарии, стихи 0–120)

- ঝারিখণ্ড → Джарикханда / Jhārikhaṇḍa (по общему глоссарию).
- মণিকর্ণিকার ঘাট → гхат Маникарника / the Maṇikarṇikā *ghāṭa*.
- বৈদ্য-চন্দ্রশেখর → Чандрашекхара Вайдья / Candraśekhara Vaidya.
- মহারাষ্ট্রীয়-ব্রাহ্মণ → брахман из Махараштры / a brāhmaṇa from Mahārāṣṭra.
- সানোড়িয়া-ব্রাহ্মণ → санодия-брахман / a Sanoḍiyā brāhmaṇa.
- শারী-শুক → Шари и Шука (попугаиха и попугай Вриндавана) / Śārī and Śuka.
- ভোজ্যান্ন ব্রাহ্মণ → бходжьянна-брахман (у которого можно принимать пищу) / a *bhojyānna* brāhmaṇa.
- বস্ত্রাম্বুভাজন → вастрамбу-бхаджана (одежда и сосуд для воды) / *vastrāmbu-bhājana*.
- কর্ম্মবুদ্ধিপ্রবল → в ком сильна склонность к кармическим делам / in whom the inclination to pious works (*karma*) is strong.
- দ্বিতীয়াভিনিবেশ → сосредоточенность на «втором» / absorption in a “second”.
- কার্ষ্ণ → каршна (принадлежащий Кришне) / *kārṣṇa*, one who belongs to Kṛṣṇa.
- কৃষ্ণসার → кришнасара (чёрный олень) / black buck (*kṛṣṇa-sāra*).
- ত্রুটি → трути (мгновение) / *truṭi*, a moment.
- ভিন্নপ্রায় → бхинна-прайа («почти дикие») / *bhinna-prāya*, “almost savage”.
- শূদ্রমহাজন → «шудры-махаджаны» / “*śūdra mahājanas*”.
- শৌক্রসাবিত্র্য-জন্ম → рождение по семени (шаукра) и по Савитри (савитрья) / birth by seed (*śaukra*) or by the Sāvitrī initiation (*sāvitrya*).
- Места (Джарикханда, APB 46): Атгар, Дхенканал, Ангул, Лахара, Кийонджхар, Бамра, Бонаи, Гангапур, Чхотанагпур, Яшапур, Саргуджа / Āṭagaṛa, Ḍheṅkānala, Āṅgula, Lāhārā, Kiyoñjhara, Bāmaṛā, Bonāi, Gāṅgapura, Choṭanāgapura, Yaśapura, Saragujā (по бенгальскому написанию, без осовременивания).
- লিখনবৃত্তি → ликхана-вритти (заработок перепиской рукописей) / *likhana-vṛtti*.
- ভাবকালি → бхава-кали (повадки бхавуки) / *bhāva-kāli*; ভাবুক → бхавука (сентименталист) / *bhāvuka*, a sentimentalist.
- ফল্গু-বৈরাগী → пхалгу-вайраги (ложный отречённый) / *phalgu-vairāgī*, a false renunciant.
- ক্লেশঘ্নী → клешагхни (уничтожающая страдания) / *kleśaghnī*; পাপ, পাপবীজ, অবিদ্যা → папа, папа-биджа, авидья / *pāpa*, *pāpa-bīja*, *avidyā*; কূট → кута (зачаток) / *kūṭa*.
- যমদণ্ড্য মর্ত্ত্যজীব → смертные, подвластные каре Ямы / mortals subject to the punishment of Yama.
- পঞ্চোপাসক → панчопасаки (почитатели пяти божеств) / *pañcopāsakas*.
- ষড়্দর্শন → шесть даршан (философских систем) / the six *darśanas*.
- তারকব্রহ্ম → тарака-брахма (имя Рамы) / the *tāraka-brahma*.
- এক-দণ্ডী → экаданди / *ekadaṇḍī*; রামানুজীয়ারস্বামী → рамануджистский джияр-свами / the Rāmānujīya *jīyar svāmī* (ср. Ади 7).
- বেটা (в цитате из ЧБ) → негодник / that rascal.
- Каши: অবিমুক্ত → Авимукта / Avimukta; অসি, বরুণা → Аси, Варуна / the Asi, the Varuṇā; কাশিকা → Кашика / Kāśikā; বিশ্বেশ্বর / বিশ্বনাথ → Вишвешвара / Вишванатха / Viśveśvara / Viśvanātha; মণিকর্ণা → Маникарна / Maṇikarṇā; কাশীখণ্ড → “Каши-кханда” / the *Kāśī-khaṇḍa*.
- বিন্দুমাধব / বেণীমাধব → Бинду-Мадхава / Вени-Мадхава / Bindu-mādhava / Veṇī-mādhava; পঞ্চগঙ্গা → Панчаганга / the Pañcagaṅgā; পঞ্চনদী(-ঘাট) → Панчанади(-гхат) / the Pañcanadī (Ghāṭa); ধূতপাপা, কিরণা → Дхутапапа, Кирана / the Dhūtapāpā, the Kiraṇā.
- আওরঙ্গজেব → Аурангзеб / Aurangzeb; আউন্ধ → Аундх / Āundh; সাতারা → Сатара / Sātārā; বোম্বাইপ্রদেশ → провинция Бомбей / the Bombay Presidency; প্রতিনিধি → пратинидхи / *pratinidhi*; শ্রীমন্ত বালাসাহেব পন্থ মহারাজ → Шримант Баласахеб Пант Махарадж / Śrīmant Bālāsāheb Pant Mahārāj; জগৎজীবন রাও সাহেব → Джагатдживан Рао Сахеб / Jagatjīvan Rāo Sāheb.
- চৈতন্যবট / যতনবট → Чайтанья-вата / Ятана-вата / Caitanya-vaṭa / Yatana-vaṭa; শশীভূষণ নিয়োগী → Шашибхушана Нийоги / Śaśībhūṣaṇa Niyogī; নারায়ণচন্দ্র ঘোষ → Нараяначандра Гхош / Nārāyaṇacandra Ghoṣa; শ্যালিকাপতি → свояк / his wife's sister's husband.
- দুর্গমসঙ্গমনী → “Дургама-сангамани” / the *Durgama-saṅgamanī*; পরমানন্দস্বামী → Парамананда Свами (гуру Шридхары Свами) / Paramānanda Svāmī.
