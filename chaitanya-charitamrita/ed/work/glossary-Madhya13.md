# Глоссарий комментариев к Мадхье 13 (новые термины, имена, места; RU / EN)

## Термины
- পাণ্ডুবিজয় / পাহাণ্ডি → Панду-виджая / паханди (вынос Божества с трона на колесницу) / Pāṇḍu-vijaya / *pahāṇḍi*
- দয়িতা, দয়িতা-পতি → дайиты (служители Джаганнатхи из шабаров), дайита-пати (дайиты-брахманы) / *dayitās*, *dayitā-patis*
- বালভোগ → бала-бхога (утреннее подношение сладостей) / *bāla-bhoga*; পাঁচন → пачан (напиток из сладкого сока) / *pā̃cana*
- তূলী → тули (хлопковые подушки) / *tūlī*; পট্টডোরী → шёлковые верёвки / silken ropes
- মণিমা → «манима» (обращение к почитаемым и к царю в Уткале) / *maṇimā*
- গৌড় (রথ টানে) → гауды (пастухи-гоала Уткалы) / the Gauḍas (cowherds, *goyālās*, of Utkala)
- সম্প্রদায় (কীর্ত্তন) → группа (сампрадая) / group (*sampradāya*); মূলগায়ক → ведущий певец / lead singer; দোহার, পালিগান → подпевающие (дохары), пали-ган / chorus singers (*dohāra*), *pāli-gāna*; বাইন → барабанщик (баин) / drummer (*bāina*); নর্ত্তক → танцор / dancer; মাদল (খোল) → мадал (кхол) / *mādala* (*khol*)
- রহস্য-দর্শন → рахасья-даршана (созерцание тайны) / *rahasya-darśana* (seeing the secret)
- লীলা-শক্তি, ইচ্ছা-শক্তি, প্রকাশ-বিগ্রহ → лила-шакти, иччха-шакти (энергия воли), облики-пракаши / *līlā-śakti*, *icchā-śakti*, *prakāśa* forms
- অলাতচক্র → алата-чакра (огненное колесо) / *alāta-cakra* (firebrand wheel)
- মণ্ডল (তিন মণ্ডল) → кольцо, круг / ring, circle
- স্বকীয়ভাব → настроение законного супружества (свакия) / the mood of wedded love (*svakīya*)
- রথ-বিজয় → выезд колесницы / the chariot sets out
- ভাবোদয়, ভাবশান্তি, ভাবসন্ধি, ভাবশাবল্য → бхаводая, бхава-шанти, бхава-сандхи, бхава-шабалья / *bhāvodaya*, *bhāva-śānti*, *bhāva-sandhi*, *bhāva-śābalya*
- ঝঞ্ঝাবাত → джханджха-вата (порывистый ветер) / *jhañjhā-vāta*; চৌগুণমঙ্গল → чаугуна-мангала / *cauguṇa-maṅgala*
- তিমিঙ্গিল → тимингила / *timiṅgila*; কুটিনাটী → кутинати (лукавство) / *kuṭināṭī* (duplicity)
- শৌক্র, সাবিত্র, দৈক্ষ জন্ম → шаукра, савитра, дайкша (три рождения брахмана) / *śaukra*, *sāvitra*, *daikṣa*
- বিপ্রশাসন → випра-шасана (брахманское селение) / *vipra-śāsana*
- প্রেমারুরুক্ষু → стремящийся подняться к преме / one who longs to rise to *prema*
- মানিনী → в обиде (мана) / hurt (*māna*); গোপবধূ (о Радхе) → пастушка / cowherd maiden
- কাম (গোপীর) → желание одного лишь служения Кришне (кама) — не «страсть» / the desire for nothing but service to Kṛṣṇa (*kāma*) — not “passion”

- Харичандана / Haricandana
- Говиндананда, Говинда Датта, Дамодара Пандит, Нараяна, Рагхава Пандит; Гангадас, Шриман, Шубхананда, Шрирама; Васудева Датта, Гопинатха, Мурари, Шриканта, Валлабха Сен; Говинда Гхош, Харидас (младший), Вишнудас, Рагхава, Мадхава, Васу Гхош; Рамананда, Сатьяраджа (Кулинаграм); Ачьютананда (Шантипур); Нарахари, Рагхунандана (Кханда / Шрикханда) / Govindānanda, Govinda Datta, Dāmodara Paṇḍita, Nārāyaṇa, Rāghava Paṇḍita; Gaṅgādāsa, Śrīmān, Śubhānanda, Śrīrāma; Vāsudeva Datta, Gopīnātha, Murāri, Śrīkānta, Vallabha Sena; Govinda Ghoṣa, Haridāsa (the younger), Viṣṇudāsa, Rāghava, Mādhava, Vāsu Ghoṣa; Rāmānanda, Satyarāja (Kulīnagrāma); Acyutānanda (Śāntipura); Narahari, Raghunandana (Khaṇḍa / Śrīkhaṇḍa)

## Нельзя
- «страсть», «рыба страсти» для камы гопи (у Бхактивиноды — желание одного лишь служения Кришне).
- «статуя» для Шри-мурти Джаганнатхи, Баладевы, Субхадры.
