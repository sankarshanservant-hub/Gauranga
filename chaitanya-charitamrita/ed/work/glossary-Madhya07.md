# Новые термины — Мадхья 7 (комментарии; RU / EN)

## Оформление
- Колофоны: «ইতি অমৃতপ্রবাহ-ভাষ্যে সপ্তম পরিচ্ছেদ» → *Так заканчивается седьмая глава “Амрита-праваха-бхашьи”.* / *Thus ends the seventh chapter of the “Amṛta-pravāha-bhāṣya.”*; «ইতি অনুভাষ্যে সপ্তম পরিচ্ছেদ» → *Так заканчивается седьмая глава “Анубхашьи”.* / *Thus ends the seventh chapter of the “Anubhāṣya.”*
- Строка-источник над шлокой 73 («(ভবভূতিকৃত ‘উত্তর-রামচরিতে’ তৃতীয়াঙ্কে ২৭ শ্লোক)») — часть стиха, в комментарий не переносится.
- Комментарии к группам: APB «২৫-২৬» → `## 25–26`; Ану «৩৭-৩৮» → `## 37–38` (после `## 37`, до `## 39`); Ану «৭১-৭২» → `## 71–72`.
- APB к шлоке 73: номер в скане неясен («৭১»/«৭৩»), отнесено к 73 по содержанию (сноска).

## Имена и Божества
- বাসুদেবামৃতপ্রদ → Васудевамрита-прада (Дарующий нектар Васудеве) / Vāsudevāmṛta-prada (He who gave nectar to Vāsudeva).
- বাসুদেব (বিপ্র) → Васудева (в комментарии — санскритская форма; у ВЧД в стихах «Васудэв») / Vāsudeva; কূর্ম্ম (ব্রাহ্মণ) → Курма / Kūrma.
- কালাকৃষ্ণদাস বিপ্র → брахман Кала Кришнадас (спутник Господа на юге; ≠ Кала Кришнадас из двенадцати гопал, Ади 11.37) / the brāhmaṇa Kālā Kṛṣṇadāsa.
- ষাঠীর মাতা → мать Шатхи / Ṣāṭhī's mother.
- আলালনাথ → Алаланатха (Божество четырёхрукого Васудевы); деревня «Алаланатх» / Ālālanātha.
- কূর্ম্মদেব, কূর্ম্মনাথ, শ্রীকূর্ম্মনায়ক → Курмадева, Владыка Курмы, Владыка Шри Курмы / Kūrmadeva, the Lord of Kūrma, the Lord of Śrī Kūrma.
- লক্ষ্মণাচার্য্য, লক্ষ্মণদেশিক, যতিভূপতি, যতীন্দ্র → Лакшманачарья, учитель Лакшмана, царь аскетов, лучший из аскетов (= Рамануджа) / Lakṣmaṇācārya, the teacher Lakṣmaṇa, the king of ascetics, the best of ascetics.
- পুরুষোত্তম যতি (надпись в Курмаме) → аскет Пурушоттама / the ascetic Puruṣottama; আনন্দতীর্থ → Анандатиртха / Ānandatīrtha; নরহরি তীর্থ → Нарахари Тиртха / Narahari Tīrtha.
- যোগানন্দ নৃসিংহদেব → Йогананда Нрисимхадева / Yogānanda Nṛsiṁhadeva; কামতদেব → Каматадева (так в издании) / Kāmatadeva.
- শবর → шабары / Śabaras; অধ্যাপক কিল্হর্ণ → профессор Кильхорн / Professor Kielhorn.
- অচ্যুত-গোত্র → род Ачьюты (ачьюта-готра) / the family of Acyuta (*acyuta-gotra*).

## Места (без осовременивания)
- কূর্ম্মাচল, শ্রীকূর্ম্মম্, কূর্ম্মতীর্থ → Курмачала, Шрикурмам, Курма-тиртха / Kūrmācala, Śrīkūrmam, Kūrma-tīrtha.
- গঞ্জাম জেলা → округ Ганджам / the Ganjam district; চিকাকোলরোড্ স্টেশন → станция «Чикаколе-роуд» / “Chicacole Road” station; ‘গঞ্জাম ম্যানুয়েল’ → «Ганджам мануал» / *Ganjam Manual*.
- রামনদ → Рамнад / Rāmnad; সেতুবন্ধ-রামেশ্বর → Сетубандха-Рамешвара / Setubandha-Rāmeśvara.
- পোরবন্দর (= Видьянагар, так в APB 62) → Порабандар / Porabandara.
- বিজয়নগর → Виджаянагар / Vijayanagara; কলিঙ্গ → Калинга / Kaliṅga.

## Термины
- সংখ্যা-নাম, সংখ্যা-নাম-জপ → имена, повторяемые по числу (санкхья-нама), повторение имени со счётом (санкхья-нама-джапа) / names chanted by number (*saṅkhyā-nāma*), chanting while keeping count (*saṅkhyā-nāma-japa*); কটীডোরক, কটিসূত্র → поясной шнур / waist-cord.
- হঠ-রঙ্গে → в лапы обманщика или мошенника / into the clutches of a cheat or a swindler; লেউটি' (хинди «লৌট») → вернувшись / having returned; সাথ → общество (санга) / company (*saṅga*); অতিকাল → прошло много времени / much time had passed.
- নিরপেক্ষতা (Господа, Дамодары) → независимость / independence.
- অধিকারী (о Рамананде) → адхикари, главный царский чиновник / *adhikārī*, the king's chief officer; অধিকারী রসিকভক্ত → «адхикари, расика-бхакта» (достойный преданный, знающий вкус расы) / *adhikārī rasika-bhakta*.
- করণ-জাতি → каста карана / the Karaṇa caste; শৌক্র-শূদ্র → шаукра-шудра (шудра по рождению) / *śaukra-śūdra*; বিষয়ী → вишайи / *viṣayī*; বিদ্বৎ / নরোত্তম-সন্ন্যাসী → видват- или нароттама-санньясин / *vidvat-* or *narottama-sannyāsī*; নৈসর্গিক বৈষ্ণবতা → природная (найсаргика) вайшнавская суть / natural (*naisargika*) Vaiṣṇava nature.
- প্রকৃতি-বাদী জ্ঞানী ও কর্ম্মী → гьяни и карми — пракрити-вадины / the *jñānīs* and *karmīs* who are *prakṛti-vādīs*; শব্দপ্রমাণ → свидетельство откровения (шабда-прамана) / the testimony of revelation (*śabda-pramāṇa*); শ্রৌতপন্থী → идущий путём шрауты / follower of the path of *śruti*.
- গোদাস, গৃহব্রত, গৃহমেধী → годасы (рабы чувств), грихавраты, грихамедхи / *go-dāsas* (servants of the senses), *gṛhavratas*, *gṛhamedhīs*.
- শক্তি সঞ্চার → вложение силы (шакти-санчара) / infusion of power; ভক্তি-শক্তি (суть хладини + суть самвит) → бхакти-шакти, сила преданности / *bhakti-śakti*, the power of devotion; পরমভক্ত → парама-бхакта (высший преданный) / *parama-bhakta*.
- প্রোজ্ঝিতকৈতব, নিরস্তকুহক → свободный от всякого обмана (проджджхита-кайтава), от всякого фокусничества (нираста-кухака) / *projjhita-kaitava*, *nirasta-kuhaka*; বুজরুকী → шарлатанство / charlatanry.
- উৎকট ভজন-পরায়ণ অভিমান / উৎকট ভক্তাভিমান → самомнение, будто ты «всецело отдан бхаджану» / напыщенное самомнение преданного / the conceit of being “wholly devoted to *bhajana*” / an inflated devotee's conceit; দীনাভিমান → показная смиренность / show of humility; অকিঞ্চন ভক্ত → преданный-акинчана / *akiñcana* devotee.
- চৈতন্য / অচৈতন্য (игра слов в Ану 152 и подзаголовке) → сознание (чайтанья) / лишённый сознания (ачайтанья) / consciousness (*caitanya*) / unconscious (*acaitanya*).
- পাণ্ডা → панды / *pāṇḍās*; পরমান্ন → параманна / *paramānna*.
