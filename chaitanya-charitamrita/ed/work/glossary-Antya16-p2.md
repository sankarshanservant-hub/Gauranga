# Новые термины — Антья 16, комментарии, часть 2 (стихи 76–151; RU / EN)

#### Термины
- দলই → далаи, привратник / *dalai*, a doorkeeper.
- বল্লভভোগ; বাল-ভোগ; বাল্য-ভোগ (подзаг. 88) → валлабха-бхога; бала-бхога; утреннее подношение (балья-бхога) / *vallabha-bhoga*; *bāla-bhoga*; the morning offering (*bālya-bhoga*).
- ঐশ্বর্য্যাশ্রিত-সেবক → служитель, чьё служение основано на айшварье / a servant whose service rests on *aiśvarya*.
- অজ্ঞ (о служителе Джаганнатхи) → несведущий / unknowing.
- কর্ম্মোন্মুখী / ভক্ত্যুন্মুখী সুকৃতি → сукрити, обращённая к карме / к бхакти / *sukṛti* turned toward *karma* / toward *bhakti* (как в общем глоссарии).
- সামান্য ভাগ্য (Ану 99) → обычная удача — удача, рождённая плодами кармы / ordinary fortune, born of the fruits of *karma*.
- ফেলা, ফেলা-লব, কৃষ্ণ-ফেলা → фела, частица фелы, Кришна-фела (остатки трапезы Кришны; не «объедки») / *phelā*, a particle of *phelā*, Kṛṣṇa-phelā (Kṛṣṇa's remnants).
- কৃষ্ণোচ্ছিষ্ট → остатки Кришны / Kṛṣṇa's remnants.
- চিদুপকরণ; চিদিন্দ্রিয় → духовные дары (подношения); духовные чувства / spiritual offerings; spiritual senses.
- নৈবেদ্য → найведья / *naivedya*.
- চিদ্বল → духовная сила / spiritual power.
- ঐক্ষব → аикшава, гур или сахар из тростника / *aikṣava*, jaggery or cane sugar; গব্য → гавья, молоко, топлёное масло и пр. / *gavya*, milk, ghee and the like.
- রসবাস → расаваса, душистые кардамон и гвоздика / *rasavāsa*, fragrant cardamom and cloves; গুড়ত্বক → гудатвака, корица (даручини) или джайтри (мускатный цвет) / *guḍatvaka*, cinnamon (*dārucini*) or *jaitrī* (mace).
- খণ্ড, সীমাবিশিষ্ট, নশ্বর, কালক্ষোভ্য (о материальном) → дробный, ограниченный, преходящий, подвластный волнениям времени / fragmentary, limited, perishable, subject to the agitations of time.
- কন্দর্পলোভ (АПБ 121–133) → любовная жажда (кандарпа-лобха) / the longing of love (*kandarpa-lobha*) — не «вожделение».
- মহা-বাজিকর → великий чародей / a great magician.
- নীবি → ниви, пояс, шнур одежды / *nīvi*, the sash, the cord of the garment.
- আলবাটী → алабати, плевательница / *ālabāṭī*, a spittoon.
- কুটিনাটি; পরিপাটী → коварство; искусство, сноровка, хитрость / deceit; artistry, skill, cunning.
- ধৃষ্ট-রায় → дерзкий, первый среди наглых / bold, foremost among the impudent.
- মেলা → встреча / meeting; পাতিয়ায় → верит / believes.
- অমৃতমুদ্রা (АПБ 142–149) → «печать нектара» (амрита-мудра) / “seal of nectar” (*amṛta-mudrā*).
- মহাজন (о реках, АПБ 145) → махаджаны (святые реки) / *mahājanas* (holy rivers).
- স্থাবর বংশ-জাতি → неподвижная, из породы бамбука / immovable, of the bamboo kind.
- সুরতবর্দ্ধন (Ану 117: সম্ভোগেচ্ছাং বর্দ্ধয়তি) → усиливающий желание единения (самбхоги) / increasing the desire for union (*sambhoga*); у Бхактивиноды (প্রেমবর্দ্ধক) → усиливающий любовь (прему) / increasing love (*prema*).
- মদয়তি (Ану 87: আনন্দয়তি) → наполняет блаженством / fills with bliss; у Бхактивиноды (উন্মত্ত করুন) → пусть сводит с ума / may He madden.
- কৃষ্ণসঙ্গকামাতুরা (Ану 140) → томимые желанием быть с Кришной (не «страстью») / longing for Kṛṣṇa's company.
- দানবীর → герой щедрости (дана-вира) / hero of generosity (*dāna-vīra*).
- কুলবৃদ্ধ → старейшины рода / the elders of a family.

#### Оформление
- (স্তবাবলীতে চৈতন্যস্তবকল্পবৃক্ষ-স্তবে ৭ম শ্লোক) → (“Става-вали”, “Чайтанья-става-калпаврикша”, шлока 7) / (*Stavāvalī*, *Caitanya-stava-kalpavṛkṣa*, verse 7).
- (গোবিন্দলীলামৃতে ৮ম সর্গে ৮ম শ্লোকে বিশাখার প্রতি শ্রীরাধা-বাক্য) → (“Говинда-лиламрита”, песнь 8, шлока 8: слова Шри Радхи к Вишакхе) / (*Govinda-līlāmṛta*, canto 8, verse 8: Śrī Rādhā's words to Viśākhā).
- মহাভারতে ও স্কান্দে উৎকল-খণ্ডে → в “Махабхарате” и в “Сканда-пуране” (Уткала-кханда) / in the *Mahābhārata* and in the *Skanda Purāṇa* (Utkala-khaṇḍa).
- শ্রীধরস্বামি-টীকা দ্রষ্টব্য → см. комментарий Шридхары Свами / see Śrīdhara Svāmī's commentary.
- পাঠান্তরে → в других списках / other manuscripts read.

#### Имена и места
- কলিন্দনন্দিনী → дочь Калинды (Ямуна) / the daughter of Kalinda (the Yamunā); মানসগঙ্গা → Манаса-ганга / Mānasa-gaṅgā.
- শ্যাম (обращение) → Шьяма / Śyāma; নাগর → нагара / *nāgara*.
