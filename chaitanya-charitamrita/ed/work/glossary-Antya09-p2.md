# Глоссарий: Антья 9, комментарии, часть 2 (стихи 81–153)

- ভিয়ান → «бхияна» — стройное и чинное исполнение служения (парипатья-абхиная) / *bhiyāna*, the orderly and elaborate performance of the service (*pāripāṭya-abhinaya*).
- নির্ম্মঞ্ছন → «нирманчхана» — особое подношение (аргхья при арати) / *nirmañchana*, a special offering (*arghya* at *ārati*).
- পূজ্য-গর্ব্বিত → «пуджья-гарвита» — достойный почитания, предмет гордости и почёта / *pūjya-garvita*, worthy of worship, an object of pride and honor.
- নেতধটী, নেতধড়ি → «нетадхати» — шёлковая ткань (паттавастра) / *netadhaṭī*, silk cloth.
- মাৎ (хинди) → «мат» — «не» / *māt*, “not.”
- নিলা মূল → «нила мула» — снова купил, заплатив цену / *nilā mūla*, bought again, paying the price.
- ফুকারে → «пхукаре» — громко рыдает / *phukāre*, weeps loudly.
- ফলাভাস / মুখ্যফল / গৌণফল → видимость плода (пхалабхаса) / главный плод / второстепенный плод — *phalābhāsa*, a semblance of fruit / the chief fruit / the secondary fruit.
- ত্রিবর্গ / অপবর্গ → триварга (три мирские цели: дхарма, артха, кама) / апаварга (освобождение) — *trivarga* / *apavarga*.
- কৃপা-বিবর্ত → «крипа-виварта», мнимая милость / *kṛpā-vivarta*, a seeming mercy.
- অমন্দোদয়া দয়া → обильная милость (амандодая-дая) / abundant mercy (*amandodayā dayā*).
- অমায়া-কৃপা → неподдельная милость (амайя-крипа) / genuine mercy (*amāyā-kṛpā*).
- শুক্লবিত্ত, শুক্লার্থ; অশুক্লবিত্তার্জ্জন → честно заработанные деньги (шукла-витта, шукла-артха); нечестно добытые деньги / honestly earned money (*śukla-vitta*, *śukla-artha*); acquiring money dishonestly.
- রাজার্থ-প্রতিগ্রহ → принятие дара из царских средств (раджартха-пратиграха) / accepting a gift from the king's funds (*rājārtha-pratigraha*).
- মহাসন্ন্যাস → великое отречение (маха-санньяса) / great renunciation (*mahā-sannyāsa*).
- নিরপেক্ষ (о вайшнаве в одежде отрёкшегося) → свободный от мирских расчётов (нирапекша) / free from worldly dependence (*nirapekṣa*).
- ভূম্যধিকারী → правитель (бхуми-адхикари) / governor (*bhūmy-adhikārī*).
- যুবরাজ → наследник престола / the crown prince.
- Места: রাজমহেন্দ্রী, বিদ্যানগর / বিদ্যাপুর, কোটদেশ, কলিঙ্গ, উৎকলিঙ্গ / উৎকল → Раджамахендри, Видьянагар / Видьяпур, Котадеша, Калинга, Уткалинга / Уткала / Rājamahendrī, Vidyānagara / Vidyāpura, Koṭadeśa, Kaliṅga, Utkaliṅga / Utkala.
