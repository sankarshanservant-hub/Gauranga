# Глоссарий комментариев к Мадхье 15, часть 2 (стихи 129–302; новые термины, имена, места; RU / EN)

## Термины
- অবতংস → аватамса (украшение для ушей или головы) / *avataṁsa* (ornament for ears or head)
- দারুব্রহ্ম / জলব্রহ্ম → Дару-Брахман (Брахман в облике дерева) / Джала-Брахман (Брахман в облике воды) / *Dāru-brahma* (Brahman in the form of wood) / *Jala-brahma* (Brahman in the form of water)
- প্রলোভন (প্রভুর) → манить, увлекать (поклонением Кришне) / to entice
- নিঃস্বার্থ / পরার্থ / স্বার্থ → «бескорыстие» / «благо других» (парартха) / «собственное благо» (свартха) / “selflessness” / “the good of others” (*parārtha*) / “one's own good” (*svārtha*)
- নিরস্তকুহক → чуждый всякого обмана / free of all deceit
- দ্বিতীয়াভিনিবেশ → поглощённость «вторым» [— тем, что отлично от Господа] / absorption in “a second” [something other than the Lord]
- অর্থবাদ → артхавада (хвалебное преувеличение) / *arthavāda* (eulogy)
- পরদুঃখদুঃখী → «страдающий от чужого страдания» / “pained by the pain of others”
- অকিঞ্চনা ভক্তি → бескорыстная (акинчана) преданность / selfless (*akiñcanā*) devotion
- অপ্রারব্ধ, কূট, বীজ, ফলোন্মুখ (পাপ) → грехи, чьи плоды ещё не созрели; скрытые; в семени; готовые принести плоды / sins whose fruits have not begun; latent; in seed form; about to bear fruit
- প্রারব্ধ / অপ্রারব্ধ → прарабдха / непрарабдха / *prārabdha* / *aprārabdha*
- ইন্দ্রগোপ → индрагопа (маленькое красное насекомое) / *indragopa* (a small red insect)
- কৃষ্ণোন্মুখ → обращённый к Кришне (кришна-унмукха) / facing Kṛṣṇa (*kṛṣṇonmukha*)
- ত্রিপাদ / একপাদ → три четверти (трипада) / одна четверть (экапада) / three quarters (*tripāda*) / one quarter (*ekapāda*)
- কামধেনু → коровы кама-дхену (исполняющие желания) / wish-fulfilling cows (*kāma-dhenus*)
- স্বরূপবস্তু (о предмете, отбрасывающем тень) → сам предмет / the real object
- সবিশেষ বৈকুণ্ঠ → Вайкунтха, исполненная качеств (савишеша) / Vaikuṇṭha full of attributes (*saviśeṣa*)
- কুণ্ঠা / কুণ্ঠতা → ограниченность (кунтха) / limitation (*kuṇṭhā*)
- গড়খাই → гадакхаи (ров, опоясывающая вода) / *gaḍakhāi* (a moat)
- ব্রহ্মসত্র → жертвоприношение брахма-сатра / the *brahma-satra* sacrifice
- অঙ্গাভাস → отражение части [Господа] / a reflection of His part
- টোটা (যমেশ্বর) → Ямешвар-тота (сад) / Yameśvara-ṭoṭā (a garden)
- আশ্রমধর্ম্ম → дхарма ашрама / the duties of one's *āśrama*
- ভিক্ষা (সন্ন্যাসীর) → трапеза (у домохозяина) / meal
- নিজ-ছায়ে → «со своей тенью», то есть один / “with one's own shadow,” alone
- অপ্রসাদি / অনর্পিত নৈবেদ্য → неподнесённая пища (апрасади, анарпита) / unoffered food (*aprasādi*, *anarpita*)
- নির্ম্মাল্য → остатки (нирмалья) / remnants (*nirmālya*)
- মাধুকরী, মধুকরবৃত্তি → мадхукари (горсть, полученная по обычаю пчелы, мадхукара-вритти) / *mādhukarī* (a mouthful obtained in the manner of the bee, *madhukara-vṛtti*)
- জ্যেঠা, খুড়া, মামা, পিসা → «джетха» (старшие дяди по отцу), «кхуда» (младшие дяди по отцу), «мама» (дяди по матери), «писа» (мужья тёток по отцу) / *jyeṭhā*, *khuḍā*, *māmā*, *pisā*
- কনিষ্ঠকল্প সখা / প্রিয়সখা / প্রিয়নর্ম্মসখা → друзья, «подобные младшим братьям» / «дорогие друзья» (прия-сакхи) / «сокровенные друзья» (прия-нарма-сакхи) / friends “like younger brothers” / “dear friends” (*priya-sakhās*) / “intimate friends” (*priya-narma-sakhās*)
- অবধান → внимание / attention
- এলাচি রসবাস → кардамон, сочный и благоуханный / cardamom, juicy and fragrant
- ব্রহ্মবন্ধু / আততায়ী → брахма-бандху (недостойный брахман) / агрессор (ататайи) / *brahma-bandhu* (unworthy brāhmaṇa) / aggressor (*ātatāyī*)
- শৌক্র ব্রাহ্মণ → брахман по рождению / brāhmaṇa by birth
- পতনানি ষট্ → шесть [путей] падения / the six [ways of] falling
- সাধুনিন্দা → хула на садху / blaspheming *sādhus*
- মহদতিক্রম → оскорбление великих (махад-атикрама) / offense against great souls (*mahad-atikrama*)
- বৈষ্ণবাপরাধ → вайшнава-апарадха / *vaiṣṇava-aparādha*
- ঘোষযাত্রা → гхоша-ятра (осмотр пастбищ) / *ghoṣa-yātrā* (inspection of the cattle stations)
- অসম্যগাবির্ভাব → неполное проявление (Истины) / incomplete manifestation
- অভিধেয়-বৃত্তি, সেবাসূত্র → склонность к абхидхее, нить служения / taking up the *abhidheya*, the thread of service
- পঞ্চ সগুণোপাসনা (নির্ব্বিশেষবাদীদের) → пять видов поклонения Брахману, наделённому качествами / five kinds of worship of Brahman with attributes
- সকাম অনুভূতি → постижение, исполненное корыстных желаний (сакама) / realization full of selfish desires (*sakāma*)
- অবিমিশ্র ব্রাহ্মণ → «чистый брахман» / “unmixed brāhmaṇa”
- সত্রযাজী → совершающий жертвоприношения (сатра-яджи) / performer of sacrifices (*satra-yājī*)
- বৃত্ত-ব্রাহ্মণতা → брахманство, проявленное в поведении (вритта-брахманата) / brahminhood shown in conduct (*vṛtta-brāhmaṇatā*)
- অচ্যুতাত্মতা → преданность Ачьюте (ачьютатмата) / devotion to Acyuta (*acyutātmatā*)
- জাড্য (অপরাধ) → «косность» (джадья) / “dullness” (*jāḍya*)
