# Глоссарий: комментарии к Антье 8 (RU / EN)

## Термины
- শুষ্কজ্ঞানী → сухой философ (шушка-гьяни) / dry speculator (*śuṣka-jñānī*); শুষ্কবৈরাগ্য → сухое отречение / dry renunciation.
- ভিক্ষা (о трапезе Господа) → трапеза, угощение / meal; ভিক্ষান্ন → мера пищи, трапеза / measure of food; ভিক্ষাসঙ্কোচ → сокращение трапезы / reduction of meals.
- পরচ্ছিদ্রান্বেষী → выискивающий чужие недостатки / one who hunts for others' faults; ছিদ্র → изъян / fault.
- গুর্ব্বজ্ঞা → неуважение к гуру / disrespect for the guru; মর্ত্ত্যজ্ঞান (о гуру, о Господе) → считая смертным / thinking (him) mortal.
- বঞ্চনা (Господа) → обманывает / deceives; বঞ্চনা-লাভ → остаться обделённым / be left deprived.
- অনুগ্রহ / নিগ্রহ (মহদনুগ্রহ-নিগ্রহ) → милость (ануграха) / кара (ниграха) / mercy (*anugraha*) / punishment (*nigraha*).
- নির্য্যাণ, অপ্রকট, অন্তর্দ্ধান (Мадхавендры) → уход из проявленного мира (апраката) / departure from the manifest world (*aprakaṭa*); не «смерть», не «сокрытие».
- নির্ব্বন্ধ → упорная привязанность (к хуле) / stubborn attachment (*nirbandha*).
- চতুর্ব্বর্গ → четыре цели жизни (чатур-варга) / the four goals of life (*catur-varga*).
- ভাববিশেষ → особое чувство (бхава-вишеша) / a special feeling (*bhāva-viśeṣa*).
- মক্ষিকা-বৃত্তি → подобен мухе / like a fly.
- নৈরপেক্ষ্য → отрешённость (найрапекшья) / detachment (*nairapekṣya*).
- পূর্ব্ববিধি / পরবিধি → прежнее / последующее предписание / earlier / later injunction; শ্লেষোক্তি → насмешка / irony.
- অভোজ্যান্ন বিপ্র / ভোজ্যান্ন বিপ্র → абходжьянна випра (брахман, у которого нельзя есть приготовленную пищу) / *abhojyānna vipra*; পাঙ্‌ক্তেয় ব্রাহ্মণ → брахман, достойный сидеть в одном ряду за трапезой (панктея) / *pāṅkteya brāhmaṇa*.
- এক-চৌঠি → эк-чаутхи (четверть горшка прасада стандартной меры, праманы) / *ek-cauṭhi*; প্রমাণ-হাঁড়ি → горшок обычной меры / pot of standard measure (*pramāṇa*).
- ঐক্ষব, ইক্ষুজাত গুড় → патока из сахарного тростника (гур) / cane molasses (*guḍa*).
- নিরাশীর্নির্নমস্ক্রিয়ঃ → «не благословляет и не кланяется» (как в общем глоссарии).
- পাষণ্ডিত্ব → безбожие (пашандата) / godlessness (*pāṣaṇḍatā*).

## Имена и источники
- Рамачандра Пури (Госани) / Rāmacandra Purī (Gosāñi); Мадхавендра Пури (Пурипада, Пури Госани) / Mādhavendra Purī (Purīpāda, Purī Gosāñi); Ишвара Пури / Īśvara Purī; Парамананда Пури / Paramānanda Purī; Говинда, Кашишвара / Govinda, Kāśīśvara.
