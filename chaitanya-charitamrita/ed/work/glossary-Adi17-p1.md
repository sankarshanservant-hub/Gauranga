# Глоссарий: Ади 17, часть 1 (стихи 1–125; RU / EN)

## Термины
- বিষ্ণুখট্টা → ложе Вишну (вишну-кхатта) / Viṣṇu's couch (*viṣṇu-khaṭṭā*).
- ষোড়শ উপচার → шестнадцать подношений / the sixteen articles of worship.
- রাজরাজেশ্বর-ঐশ্বর্য্য → величие Царя царей / majesty as the King of kings.
- চতুর্ব্বিধ ভক্তভাব → четыре вида чувств преданных / the four kinds of devotional moods.
- পূর্ব্বাধিকার → прежнее положение / former position.
- অনুবাদ (পৃথক্ পৃথক্, о пересказе 17 глав) → пересказ по порядку / recapitulation.
- আম্র-মহোৎসব → праздник манго / the mango festival.
- শ্রীহল, মুষল → плуг, пест-мушала / plough, pestle (*muṣala*).

## Термины (добавлено)
- নামাভাস / নামাপরাধ → «намабхаса» (лишь тень имени) / «намапарадха» (оскорбление имени) / *nāmābhāsa* / *nāmāparādha*.
- অর্থবাদ → артхавада (толкование славы имени как преувеличения) / *arthavāda*.
- সুনীচত্ব, সহিষ্ণুত্ব, অমানিত্ব, মানদত্ব → суничатва (смирение), сахишнутва (терпение), аманитва, манадатва / *sunīcatva*, *sahiṣṇutva*, *amānitva*, *mānadatva*; প্রাকৃতাভিমান → мирское самомнение / worldly self-conception; রক্ষাকবচ → охранный амулет (ракша-кавача) / protective amulet (*rakṣā-kavaca*).
- প্রাকৃত বিদ্ধবৈষ্ণব → мирской, смешанный вайшнав (пракрита-виддха-вайшнав) / worldly, mixed Vaiṣṇava; বহ্বীশ্বরবাদ → учение о многих богах / the doctrine of many gods; দুঃসঙ্গ → дурное общество / bad association.
- ব্রহ্মবন্ধু, দ্বিজবন্ধু, শৌক্রশূদ্র → брахма-бандху, двиджа-бандху, шудра по рождению / *brahma-bandhu*, *dvija-bandhu*, a *śūdra* by birth; ব্রহ্মণ্যদেব → Брахманья-дева / Brahmaṇya-deva.
- গলৎকুষ্ঠ → гниющая проказа / rotting leprosy; হাড়ি → хади (уборщик) / *hāḍi* (sweeper); গাড়ু → гару (сосуд с водой) / *gāḍu* (water pot); সচেল → «сачеле», прямо в одежде / *sacele*, with one's clothes on.
- মাধুকরী ভিক্ষা → мадхукари-подаяние / *mādhukarī* alms; ব্যাসপূজা → Вьяса-пуджа / Vyāsa-pūjā; সাতপ্রহরিয়া ভাব, মহাপ্রকাশ → «сат-прахария»-бхава, маха-пракаша (как в общем глоссарии).
- ফৌজদার, সুবাদার, মণ্ডল, পরগণা → фаудждар (начальник округа), субадар (наместник), мандал (сельский староста), паргана / *phaujadāra*, *subādāra*, *maṇḍala* (village headman), *parganā*.
- খোল → кхол / *khola*; মন্দিরা → караталы / cymbals; দণ্ডপ্রসাদ, দণ্ডানুগ্রহ → милость-наказание / mercy through punishment.
- রহস্যবাক্য → шутливые, таинственные слова / playful, mysterious words; সর্ব্বজ্ঞ → сарвагья, знающий три времени / *sarvajña*.
