# Новые термины: Антья 13, часть 1 (стихи 0–70; комментарии, RU / EN)

## Термины
- কলার শরলা (শরলাতে) → кора банана (калар шарала) / banana bark (*kalāra śaralā*).
- কলার পেটো → сухие листья банана (пето) / dry banana leaves (*peṭo*).
- লেপ → одеяло (лепа) / quilt (*lepa*); তুলি → тули, хлопковый тюфяк, матрас (гади) / *tuli*, cotton mattress, pad (*gadi*).
- ওড়ন-পাড়ন → одана-падана: ота-прота (букв. «уток и основа»); по мнению некоторых, подушка и тюфяк / *oḍana-pāḍana*: *ota-prota* (literally “weft and warp”); according to some, a pillow and a mattress.
- মস্তক-মুণ্ডন → мастака-мундана («обритая голова»), выражение позора / *mastaka-muṇḍana* (“a shaven head”), an expression for disgrace.
- আচার্য্যাভিমান → роль наставника (ачарья-абхимана) / the role of a teacher (*ācārya-abhimāna*).
- রহস্য (পিলুফল-ভক্ষণের) → забавная история / an amusing episode.
- পরস্ত্রী → чужая женщина (парастри) / a woman not one's own (*para-strī*).
- বিরক্ত যতি → отрешённый аскет (яти) / renounced ascetic (*yati*).
- বাম্যস্বভাব (বামাস্বভাব) → своенравный по природе (вамья-свабхава) / contrary by nature (*vāmya-svabhāva*) — как в Антья 12.
- বাটপাড় → батапар, разбойник с большой дороги / *bāṭapāḍa*, highway robber; সুচতুর → весьма смышлёный (сучатура) / very clever (*sucatura*).
- মথুরার স্বামী (APB 36) → чаубе, жители Матхуры / the Caubes, residents of Mathurā.
- শুদ্ধবাৎসল্য → чистое родительское чувство (шуддха-ватсалья) / pure parental love (*śuddha-vātsalya*).
- ঐশ্বর্য্যভাব, ঐশ্বর্য্যভাবপ্রিয় → настроение величия (айшварья-бхава); тот, кому дорого настроение величия / the mood of majesty (*aiśvarya-bhāva*); one who loves the mood of majesty.
- ঐশ্বর্য্যজ্ঞানহীন → свободный от сознания величия (айшварья-гьяны) / without awareness of majesty (*aiśvarya-jñāna*).
- অশ্রদ্ধা → неуважение / disrespect.
- সাক্ষাদ্ভগবন্মূর্ত্তি (о Говардхане) → Сам Бхагаван в зримом облике / Bhagavān Himself in visible form.
- অন্যাশ্রমে যান (о Гопале) → уходит в другое место / goes to some other place.
- রুটি → лепёшка (рути) / flatbread (*ruṭi*).
- রাতুল → ратула, красный (кашая, цвета охры) / *rātula*, red (*kāṣāya*, ochre).
- সমাধান (করা) → самадхана, исполнение всех дел, служение / *samādhāna*, carrying out all affairs, serving.
- বৈধ-সন্ন্যাসী → санньяси по предписаниям (вайдха-санньяси) / *sannyāsīs* who follow the scriptural rules (*vaidha-sannyāsīs*).
- পারমহংস্যাশ্রম → ступень парамахамсы / *paramahaṁsa* status.
- গৈরিক / কাষায় বসন → шафрановая одежда (гайрика / кашая) / saffron cloth (*gairika* / *kāṣāya*).
- তদ্দাসাভিমান → сознание себя Его слугой / thinking of oneself as His servant.
- চিদ্বিলাস-ভেদবুদ্ধি → память о различии [между Господом и слугой] в духовной игре (чид-виласе) / remembering the distinction [between the Lord and His servant] in the spiritual play (*cid-vilāsa*).
- পরমহংস বৈষ্ণবাসন → престол вайшнава-парамахамсы / the seat of a *paramahaṁsa* Vaiṣṇava.
- গুরু বৈষ্ণব → гуру-вайшнав / guru-Vaiṣṇava.
- মঠ (стих 69) → матх, храм (девалая) / *maṭha*, a temple (*devālaya*).

## Имена и места
- রামদাস বিশ্বাস পণ্ডিত → Рамадас Вишваса Пандит (Вишваса Пандит), каястха / Rāmadāsa Viśvāsa Paṇḍita (Viśvāsa Paṇḍita), a *kāyastha*.
- রঘুনাথ ভট্ট গোস্বামী, ভট্টগোস্বামী → Рагхунатха Бхатта Госвами, Бхатта Госвами / Raghunātha Bhaṭṭa Gosvāmī, Bhaṭṭa Gosvāmī.
- মুকুন্দ সরস্বতী → Мукунда Сарасвати / Mukunda Sarasvatī.
- তপনমিশ্র, বৈদ্য চন্দ্রশেখর → Тапана Мишра, Чандрашекхара Вайдья / Tapana Miśra, Candraśekhara Vaidya.
- দ্বাদশাদিত্য-টিলা (দ্বাদশ আদিত্য-টিলা) → Двадашадитья-тила («Двадаша-адитья-тила»), холм / Dvādaśāditya-ṭilā (“Dvādaśa-āditya-ṭilā”), a mound; দ্বাদশাদিত্য → двенадцать Адитьев / the twelve Ādityas.
- শ্রীমদনমোহন (старый храм) → Шри Мадана-мохана / Śrī Madana-mohana.
- ব্রজমণ্ডল → Враджа-мандала / Vraja-maṇḍala.
