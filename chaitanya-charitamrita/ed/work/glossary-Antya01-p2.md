# Глоссарий: Антья 1, часть 2 (стихи 140–223) — новые термины (RU / EN)

- পূর্ব্বানুরাগ / পূর্ব্বরাগ → пурванурага, пурва-рага (первое влечение, прежде встречи) / *pūrvānurāga*, *pūrva-rāga* (the first attraction, before meeting).
- প্রণয়-বিকার → любовное преображение (пранайя-викара) / transformation of love (*praṇaya-vikāra*); ব্যাধি (о любви) → любовный недуг (вьядхи) / lovesickness (*vyādhi*) — не «болезнь».
- চেষ্টা → чешта (проявление в действиях) / *ceṣṭā*, the display in actions.
- কামলিখন, কামলেখ, কন্দর্পলেখ → кама-ликхана, кама-лекха, кандарпа-лекха (любовное письмо) / *kāma-likhana*, *kāma-lekha*, *kandarpa-lekha* (love letter).
- ব্যবসায় → решимость (вьявасая) / resolve (*vyavasāya*).
- নবীনগ্রহ → новый грах (сила, овладевающая душой) / a new *graha* (a power that possesses the soul).
- সাহজিক → естественный (сахаджика) / natural (*sāhajika*).
- উত্তরকৃতি, অন্ত্যেষ্টিক্রিয়া → погребальный обряд / funeral rite.
- পরপুরুষ → чужой мужчина / another man.
- Источник в подзаголовке «(বিদগ্ধমাধবে ২য় অঙ্কে ৯ম শ্লোক)» → (“Видагдха-мадхава”, действие 2, шлока 9) / (*Vidagdha-mādhava*, Act 2, verse 9); «তত্র X যথা—» → «Пример X —» / “An example of X —”.
- Паурнамаси (Бхагавати) → Паурнамаси / Paurṇamāsī; Мадхумангала → Madhumaṅgala.
- নাটক: আমুখ / প্রস্তাবনা → амукха / праставана (пролог) / *āmukha* / *prastāvanā* (prologue); пять видов: удгхатьяка, катходгхата, прайогатишая, правартака, авалагита / *udghātyaka*, *kathodghāta*, *prayogātiśaya*, *pravartaka*, *avalagita* (как в ч. 1).
- ভারতীবৃত্তি → бхарати-вритти / *bhāratī-vṛtti*; её части: прарочана, витхи, прахасана / *prarocanā*, *vīthī*, *prahasana* (в ч. 1 — «вити»; по ВЧД 1.185 — «витхи»: свести при слиянии).
- মুখ / নির্ব্বহণ সন্ধি → начальное / заключительное сочленение (мукха / нирвахана) / opening / closing juncture (*mukha* / *nirvahaṇa*); অর্থপ্রকৃতি → артха-пракрити / *artha-prakṛti*; বীজ → биджа / *bīja*; আকাশভাষিত → голоса с неба / voices from the sky.
- নান্দী → нанди / *nāndī*; প্রযোজক-কর্ত্তা → побуждающий деятель (прайоджака-карта) / the One who impels action (*prayojaka-kartā*).
- নিসৃষ্টার্থা (дути) → нисриштартха (посланница, которой поручено дело) / *nisṛṣṭārthā*; দূতী → посланница / messenger; কাকলী → какали (нежный звук) / *kākalī*.
- বিট, কামুক (о Кришне в устах Лалиты) → волокита (вита), ищущий любви / gallant (*viṭa*), who seeks love; আভীর-পল্লী-লম্পট → ловелас из пастушьей деревни / philanderer of the cowherd village.
- নীবি / নীবিবন্ধ → узел пояса (нӣви) / the knot of the sash (*nīvi*).
- কুলধর্ম্ম, পাতিব্রত্য → дхарма рода, верность мужу / the *dharma* of the family, fidelity to a husband; কুলবধূ, কুলাঙ্গনা → благородные жёны / noble wives.
- পুলিন্দ → пулинда / Pulinda; বকীহন্তা → убийца Баки (Путаны) / slayer of Bakī (Pūtanā).
- Тумбуру, Санандана, Бали, Ананта (Шеша), Каланидхи, Тара, Пурна-манаратха → Tumburu, Sanandana, Bali, Ananta (Śeṣa), Kalānidhi, Tārā, Pūrṇa-manoratha.
- অকিঞ্চন → акинчана (тот, кто ничем не владеет) / *akiñcana* (one who owns nothing); পরাভক্তি → высшая бхакти (пара-бхакти) / the highest devotion (*parā-bhakti*); যুক্ত বৈরাগ্য → юкта-вайрагья / *yukta-vairāgya*.
- Источники: “Уджвала-ниламани” (раздел о випраламбхе; раздел о видах посланниц) / *Ujjvala-nīlamaṇi*; “Сахитья-дарпана” / *Sāhitya-darpaṇa*; “Лалита-мадхава” / *Lalita-mādhava*; (шлока древнего автора) / (a verse of an ancient author).
