# Глоссарий: Антья 1, часть 2 (стихи 140–223) — новые термины (RU / EN)

- পূর্ব্বানুরাগ / পূর্ব্বরাগ → пурванурага, пурва-рага (первое влечение, прежде встречи) / *pūrvānurāga*, *pūrva-rāga* (the first attraction, before meeting).
- প্রণয়-বিকার → любовное преображение (пранайя-викара) / transformation of love (*praṇaya-vikāra*); ব্যাধি (о любви) → любовный недуг (вьядхи) / lovesickness (*vyādhi*) — не «болезнь».
- চেষ্টা → чешта (проявление в действиях) / *ceṣṭā*, the display in actions.
- কামলিখন, কামলেখ, কন্দর্পলেখ → кама-ликхана, кама-лекха, кандарпа-лекха (любовное письмо) / *kāma-likhana*, *kāma-lekha*, *kandarpa-lekha* (love letter).
- ব্যবসায় → решимость (вьявасая) / resolve (*vyavasāya*).
- নবীনগ্রহ → новый грах (сила, овладевающая душой) / a new *graha* (a power that possesses the soul).
- সাহজিক → естественный (сахаджика) / natural (*sāhajika*).
- উত্তরকৃতি, অন্ত্যেষ্টিক্রিয়া → погребальный обряд / funeral rite.
- পরপুরুষ → чужой мужчина / another man.
- Источник в подзаголовке «(বিদগ্ধমাধবে ২য় অঙ্কে ৯ম শ্লোক)» → (“Видагдха-мадхава”, действие 2, шлока 9) / (*Vidagdha-mādhava*, Act 2, verse 9); «তত্র X যথা—» → «Пример X —» / “An example of X —”.
- Паурнамаси (Бхагавати) → Паурнамаси / Paurṇamāsī; Мадхумангала → Madhumaṅgala.
