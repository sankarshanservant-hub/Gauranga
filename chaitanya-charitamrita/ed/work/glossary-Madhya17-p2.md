# Глоссарий комментариев к Мадхье 17, часть 2 (стихи 121–234; новые термины, имена, места; RU / EN)

## Термины
- মুখ্যনাম / গৌণনাম → главные имена (мукхья-нама) / второстепенные имена (гауна-нама) / principal names (*mukhya-nāma*) / secondary names (*gauṇa-nāma*)
- তুরীয় বৈকুণ্ঠ নাম → имя Вайкунтхи, лежащее за пределами трёх состояний (турия) / the name of Vaikuṇṭha, beyond the three states (*turīya*)
- দেহ-দেহী, নাম-নামী → тело и «воплощённый» (дехи), имя и «носитель имени» (нами) / body and the “embodied one” (*dehī*), name and the “bearer of the name” (*nāmī*)
- চৈতন্যরসবিগ্রহ → воплощение духовной расы / the embodiment of spiritual *rasa*
- স্বতঃপ্রকাশবস্তু → самопроявляющаяся реальность (свата-пракаша-васту) / self-manifest reality (*svataḥ-prakāśa-vastu*)
- সেবোন্মুখ → обращённый к служению (севонмукха) / turned toward service (*sevonmukha*)
- লৌল্য, লোভ, রুচি (как «цена») → жадное желание (лаулья), стремление (лобха), вкус (ручи) / eager longing (*laulya*), greed (*lobha*), taste (*ruci*)
- শ্রদ্ধাভাস → отблеск веры (шраддха-абхаса) / a semblance of faith (*śraddhābhāsa*)
- অদ্বয়জ্ঞানত্ব (নাম-রূপ-গুণ-লীলার) → то, что имя, облик… — недвойственное знание (адвая-гьяна) / their being nondual knowledge (*advaya-jñāna*)
- দৈব / অদৈব বর্ণাশ্রম → дайва- / адайва-варнашрама / *daiva* / *adaiva varṇāśrama*
- জলাচরণীয় → тот, из чьих рук можно принять воду / one from whose hands water may be accepted
- মনোধর্ম্মী → следующий дхарме ума (манодхарми) / a follower of the religion of the mind (*manodharmī*)
- মহাজন (мирское значение) → заимодавец (уттамарна) / creditor (*uttamarṇa*)
- কর্ম্মবীর, ধর্ম্মবীর, জ্ঞানবীর, ত্যাগবীর → «герой деятельности» (карма-вира), «герой дхармы», «герой знания», «герой отречения» / “hero of action” (*karma-vīra*), “hero of *dharma*,” “hero of knowledge,” “hero of renunciation”
- জীবন্মৃত → «живой мертвец» / “dead while living”
- প্রাতঃস্মরণীয় কার্য্য → «дела, достойные утреннего поминовения» / “deeds worthy of remembrance at dawn”
- গড্ডলিকা-প্রবাহ → «как стадо овец» / like a flock of sheep
- গোঁড়ামী → «фанатизм» / “bigotry”
- চিজ্জড়সমন্বয়বাদী → приверженцы смешения духа и материи / advocates of blending spirit and matter
- নিষ্কিঞ্চন → бескорыстный (нишкинчана) / *niṣkiñcana*
- অধোক্ষজ-দর্শন / সুদর্শন → видение Адхокшаджи / истинное видение (сударшана) / seeing Adhokṣaja / true vision (*sudarśana*)
- অন্যাভিলাষী → аньябхилаши (имеющий иные желания) / *anyābhilāṣī* (one with other desires)
- গুরুর উপর গুরুগিরি → «поучать гуру» / “play *guru* over the *guru*”
- সন্তর্পণ → сантарпана (заботливое служение) / *santarpaṇa* (careful service)
- পাথার → патхара (половодье) / *pāthāra* (a flood)
- বৈতানিক কর্ম্ম → великие обряды жертвоприношений / great sacrificial rites
- অর্থবাদ → артхавада (хвалебные слова) / *arthavāda* (eulogy)
