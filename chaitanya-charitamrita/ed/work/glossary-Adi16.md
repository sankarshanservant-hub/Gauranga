# Новые термины, имена и места — комментарии к Ади 16 (RU / EN)

Формат: бенг./санскр. → RU / EN. Общий глоссарий (`ed/GLOSSARY-commentary.md`) не правился.

## Поэтика (аланкара-шастра; разбор шлоки Кешавы Кашмири, Ади 16.41–86)
- অলঙ্কার; শব্দালঙ্কার; অর্থালঙ্কার → украшение (аланкара), аланкара (поэтика); украшение звука (шабда-аланкара); украшение смысла (артха-аланкара) / ornament (*alaṅkāra*), poetics (*alaṅkāra*); ornament of sound (*śabdālaṅkāra*); ornament of sense (*arthālaṅkāra*).
- গুণ / দোষ → достоинство / недостаток (доша) / merit / fault (*doṣa*).
- অবিমৃষ্টবিধেয়াংশ → авимришта-видхеямша (видхея, то есть новое утверждение, не выделена как следует) / *avimṛṣṭa-vidheyāṁśa* (the *vidheya*, the new statement, not properly set apart) — как в общем глоссарии (Ади 2).
- বিরুদ্ধমতি, বিরুদ্ধমতিকৃৎ → вируддха-мати, вируддха-мати-крит (порождающее противоречивую мысль) / *viruddha-mati*, *viruddha-mati-kṛt* (creating a contradictory idea).
- পুনরুক্তি → пунарукти (повтор) / *punarukti* (repetition). পুনরাত্ত → пунар-атта (возврат к законченному предложению) / *punar-ātta* (returning to a finished sentence).
- ভগ্নক্রম → бхагна-крама (нарушенный порядок) / *bhagna-krama* (broken order).
- পুনরুক্তবদাভাস → пунарукта-вад-абхаса (кажущийся повтор) / *punarukta-vad-ābhāsa* (apparent repetition).
- উপমা, উপমালঙ্কার → сравнение (упама), упама-аланкара / simile (*upamā*), *upamālaṅkāra*. অনুপ্রাস → анупраса (аллитерация) / *anuprāsa* (alliteration).
- বিরোধ, বিরোধাভাস → противоречие (виродха), кажущееся противоречие (виродхабхаса) / contradiction (*virodha*), apparent contradiction (*virodhābhāsa*). অনুমান → анумана (умозаключение) / *anumāna* (inference).
- দ্বিতীয়ত্ব → «вторость» (двитийатва) / “secondness” (*dvitīyatva*). সমাস → сложное слово (самаса) / compound (*samāsa*).
- প্রতিভা → пратибха (поэтический дар) / *pratibhā* (poetic genius). বিগীত → вигита (порицаемый) / *vigīta* (condemned).
- রস (শৃঙ্গারাদি) → раса (шрингара и другие) / *rasa* (*śṛṅgāra* and the rest). কাব্য — রসাত্মক বাক্য → кавья — речь, суть которой — раса / *kāvya*, speech whose soul is *rasa*.
- শ্বিত্র → швитра, белая проказа / *śvitra*, white leprosy.

## Прочие термины
- কৈশোর / কিশোর → кайшора / кишора (возраст 11–15 лет) / *kaiśora* / *kiśora* (age 11–15).
- সাধ্য / সাধন → садхья (цель) / садхана (средство) / *sādhya* (goal) / *sādhana* (means).
- নীচগা → нича-га (текущая вниз) / *nīca-gā* (flowing downward).
- দিগ্বিজয়ী → дигвиджайи (покоритель сторон света) / *digvijayī* (conqueror of all directions).
- বাল্যশাস্ত্র → бальйа-шастра (грамматика) / *bālya-śāstra* (grammar). বৈয়াকরণ → вайякарана (грамматист) / *vaiyākaraṇa* (grammarian).
- ফাঁকি; সংলাপ → «пхаки» (запутанные вопросы грамматики); санлапа (беседа) / *phāṅki*; *saṁlāpa*.
- ঘটী, ঘটিকা → гхатика (24 минуты) / *ghaṭikā* (24 minutes).
- টিপ্পনী → типпани (комментарий) / *ṭippanī* (gloss).
- মানদ-ধর্ম → манада-дхарма (почтение к другим) / *mānada-dharma*.
- পরলোক → «иной мир» (пара-лока) / “other world” (*para-loka*). অপ্রাকট্য → уход из явленных игр / departure from the manifest pastimes.
- পাণ্ডিত্যাভিমানরূপ মায়া-বন্ধন → путы майи, то есть гордость учёностью / the bondage of *māyā*, that is, pride in learning.
