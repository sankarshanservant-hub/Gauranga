# Новые термины — Мадхья 1, часть 1 (RU / EN)

- শেষলীলা → Шеша-лила («заключительные игры», как у ВЧД) / Śeṣa-līlā.
- অধিদেবতা (в подзаголовках мангалачараны) → Божество — Владыка (самбандхи, абхидхеи, прайоджаны) / the Deity who is the Lord of *sambandha*, *abhidheya*, *prayojana*.
- গৌড়মণ্ডল / মাথুরমণ্ডল → Гауда-мандала / Матхура-мандала (Mathurā-maṇḍala).
- পাল্য (о Кришнадасе по отношению к Вриндавана дасу) → питомец (пальйа) / ward (*pālya*).
- সাত্বতশাস্ত্র → сатвата-шастры / *sātvata-śāstras*. রাগভক্তি → рагабхакти / *rāga-bhakti*.
- প্রাকৃত সহজিয়া → пракрита-сахаджии / *prākṛta-sahajiyās*; বাউলিয়া → баулский / *bāul*-like.
- Источники: «Бхакти-ратнакара» (1-я тарангa); «Лагху-тошани» (заключительные шлоки); «Хари-бхакти-виласа» (20 вилас) / *Bhakti-ratnākara* (first wave); *Laghu-toṣaṇī*; *Hari-bhakti-vilāsa* (20 *vilāsas*).
- Книги Рупы, Санатаны, Дживы (по списку в Ану 35–44): Хамсадута, Уддхава-сандеша, Чхандо-аштадашака, Уткалика-валли, Говинда-вирудавали, Премендусагара, Видагдха-мадхава, Лалита-мадхава, Дана-кели, Матхура-махима, Падьявали, Натака-чандрика, Санкшипта-Бхагаватамрита, Кришна-джанма-титхи-видхи, Ганоддеша-дипика, Става-мала, Прайуктакхьята-чандрика; Бхагаватамрита, Хари-бхакти-виласа, Диг-прадаршини (Дигдаршини), Лила-става, Вайшнава-тошани, Лагху-тошани; Хари-намамрита (грамматика), Сутра-малика, Дхату-санграха, Кришнарча-дипика, Гопала-вирудавали, Расамрита-шеша, Мадхава-махотсава, Санкальпа-калпавришка, Гаятри-виврити, Сандарбхи (Таттва, Бхагават, Параматма, Кришна, Бхакти, Прити, Крама) / *Haṁsadūta*, *Uddhava-sandeśa*, *Chando-'ṣṭādaśaka*, *Utkalikā-vallī*, *Govinda-virudāvalī*, *Premendu-sāgara*, *Vidagdha-mādhava*, *Lalita-mādhava*, *Dāna-keli*, *Mathurā-mahimā*, *Padyāvalī*, *Nāṭaka-candrikā*, *Saṁkṣipta-Bhāgavatāmṛta*, *Kṛṣṇa-janma-tithi-vidhi*, *Gaṇoddeśa-dīpikā*, *Stava-mālā*, *Prayuktākhyāta-candrikā*; *Bhāgavatāmṛta*, *Hari-bhakti-vilāsa*, *Dig-pradarśinī* (*Digdarśinī*), *Līlā-stava*, *Vaiṣṇava-toṣaṇī*, *Laghu-toṣaṇī*; *Hari-nāmāmṛta* (grammar), *Sūtra-mālikā*, *Dhātu-saṅgraha*, *Kṛṣṇārcā-dīpikā*, *Gopāla-virudāvalī*, *Rasāmṛta-śeṣa*, *Mādhava-mahotsava*, *Saṅkalpa-kalpavṛkṣa*, *Gāyatrī-vivṛti*, the *Sandarbhas* (*Tattva*, *Bhagavat*, *Paramātmā*, *Kṛṣṇa*, *Bhakti*, *Prīti*, *Krama*).
