# Новые термины — Антья 17, часть 2 (стихи 36–73)

- শিঞ্জিত → звон / tinkling (в «Анубхашье» ч. 1 — «звук» / sound).
- চটক (পক্ষী) → птица чатака / the *caṭaka* bird.
- কাকলী → какали (нежный напев) / *kākalī* (soft song).
- শব্দশক্তি / অর্থশক্তি; অভিধা / লক্ষণা; অর্থালঙ্কার; ব্যঞ্জনা → сила слова (шабда-шакти) / сила смысла (артха-шакти); абхидха (прямое значение) / лакшана (переносное); артхаланкары (смысловые украшения); вьянджана (выражение) / *śabda-śakti*, *artha-śakti*; *abhidhā*, *lakṣaṇā*; *arthālaṅkāra*; *vyañjanā*.
- কর্ণচকোর → птица чакора ушей / the *cakora* bird of the ears.
- কাণাকড়ি → дырявая ракушка-каури / a cracked cowrie shell.
- তৃষ্ণা-রঙ্গ (в издании; в стихе — তৃষ্ণা-তরঙ্গ) → волны жажды (сноска) / the waves of thirst (note).
- লীলাশুক → Лилашука = Бильвамангала Госвами / Līlāśuka = Bilvamaṅgala Gosvāmī; পাঠান্তর লীলাসুখ → Лиласукха / Līlāsukha.
- পিঙ্গলা (বেশ্যা); পিঙ্গলোপাখ্যান → блудница Пингала; сказание о Пингале / the courtesan Piṅgalā; the story of Piṅgalā.
- নৈরাশ্য → отказ от надежды / giving up hope.
- মোক্ষধর্ম্ম-পর্ব্ব, শান্তিপর্ব্ব → “Мокша-дхарма-парва”, “Шанти-парва” / *Mokṣa-dharma-parva*, *Śānti-parva*.
- মার (имя Камадевы; игра слов с মারে) → Мара / Māra.
- কামদেব, কন্দর্প → Камадева, Кандарпа / Kāmadeva, Kandarpa.
- বাম-দীন → жалкий из-за своенравия (вамьи) / wretched from contrariness (*vāmya*).
- রসায়ন → эликсир (расаяна) / elixir (*rasāyana*).
- কৃষ্ণপরতন্ত্রতা → всецело во власти Кришны / wholly in Kṛṣṇa's power.
- মধুরবিগ্রহ → воплощение сладости / sweetness embodied.
- মর্ত্ত্যবুদ্ধি → мирской (смертный) ум / the mortal mind.
- তৈলঙ্গ / ত্রৈলঙ্গ; তৈলঙ্গী গাভী; কালিঙ্গিক-সুরভি → Тайланга / Трайланга; тайлангские коровы; калингика-сурабхи / Tailaṅga / Trailaṅga; Tailaṅga cows; *kāliṅgika-surabhi*.
- করিঙ্গ, দক্ষিণ-কলিঙ্গ → Каринга, Дакшина-Калинга (Южная Калинга) / Kariṅga, Dakṣiṇa-Kaliṅga (South Kaliṅga).
- কমঠ / কূর্ম্ম; কূর্ম্মাকৃতি → черепаха; облик черепахи / tortoise; the tortoise form.
