# Глоссарий комментариев к Мадхье 9, часть 2 (стихи 201–365) — RU / EN

## Термины
- ছায়াসীতা → Сита-тень, чхая-Сита / the shadow Sītā (*chāyā-Sītā*); মূলসীতা → изначальная Сита / the original Sītā; মায়াসীতা → майя-Сита (как в Мадхье 1) / *māyā-Sītā*; বহ্নিপুর → обитель Агни (вахни-пура) / the abode of Agni (*vahni-pura*).
- দাক্ষিণাত্য → Дакшинатья (Юг) / the Dākṣiṇātya (the South).

## Источники
- «Курма-пурана» (Пурва-кханда, Уттара-кханда; Лакшми-кальпа) / *Kūrma Purāṇa* (Pūrva-khaṇḍa, Uttara-khaṇḍa; Lakṣmī-kalpa).
- «Рамаяна», Кишкиндха-канда (Тамрапарни, врата Пандьев) / *Rāmāyaṇa*, Kiṣkindhā-kāṇḍa.

## Места (в привычной передаче; EN — по изданию с диакритикой или в принятом английском написании)
- পাণ্ড্যদেশ → Пандья-деша / Pāṇḍya-deśa; কেরল, চোল → Керала, Чола / Kerala, Cola; মাদুরা → Мадура (= Южная Матхура) / Madurai.
- তিনেভেলি → Тинневелли / Tinnevelly; তাম্রপর্ণী, 'পরুণৈ' → Тамрапарни, «Порунаи» / Tāmraparṇī, “Porunai”; পশ্চিমঘাট → Западные Гхаты / the Western Ghats.
- নব তিরুপতি / নয় ত্রিপতি → Нава Тирупати / Ная Трипати / Nava Tirupati / Naya Tripati; আলোবর তিরুনগরী → Алвар-Тирунагари / Ālvār Tirunagarī.
- চিয়ড়তলা, ছেরতলা → Чиядатала, Чератала / Ciyaḍatalā, Cheratalā; নগরকৈল → Нагеркойл / Nagercoil; তিলকাঞ্চী → Тилаканчи / Tilakāñcī; তেন্‌কাশী → Тенкаси / Tenkasi.
- গজেন্দ্রমোক্ষণ → Гаджендра-мокшана / Gajendra-mokṣaṇa; স্থাণুলিঙ্গ, দেবেন্দ্র-মোক্ষণশিব → Стхану-линга, Девендра-мокшана-Шива / Sthāṇu-liṅga, Devendra-mokṣaṇa-Śiva; পানাগড়ি → Панагади / Pānāgaḍi.
