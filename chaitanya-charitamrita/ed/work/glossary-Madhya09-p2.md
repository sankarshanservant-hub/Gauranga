# Глоссарий комментариев к Мадхье 9, часть 2 (стихи 201–365) — RU / EN

## Термины
- ছায়াসীতা → Сита-тень, чхая-Сита / the shadow Sītā (*chāyā-Sītā*); মূলসীতা → изначальная Сита / the original Sītā; মায়াসীতা → майя-Сита (как в Мадхье 1) / *māyā-Sītā*; বহ্নিপুর → обитель Агни (вахни-пура) / the abode of Agni (*vahni-pura*).
- দাক্ষিণাত্য → Дакшинатья (Юг) / the Dākṣiṇātya (the South).

## Источники
- «Курма-пурана» (Пурва-кханда, Уттара-кханда; Лакшми-кальпа) / *Kūrma Purāṇa* (Pūrva-khaṇḍa, Uttara-khaṇḍa; Lakṣmī-kalpa).
- «Рамаяна», Кишкиндха-канда (Тамрапарни, врата Пандьев) / *Rāmāyaṇa*, Kiṣkindhā-kāṇḍa.

## Места (в привычной передаче; EN — по изданию с диакритикой или в принятом английском написании)
- পাণ্ড্যদেশ → Пандья-деша / Pāṇḍya-deśa; কেরল, চোল → Керала, Чола / Kerala, Cola; মাদুরা → Мадура (= Южная Матхура) / Madura.
- তিনেভেলি → Тинневелли / Tinnevelly; তাম্রপর্ণী, 'পরুণৈ' → Тамрапарни, «Порунаи» / Tāmraparṇī, “Porunai”; পশ্চিমঘাট → Западные Гхаты / the Western Ghats.
- নব তিরুপতি / নয় ত্রিপতি → Нава Тирупати / Ная Трипати / Nava Tirupati / Naya Tripati; আলোবর তিরুনগরী → Алвар-Тирунагари / Ālvār Tirunagarī.
- চিয়ড়তলা, ছেরতলা → Чиядатала, Чератала / Ciyaḍatalā, Cheratalā; নগরকৈল → Нагеркойл / Nagercoil; তিলকাঞ্চী → Тилаканчи / Tilakāñcī; তেন্‌কাশী → Тенкаси / Tenkasi.
- গজেন্দ্রমোক্ষণ → Гаджендра-мокшана / Gajendra-mokṣaṇa; স্থাণুলিঙ্গ, দেবেন্দ্র-মোক্ষণশিব → Стхану-линга, Девендра-мокшана-Шива / Sthāṇu-liṅga, Devendra-mokṣaṇa-Śiva; পানাগড়ি → Панагади / Pānāgaḍi.
- ত্রিবান্দ্রাম → Тривандрам / Trivandrum; রামলিঙ্গ শিব → Рамалинга-Шива / Rāmaliṅga Śiva; চামতাপুর, চেঙ্গানুর → Чамтапур, Ченганнур / Cāmtāpura, Chengannur; ত্রিবাঙ্কুর → Траванкор / Travancore.
- শ্রীবৈকুণ্ঠ, শ্রীবৈকুণ্ঠম্ → Шри Вайкунтха, Шривайкунтам / Śrī Vaikuṇṭha, Śrīvaikuṇṭham.
- মলয় পর্ব্বত → гора Малая / Malaya Mountain; কুমারিকা-অন্তরীপ → мыс Кумарика / Cape Kumārikā; কন্যাকুমারী → Каньякумари / Kanyākumārī.
- তাঞ্জোর-জিলা, কলিমিয়ার পয়েণ্ট, বেদারণ্যম্, অগস্ত্যম্‌পল্লী → округ Танджор, мыс Калимир, Ведараньям, Агастьямпалли / the Tanjore district, Point Calimere, Vedāraṇyam, Agastyampalli; শিবগিরি → гора Шивагири / the Śivagiri hill; পঠিয়া-পর্ব্বত → гора Потхия / the Pothiya mountain; অগস্ত্যমলয় → Агастья-малая / Agastya-malaya; সুব্রহ্মণ্য → Субрахманья / Subrahmaṇya.
- আম্‌লিতলা → Амлитала / Āmlitalā; মল্লার-দেশ, ম্যালেবার → Маллара-деша, Малабар / Mallāra-deśa, Malabar; দক্ষিণ-কানাড়া, কুর্গ, মহীশূর, কোচিন, আরব-সাগর → Южная Канара, Кург, Майсур, Кочин, Аравийское море / South Kanara, Coorg, Mysore, Cochin, the Arabian Sea.
- তমাল-কার্ত্তিক → Тамала-картика / Tamāla-kārttika; অরমবল্লী গিরিসঙ্কট → перевал Арамвалли / the Aramvallī pass; তোবল-তালুক → талук Товала / the Tovala *tāluk*; বেতাপনি, ভূতপণ্ডি → Ветапани, Бхутапанди / Vetāpani, Bhūtapaṇḍi; ভূতনাথ → Бхутанатха / Bhūtanātha.
