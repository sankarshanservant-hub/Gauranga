# Новые термины — комментарии к Ади 14–15 (RU / EN)

Формат: бенг./санскр. → RU / EN. Для переноса в `ed/GLOSSARY-commentary.md` координатором.

## Термины
- তৈর্থিক (অতিথি-বিপ্র) → паломник-тиртхика / pilgrim (*tairthika*).
- নৈবেদ্য, বিষ্ণুনৈবেদ্য → найведья (подношение), найведья Вишну / offering (*naivedya*), Viṣṇu's *naivedya*.
- বৈষ্ণবী শক্তি → сила Вишну (вайшнави-шакти) / a potency of Viṣṇu (*vaiṣṇavī śakti*).
- স্বীয় মায়া (о Господе, сбившем воров с пути) → Свою майю / His *māyā* (не «иллюзию»).
- সাহজিক (সহজাত) প্রীতি → врождённая любовь (сахаджика) / inborn love (*sāhajika*).
- উত্তান / উত্থান (পাঠান্তর) → «уттана» (лёжа на спине) / разночтение «уттхана» / *uttāna* / variant *utthāna*.
- জানুচংক্রমণ, হামাগুড়ি → джану-чанкрамана, ползание на коленках / *jānu-caṅkramaṇa*, crawling on the knees.
- বাটা → бата (сосуд, блюдо для еды или бетеля) / *bāṭā* (a vessel or dish for food or betel).
- ওলাহন → олахана (упрёк, выговор) / *olāhana* (a reproach, a scolding).
- উচ্ছিষ্ট / অনুচ্ছিষ্ট → осквернённое остатками / неосквернённое / defiled by remnants / undefiled; নরভাব → человеческие представления / human notions.
- ব্রহ্মজ্ঞান (Нимай — матери) → знание о Брахмане / knowledge of Brahman.
- মহাপুরুষ, বত্রিশ লক্ষণ → махапуруша (великая личность), тридцать два признака / *mahāpuruṣa*, the thirty-two marks; সত্ত্ব (в перечне признаков) → сила духа (саттва) / strength of character (*sattva*).
- অচিৎ-জাতীয় চেষ্টা → деятельность материального рода / an activity of the material kind; মূঢ়-নির্ব্বিশেষ-চিন্তা → глупое безличное мышление / foolish impersonal thinking.
- শুদ্ধবাৎসল্য → чистая родительская любовь (шуддха-ватсалья) / pure parental love (*śuddha-vātsalya*); বৎসল (রস) → «ватсала»-раса / *vatsala* [*rasa*].
- দ্বাদশ ফলা, রেফ → двенадцать пхала (подписных знаков), репха / the twelve *phalās* (subscript signs), the *repha*.
- হাতে খড়ি → «взять в руки мел» (начало обучения грамоте) / taking the chalk in hand.
- পৌগণ্ড → пауганда (с пятого года до десятого) / *paugaṇḍa* (from the fifth year to the tenth); পৌগণ্ডলীলা → игры пауганды / *paugaṇḍa* pastimes.
- পঞ্জী-টীকা; টিপ্পনী → «Панджи-тика»; пояснения (типпани) / *Pañjī-ṭīkā*; glosses (*ṭippanī*).
- সুমনঃ / কুমনাঃ / সুমনস্ত্ব → сумана (цветы; благой ум) / ку-мана (дурной ум) / благоумие; со сноской об игре слов / *sumanas* (flowers; a good mind) / *ku-manāḥ*; with a note on the pun.
- কৃষ্ণানুশীলন → служение Кришне (кришна-анушилана) / serving Kṛṣṇa (*kṛṣṇānuśīlana*).
- নিরাহারত্ব / উপবাস → пост (нирахаратва) / пост (упаваса) / fasting (*nirāhāratva*) / fasting (*upavāsa*); মহাপ্রসাদান্ন → маха-прасад из зерна (анны) / the *mahā-prasāda* grain (*anna*).
- পুরুষার্থ (ধর্ম, অর্থ, কাম, মোক্ষ) → пурушартхи, цели жизни / the goals of human life (*puruṣārthas*); সহধর্ম্মিণী → спутница в дхарме / partner in *dharma*.
- ঘটক, ঘটকালি → сват (гхатака), сватовство / matchmaker (*ghaṭaka*), matchmaking.
- পরলোক, অপ্রাকট্য, অন্তর্দ্ধান, বিজয় (о Джаганнатхе Мишре) → уход (ушёл из этого мира) / departure (departed from this world) — не «смерть», не «сокрытие».
- দুঃখরস → раса горя / the *rasa* of sorrow.
- রাজপণ্ডিত → царский пандит (раджа-пандит) / royal paṇḍita (*rāja-paṇḍita*).
- কাত্যায়নী ব্রত → обет Катьяяни / the Kātyāyanī vow.
- উপনয়ন → обряд священного шнура (упанаяна) / the sacred-thread ceremony (*upanayana*).
- হরিসঙ্কীর্ত্তন → хари-санкиртана / *hari-saṅkīrtana*.

## Имена
- Хиранья (Пандит), Джагадиша (Пандит) / Hiraṇya (Paṇḍita), Jagadīśa; Ниламбара Чакраварти / Nīlāmbara Cakravartī; Вишвамбхара / Viśvambhara; Шачинандана / Śacīnandana.
- Валлабхачарья (Джанака, Бхишмака) / Vallabhācārya (Janaka, Bhīṣmaka); Лакшмиприя Деви (Лакшми-деви; Джанаки, Рукмини) / Lakṣmīpriyā Devī (Lakṣmī-devī; Jānakī, Rukmiṇī).
- Ванамали (гхатака; Вишвамитра; брахман, посланный Рукмини к Кешаве) / Vanamālī (*ghaṭaka*; Viśvāmitra; the brāhmaṇa Rukmiṇī sent to Keśava).
- Гангадас Пандит; Вишну и Сударшана (первые учителя) / Gaṅgādāsa Paṇḍita; Viṣṇu and Sudarśana (first teachers).
- Вишварупа / Viśvarūpa; Пурандара Мишра (= Джаганнатха Мишра; сноска) / Purandara Miśra (= Jagannātha Miśra; note); Дашаратха, лучший из Рагху / Daśaratha, the best of the Raghus.
