# Новые термины, имена, места — комментарии к Мадхье 12 (RU / EN)

- গুণ্ডিচাবাড়ী → Гундича-бари (храм Гундичи) / the Guṇḍicā-bāḍī (the Guṇḍicā temple)
- গৌড়ীয় (ভক্ত), গৌড়ীয়া → гаудиец, гаудия-преданный / a devotee from Gauḍa, a Gauḍīya devotee
- নবযৌবন-দর্শন; জগদ্বন্ধু → даршан Нава-яуваны; Джагадбандху (Джаганнатха) / the Nava-yauvana *darśana*; Jagadbandhu (Jagannātha)
- কাণফাটা যোগী; কাণে মুদ্রা → «канпхата-йоги» («йоги с разрезанными ушами»); мудра в ушах (знак из раковины) / *kānphaṭā* yogīs; *mudrā* in the ears (a token of conch shell)
- লৌল্যলিপি → письмо, полное нетерпения / an eager letter
- বাগ্দণ্ড → словесное наказание / verbal chastisement; অনধিকার-চর্চ্চা → браться судить о том, что не по праву / judging what is not one's to judge; কটাক্ষ → насмешливый намёк / a jibe
- ঐকান্তিক ভক্ত → беззаветные (айкантика) преданные / exclusive (*aikāntika*) devotees
- যাজ্ঞিক বিপ্রপত্নী → жёны брахманов-ягьиков / the wives of the sacrificing *brāhmaṇas*
- সন্ধিনীশক্তিমদ্বিগ্রহ (Баладева); কলা 'শেষ' → облик, обладающий энергией сандхини; часть (кала) Шеша / the form possessing the *sandhinī* energy; the portion (*kalā*) Śeṣa
- পুরুষোত্তম জানা (сын Пратапарудры, «(?)» — в издании) → Пурушоттама Джана / Puruṣottama Jānā
- বিষয়-বিগ্রহ / আশ্রয় → вишая-виграха (Тот, на Кого обращена любовь) / ашрая (вместилище любви) / *viṣaya-vigraha* / *āśraya*
- ভৌমে ইজ্যধী → считать достойным поклонения сделанное из земли (ср. ШБ 10.84.13) / taking what is made of earth to be worshipable
- অভয়-দর্শন → бесстрашное видение / fearless vision; বৈষ্ণবদর্শন → видение вайшнава; даршан вайшнава / the vision of a Vaiṣṇava; the *darśana* of a Vaiṣṇava
- ক্রোশ, হাত → крош, локоть / *krośa*, cubit; রত্নবেদী → драгоценный алтарь (ратна-веди) / jeweled altar (*ratna-vedī*); নাটমন্দির → натья-мандир / *nāṭya-mandira*; ভোগমন্দির → бхога-мандир / *bhoga-mandira*; জগমোহন → Джагамохана / Jagamohana
- প্রণালিকা → сток, сточная канава / drain
- আবরণ-পরিষ্করণ → снятие покровов / removing the coverings
- সেবাপরাধ → оскорбление в служении (сева-апарадха) / offense in service (*sevāparādha*); গুরুব্রুব → гуру-брува (лишь называющий себя гуру) / *guru-bruva*; বিভিন্নাংশ → отделённая частица (вибхиннамша) / separated part (*vibhinnāṁśa*)
- মাধ্বগৌড়ীয়েশ্বর → владыка мадхва-гаудиев / lord of the Mādhva-Gauḍīyas
- ঢেকা → толчок / a shove; গুণ্ডিচাপুরী → обитель (пури) Гундичи / the abode of the Guṇḍicā
- কুটিনাটি, প্রতিষ্ঠাশা, জীবহিংসা, নিষিদ্ধাচার, লাভ-পূজা → кутинати (лицемерие), пратиштхаша (жажда почёта), джива-химса, нишиддхачара (запретное поведение), лабха-пуджа / *kuṭināṭi* (duplicity), *pratiṣṭhāśā* (hope for honor), *jīva-hiṁsā*, *niṣiddhācāra* (forbidden conduct), *lābha-pūjā*
- বুজরুগী → напускная святость / a show of sanctity; ভাবাভাস → бхавабхаса (тень бхавы) / *bhāvābhāsa*
- কেবলাভক্তি → беспримесная преданность (кевала-бхакти) / unalloyed devotion (*kevala-bhakti*); আত্মবৃত্তি → природная деятельность души (атма-вритти) / the soul's own function (*ātma-vṛtti*)
- নৃসিংহ-মন্দির, নৃসিংহচতুর্দ্দশী → храм Нрисимхи, Нрисимха-чатурдаши / the temple of Nṛsiṁha, Nṛsiṁha-caturdaśī
- ইন্দ্রদ্যুম্ন-পুষ্করিণী → пруд Индрадьюмна / the Indradyumna pond
- তুলসী-পড়িছা → Туласи-падичха / Tulasī the *paḍichā*
- পিণ্ডা (уткал.), পিঁড়ি (бенг.) → пинда, пири (деревянное сиденье) / *piṇḍā*, *pĩṛi* (a wooden seat)
- লাফ্রা-ব্যঞ্জন, অমৃত-গুটিকা, অমৃতরসাবলী → лапхра-вьянджана, амрита-гутика, амрита-расавали / *lāphrā-vyañjana*, *amṛta-guṭikā*, *amṛta-rasāvalī*
- বহির্ম্মুখ → бахирмукха (отвернувшиеся вовне) / *bahirmukha* (turned outward); দেবীধাম → Деви-дхама (царство Дурги) / Devī-dhāma
- মস্করী → санньяси (маскари) / *maskarī*; ব্যাজস্তুতি / ছলস্তুতি → скрытая хвала (вьяджа-стути, чхала-стути) / veiled praise (*vyāja-stuti*, *chala-stuti*)
- কেবলাদ্বৈতবাদ; নির্ভেদ-ব্রহ্মসাযুজ্য; অহংগ্রহোপাসক → кевала-адвайта; слияние с Брахманом без различий (нирбхеда-брахма-саюджья); аханграхопасака (поклоняющийся себе как Богу) / *kevala-advaita*; *nirbheda-brahma-sāyujya*; *ahaṅgrahopāsaka*
- স্বগত-সজাতীয়-বিজাতীয়ভেদ → различия свагата, саджатия, виджатия / *svagata*, *sajātīya*, *vijātīya* distinctions; ভূমা, বিরাট্ → бхума, вират / *bhūmā*, *virāṭ*
- জীব-মায়া / গুণ-মায়া; প্রকৃতি / প্রধান → джива-майя / гуна-майя; пракрити / прадхана / *jīva-māyā* / *guṇa-māyā*; *prakṛti* / *pradhāna*
- প্রাকৃত-সহজিয়া → пракрита-сахаджия / *prākṛta-sahajiyā*
- ধোয়াপাখলা → «дхоя-пакхала» (уткальское название очищения Гундичи) / *dhoyā-pākhalā*
- নেত্রোৎসব → Нетротсава («праздник глаз»; роспись глаз Божества) / the Netrotsava (“festival of the eyes”)
- করঙ্গ → каранга (сосуд санньяси для воды) / *karaṅga*; মর্য্যাদা → мардьяда (правило почтения) / *maryādā*
- গরুড়স্তম্ভ; ভোগমণ্ডপ → колонна Гаруды; бхога-мандапа / the Garuḍa pillar; the *bhoga-maṇḍapa*
- বান্ধুলী; সুরঙ্গ; হিঙ্গুল → бандхули (красный цветок); суранга; хингула (киноварь) / *bāndhulī*; *suraṅga*; *hiṅgula* (vermilion)
- Источники: «Кальяна-калпатару» (Бхактивинода); «Шри Чайтанья-чарита» (Мурари Гупта); «Упадешамрита» 4; «Лагху-бхагаватамрита»; Тантра; Брихад-араньяка-упанишада 1.4.2; Чхандогья-упанишада 6.2.1; Катха 1.2.23 / Мундака 3.2.3; ШБ 1.2.11, 2.9.33, 3.16, 7.4.37, 7.5.30–31, 10.23, 10.29.14, 10.78.36, 10.84.13 / *Kalyāṇa-kalpataru*; *Śrī Caitanya-carita*; *Upadeśāmṛta*; *Laghu-bhāgavatāmṛta*; Tantra; *Bṛhad-āraṇyaka*, *Chāndogya*, *Kaṭha*, *Muṇḍaka Upaniṣads*
