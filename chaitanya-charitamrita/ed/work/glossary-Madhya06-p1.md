#### Имена и места
- পড়িছা → падичха (служащий храма, подобный дароге) / *paḍichā*; দারোগা → дарога, надзиратель / *dārogā*.
- চন্দনেশ্বর → Чанданешвара (сын Сарвабхаумы) / Candaneśvara; মহেশ্বর বিশারদ → Махешвара Вишарада / Maheśvara Viśārada; মধুসূদন বাচস্পতি → Мадхусудана Вачаспати / Madhusūdana Vācaspati; বাসুদেব সার্ব্বভৌম → Васудева Сарвабхаума / Vāsudeva Sārvabhauma; গোপীনাথাচার্য্য → Гопинатха Ачарья / Gopīnātha Ācārya.
- বালুখণ্ড, মার্কণ্ডেয়-সরঃ, গঙ্গামাতা-মঠ → Балукханда, Маркандея-сарас, «Гангамата-матх» / Bālukhaṇḍa, the Mārkaṇḍeya-saras, the “Gaṅgāmātā Maṭha”; সমুদ্রগড়, বিদ্যানগর → Самудрагада, Видьянагар / Samudragaḍa, Vidyānagara; আঠারনালা → Атхаранала / Āṭhāranālā.
- শ্রীরাঘবেন্দ্র যতি → Шри Рагхавендра Яти / Śrī Rāghavendra Yati; বারুণি ভৃগু → Бхригу, сын Варуны / Bhṛgu, son of Varuṇa; করভাজন → Карабхаджана / Karabhājana.

#### Термины
- সুদ্দীপ্ত / উদ্দীপ্ত / দীপ্ত / জ্বলিত / ধূমায়িত (সাত্ত্বিক) → суддипта / пламенеющие (уддипта) / горящие (дипта) / пылающие (джвалита) / дымящиеся (дхумайита) / *sūddīpta* / blazing (*uddīpta*) / burning (*dīpta*) / flaming (*jvalita*) / smoldering (*dhūmāyita*).
- সহজ-ভাবুক → преданный, чувствующий естественно (сахаджа-бхавука) / one who feels naturally (*sahaja-bhāvuka*).
- নিত্যসিদ্ধ ভক্ত, পার্ষদ, দিব্যসূরি → нитья-сиддха-бхакта, паршада, дивья-сури / *nitya-siddha-bhakta*, *pārṣada*, *divya-sūri*.
- অনুরাগ, ভাব, মহাভাব, রূঢ়, অধিরূঢ়, মোদন, মাদন, মোহন → анурага, бхава, махабхава, рудха, адхирудха, модана, мадана, мохана / *anurāga*, *bhāva*, *mahābhāva*, *rūḍha*, *adhirūḍha*, *modana*, *mādana*, *mohana*; স্বসংবেদ্য দশা → состояние, ощутимое самим собой (сва-самведья) / *sva-saṁvedya*; যাবদাশ্রয়বৃত্তি → яват-ашрая-вритти / *yāvad-āśraya-vṛtti*; নায়ক / নায়িকা → герой (наяка) / героиня (наика) / hero (*nāyaka*) / heroine (*nāyikā*).
- লাফ্রা-ব্যঞ্জন → лапхра-вьянджана / *lāphrā-vyañjana*; ঘণ্ট → тушёное / stewed (*ghaṇṭa*); তরকারী → таркари / *tarakārī*.
- নিরাশীর্নির্নমস্ক্রিয়ঃ → «не благословлять и не кланяться» / “no blessings and no obeisances.”
- পূর্ব্বাশ্রম → пурвашрама (прежний ашрам) / *pūrvāśrama*; শিক্ষা-শিষ্য → шикша-шишья (ученик, получающий наставления) / *śikṣā-śiṣya*.
- নৈসর্গিক বৃত্তি / নৈসর্গিক বিনয় → природа / естественное смирение / natural disposition / natural humility.
- দশনামী: তীর্থ, আশ্রম, বন, অরণ্য, গিরি, পর্ব্বত, সাগর, সরস্বতী, ভারতী, পুরী → Тиртха, Ашрама, Вана, Аранья, Гири, Парвата, Сагара, Сарасвати, Бхарати, Пури / Tīrtha, Āśrama, Vana, Araṇya, Giri, Parvata, Sāgara, Sarasvatī, Bhāratī, Purī; ব্রহ্মচারী-নাম: স্বরূপ, প্রকাশ, আনন্দ, চৈতন্য → Сварупа, Пракаша, Ананда, Чайтанья / Svarūpa, Prakāśa, Ānanda, Caitanya; সমাবর্ত্তন → самавартана (возвращение домой) / *samāvartana*.
- যোগপট্ট → йогапатта / *yogapaṭṭa*; সংস্কার (সন্ন্যাস) → обряд посвящения (санскара) / initiation rite (*saṁskāra*).
- শমদমাদি সাধন-ষট্ক → шесть средств садханы (шама, дама и др.) / the six means of practice (*śama*, *dama*, etc.).
- কেবলাদ্বৈত → кевала-адвайта / *kevala-advaita*.
- অনুমান, ব্যাপ্তিজ্ঞান → умозаключение (анумана), знание неизменной связи (вьяпти) / inference (*anumāna*), invariable concomitance (*vyāpti*); প্রত্যক্ষ, ঐতিহ্য, শব্দ → прямое восприятие (пратьякша), предание (айтихья), слово (шабда) / *pratyakṣa*, *aitihya*, *śabda*; স্বতঃপ্রামাণ্য → самоочевидность / self-evidence; প্রমাণাভাস → подобие свидетельства / a semblance of evidence.
- বস্তু, বস্তুজ্ঞান, বস্তুশক্তি → Реальность (васту), знание Реальности (васту-гьяна), энергия Реальности / the Reality (*vastu*), knowledge of the Reality (*vastu-jñāna*), the potency of the Reality; খণ্ডজ্ঞান → раздробленное знание / divided knowledge; দাহিকা শক্তি → способность жечь / the power to burn.
- লীলাবতার, যুগাবতার, ত্রিযুগ → лила-аватара, юга-аватара, Триюга / *līlā-avatāra*, *yuga-avatāra*, Triyuga.
- ইষ্টগোষ্ঠী → иштагоштхи / *iṣṭa-goṣṭhī*.
- হংসগুহ্য স্তব → молитва «Хамса-гухья» / the *Haṁsa-guhya* prayer.
- সবিশেষ / নির্ব্বিশেষ → обладающий качествами (савишеша) / лишённый качеств (нирвишеша) / with attributes (*saviśeṣa*) / without attributes (*nirviśeṣa*); সবিশেষবাদ → савишеша-вада (учение о Брахмане, обладающем качествами) / *saviśeṣa-vāda*; নিঃশক্তিক → лишённый энергий / without potency; প্রাকৃত / অপ্রাকৃত বিশেষ → материальные / трансцендентные качества / material / transcendental attributes.
- অপাদান, করণ, অধিকরণ কারক → исходный (ападана), орудийный (карана), местный (адхикарана) падеж / the ablative (*apādāna*), instrumental (*karaṇa*), locative (*adhikaraṇa*) case.
- অন্নময়, প্রাণময়, চক্ষুর্ম্ময়, শ্রোত্রময়, মনোময়, বাঙ্ময়, বিজ্ঞানময়, আনন্দময় → состоящий из пищи, праны, зрения, слуха, ума, речи, знания, блаженства / made of food, breath, sight, hearing, mind, speech, knowledge, bliss; উপলক্ষণ → указание [на целое] / indication; নামৈকদেশে নামগ্রহণ-ন্যায় → правило «имя называют по части имени» / the rule that a name is mentioned by part of it.
- কুবর্ত্ম → кувартма (ложный путь) / *kuvartma* (a wrong path).
- বৃহত্ত্ব → брихаттва (величие) / *bṛhattva* (greatness).
