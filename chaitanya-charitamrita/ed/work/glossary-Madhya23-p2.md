# Новые термины: Мадхья 23, часть 2 (стихи 66–121) — RU / EN

## Термины
- সামুদ্রিকশাস্ত্র → самудрика-шастра / *sāmudrika-śāstra*; বত্রিশ শুভচিহ্ন, ষোড়শ রেখা → тридцать два благих знака, шестнадцать линий / thirty-two auspicious marks, sixteen lines.
- প্রতিভা → дар озарения (пратибха) / inspired insight (*pratibhā*); বিদগ্ধ → искусный (видагдха) / artful (*vidagdha*); দক্ষিণ (качество героя) → учтивый (дакшина) / courteous (*dakṣiṇa*).
- ধৃতিমান্ (অবরুদ্ধ-সৌরতঃ) → «сдерживающий любовное влечение, победивший чувства» / “holding amorous desire in check, master of the senses.”
- সদা-স্বরূপ-সংপ্রাপ্ত (মায়য়া অনভিভাব্যানুভূতিবিশিষ্ট) → «наделённый сознанием, которое майя не может одолеть» / “possessed of a consciousness that *māyā* cannot overpower.”
- আত্মারাম → атмарамы (довольные в себе) / *ātmārāmas* (those content in the self).
- প্রিয়াধিক্য → несравненное общество возлюбленных / the incomparable company of His beloveds.
- সুমর্য্যাদা / সুবিলাসা / নর্ম্ম → соблюдающая достойную меру (сумарьяда) / богатая играми (сувиласа) / шутки (нарма) / keeping proper bounds (*sumaryādā*) / rich in play (*suvilāsā*) / joking (*narma*).
- গুর্ব্বর্পিত-গুরুস্নেহা → «та, кому старшие дарят великую любовь» (так у обоих комментаторов; у ВЧД — иначе) / “She on whom the elders bestow great affection.”
- চমৎকার → изумление (чаматкара) / wonder (*camatkāra*); রস্যতা → состояние расы, «становится предметом вкушения» / the state of *rasa*, “becomes relishable.”
- সংস্কার (প্রাক্তন ও আধুনিক; БРС 2.1.7–9) → самскары (прежние и нынешние впечатления), не «обряды» / *saṁskāras* (former and present impressions), not “rites.”
- কুরসিক → дурной ценитель (курасика) / false connoisseur (*kurasika*); অদ্বয়জ্ঞান-কৃষ্ণাশ্লিষ্ট → соединённый с Кришной — недвойственным Знанием (адвая-гьяной) / united with Kṛṣṇa, the nondual Knowledge (*advaya-jñāna*).
- ভক্তিস্মৃতিশাস্ত্র → шастры бхакти-смрити (= “Хари-бхакти-виласа”) / *bhakti-smṛti-śāstra*.
- সাম্প্রদায়িক সেবাভার → обязанности служения ради сампрадаи / duties of service for the *sampradāya*; বৈষ্ণব-সদাচার → благочестивое поведение (садачара) вайшнавов / the proper conduct (*sadācāra*) of Vaiṣṇavas; বৈষ্ণবসমাজ → вайшнавское общество / the Vaiṣṇava community.
- যুক্তবৈরাগ্য / শুষ্কবৈরাগ্য / ফল্গুবৈরাগ্য → юкта-вайрагья (уместное отречение) / сухое отречение / ложное отречение (пхалгу-вайрагья) / *yukta-vairāgya* (fitting renunciation) / dry renunciation / false renunciation (*phalgu-vairāgya*).
- যাবন্নির্ব্বাহ-প্রতিগ্রহ → принимать лишь столько, сколько нужно для поддержания жизни / accepting only as much as is needed to maintain life.
- তটস্থ-লক্ষণ (о преданном) → внешние признаки (татастха-лакшаны) / marginal characteristics (*taṭastha-lakṣaṇas*).
- মৌষল-লীলা / কৃষ্ণ-অন্তর্দ্ধান / কেশাবতার / মহিষী-হরণ → маушала-лила / игра ухода Кришны / кеша-аватара / похищение цариц / *mauṣala-līlā* / Kṛṣṇa’s pastime of departure / the hair-*avatāra* / the abduction of the queens.
- অসুর-মোহিনী → вводящие в заблуждение асуров / bewildering the *asuras*.
- মহাকাশ / স্বল্পাকাশ → великое пространство (махакаша) / малое пространство / the great space (*mahākāśa*) / a small space; দেবীধাম → Деви-дхама / Devī-dhāma; সাধ্য → садхьи / the Sādhyas.
- পূর্ব্বপক্ষ → возражение (пурвапакша) / objection (*pūrvapakṣa*).
- চিদ্বৃত্তি → духовная деятельность души (чид-вритти) / the spiritual function of the soul (*cid-vṛtti*).

## Книги

- “Брихад-вайшнава-тошани” (комментарий к Десятой песни), “Брихад-бхагаватамрита” / *Bṛhad-vaiṣṇava-toṣaṇī*, *Bṛhad-bhāgavatāmṛta*.
- “Хари-вамша” (Вишну-парва) / *Hari-vaṁśa* (*Viṣṇu-parva*); “Риг-веда-самхита” / *Ṛg-veda-saṁhitā*.
- “Лагху-бхагаватамрита” (часть “Кришнамрита”) / *Laghu-bhāgavatāmṛta* (*Kṛṣṇāmṛta*); “Кришна-сандарбха” (“Шат-сандарбха”), “Сарва-самвадини” / *Kṛṣṇa-sandarbha* (*Ṣaṭ-sandarbha*), *Sarva-saṁvādinī*.
