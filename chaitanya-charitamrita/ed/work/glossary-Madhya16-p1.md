# Новые термины — Мадхья 16, часть 1 (комментарии, стихи 0–150)

## Термины
- তর্জ্জা → тарджа (речь в размерах пайяр и т. п., непонятная посторонним) / *tarjā*.
- ঘাটি-সমাধান → «улаживать дела на заставах (гхати)» / “settling matters at the toll stations (*ghāṭi*)”; কর → пошлина («кара») / toll (*kara*).
- ঘাটিয়াল → гхатиялы (дорожные досмотрщики) / *ghāṭiyāls* (inspectors on the road).
- ক্ষীরপ্রসাদ → кшира-прасад / *kṣīra-prasāda*.
- বাপী → вапи (колодец, водоём) / *vāpī*; ইঁদারা → индара (колодец) / *indārā*.
- ওড়নষষ্ঠী → Одана-шаштхи (как у ВЧД) / Oḍana-ṣaṣṭhī; মাড়ুয়া বসন → ткань «маруя» (невыстиранная, с крахмалом — «маром») / *māṛuyā* cloth (unwashed, starched — *māṛ*).
- খুঁটিনাটি → «придирка» / “finding fault”.
- বৈষ্ণব / বৈষ্ণবতর / বৈষ্ণবতম → вайшнав / вайшнаватара (лучший вайшнав) / вайшнаватама (наилучший вайшнав) / *vaiṣṇava*, *vaiṣṇavatara*, *vaiṣṇavatama*.
- সুহৃৎ, অতিথি → доброжелатель, гость / well-wisher, guest.
- কোমলশ্রদ্ধ কনিষ্ঠ বৈষ্ণব → младший (каништха) вайшнав с мягкой верой / the junior (*kaniṣṭha*) Vaiṣṇava of tender faith.
- নিরন্তর / অন্তর → «непрестанно» / «антара» (промежуток) / “constantly” (*nirantara*) / *antara* (interval).
- চেতনবৃত্তি → деятельность сознания (четана-вритти) / the conscious faculty (*cetana-vṛtti*); শৈথিল্য → вялость (шайтхилья) / laxity (*śaithilya*); জাড্য (здесь) → косность / inertness.
- দেহ, দ্রবিণ, জনতা, লোভ, পাষণ্ডতা (Бхакти-сандарбха 265) → тело (деха), богатство (дравина), люди (джаната), жадность (лобха), безбожие (пашандата) / body (*deha*), wealth (*draviṇa*), people (*janatā*), greed (*lobha*), godlessness (*pāṣaṇḍatā*).
- ধাতুবুদ্ধি (о виграхе) → представление как о «веществе» / regarding as “matter”.
- অপ্রাকৃত কৃষ্ণদাস → «трансцендентный слуга Кришны (кришна-дас)» / “transcendental servant of Kṛṣṇa” (*kṛṣṇa-dāsa*).
- আশ্রয়জাতীয় কৃষ্ণ → Кришна в облике прибежища (ашрая) / Kṛṣṇa in the form of the shelter (*āśraya*).
- সাঙ্গীকৃত বস্তু (কৃষ্ণের) → тот, кого Кришна принял как Своего / one whom Kṛṣṇa has accepted as His own.
- হঠ → хатха (применение силы, принуждение) / *haṭha* (force, compulsion).
- পয়ান → паяна (= прайана, отправление в путь) / *payāna* (= *prayāṇa*).
- কড়ার, ডোর → кадар (желтовато-бурый; притирание?), дор (верёвка) / *kaṛāra* (tawny; an ointment?), *ḍora* (rope).
- অ-মায়া (প্রভুর কৃপা) → «без притворства» / “without pretense”.
- প্রতাপরুদ্র-সংত্রাতা → «Пратапарудра-санстрата» (Спаситель Пратапарудры) / “Pratāparudra-saṁtrātā” (the Savior of Pratāparudra).
- বিষয়ী → вишайи (царский чиновник, собирающий подати) / *viṣayī* (revenue officer).
- মহাপাত্র → махапатра / *mahāpātra*.
- নব্যবাস → навья-васа (новый дом) / *navya-vāsa*.
- একেশ্বর / অশ্বর (Чаттаграм) → экешвара («один») / ашвара / *ekeśvara* / *aśvara*.
- ক্ষেত্রসন্ন্যাস → кшетра-санньяса (по общему глоссарию); বানপ্রস্থধর্ম্ম → ванапрастха-дхарма / *vānaprastha-dharma*.
- প্রেমবিবর্ত / প্রেমের বিবর্ত → «према-виварта» (превратность любви) / *prema-vivarta* (the paradox of love).
- অভিমান (Гададхары) → любовная обида / loving pique.
- স্বেচ্ছামৃত্যু (Бхишма) → «сам избирал час своей кончины» / “could choose the hour of his own passing”.
- মাতৃগণ (Варахи, Вайшнави, Индрани) → матери (матрики) / the Mothers.

## Имена и места
- মঙ্গরাজ (মরদরাজ ?) → Мангараджа (Мардараджа?) / Maṅgarāja (Mardarāja?); হরিচন্দন → Харичандана / Haricandana.
- চিত্রোৎপলা → река Читротпала / the river Citrotpalā; চতুর্দ্বার («চৌদার») → Чатурдвар («Чаудар») / Caturdvāra (“Caudār”).
- ভবানীপুর, জানকাদেইপুর, জানকীদেবীপুর → Бхаванипур, Джанакадеипур, Джанакидевипур / Bhavānīpura, Jānakādeipura, Jānakīdevīpura.
- আঠারনালা → Атхаранала (мост) / Āṭhāranālā.
- ওড্রদেশ → страна Одра / the Oḍra country; যবনাধিকারী → правитель-яван / a *yavana* governor.
- জগন্নাথবল্লভ (сад), নরেন্দ্র-সরোবর → Джаганнатха-валлабха, озеро Нарендра (по общему глоссарию).
- আচার্য্যনিধি (Ану 80–81, так в издании) → Ачарьянидхи / Ācāryanidhi.
- প্রেমনিধি → Према-нидхи (Пундарика Видьянидхи) / Prema-nidhi.
- যাজপুর, যযাতি-নগর → Яджапур, Яяти-нагара / Yājapura, Yayāti-nagara.
- সনাতন-শিক্ষা → «Наставления Санатане» (Мадхья 22) / the instructions to Sanātana (Madhya 22).
