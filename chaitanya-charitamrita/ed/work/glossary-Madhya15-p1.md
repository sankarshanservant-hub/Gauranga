# Глоссарий комментариев к Мадхье 15, часть 1 (стихи 0–128; новые термины, имена, места; RU / EN)

## Термины
- যোঽসি সোঽসি (মন্ত্র) → «Кем бы Ты ни был, таков Ты» / “Whoever You are, that You are”
- উপলভোগ, ভোগবর্দ্ধন-খণ্ড → упала-бхога, зал бхога-вардханы / *upala-bhoga*, the *bhoga-vardhana* hall (как в Мадхье 12–13)
- খুটিয়া, মাহাতি, পাত্র (উপাধি) → Кхутия (титул брахманов Уткалы), Махити (титул каранов — писцов Уткалы), Патра (титул почтенных людей) / Khuṭiyā, Māhāti, Pātra
- লগুড়, পাদসন্ধ্যে, অলাতচক্র → лагуда (палка), пада-сандхье (между ступнями), алата-чакра / *laguḍa*, *pāda-sandhye*, *alāta-cakra*
- লঙ্কা-গড় → Ланка-гада (укрепление, или ров, вокруг Ланки) / *Laṅkā-gaḍa*
- দীপাবলী, উত্থান-দ্বাদশী, চাতুর্ম্মাস্যান্তব্রত → Дипавали (Дивали), Уттхана-двадаши, завершение обета чатурмасьи / Dīpāvalī (Diwali), Utthāna-dvādaśī, the close of the Cāturmāsya vow
- কুণপাত্মবাদী → «кунапатма-вади» (принимающие тело-труп за себя) / *kuṇapātma-vādīs*
- গৃহব্রত / গৃহমেধী → грихавраты / грихамедхи / *gṛha-vratas* / *gṛhamedhīs*
- শালান্ন, ভৃষ্ট পটোল-নিম্বপাত, ভাজন → шальянна (рис шали), жареные патолы с листьями нима, бхаджана (сосуд) / *śālyanna*, fried *paṭolas* with *nīm* leaves, *bhājana* (vessel)
- শুচি-বায়ু-রোগ → «болезнь чистоплотности» / the “disease of cleanliness”; ভৌমে ইজ্যধী → «почитающий достойным поклонения землю» (ШБ 10.84.13) / “considers the earth worshipable”
- কর্ম্মমিশ্র-বিদ্ধভক্ত → преданные, чья преданность смешана с кармой и запятнана / devotees whose devotion is mixed with *karma* and tainted
- হুড়ুম, মুড়িকি; কাশমদি / কাসুন্দি; ক্ষীর-ওদন → худума (зерно; хлопья-кхаи), мудики; кашамди / касунди; кшира-одана (паяса) / *huḍuma*, *muḍiki*; *kāśamdi* / *kāsundi*; *kṣīra-odana*
- সরখেল → саркхел (попечитель) / *sarakhela* (guardian); ঘাটি সমাধান → уплата сборов на заставах / settling the tolls at the checkpoints
- পয়ার → паяр (четырнадцатисложный размер) / *payāra*; কৌলীন্য-প্রথা (বল্লালী) → обычай кулинства (введённый Баллалой) / the custom of Kulīnism (introduced by Ballāla); পাট → пат (святое место) / *pāṭa*
- কোমল শ্রদ্ধা → мягкая вера / soft faith; বৈষ্ণবপ্রায় → «почти вайшнав» / “almost a Vaiṣṇava”; শুদ্ধ-বৈষ্ণব → чистый вайшнав / pure Vaiṣṇava
- দীক্ষা, পুরশ্চর্য্যা / পুরশ্চরণ, পুরঃক্রিয়া, ন্যাস → дикша, пурашчарья / пурашчарана, пура-крия, ньяса / *dīkṣā*, *puraścaryā* / *puraścaraṇa*, the preliminary rite, *nyāsa*
- পঞ্চাঙ্গোপাসনা (ত্রিকাল পূজা, জপ, তর্পণ, হোম, ব্রাহ্মণভোজন) → пятичастное поклонение / the fivefold worship
- মন্ত্রদেবতা → божество мантры / the deity of the *mantra*; শব্দসামান্য বুদ্ধি → считать «обычным звуком» / regarding as “ordinary sound”
- সেবোন্মুখ জিহ্বা → язык, обращённый к служению / a tongue inclined to service
- আড়ানী → адани (зонт, большое опахало) / *āḍānī*; উচ্চ-টুঙ্গি → учча-тунги (домик на возвышении) / *ucca-ṭuṅgi*
- মহাবিদগ্ধ, মহাসিদ্ধ → маха-видагдха (сведущий в правлении), маха-сиддха (освобождённый) / *mahā-vidagdha*, *mahā-siddha*
- দারুব্রহ্ম, জলব্রহ্ম → Дару-брахман, Джала-брахман / the Dāru-brahma, the Jala-brahma
