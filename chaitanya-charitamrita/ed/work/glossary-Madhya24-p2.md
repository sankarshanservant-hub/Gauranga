# Новые термины — Мадхья 24, часть 2 (комментарии, стихи 138–230)

- সাধক, ব্রহ্মময়, প্রাপ্তব্রহ্মলয় (атмарамы-брахмавадины) → садхака (начинающий), брахмамая (погружённый в Брахман), прапта-брахма-лая (растворившийся в Брахмане) / the *sādhaka* (beginner), the *brahmamaya* (absorbed in Brahman), the *prāpta-brahma-laya* (merged in Brahman).
- মুমুক্ষু, জীবন্মুক্ত, প্রাপ্তস্বরূপ → мумукшу (стремящийся к освобождению), дживан-мукта (освобождённый при жизни), прапта-сварупа (обретший свою истинную природу) / the *mumukṣu* (seeker of liberation), the *jīvan-mukta* (liberated while living), the *prāpta-svarūpa* (one who has attained his true nature).
- মনন → размышление (о Кришне) / contemplation (of Kṛṣṇa); মুনি → мудрец (муни) / sage (*muni*).
- একশেষ → экашеша (одно оставшееся слово) / *ekaśeṣa*.
- সগর্ভ-যোগী / নির্গর্ভ-যোগী → сагарбха-йог / ниргарбха-йог (как в издании «নির্গর্ভ»; у ВЧД в стихе — «нигарбха») / the *sagarbha* / *nirgarbha* yogī.
- যোগারুরুক্ষু, যোগারূঢ়, প্রাপ্তসিদ্ধি → йогарурукшу (желающий взойти на ступень йоги), йогарудха (взошедший на ступень йоги), прапта-сиддхи (достигший совершенства) / *yogārurukṣu*, *yogārūḍha*, *prāpta-siddhi*.
- বৈরাজধারণা → медитация на вселенский облик (вайраджа-дхарана) / meditation on the universal form (*vairāja-dhāraṇā*); ব্যষ্ট্যন্তর্য্যামী → Антарьями отдельного существа (вьяшти-антарьями) / the *vyaṣṭi-antaryāmī*.
- প্রাদেশ → прадеша (пядь — от большого пальца до указательного) / *prādeśa*, a span.
- বড়িশ → крючок (бадиша) / hook (*baḍiśa*).
- ধারণা, ধ্যান, প্রত্যাহার, যম, নিয়ম, আসন, প্রাণায়াম, শম → дхарана, дхьяна, пратьяхара, яма, нияма, асана, пранаяма, шама (покой) / *dhāraṇā*, *dhyāna*, *pratyāhāra*, *yama*, *niyama*, *āsana*, *prāṇāyāma*, *śama* (tranquillity).
- সঙ্কল্প → намерение (санкальпа) / intention (*saṅkalpa*).
- Значения слова আত্মা (по «Вишва-пракаше»), в этой части: (3) মন → ум / mind; (4) যত্ন → усилие / effort; (5) ধৃতি → стойкость (дхрити) / steadfastness (*dhṛti*).
- শান্ত (ভক্ত) → шанта (преданный в шанта-расе) / *śānta*; শান্তরস → шанта-раса / *śānta-rasa*.
- শার্করাক্ষ, আরুণি ঋষিগণ → риши Шаркаракши, риши Аруни / the Śārkarākṣa, the Āruṇi *ṛṣis*; কূর্পদৃক্ → «курпа-дрик» (с грубым зрением) / “*kūrpa-dṛk*” (of gross vision).
- উদর, দহর, মণিপুর, মূলাধার, সুষুম্না, ব্রহ্মরন্ধ্র, নাড়ী → удара, дахара, манипура, муладхара, сушумна, брахмарандхра, нади / *udara*, *dahara*, *maṇipūra*, *mūlādhāra*, *suṣumnā*, *brahma-randhra*, *nāḍī*.
- ব্রহ্মসত্র → брахма-сатра (жертвоприношение) / the *brahma-satra* sacrifice; সনন্দন → Санандана / Sanandana; আদিঋষি নারায়ণ → изначальный риши Нараяна / the original *ṛṣi* Nārāyaṇa.
- আসঙ্গ → асанга (стремление к любви Кришны) / *āsaṅga*; যত্নাগ্রহ → горячее стремление / eager longing.
- অন্তর্য্যামী গুরুদেব (Нарада у Вьясы) → гуру, знающий его сердце / his guru, who knew his heart.
- (6) বুদ্ধি → разум / intelligence; বুদ্ধ্যারাম → буддхьярама / *buddhy-ārāma*; (7) স্বভাব → природа / nature; (2) দেহ → тело / body; দেহারামী / দেহারাম → дехарами (тот, кто находит радость в теле), дехарама / *dehārāmī*, *dehārāma*; কৃষ্ণারাম → кришнарама / *kṛṣṇārāma*.
- বিবর্ত্তবাদী, বিবর্ত্তবুদ্ধি → вивартавадин, представление о виварте / *vivarta-vādī*, the notion of *vivarta*; ঔপাধিক ব্রহ্ম → обусловленный Брахман / conditioned Brahman.
- Значения частиц: সমুচ্চয় → самуччая (соединение) / *samuccaya* (conjunction); অন্বাচয় → анвачая (главное и второстепенное) / *anvācaya*; এব → эва; গর্হা → гарха (порицание) / *garhā* (censure); নির্দ্ধারণ → нирдхарана (уточнение) / *nirdhāraṇa* (specification); বিশেষণ → определение / qualifier; নির্ধন → нирдхана (бедняк) / *nirdhana* (pauper); ইতরেতর → итаретара / *itaretara*.
- ধৃতি (по БРС 2.4.144) → дхрити: отсутствие страданий от обретения высшего и сознание полноты / *dhṛti*.
- সদ্‌বুদ্ধি → благой разум / good intelligence; পঞ্চবিধ সাধন → пять видов садханы / the five *sādhanas*.
- পৌগণ্ড → пауганда (возраст) / *paugaṇḍa* age; কুসুমাকর-বন → лес Кусумакара / the Kusumākara forest; নির্যোগ, পাশ → нирйога (верёвка для ног коровы при дойке), паша (петля) / *niryoga*, *pāśa*.
- সন্ধিনীশক্তি → энергия сандхини / the *sandhinī* potency; শুদ্ধসত্ত্বাধীশ → Владыка чистой саттвы / Lord of pure *sattva*.
- উপাশ্রয় (ভাগবত-বৈষ্ণব) → упашрая — укрывшиеся у Бхагавана бхагавата-вайшнавы / *upāśraya*.
- কিরাত, হূণ, অন্ধ্র, পুলিন্দ, পুক্কশ, আভীর, শুহ্ম (в стихе শুম্ভ), যবন, খশ, শবর → кираты, хуны, андхры, пулинды, пуккаши, абхиры, шухмы, яваны, кхаши, шабары / Kirātas, Hūṇas, Andhras, Pulindas, Pukkaśas, Ābhīras, Śuhmas, Yavanas, Khaśas, Śabaras.
- অদ্ভুতক্রম → Адбхута-крама (= Урукрама) / Adbhuta-krama.
- আসব (গোবিন্দপাদপদ্মাসব) → медовый нектар (асава) / honeyed nectar (*āsava*).
- ব্যাধ, মৃগারি → охотник, Мригари / the hunter, Mṛgāri; ওঁত → «ота» (спрятавшись, в засаде) / “*õta*” (in hiding).
- Нумерация: ссылка издания «Мадхья 22.129» (БРС 1.2.238) = у нас Мадхья 22.128.
