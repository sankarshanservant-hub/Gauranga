# Глоссарий: Антья 10, часть 2 (стихи 86–162) — новые термины (RU / EN)

- পরিমুণ্ডা-নৃত্য (= পরিমণ্ডল-নৃত্য) → паримунда-нритья, танец по кругу (паримандала-нритья) / *parimuṇḍā-nṛtya*, dancing in a circle (*parimaṇḍala-nṛtya*).
- পাদ-সম্বাহন → растирание стоп / massaging the feet.
- বহির্ব্বাস (Говинды, Ану-подзаг. 89) → бахирвас, верхняя ткань / *bahirvāsa*, outer cloth.
- প্রসাদ-সম্মান → почтить прасад / to honor *prasāda*.
- আদিবস্যা → адивасья: (APB) тот, кто давно живёт здесь, со Господом; (Ану) «несчастный», «глупый», «непостоянный», «а-декхла» (кангла, жадный) / *ādivasyā*.
- আ-দেখ্‌লা, কাঙ্‌লা → «а-декхла» (слишком нетерпеливый), «кангла» (жадный) / *ā-dekhlā* (overeager), *kāṅlā* (greedy).
- পৈড় (уткальское) → пайда, кокос / *paiḍa* (an Utkala word), coconut.
- মুকুতা (নারিকেল) → мукута, со вскрытым верхом / *mukutā*, with the top cut open.
- পূপী, কূপী → пупи (пирожок, пиштака), купи (сосуд для камфары) / *pūpī* (cake, *piṣṭaka*), *kūpī* (camphor vessel).
- পদ্মচিনি, ছানা → сахарные лотосы (падма-чини), творог (чхана) / sugar lotuses (*padma-cini*), curd cheese (*chānā*).
- উপযোগ → упайога, принятие, вкушение / *upayoga*, accepting, partaking.
- ভাজন (উচ্ছিষ্ট-ভাজন) → бхаджана: «бхак», «патра» (получатель, сосуд) / *bhājana*: *bhāk*, *pātra* (recipient, vessel).
- ঘাটাইলা → гхатаила, уменьшили / *ghāṭāila*, reduced.
- বিশ্রম্ভ-সখ্য → доверительная дружба (вишрамбха-сакхья) / intimate friendship (*viśrambha-sakhya*); সেবা-মর্য্যাদা → как подобает служить / the proper decorum of service.
- স্বারসিকী সেবা → служение по собственному побуждению (сварасики) / service on one's own initiative (*svārasikī*).
- অগ্নিমান্দ্যনাশক দ্রব্য → яства, пробуждающие ослабевший огонь пищеварения / foods that revive a weak digestive fire.
- হৃৎকর্ণরসায়ন → эликсир (расаяна) для сердца и ушей / an elixir (*rasāyana*) for the heart and ears.
- অর্দ্ধভোজন (страх перед Рамачандрой Пури) → угощение уменьшают вдвое / the meal is cut by half.
- শৌক্র-ব্রাহ্মণ; অভোজ্যান্ন শৌক্র-ব্রাহ্মণ → брахман по рождению (шаукра-брахман); брахман по рождению, у которого нельзя есть приготовленную пищу (абходжьянна) / *brāhmaṇa* by birth (*śaukra-brāhmaṇa*); one whose cooked food may not be eaten (*abhojyānna*).
- দুইপণ / চারিপণ কৌড়ি → две / четыре паны каури / two / four *paṇas* of cowries.
- Книги: “Кришна-карнамрита” (санскр. комментарий Чайтаньи даса); махакавья “Чайтанья-чаритамрита” / *Kṛṣṇa-karṇāmṛta*; the *mahākāvya* *Caitanya-caritāmṛta*.
- Имена: Чайтанья дас (сын Шивананды); Сатьяраджа Кхан, Рамананда Васу (Кулинаграм); Мукунда дас, Нарахари дас, Рагхунандана (Кханда) / Caitanya dāsa; Satyarāja Khān, Rāmānanda Vasu; Mukunda dāsa, Narahari dāsa, Raghunandana.
