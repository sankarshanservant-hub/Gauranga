# Новые термины — Мадхья 25, часть 2 (комментарии, стихи 132–276)

Формат: бенг./санскр. → RU / EN.

- সম্বন্ধ- / অভিধেয়- / প্রয়োজন-দ্যোতক শ্লোক → шлока, раскрывающая самбандху / абхидхею / прайоджану / a verse that reveals the *sambandha* / *abhidheya* / *prayojana*.
- নিৰ্ব্বোধ (দেহাত্মবুদ্ধি) → лишённые разумения, принимающие себя за тело / those who lack understanding and take themselves to be the body.
- প্রবুদ্ধ-ঋষি → Прабуддха-риши (один из девяти Йогендр) / Prabuddha Ṛṣi.
- কীর্ত্তনাখ্যা ভক্তি → бхакти, называемая киртаном / the devotion called *kīrtana*.
- উত্তরমীমাংসা → Уттара-мимамса / the Uttara-mīmāṁsā.
- ব্রহ্মগায়ত্রী, বেদমাতা → брахма-гаятри, мать Вед / the Brahma-gāyatrī, the mother of the Vedas.
- সামরূপ (পুরাণানাং) → Сама[-веда] среди Пуран / the Sāma[-veda] among the Purāṇas; শতবিচ্ছেদ → сто разделов / a hundred divisions.
- ভারতার্থবিনির্ণয় → установление смысла «Махабхараты» / establishing the meaning of the *Mahābhārata*; বেদার্থপরিবৃংহিত → обогащённый смыслом Вед / enriched by the meaning of the Vedas.
- রসিক / ভাবুক (Бхаг. 1.1.3) → расики (знающие расу служения) / бхавуки (искусные в созерцании рас; здесь не «сентименталисты») / *rasikas* / *bhāvukas* (adept at contemplating *rasas*; not “sentimentalists” here).
- পরমলয় (в расе) → полное растворение, погружение (парама-лая) в истине расы / full absorption (*parama-laya*) in the truth of *rasa*.
- আ-লয়ম্ (মোক্ষানন্দমভিব্যাপ্য) → вплоть до блаженства освобождения включительно / up to and including the bliss of liberation.
- উত্তমঃশ্লোক (উৎ + তমঃ) → Уттамашлока: Тот, Чья слава прогоняет тьму / Uttamaśloka, whose fame drives away darkness.
- নামাভাস → намабхаса / *nāmābhāsa*.
- Источники: “Гаруда-пурана” / *Garuḍa Purāṇa*; “Сарвагья-бхашья” (у Шридхары к Бхаг. 10.87.21) / *Sarvajña-bhāṣya*.
- Нумерация: в издании источник стиха 138 — «Бхаг. 1.3.42» (у ВЧД и в принятой нумерации — 1.3.41; сноска).
- মুন্সীফ (от ইনসাফ) → мунсиф (от «инсаф», справедливость): тот, кто ведает делом от имени хозяина / *munsīph* (from *insāph*, justice): one who takes charge of a matter on the owner's behalf; ছিদ্র → оплошность / fault.
- করোঁয়া → кароя (сосуд мусульман для воды) / *karoyā*; ছদ্ম → чхадма, предлог / *chadma*, pretext; বেগম → бегум / begum.
- ব্যবহার-স্নেহ → вьявахара-снеха (привязанность мирских отношений) / *vyavahāra-sneha*, affection rooted in worldly relationships; পূর্ব্বাশ্রমোচিত → как подобало до санньясы / as was fitting before renunciation.
- সাম্প্রদায়িক আচার্য্যকার্য্য → дело ачарьи сампрадаи / the work of an ācārya of the *sampradāya*.
- মৃতসঞ্জীবনী-মন্ত্র → мантра, воскрешающая мёртвых (мрита-санджавани) / the mantra that revives the dead (*mṛta-sañjīvanī*).
- পড়িছা → падичха / *paḍichā*; আঠারনালা → Атхаранала / Āṭhāranālā; নরেন্দ্র-সরোবর → Нарендра-саровара / Narendra-sarovara; কটক → Катак / Kaṭaka.
- চিদ্বৃত্তিস্ফূর্ত্তি → пробуждение духовного сознания / awakening of spiritual consciousness.
- [যথা রাগঃ] → [мелодия — любая подходящая] / [in any suitable melody]; ধ্রু (ধ্রুবপদ) — в стихе, не переводится.
- অমৃতসারবস্তু / অসার → «суть нектара» (амрита-сара-васту) / «лишённое сути» (асара) / “the essence of nectar” (*amṛta-sāra-vastu*) / “without essence” (*asāra*).
- থিয়সফিষ্ট দল → общество теософов / the Theosophical Society; প্রাকৃত বাউল → пракрита-баулы / the *prākṛta* Bāuls; শক্তি-উপাসক → почитатель Шакти / worshipper of Śakti; অবৈধ নাগরীর লম্পট → распутник с незаконными возлюбленными (нагари) — так у противников, Ану 264–266 / a libertine with illicit lovers (*nāgarīs*) — the opponents' view.
- গৌর-নাগর-লীলা → «гаура-нагара-лила» (в кавычках) / “Gaura-nāgara-līlā”; ‘নবগোরার দল’ → «община нового Горы» (Гора — разг. форма имени Гаура; сноска) / “the party of the new Gorā”.
- নিত্যসম্ভোগরসবিগ্রহ / নিত্যবিপ্রলম্ভরসবিগ্রহ → воплощение расы вечной самбхоги (Кришна) / вечной випраламбхи (Гаура) / the embodiment of the *rasa* of eternal *sambhoga* / *vipralambha*.
- পূর (ঘনদুগ্ধপূর) → «пура», начинка (из густого молока) / *pūra*, a filling (of thickened milk); সুকর্পূর → тонкая камфара / fine camphor; সুমাধুর্য্য → превосходная сладость / excellent sweetness.
- গৌরমন্ত্র → гаура-мантра / the Gaura-mantra; অসুরদল / দৈত্যদল → шайка асуров / дайтьев / the band of *asuras* / *daityas*; নাগরী-অভিমান → воображать себя нагари / imagining oneself a *nāgarī*.
- অনুপান (разночтение 271) → запивая [пищу] / with a drink (*anupāna*).
- শ্রীমন্মদনগোপাল, গোবিন্দদেব → Шриман Мадана-Гопала, Говинда-дева / Śrīman Madana-Gopāla, Govinda-deva.
- সমুদয়লোক (Ану 276) → все нечестивые, недостойные люди / all the wicked, unqualified people; সহৃদয়-সুমনস্ → бесхитростные мудрецы, всецело преданные / guileless sages, wholly devoted.
- Колофоны: *Так заканчивается двадцать пятая глава “Амрита-праваха-бхашьи”.* / *Thus ends the twenty-fifth chapter of the “Amṛta-pravāha-bhāṣya.”*; то же для “Анубхашьи” / “Anubhāṣya.” Строка ЧЧ «ইতি মধ্যলীলা সমাপ্তা» — часть текста стихов, в комментарий не перенесена.
