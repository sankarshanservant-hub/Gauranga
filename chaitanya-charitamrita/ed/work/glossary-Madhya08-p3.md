#### Термины (раса)
- পূর্ব্বরাগ → пурва-рага / *pūrva-rāga*; বিরাগ (в песне) → «вирага» — особая рага, рага разлуки, адхирудха-бхава / *virāga*.

- দশ দশা: লালসা, উদ্বেগ, জাগর্য্যা, তানব, জড়তা, ব্যগ্রতা, ব্যাধি, উন্মাদ, মোহ, মৃত্যু; চিন্তা, জাগর, মলিনাঙ্গতা, প্রলাপ → страстное желание (лаласа), тревога (удвега), бессонница (джагарья), исхудание (танава), оцепенение (джадата), нетерпение (вьяграта), недуг (вьядхи), безумие (унмада), обморок (моха), смерть (мритью); думы (чинта), бодрствование (джагара), нечистота тела (малинангата), бессвязные речи (пралапа) / intense longing (*lālasā*), anxiety (*udvega*), sleeplessness (*jāgaryā*), emaciation (*tānava*), numbness (*jaḍatā*), impatience (*vyagratā*), sickness (*vyādhi*), madness (*unmāda*), fainting (*moha*), death (*mṛtyu*); anxious thought (*cintā*), wakefulness (*jāgara*), uncleanliness of the body (*malināṅgatā*), incoherent speech (*pralāpa*).
- অভিলাষ, স্মৃতি, গুণকীর্ত্তন, সবিলাপ উন্মাদ → желание (абхилаша), воспоминание (смрити), восхваление качеств (гуна-киртана), безумие с причитаниями (савилапа унмада) / desire (*abhilāṣa*), remembrance (*smṛti*), praise of qualities (*guṇa-kīrtana*), madness with lamentation (*savilāpa unmāda*).

- রমণ / রমণী → наслаждающийся (рамана) / наслаждающая (рамани) / the enjoyer (*ramaṇa*) / the enjoyed one (*ramaṇī*).
- প্রেমবিলাস-বিবর্ত্ত → према-виласа-виварта / *prema-vilāsa-vivarta*; বিপ্রলম্ভে সম্ভোগস্ফূর্ত্তি → явление самбхоги посреди випраламбхи / the appearance of *sambhoga* in the midst of *vipralambha*.
- সর্পে রজ্জুভ্রম → «как змею принимают за верёвку» (так в издании) / “as one takes a snake for a rope.”

- কুঞ্জসেবা → служение в рощах (кунджа-сева) / service in the groves (*kuñja-sevā*); কান্তভাব → чувство возлюбленной (канта-бхава) / the mood of a beloved (*kānta-bhāva*).
- কাম / প্রেম (гопи) → «кама» (цель — счастье иного, не Кришны) / «према» (цель — только счастье Кришны); কৃষ্ণ-কাম → кама, обращённая к Кришне (кришна-кама) / *kāma* directed to Kṛṣṇa (*kṛṣṇa-kāma*). Нельзя: «вожделение/страсть» о любви гопи.
- রাগানুগা / রাগাত্মিকা ভক্তি → рагануга- / рагатмика-бхакти / *rāgānugā-* / *rāgātmikā-bhakti*; লোভ → жажда (лобха) / greed (*lobha*); চতুঃষষ্টি ভজনাঙ্গ → шестьдесят четыре части бхаджана / the sixty-four limbs of *bhajana*.
