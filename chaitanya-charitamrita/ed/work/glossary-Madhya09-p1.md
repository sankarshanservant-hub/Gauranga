# Новые термины — Мадхья 9, часть 1 (стихи 0–200; RU / EN)

#### Оформление
- Помета «(অঃ প্রঃ ভাঃ)» в конце «Краткого содержания» (подпись APB) — не переводится.
- Строки-источники над шлоками ЧЧ («(পদ্মপুরাণে শ্রীরামচন্দ্রের শতনামস্তোত্রে …)», «(শ্রীধরস্বামি-ধৃত …)») — часть стиха, в комментарий не переносятся.

#### Места (по «Краткому содержанию» и «Анубхашье»; где есть — как в Мадхья 1 «Анубхашья» 105–122)
- বিদ্যানগর → Видьянагар / Vidyānagara; গৌতমীগঙ্গা → Гаутами-Ганга / Gautamī-gaṅgā; মল্লিকার্জ্জুন(-তীর্থ) → Малликарджуна(-тиртха) / Mallikārjuna(-tīrtha); শ্রীশৈলম্ → Шришайлам / Śrīśailam; শ্রীশৈলপর্ব্বত → гора Шри Шайла / Śrī Śaila hill.
- অহোবল-নৃসিংহ → Ахобала-Нрисимха (как в Мадхья 1.106; у ВЧД в стихах «Аховала») / Ahobala-nṛsiṁha.
- সিদ্ধবট → Сиддхавата / Siddhavaṭa; ‘সিধৌট’ → «Сидхаут» / “Sidhout”; ‘দক্ষিণ কাশী’ → «Южная Каши» / “Southern Kāśī”; আশ্রম-বটবৃক্ষ → ашрама-ватаврикша (баньян при ашраме) / *āśrama-vaṭa-vṛkṣa*.
- স্কন্দক্ষেত্র → Сканда-кшетра / Skanda-kṣetra; ত্রিমঠ → Триматха / Trimaṭha; বৃদ্ধকাশী → Вриддхакаши / Vṛddhakāśī; বৌদ্ধস্থান → место буддистов / the place of the Buddhists.
- ত্রিপতি, ত্রিমল্ল → Трипати, Трималла / Tripati, Trimalla; পানা-নৃসিংহ → Пана-Нрисимха / Pānā-nṛsiṁha; শিবকাঞ্চী, বিষ্ণুকাঞ্চী → Шива-канчи, Вишну-канчи / Śiva-kāñcī, Viṣṇu-kāñcī; ত্রিকালহস্তী → Трикалахасти / Trikālahastī; বৃদ্ধকোল → Вриддхакола / Vṛddhakola; শিয়ালীভৈরবী → Шияли-Бхайрави / Śiyālī-bhairavī; কুম্ভকর্ণকপাল → Кумбхакарна-капала / Kumbhakarṇa-kapāla.
- শ্রীরঙ্গক্ষেত্র, শ্রীরঙ্গম্ → Шри Ранга-кшетра, Шрирангам / Śrī Raṅga-kṣetra, Śrīraṅgam; ঋষভপর্ব্বত → гора Ришабха / Ṛṣabha hill; কামকোষ্ঠিপুরী → Камакоштхи-пури / Kāmakoṣṭhī-purī; দক্ষিণ মথুরা → Южная Матхура / Southern Mathurā; কৃতমালা → Критамала / Kṛtamālā; মহেন্দ্রশৈল → гора Махендра / Mahendra hill; ধনুস্তীর্থ → Дханус-тиртха / Dhanus-tīrtha.
- পাণ্ড্যদেশ → страна Пандья / the land of Pāṇḍya; তাম্রপর্ণী → Тамрапарни / Tāmraparṇī; নয়ত্রিপদী → Ная-трипади / Naya-tripadī; চিয়ড়তলা → Чиядатала / Ciyaḍatalā; তিলকাঞ্চী → Тила-канчи / Tila-kāñcī; গজেন্দ্রমোক্ষণ → Гаджендра-мокшана / Gajendra-mokṣaṇa; পানাগড়ি → Панагади / Pānāgaḍi; চাম্তাপুর → Чамтапур / Cāmtāpura; শ্রীবৈকুণ্ঠ → Шри Вайкунтха / Śrī Vaikuṇṭha; মলয়পর্ব্বত → гора Малая / Malaya hill; কন্যাকুমারী → Каньякумари / Kanyākumārī; মল্লারদেশ → страна Маллара / the land of Mallāra.
- পয়স্বিনী → Паясвини / Payasvinī; শৃঙ্গবের-পুরীমঠ → матх Шрингавера-пури / the Śṛṅgavera-purī monastery; মৎস্যতীর্থ → Матсья-тиртха / Matsya-tīrtha; উড়ুপী → Удупи / Uḍupī; ফল্গুতীর্থ → Пхалгу-тиртха / Phalgu-tīrtha; ত্রিতকূপ → Трита-купа / Trita-kūpa; পঞ্চাপ্সরা → Панчапсара / Pañcāpsarā; সূর্পারক → Сурпарака / Sūrpāraka; কোলাপুর → Колапур / Kolāpura; পাণ্ডেরপুর → Пандарапур / Pāṇḍarapura; কৃষ্ণবেণ্বা → Кришнавенва / Kṛṣṇaveṇvā; তাপ্তী → Тапти / Tāptī; মাহিষ্মতীপুর → Махишмати-пура / Māhiṣmatī-pura; ঋষ্যমূকপর্ব্বত → гора Ришьямука / Ṛṣyamūka hill; দণ্ডকারণ্য → Дандакаранья / Daṇḍakāraṇya; সপ্ততাল → семь пальм (саптатала) / the seven palm trees (*sapta-tāla*); পম্পা-সরোবর → озеро Пампа / Pampā lake; পঞ্চবটী, নাসিক, ব্রহ্মগিরি, কুশাবর্ত → Панчавати, Насик, Брахмагири, Кушаварта / Pañcavaṭī, Nāsika, Brahmagiri, Kuśāvarta; শ্রীক্ষেত্র → Шри Кшетра / Śrī Kṣetra.
- ত্রিমন্দ, ঢুণ্ডিরাম-তীর্থ (по «Кадаче» Говинды даса, APB 14) → Триманда, Дхундирама-тиртха / Trimanda, Ḍhuṇḍirāma-tīrtha.
- কুর্ণুল, কুড়াপা; ‘কুর্ণুল ম্যানুয়েল’, ‘কুড়াপা-ম্যানুয়েল’ → Карнул, Кудапа; «Курнул-мануал», «Кудапа-мануал» / Kurnool, Cuddapah; *Kurnool Manual*, *Cuddapah Manual*; হায়দ্রাবাদ → Хайдарабад / Hyderabad.
- উত্তররাঢ়ী মঠ → Уттара-радхи-матх (как в Мадхья 1.114) / the Uttara-rāḍhī Maṭha.

#### Имена
- শ্রীব্যেঙ্কটভট্ট → Шри Венката Бхатта / Śrī Veṅkaṭa Bhaṭṭa; পরমানন্দ পুরী গোসাঞি → Парамананда Пури Госани / Paramānanda Purī Gosāñi; রামদাস বিপ্র → брахман Рамадас / the brāhmaṇa Rāmadāsa; শ্রীরঙ্গপুরী → Шри Рангапури / Śrī Raṅgapurī; শঙ্করারণ্য → Шанкараранья / Śaṅkarāraṇya; ভট্টথারী → бхаттатхари / Bhaṭṭathāris.
- শ্রীপদ্মনাভাচার্য্য (современный автор-таттвавади) → Шри Падманабхачарья / Śrī Padmanābhācārya; শ্রীনরহরিতীর্থপাদ → Шри Нарахари Тиртхапада / Śrī Narahari Tīrthapāda; ক্ষেমাকান্ত → «Кшемаканта» / “Kṣemakānta”; গজপতি-রাজগণ (উৎকল) → цари Гаджапати из Уткалы / the Gajapati kings of Utkala.
- রামদাস শম্ভু (подзаголовок 15) → Шамбху — слуга Рамы / Śambhu, the servant of Rāma.

#### Термины
- তত্ত্ববাদী; শুদ্ধদ্বৈতবাদ → таттвавади; шуддха-двайта-вада (учение о чистой двойственности) / Tattvavādī; *śuddha-dvaita-vāda*, the doctrine of pure duality.
- রামাৎ বৈষ্ণব; রামানন্দী, জমায়েৎ, রামাৎ (সম্প্রদায়) → вайшнавы-раматы; сампрадая «рамананди», «джамайет», или «рамат» / Rāmāt Vaiṣṇavas; the “Rāmānandī,” “Jamāyet,” or “Rāmāt” *sampradāya*.
- ব্রহ্মবৈষ্ণব → брахма-вайшнавы (Брахма-сампрадая) / Brahma Vaiṣṇavas; ব্রহ্মমোহন-লীলা → лила о том, как Брахма был введён в заблуждение / the pastime of Brahmā's bewilderment.
- শ্রীরামায়ণ-গুরু-করণ-পন্থা → путь «Шри Рамаяна-гуру-карана» (предположительно; сноска) / the path of “Śrī Rāmāyaṇa-guru-karaṇa.”
- জ্যোতির্লিঙ্গ → джьотирлинга / *jyotir-liṅga*; কর্ম্মবাদী → приверженцы карма-вады / followers of *karma-vāda*.
