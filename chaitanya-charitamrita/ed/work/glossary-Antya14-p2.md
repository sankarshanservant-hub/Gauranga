# Рабочий глоссарий: Антья 14, часть 2 (разделы 61–123; RU и EN)

## Термины
- উত্তান-নয়ন → уттана-найана, глаза закатились кверху / *uttāna-nayana*, the eyes rolled upward.
- তাত (о теле) → тата, тепло, показывающее, что жизнь ещё есть / *tāta*, the warmth that shows life is present.
- ক্যা কর কিবা = কেয়া করো, কেঁও → «кья кара киба» = «кея каро, кеон» (хиндустани: «Что делаете? Почему?») / *kyā kara kibā* = *keyā karo, keṁo* (Hindustani: “What are you doing? Why?”).
- পাণিশঙ্খ / পানী-শঙ্খ → па̄н̣и-ш́ан̇кха (раковина, которую держат в руке) / па̄нӣ-ш́ан̇кха (раковина [с водой] для ачаманы) / *pāṇi-śaṅkha* (a hand-held conch) / *pānī-śaṅkha* (a conch [of water] for *ācamana*).
- অপ্রাকৃত অধোক্ষজ-ভাবমুদ্রা → трансцендентные знаки чувств, обращённых к Адхокшадже / the transcendental signs of emotion for Adhokṣaja.
- অপ্রাকৃত অনুভূতি → трансцендентное постижение / transcendental realization.
- অদৃষ্টাশ্রুতপূর্ব্ব → невиданный и неслыханный прежде / never seen or heard of before.
- চটক-পর্ব্বত (Анубхашья 84) → высокий песчаный холм, похожий на гору; песчаная дюна / a high mound of sand that looks like a mountain; a sand dune.
- অষ্টসাত্ত্বিকবিকার → ашта-саттвика-викара, восемь духовных преображений / *aṣṭa-sāttvika-vikāra*, the eight spiritual transformations (перечень — как в общем глоссарии, строка «সাত্ত্বিক বিকার (৮)»).
- শ্রবণে (Анубхашья 100) → у самого уха / right at the ear.
- অর্দ্ধবাহ্য → полувнешнее сознание; «не обретя полного внешнего сознания» / half in external consciousness.
- নিপট্ট বাহ্য → полное внешнее сознание («внешнее сознание без покрова») / full (“uncovered”) external consciousness.
- শ্রীরাধা-কিঙ্করী-অভিমান → ощущая Себя служанкой Шри Радхи / feeling Himself a maidservant of Śrī Rādhā.
- করিয়া সাজনি → нарядившись / dressed and adorned.
- কন্দর → пещера / cave.
- অলৌকিক ও অপ্রাকৃত মহাভাব-লীলা-খেলা → необыкновенные, трансцендентные игры и забавы в махабхаве / extraordinary, transcendental pastimes and play in *mahābhāva*.
- মদয়তি (হর্ষয়তি, আনন্দয়তি — у Бхактисиддханты) → радует, наполняет блаженством / delights, fills with bliss; у Бхактивиноды (উন্মত্ত করিতেছেন) → сводит с ума / maddens.

## Имена и места
- চটকগিরি → Чатака-гири / Caṭaka-giri; গোবর্দ্ধনগিরিরাজ → Говардхана, царь холмов / Govardhana, the king of hills.
- ক্ষেত্র (Пури) → Кшетра / Kṣetra; নীলাচল, নীলাদ্রি → Нилачала / Nīlācala.
- পুরী, ভারতী → Пури, Бхарати (Парамананда Пури, Брахмананда Бхарати) / Purī, Bhāratī.
- স্তবাবলী, চৈতন্যস্তবকল্পবৃক্ষ → “Става-вали”, “Чайтанья-става-калпаврикша” / *Stavāvalī*, *Caitanya-stava-kalpavṛkṣa*.
