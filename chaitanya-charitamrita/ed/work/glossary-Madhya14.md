# Глоссарий комментариев к Мадхье 14 (RU / EN)

## Термины
- হেরাপঞ্চমী / হারাপঞ্চমী (у атибари) → Хера-панчами («херия» — увидев) / Хара-панчами («панчами потери») / Herā-pañcamī / Hārā-pañcamī
- লক্ষ্মীবিজয়োৎসব → праздник шествия Лакшми (виджая-утсава) / Lakṣmī's festival procession (*vijayotsava*)
- নবরাত্র-যাত্রা → нава-ратра-ятра (празднество девяти ночей) / *nava-rātra-yātrā*; পুনর্যাত্রা → обратное шествие (пунар-ятра) / return journey (*punar-yātrā*); ভিতর-বিজয় / বহির্বিজয় → бхитара-виджая / бахир-виджая / *bhitara-vijaya* / *bahir-vijaya*
- পট্টডোরী → шёлковые верёвки (патта-дори) / silken ropes (*paṭṭa-ḍorī*); যজমান (о поставщиках верёвок) → яджамана / *yajamāna*
- রত্নবেদী, জগমোহন → драгоценный алтарь (ратна-веди), джагамохана / jeweled altar (*ratna-vedī*), *jagamohana*
- স্নানভোগ → снана-бхога / *snāna-bhoga*; দনা-চুরি-লীলা → игра «похищения даны» (дана-чури-лила) / *danā-curi-līlā*
- সকড়ি / নি-সকড়ি → сакри / ни-сакри / *sakaḍi* / *ni-sakaḍi*
- Яства (Ану 26–34): биджа-тала, наранга, чхоланга, таба, камала, биджапура, чхохара, дракша, манохара, кширса, амрита-бханда, саравати, сара-бхаджа, сара-пури, хари-валлабха, сеунти, карпура, дал-марич-ладу, набат, амрити, чандраканти, бияри, кадма, тиле-кхаджа, такра, расала, кея-патра-дрони, дона / *bīja-tāla*, *nāraṅga*, *cholaṅga*, *ṭābā*, *kamalā*, *bījapūra*, *chohārā*, *drākṣā*, *manoharā*, *kṣīrasā*, *amṛta-bhaṇḍā*, *saravatī*, *sara-bhājā*, *sara-purī*, *hari-vallabha*, *seũti*, *karpūra*, *ḍāla-marica-lāḍu*, *nabāta*, *amṛti*, *candrakānti*, *biyaḍi*, *kadmā*, *tile-khājā*, *takra*, *rasālā*, *keyā-patra-droṇī*, *donā*
- জলমণ্ডুক-বাদ্য → джала-мандука-вадья / *jala-maṇḍuka-vādya*; খলি → жмых (кхали) / oil-cake (*khali*); গণ্ড-শৈল → небольшие холмы / small hills (*gaṇḍa-śaila*)
- গৌরনাগরীবাদ → учение «гаура-нагари» / the “Gaura-nāgarī” doctrine; পরদারাভিমর্ষণরূপ ভোক্তৃ-লীলা → игры наслаждающегося (бхокты) — сближение с чужими жёнами / pastimes as an enjoyer (*bhoktā*), approaching the wives of others; কিঙ্করী → служанка (кинкари) / maidservant (*kiṅkarī*)
- নায়িকা; মানিনী; ধীরা, অধীরা, ধীরাধীরা; মুগ্ধা, মধ্যা, প্রগল্ভা; বামা, দক্ষিণা; প্রখরা, মৃদ্বী, সমা → героиня (наика); в мане (манини); дхира, адхира, дхира-адхира; мугдха, мадхья, прагалбха; вама, дакшина; пракхара, мридви, сама / *nāyikā*; *māninī*; *dhīrā*, *adhīrā*, *dhīrādhīrā*; *mugdhā*, *madhyā*, *pragalbhā*; *vāmā*, *dakṣiṇā*; *prakharā*, *mṛdvī*, *samā*
- নায়িকা-ভেদ, যূথেশ্বরী-ভেদ, সখী-ভেদ → наика-бхеда, ютхешвари-бхеда, сакхи-бхеда / *nāyikā-bheda*, *yūtheśvarī-bheda*, *sakhī-bheda*
- সোল্লুণ্ঠ-বাক্য, ব্যাজস্তুতি, নিরসন, বৈদগ্ধ্য-বিভেদ → соллунтха-вакья, вьяджа-стути (хвала, за которой скрыт упрёк), нирасана (отпор), вайдагдхья-вибхеда (уловки) / *solluṇṭha-vākya*, *vyāja-stuti*, *nirasana*, *vaidagdhya-vibheda*
- রসাভাস: উপরস, অনুরস, অপরস → расабхаса: упараса, анураса, апараса / *rasābhāsa*: *uparasa*, *anurasa*, *aparasa*
- চিদ্রস, ভোক্তা / ভোগ্য, বিষয় / আশ্রয় → чид-раса, бхокта / бхогья, вишая / ашрая / *cid-rasa*, *bhoktā* / *bhogya*, *viṣaya* / *āśraya*
- সৌরত, সুরত-ব্যাপার → любовные игры (саурата) / love play (*saurata*) — только как духовные деяния (APB 158)
- অধিরূঢ় মহাভাব, রূঢ় ভাব → адхирудха-махабхава, рудха-бхава / *adhirūḍha-mahābhāva*, *rūḍha-bhāva*
- সাত্ত্বিক বিকার (৮): স্তম্ভ, স্বেদ, রোমাঞ্চ, স্বরভঙ্গ, বেপথু, বৈবর্ণ্য, অশ্রু, প্রলয় → оцепенение, пот, трепет волос, срыв голоса, дрожь, изменение цвета, слёзы, обморок (транслитерация в скобках) / becoming stunned, perspiration, hair standing on end, faltering voice, trembling, change of color, tears, fainting
- ব্যভিচারী / সঞ্চারী ভাব (৩৩) → вьябхичари / санчари-бхавы, названия транслитерацией / *vyabhicārī* / *sañcārī bhāvas*, names in transliteration
- বিংশতি ভাবালঙ্কার: অঙ্গজ, অযত্নজ (так в APB 167), স্বভাবজ → двадцать украшений-бхав: ангаджа (рождённые телом), айатнаджа (возникающие без усилий), свабхаваджа (рождённые природой) / *aṅgaja*, *ayatnaja*, *svabhāvaja*; মৌগ্ধ্য, চকিত → маугдхья, чакита / *maugdhya*, *cakita*
- কিলকিঞ্চিত; সঙ্করীকরণ → кила-кинчита; сочетание (санкарикарана) / *kila-kiñcita*; blending (*saṅkarīkaraṇa*); দানঘাটি, দানকেলি → дорога к переправе (дана-гхати), игра со сбором пошлины (дана-кели) / *dāna-ghāṭi*, *dāna-keli*
- ত্রিভঙ্গ → трибханга (изгиб в трёх местах) / *tribhaṅga*; কঞ্চুক / কাঁচুলি → корсаж (канчука, канчули) / bodice (*kañcuka*, *kā̃culi*)
- বিটিল (ধর্ম্মধ্বজী ভণ্ড) → витила (лицемер, выставляющий напоказ благочестие) / *viṭila* (a hypocrite who makes a show of piety)
- অধিকার-বিরোধ → несоответствие положению (адхикара-виродха) / *adhikāra-virodha*; রসবিরোধ → нарушение расы / disrupting the *rasa*
- শেষ-অধিষ্ঠান, দশমূর্ত্তি → обитель Анантадевы («Шеша»-адхиштхана), даша-мурти / *Śeṣa-adhiṣṭhāna*, *daśa-mūrti*

## Нельзя
- «обычная ревнивая жена» о Лакшми: «любящая Лакшми по самой своей природе вспыхивает гневом» (APB 132–133); асуя/ирша — «ревнивая досада», не «злоба».
- «страсть», «похоть» о любви гопи и о «саурате»: у Бхактивиноды (APB 158) всё это — духовные деяния, материальное их не касается.
- «Нарайяна» → только «Нараяна».
