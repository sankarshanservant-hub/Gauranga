# Новые термины: Антья 4, часть 2 (стихи 121–239)

Термин → RU / EN.

- কণ্ডুরস(া) → влага мокнущих язв (кандураса), как в ч. 1 / the fluid of oozing sores (*kaṇḍu-rasā*).
- লাল্য / লালক → лелеемый (лалья) / тот, кто лелеет (лалака), как в ч. 1 / the one cherished (*lālya*) / the one who cherishes (*lālaka*); লাল্যামেধ্য → нечистое у лелеемого / what is unclean in the one cherished.
- মর্য্যাদা (поведение, этикет) → марьяда, подобающее положение, должное почтение / *maryādā*, propriety, one's proper place; ব্যবহার-ভক্তি → проявление марьяды, благопристойности (шиштачары) / showing propriety, good manners (*śiṣṭācāra*).
- রাগমার্গীয় পরমহংস → парамахамса пути раги (рага-марга) / a *paramahaṁsa* on the path of spontaneous love (*rāga-mārga*); বৈধ অর্চ্চন-মার্গ → путь поклонения по предписаниям (вайдха-арчана-марга) / the path of Deity worship by regulation (*vaidha arcana-mārga*).
- মানদ / অমানী → почитающий других (манада) / свободный от гордости (амани) / one who honors others (*mānada*) / free of pride (*amānī*).
- দৈন্যবিগ্রহ → воплощённое смирение / the embodiment of humility.
- নির্ব্বিণ্ণ (APB 150) → исполненный нирведы, то есть отрешённости (вираги) / filled with *nirveda*, that is, detachment (*virāga*).
- প্রভুদত্ত দেশ → «край, данный Господом» / “the land given by the Lord”.
- অপ্রাকৃততনু, চিন্ময় দেহ, অপ্রাকৃত-স্বরূপ → трансцендентное (апракрита) тело, духовное (чинмая) тело, трансцендентный по природе / a transcendental (*aprākṛta*) body, a spiritual (*cinmaya*) body, transcendental by nature.
- ব্রহ্মবস্তু → духовная сущность (брахма-васту) / a spiritual entity (*brahma-vastu*).
- কামচার → телесное своеволие (камачара) / bodily license (*kāmacāra*).
- চিজ্জড়-সমন্বয়বাদ → учение о соединении духа и материи (чид-джада-саманвая-вада) / the doctrine that reconciles spirit and matter (*cij-jaḍa-samanvaya-vāda*).
- উপসম্প্রদায় → побочные общины (упасампрадаи) / offshoot sects (*upasampradāyas*); উত্তমাধিকারী → преданный высшего уровня (уттама-адхикари) / the highest devotee (*uttama-adhikārī*).
- অক্ষজ-দর্শন → видение, рождённое от чувств (акшаджа-даршана) / vision born of the senses (*akṣaja-darśana*).
- সঙ্কল্প-বিকল্প → принятие и отвержение (санкальпа-викальпа) / accepting and rejecting (*saṅkalpa-vikalpa*); দ্বিতীয়াভিনিবেশ → погружение во «второе» / absorption in a “second”.
- নির্গলিতার্থ → простой и сокровенный (букв. «выжатый») смысл / the plain essential meaning.
- যোগারূঢ় → утвердившийся в йоге (йога-арудха) / established in yoga (*yogārūḍha*); কূটস্থ → кутастха, неизменный / *kūṭastha*, unchanging.
- সুদর্শন (о видении) → прекрасное видение (сударшана; игра слов с диском Господа, сноска) / beautiful vision (*sudarśana*; a play on the Lord's disc, with a note); চিদ্বিলাস → духовная игра (чид-виласа) / a spiritual pastime (*cid-vilāsa*).
- অচ্যুতাত্মতা → «стать Ачьюте родным» (ачьютатмата) / becoming Acyuta's own (*acyutātmatā*).
- অস্মিতা → «я» (асмита) / sense of self (*asmitā*); ভাবসেবা → служение в бхаве / service in *bhāva*.
- পারিষদ-দেহ → тело спутника (паршады) / the body of an associate (*pārṣada*).
- চতুঃসম → чатухсама (смесь мускуса, сандала, кункумы и камфары; “Гаруда-пурана”, “Хари-бхакти-виласа”, 6.115) / *catuḥsama*.
- জনশৈথিল্য (подзаг. 216) → нерешительность (джана-шайтхилья), предположительно, со сноской / irresolution (*jana-śaithilya*), conjectural, with a note.
- শ্লোকগ্রন্থ-সংখ্যা → счёт в шлоках-грантхах / counting in *śloka-granthas*; লক্ষগ্রন্থ → сто тысяч грантх / a hundred thousand *granthas*.
- গ্রন্থচতুষ্টয় → четыре книги / the four books; দিগ্দর্শিনী → “Дигдаршини” / *Dig-darśinī*; লীলাস্তব → “Лила-става” / *Līlā-stava*; বৃহদ্বৈষ্ণবতোষণী → “Брихад-вайшнава-тошани” / *Bṛhad-vaiṣṇava-toṣaṇī*; ষট্সন্দর্ভ → “Шат-сандарбха” / *Ṣaṭ-sandarbha*.
- শ্রীসনাতনান্বয় শ্রীরূপানুগ → рупануги из рода Шри Санатаны / the *rūpānugas* of Śrī Sanātana's line.
- চতুর্ব্বিধ আজ্ঞা-সেবা → четыре вида служения по повелению Господа / the four kinds of service the Lord entrusted.
- Имена и места: Симха-двара (Львиные врата) / the Siṁha-dvāra (the Lion Gate); Балабхадра / Balabhadra; Дола-ятра / the Dola-yātrā; Шри Мадана-мохан / Śrī Madana-mohana.
