# Новые термины — Мадхья 21, комментарии, часть 1 (стихи 0–91)

### Madhya21-p1

#### Термины
- কর্ণিকা, কর্ণিকার (лотоса) → сердцевина (карника) / the whorl (*karṇikā*).
- আধার / আধেয় → вместилище / вмещаемое / the container / the contained.
- শুদ্ধসত্ত্বচিদ্বিলাসময় ভগবদ্বিগ্রহ → облик Бхагавана — игра духа в чистой благости (шуддха-саттве) / the form of Bhagavān, a spiritual play of pure goodness (*śuddha-sattva*).
- কুণ্ঠধর্ম্ম (в определении «Вайкунтхи») → ограниченность (кунтха-дхарма) / limitation (*kuṇṭha-dharma*).
- বশ্য জীব → джива, подвластная майе / the *jīva*, who is subject to *māyā*.
- গো-বৎস-হরণ → похищение телят (Брахмой) / the theft of the calves.
- অতন্নিরসন → отвержение «не того» (атан-нирасана), неустанное отрицание материи / rejecting “not this” (*atan-nirasana*), ceaseless negation of matter.
- অবধূত (в стихе 18) → потрясённый, взволнованный, переполненный, покорённый, сражённый / shaken, stirred, overflowing, overwhelmed, overcome.
- অযুত, লক্ষ, নিযুত, কোটি, অর্ব্বুদ, বৃন্দ, খর্ব্ব, নিখর্ব্ব, শঙ্খ, পদ্ম, সাগর, অন্ত্য, মধ্য, পরার্দ্ধ → айута, лакша, нийута, коти, арбуда, вринда, кхарва, никхарва, шанкха, падма, сагара, антья, мадхья, парардха (каждое вдесятеро больше предыдущего) / *ayuta*, *lakṣa* … *parārdha*.
- ত্র্যধীশ → Владыка трёх (трьядхиша) / the Lord of the three (*tryadhīśa*); ত্রিসর্গ → три творения (причинное, совокупное, индивидуальное) / the three creations.
- ব্যাহৃতিত্রয় (ভূঃ ভুবঃ স্বঃ) → три вьяхрити (бхух̣, бхувах̣, свах̣) / the three *vyāhṛtis*.
- চিরলোকপাল → извечные хранители миров (чира-локапалы: Брахма, Рудра и др.) / the age-old guardians of the worlds (*cira-loka-pālas*); অষ্টদিক্পাল → восемь хранителей сторон света / the eight guardians of the directions.
- অন্তরাবাস / মধ্যমাবাস / বাহ্যাবাস → внутренняя / срединная (как у ВЧД, ст. 47) / внешняя обитель / the inner / middle / outer abode (в ч. 2 — «средняя»).
- ত্রিপাদ্বিভূতি / একপাদবিভূতি / ত্রিপাদ্ভূত / ত্রিপাদৈশ্বর্য্য → трипад-вибхути / экапад-вибхути / трипад-бхута / трипад-айшварья / *tripād-vibhūti* / *ekapād-vibhūti* / *tripād-bhūta* / *tripād-aiśvarya*.
- জগল্লক্ষ্মী → Джагал-лакшми / Jagal-lakṣmī (хранит джив Деви-дхамы; её служанка — Майя).
- মহেশধাম → обитель Махеши (Шива-дхама) / the abode of Maheśa (Śiva-dhāma).
- তদুপবৈভব (в издании; понято как তদ্রূপবৈভব) → тад-рупа-вайбхава (величие, свойственное облику Господа) / *tad-rūpa-vaibhava*.
- প্রকোষ্ঠত্রয় (Гокула, Матхура, Дварака; в Гаура-лиле — Навадвипа, Шри Кшетра, Врадж) → три покоя (пракоштхи) / three chambers (*prakoṣṭhas*).
- খকক্ষা → орбита неба (кха-какша) / the orbit of the sky (*kha-kakṣā*); ব্রহ্মাণ্ড-কটাহ-সম্পুট → створки (две половины) чаши вселенной / the two halves of the bowl of the universe; অদৃশ্যদৃশ্যক-গিরি → гора видимая и невидимая / the mountain both visible and invisible.
- সূর্য্যসিদ্ধান্ত, সিদ্ধান্তশিরোমণি (গ্রহগণিত — মধ্যমাধিকার; গোলাধ্যায় — ভুবনকোশ) → “Сурья-сиддханта”, “Сиддханта-широмани” (“Граха-ганита” — “Мадхьямадхикара”; “Голадхьяя” — “Бхувана-коша”) / *Sūrya-siddhānta*, *Siddhānta-śiromaṇi*.
- গোস্বামিপাদ (автор стиха 45) → Госвамипада / the Gosvāmīpāda.
