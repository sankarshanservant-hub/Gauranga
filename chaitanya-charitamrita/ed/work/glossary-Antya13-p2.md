# Новые термины: Антья 13, часть 2 (стихи 71–139) — RU / EN

- সিজের বাড়ী → сиджера бади (изгородь из кустов сидж) / *sijera bāḍī* (a hedge of *sij* shrubs); মনসাসিজ, কাঁটাসিজ → манаса-сидж, колючий сидж / *manasā-sij*, the thorny *sij*; ফুলবাড়ী → пхул-бади (цветочный сад, уткал.) / *phul-bāḍī* (flower garden, Oriya).
- বিশ্বাসখানা → Вишваса-кхана (счётная палата правителя Гауды) / the *Viśvāsa-khānā* (accounts office of the ruler of Gauḍa).
- বৈষ্ণবপ্রায় → «почти вайшнав» (вайшнава-прая) / “almost a Vaiṣṇava” (*vaiṣṇava-prāya*).
- কাব্যপ্রকাশ; মম্মটভট্ট → “Кавья-пракаша”; Маммата Бхатта / *Kāvya-prakāśa*; Mammaṭa Bhaṭṭa. অলঙ্কার-গ্রন্থ → трактат о поэтических украшениях (аланкара-грантха) / a treatise on poetic ornament (*alaṅkāra-grantha*).
- রামানন্দী সম্প্রদায় (রামায়েৎ) → сампрадая Рамананди (рамаят) / the Rāmānandī *sampradāya* (Rāmāyet).
- নৈষ্ঠিক ব্রহ্মচারী; বৃহদ্ব্রতী → найштхика-брахмачари; хранящий великий обет (брихад-врату) / *naiṣṭhika-brahmacārī*; keeping the great vow (*bṛhad-vrata*).
- পট্টনায়ক-গোষ্ঠী → Паттанаяка-гоштхи (потомки Бхавананды) / *Paṭṭanāyaka-goṣṭhī* (the descendants of Bhavānanda).
- অত্যাহার, প্রয়াস, লৌল্য → излишество (атьяхара), чрезмерные усилия (праяса), жадность (лаулья) / excess (*atyāhāra*), overendeavour (*prayāsa*), greed (*laulya*).
- ভোক্তা পুরুষাভিমান → самомнение, будто ты — наслаждающийся мужчина (пуруша) / the conceit of being an enjoying male (*puruṣa*); স্ত্রৈণ → подвластный жене / ruled by one's wife.
- ছুটা-পান-বিড়া → чхута-пана-вида (бетель сам по себе, без пряностей) / *chuṭā-pāna-viḍā* (betel by itself, without spices).
- অষ্টসাত্ত্বিক ভাব → восемь саттвика-бхав (духовных преображений) / the eight *sāttvika-bhāvas* (spiritual transformations).
- রূপানুগবর → лучший из последователей Рупы (рупануг) / the best of the followers of Rūpa (*rūpānugas*); বিরক্তকুলচূড়ামণি → венец отрешённых / crest-jewel of the renounced.
- অর্দ্ধবাহ্যদশা → полувнешнее сознание / half in external consciousness; আত্মহারা → забывший Себя (себя) / having lost Himself (himself).
- গৌরনাগর-বাদ → учение «гаура-нагара» / the “Gaura-nāgara” doctrine.
- ধামপ্রাপ্তি (о родителях-вайшнавах) → достигли обители Господа / reached the Lord's abode.
- মধ্যমাধিকারী ভাগবত → бхагавата средней ступени (мадхьяма-адхикари) / a *bhāgavata* of the middle stage (*madhyama-adhikārī*).
- আউলায় → аулая: [ум] теряет опору, слабеет, в смятении, безумен / *āulāya*: [the mind] loses its hold, grows slack, agitated, mad.
- মননের কালে → во время памятования (смараны) / at the time of remembrance (*smaraṇa*).
- অব্যবহিত কৃষ্ণপ্রেম → ничем не заслонённая любовь к Кришне / unobstructed love for Kṛṣṇa.
