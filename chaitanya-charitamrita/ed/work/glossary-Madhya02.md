# Глоссарий к комментариям Мадхьи 2 (APB и «Анубхашья»): новые термины, имена, места (RU / EN)

Дополнение к `ed/GLOSSARY-commentary.md` (общий глоссарий не трогался). Формат: бенг./санскр. → RU / EN.

## Оформление
- «Амрита-праваха-бхашья» к Мадхье 2 / *Amṛta-pravāha-bhāṣya* on Madhya-līlā 2; колофон APB: *Так заканчивается вторая глава Мадхья-лилы в “Амрита-праваха-бхашье”.* / *Thus ends the second chapter of the Madhya-līlā in the “Amṛta-pravāha-bhāṣya.”* (в издании: «ইতি অমৃতপ্রবাহভাষ্যে মধ্যলীলা দ্বিতীয় পরিচ্ছেদ»).
- শ্লোকার্থ— (мелкая строка над бенгальским пересказом шлоки) → в подзаголовок: «Смысл шлоки —» / “The meaning of the verse —”.
- Строки-источники над шлоками ЧЧ («(জগন্নাথবল্লভনাটকে ৩য় অঃ ৯ শ্লোক)», «(গোস্বামি-পাদোক্ত-শ্লোক)» и т. п.) — часть стиха, в комментарий не переносятся.
- ভঃ রঃ সিঃ, দঃ বিঃ ৪র্থ লঃ → (Бхакти-расамрита-синдху, Дакшина-вибхага, 4-я лахари) / (*Bhakti-rasāmṛta-sindhu*, Southern Division, fourth wave); পঃ বিঃ → Пашчима-вибхага / Western Division; (ঐ) → (Там же) / (Ibid.).

## Термины
- বিচ্ছেদ (в шлоке 1 = глава) → глава / chapter (Бхактисиддханта: «অস্মিন্ বিচ্ছেদে» = в этой главе).
- প্রলাপ → бессвязные речи (пралапа) / incoherent words (*pralāpa*); উদ্ঘূর্ণা → удгхурна / *udghūrṇā*; চিত্রজল্প → читра-джалпа / *citra-jalpa*.
- বিপ্রলম্ভ → разлука (випраламбха) / separation (*vipralambha*); দিব্যোন্মাদ → дивьонмада, божественное безумие / *divyonmāda*, divine madness; মোহন → мохана / *mohana*.
- উদ্দীপন → пробуждение (о играх Враджа) / awakening; বিয়োগ → разлука / separation.
- গম্ভীরা → Гамбхира / the Gambhīrā; আলিন্দা → веранда (алинда) / veranda (*ālindā*); দালান → зала (далан) / hall (*dālān*).
- চটকপর্ব্বত → Чатака-Парват; чатака-парваты (песчаные холмы) / Caṭaka-parvata; *caṭaka-parvatas* (sand hills).
- জগমোহন → джагамохана / *jagamohana*; গরুড়স্তম্ভ → колонна Гаруды / the Garuḍa-stambha, the pillar of Garuḍa (не «статуя Гаруды»).
- বিতস্তি → витасти (пядь) / *vitasti* (a span).
- নাগররাজ → царь возлюбленных (нагара-раджа) / the king of lovers (*nāgara-rāja*).
- অগেয়ান → «агейан» — неразумная, слепая / *ageyān* — senseless, blind; উকাশিতে → освободиться / to free oneself; তনুহীন → бестелесный, Ананга / bodiless, Ananga.
- গুণ (игра слов «достоинство / верёвка») → верёвка достоинств (со сноской) / the rope of the qualities (with a note).
- ভোগরত (চক্ষু, কর্ণ…) → (глаза, уши…) «занятые наслаждением» / “engaged in enjoyment”; কৃষ্ণভোগ → вкушение Кришны / relishing Kṛṣṇa; ভোগাঙ্গ → органы, которыми наслаждаются / organs of enjoyment.
- দৈন্য / নির্ব্বেদ / বিষাদ → дайнья (смирение) / нирведа (горькое разочарование) / вишада (уныние) — *dainya* (humility) / *nirveda* (bitter despondency) / *viṣāda* (dejection).
- ব্যভিচারী / সঞ্চারী ভাব → вьябхичари-бхавы, «санчари» / *vyabhicārī-bhāvas*, *sañcārī*; স্থায়িভাব → стхайи-бхава / *sthāyi-bhāva*; সাত্ত্বিকানুভাব → саттвика-анубхавы / *sāttvika-anubhāvas*.
- সন্ধি (সরূপ, ভিন্নরূপ) → сандхи (сарупа-, бхинна-рупа) / *sandhi* (*sarūpa*, *bhinna-rūpa*); শাবল্য (শবলত্ব) → шабалья (шабалатва) / *śābalya* (*śabalatva*).
- ঔৎসুক্য, চাপল, রোষ (উগ্রতা), অমর্ষ → аутсукья (нетерпеливое желание), чапала (порывистость), роша (уграта, гнев), амарша (негодование) / *autsukya* (eagerness), *cāpala* (restlessness), *roṣa* (*ugratā*, anger), *amarṣa* (indignation).
- উন্মাদ → унмада (безумие) / *unmāda* (madness); প্রণয় → пранайа / *praṇaya*; মান → мана / *māna*; সম্ভ্রম → почтительный трепет (самбхрама) / reverential awe (*sambhrama*); স্নেহ → снеха / *sneha*.
- স্তম্ভ, কম্প (বেপথু), স্বেদ, বৈবর্ণ্য, অশ্রু, গদ্গদ (বৈস্বর্য্য, স্বরভেদ), পুলক (রোমাঞ্চ) → стамбха (оцепенение), кампа (вепатху, дрожь), сведа (пот), вайварнья (бледность), ашру (слёзы), гадгада (вайсварья, свара-бхеда; прерывающийся голос), пулака (романча; волоски дыбом) / *stambha*, *kampa* (*vepathu*), *sveda*, *vaivarṇya*, *aśru*, *gadgada* (*vaisvarya*, *svara-bheda*), *pulaka* (*romāñca*).
- অবলম্বন / আলম্বন → аваламбана / аламбана / *avalambana* / *ālambana*; সেব্য বিষয় / সেবক আশ্রয় → вишая (тот, кому служат) / ашрая (слуга) / the *viṣaya* (the one served) / the *āśraya* (the servant).
- অনুরাগ → анурага / *anurāga*; বৈদগ্ধ্য → вайдагдхья (ловкость, учёность, расикность, хитроумие, изящество) / *vaidagdhya*; সোল্লুণ্ঠ → соллунтха, порицание в словах похвалы / *solluṇṭha*, censure in words of praise.
- প্রেমচিন্তামণি → чинтамани премы / the *cintāmaṇi* of *prema*.
- সহজ বস্তু, সহজতত্ত্ব → сахаджа-васту (естественная реальность), сахаджа-таттва (естественная истина) / *sahaja-vastu* (the natural reality), *sahaja-tattva* (the natural truth); রাগতত্ত্ব / বিচারতত্ত্ব → истина раги / путь рассуждения / the truth of *rāga* / the path of reasoning; রাগোদ্দেশ → направленность раги / the orientation of *rāga*; রাগানুগ → рагануга / *rāgānuga*.
- সহজিয়া, বাউল → «сахаджии», «баулы» / *sahajiyās*, *bāuls*.
- কড়চাসূত্র → сутры дневника (кадачи) / *sūtras* of the diary (*kaḍacā*); ভেটে → в подарок / as a gift; লাজবীজ খাঞা → отбросив всякий стыд (досл. «съев зерно стыда») / casting off all shame.
- শ্রৌতপন্থা → путь шрауты (знания, нисходящего по цепи слушания) / the path of *śrauta*.
- ভজনবিজ্ঞ, ভজনশীল, কৃষ্ণনামে দীক্ষিত কৃষ্ণনামকারী → «знающие бхаджан», «совершающие бхаджан», «получившие посвящение в имя Кришны и повторяющие его» / “expert in *bhajana*,” “engaged in *bhajana*,” “initiated into Kṛṣṇa's name and chanting it”; তর্কনিষ্ঠ কনিষ্ঠ-ভক্ত → неопытный преданный, преданный спорам / a neophyte devotee devoted to argument.
- মুহূর্ত্ত, ঘটী, পল, বিপল → мухурта, гхати, пала, випала / *muhūrta*, *ghaṭī*, *pala*, *vipala*.
