## Имена и Божества
- মাধবপুরী (так в издании, напр. в «Кратком содержании», ст. 20, 21) → Мадхава Пури (= Мадхавендра Пури; APB 20 сама это поясняет) / Mādhava Purī.
- যতিরাজ (о Мадхавендре) → царь аскетов (ятираджа) / the king of ascetics (*yatirāja*); শ্রীপুরীপাদ → Шри Пурипада / Śrī Purīpāda; পুরীগোসাঞি / পুরীগোস্বামী → Пури Госани / Пури Госвами / Purī Gosāñi / Purī Gosvāmī.
- লক্ষ্মীপতি → Лакшмипати (гуру Мадхавендры) / Lakṣmīpati.
- বজ্র → Ваджра (сын Анируддхи, правнук Кришны; установил Гопалу) / Vajra.
- গোবর্দ্ধনধারী, গিরিধারী → Держащий Говардхану; Гиридхари / the Holder of Govardhana; Giridhārī. শ্রীগোপালদেব → Шри Гопаладева / Śrī Gopāladeva.
- ক্ষীরচোরা গোপীনাথ → «Кширачора Гопинатха» (род. Гопинатхи) / “Kṣīra-corā Gopīnātha”.
- রসিকানন্দ প্রভু, শ্যামানন্দ প্রভু → Расикананда Прабху, Шьямананда Прабху / Rasikānanda Prabhu, Śyāmānanda Prabhu.
- উদ্ধব → Уддхава / Uddhava; মধুসূদন → Мадхусудана / Madhusūdana.

## Места (без осовременивания)
- বৃদ্ধমন্ত্রেশ্বর → Вриддха-Мантрешвар / Vṛddha-mantreśvara.
- বালেশ্বর → Балешвар / Bāleśvara; রেমুণা → Ремуна / Remuṇā.
- মেদিনীপুর জেলা → округ Мединипур / the Medinīpura district.
- মলয়দেশ, মালাবার, চন্দনগিরি, পশ্চিমঘাট, নীলগিরি → страна Малая, Малабар, «Чандана-гири», «Западные Гхаты», Нилагири / the land of Malaya, Malabar, “Candana-giri,” the “Western Ghats,” the Nilgiris.
- গোবিন্দকুণ্ড → Говинда-кунда / Govinda-kuṇḍa; শৈল (= Говардхана) → холм / hill (*śaila*).

## Термины
- ক্ষীর → кшира (параманна, сладкий рис) / *kṣīra* (*paramānna*, sweet rice); ক্ষীরপ্রসাদ → кшира-прасад / *kṣīra-prasāda*; পায়স → паяса / *pāyasa*.
- অন্নকূট → Аннакута («гора риса»; кута — крепость, твердыня, гора) / Annakūṭa (*kūṭa* — fortress, stronghold, mountain).
- মলয়জ চন্দন → сандал малаяджа / *malayaja* sandalwood; শ্রীকর্পূর → камфара (шри-карпура) / camphor (*śrī-karpūra*).
- মণ, তোলা, পল → ман, тола, пала (1 пала = 4 толы; 2000 пал = 2½ мана) / maund, *tolā*, *pala*.
- ক্রোশ, যোজন → кроша, йоджана / *krośa*, *yojana*.
- মহাস্নান → махаснана / *mahā-snāna*; অভ্যঙ্গ → абхьянга (умащение) / *abhyaṅga*; সম্মার্জ্জন → саммарджана (очищение) / *sammārjana*; উদ্বর্ত্তন / আবাটা → удвартана, «абата» (растирание пастой) / *udvartana*, *ābāṭā*; কূর্চ্চ → щётка-курча / brush (*kūrca*); উশীর → ушира / *uśīra*; লোধ্র → лодхра / *lodhra*.
- পঞ্চগব্য / পঞ্চামৃত → панча-гавья / панчамрита / *pañca-gavya* / *pañcāmṛta*; শঙ্খোদক, গন্ধোদক → шанкходака, гандходака / *śaṅkhodaka*, *gandhodaka*.
- দেবপ্রতিমা → Божество (пратима) / the Deity (*pratimā*) — не «статуя».
- মূলমন্ত্র, অষ্টাক্ষর → мула-мантра (восьмисложная) / the *mūla-mantra*, the eight-syllable mantra.
- মাঠা, শিখরিণী, মথনি, নবনীত, হৈয়ঙ্গব → матха (пахта, гхол), шикхарини, матхани, наванита, хайянгава / *māṭhā* (buttermilk, *ghola*), *śikhariṇī*, *mathani*, *navanīta*, *haiyaṅgava*.
- সংযাব, অপূপ, শষ্কুলী → самьява, апупа, шашкули / *saṁyāva*, *āpūpa*, *śaṣkulī*; স্বস্ত্যয়ন → свастьяяна / *svastyayana*.
- বিড়ক → видака (свёрток пана) / *viḍaka* (roll of betel); শীতল-ভোগ → шитала-бхога / *śītala-bhoga*.
- দানী → дани: в APB 12 — перевозчики на переправах, в APB 153 — берущие плату за переправу / *dānī*; ঘাটী → гхати, гхатвалы (собирающие дорожную пошлину) / *ghāṭī*, *ghāṭoyāls*; জগাতি → джагати, джагаиты (под видом стражи не спят на дорогах) / *jagāti*, *jagāitas*; রাজলেখা, পরওয়ানা → царская грамота (раджа-лекха), парвана / royal letter (*rāja-lekhā*), *paravānā*; সম্বল → самбала (деньги на дорогу) / *sambala*.
- বট, কপর্দক → бата (каури), капардака / *baṭa*, *kapardaka*; বাট (уткальское слово) → бата (путь) / *bāṭa* (road).
- মঠ → матх (храм) / *maṭha* (temple); জগমোহন → джагамохана / *jagamohana*.
- মানদ-ধর্ম্ম → смирение того, кто воздаёт честь другим (манада-дхарма) / the humility of giving honor to others (*mānada-dharma*).
- প্রতিষ্ঠা → слава (пратиштха) / fame (*pratiṣṭhā*); মৎসর → завистливый (матсара) / envious (*matsara*); তদীয় ভক্ত → Свой преданный (тадия-бхакта) / His own devotee (*tadīya-bhakta*).
- পারমহংস্য-অবস্থা (সহজ) → естественное состояние парамахамсы / the natural state of a *paramahaṁsa*; উদাস / উদাসীন → удас, удасин (безразличный, беспристрастный) / *udāsa*, *udāsīna*.
- ষড়্গুণ (বিজিত-ষড়্গুণ) → шесть свойств (шад-гуна) — так в издании / the six qualities (*ṣaḍ-guṇa*).
- গ্রাম্যবার্ত্তা → грамья-варта / *grāmya-vārtā*; রাজস → раджасный / *rājasic*.
- চাতুর্ম্মাস্য → чатурмасья / *cāturmāsya*; শয়ন-একাদশী, উত্থান-একাদশী → Шаяна-экадаши, Уттхана-экадаши / Śayana Ekādaśī, Utthāna Ekādaśī; শাক, আমিষ → шака (зелень), амиша / *śāka* (greens), *āmiṣa*.
- চিদ্বিপ্রলম্ভ → духовная випраламбха / spiritual *vipralambha*; নির্ব্বেদ → нирведа / *nirveda*; কৃষ্ণেন্দ্রিয়প্রীতিবাঞ্ছা → желание доставить радость чувствам Кришны / the desire to please Kṛṣṇa's senses; মূল-মহাজন → изначальный махаджана / the original *mahājana*.
- দ্বিতীয়াভিনিবেশ → погружённость во «второе» (двития-абхинивеша) / absorption in “the second” (*dvitīyābhiniveśa*).
- জাড্য → джадья (утрата способности рассуждать; до и после мохи) / *jāḍya*; মোহ → моха (беспамятство) / *moha* (unconsciousness).
- শৃঙ্গার-রসময়ী ভক্তি → бхакти, исполненная шрингара-расы / devotion imbued with *śṛṅgāra-rasa*; ভাববৈচিত্র্য → разнообразие чувств (бхава-вайчитрья) / variety of feelings (*bhāva-vaicitrya*); সাধারণী → садхарани (обычная возлюбленная) / *sādhāraṇī*.
- শৃঙ্গার-রসতরুর মূল / প্ররোহ / মূলস্কন্ধ / শাখা-প্রশাখা → корень / росток / ствол / ветви и побеги древа шрингара-расы / root / sprout / trunk / branches and twigs.
- Гуру и дикша (Ану 111): দৈক্ষ-ব্রাহ্মণতা → брахманство по посвящению (дайкша-) / *daikṣa* brāhmaṇa status; শৌক্র-বিপ্রত্ব / শৌক্র-শূদ্রত্ব → шаукра-випратва / шаукра-шудратва / *śaukra-vipratva* / *śaukra-śūdratva*; সাবিত্র / দৈক্ষ্য → савитрья / дайкшья / *sāvitrya* / *daikṣya*; গৃহস্থগুরু → гуру-домохозяин / householder guru; গৃহব্রত → грихаврата / *gṛhavrata*; পারমার্থিক গুরু → парамартхика-гуру / *pāramārthika-guru*; উপচার → упачары / *upacāras*.
