#### Имена и места
- বালিসাহি → квартал Балисахи / the Bālisāhi quarter; শ্রীরাধাকান্তমঠ → Шри Радхаканта-матх (дом Каши Мишры) / Śrī Rādhākānta Maṭha.
- বাণীনাথ পট্টনায়ক → Ванинатха Паттанаяка / Vāṇīnātha Paṭṭanāyaka; গোপীনাথ, কলানিধি, সুধানিধি → Гопинатха, Каланидхи, Судханидхи / Gopīnātha, Kalānidhi, Sudhānidhi.
- কমলাকান্ত (দ্বিজ) → брахман Камалаканта / the brāhmaṇa Kamalākānta; চৈতন্যানন্দ (гуру Сварупы) → Чайтаньянанда / Caitanyānanda.
- চুল্লিভট্ট → Чулли Бхатта / Culli Bhaṭṭa.
- জনার্দ্দন, চন্দনেশ্বর, সিংহেশ্বর, বিষ্ণুদাস, মুরারি মাহাতি → Джанардана, Чанданешвара, Симхешвара, Вишнудас, Мурари Махити / Janārdana, Candaneśvara, Siṁheśvara, Viṣṇudāsa, Murāri Māhiti.

#### Термины
- প্রভুপাদ / ওঁ বিষ্ণুপাদ / শ্রীপাদ → «Прабхупада» / «Ом Вишнупада» / «Шрипада» / “Prabhupāda” / “Oṁ Viṣṇupāda” / “Śrīpāda”.
- গোস্বামিব্রুব → «госвами» лишь по названию (госвами-брувы) / *gosvāmīs* in name only (*gosvāmi-bruvas*).
- চর্ম্মাম্বর → одеяние из шкуры / garment of skin.
- অনবসর, স্নানযাত্রা, নবযৌবন → анавасара, Снана-ятра, «Нава-яувана» (даршан) / *anavasara*, the Snāna-yātrā, the “Nava-yauvana” *darśana*.
- লিখনাধিকারী, দেউলকরণ, মাত্লা-পাঁজি → ликхана-адхикари, деула-карана, «Матла-панджи» (храмовая летопись, «Мадала-панджи») / *likhana-adhikārī*, *deula-karaṇa*, the *Mātlā-pāñji* (*Mādalā-pāñji*).
- মহাসোয়ার, মহাসূপকার → маха-соара, маха-супакара (главный повар) / *mahā-soyāra*, *mahā-sūpakāra* (chief cook).
- প্রহররাজ (পহরাজ) → прахараджа (пахараджа) / *praharāja* (*paharāja*).
