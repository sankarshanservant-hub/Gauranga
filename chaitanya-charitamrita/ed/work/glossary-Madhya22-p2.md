# Новые термины — Мадхья 22, часть 2 (стихи 91–164)

- অকিঞ্চন (ভক্ত) / শরণাগত (ভক্ত) → акинчана (тот, у кого нет ничего, кроме Кришны) / шаранагата / *akiñcana* (one who has nothing but Kṛṣṇa) / *śaraṇāgata*.
- আত্মসমর্পণ → самопредание (атма-самарпана) / offering of the self (*ātma-samarpaṇa*).
- আনুকূল্যস্য সঙ্কল্প / প্রাতিকূল্যবিবর্জ্জন / গোপ্তৃত্বে বরণ / আত্মনিক্ষেপ / কার্পণ্য → анукулья-санкальпа / пратикулья-виварджана / принятие Кришны хранителем (гопта) / атма-никшепа / карпанья (сознание своего ничтожества) / *ānukūlya-saṅkalpa* / *prātikūlya-vivarjana* / accepting Kṛṣṇa as maintainer (*goptā*) / *ātma-nikṣepa* / *kārpaṇya* (considering oneself lowly).
- অঙ্গ / অঙ্গী (শরণাগতি, Бхакти-сандарбха 236) → части / целое (анги / ангин) / limbs / the whole (*aṅga* / *aṅgī*).
- কৃষ্ণাভিন্ন (вайшнав) → неотличен от Кришны / nondifferent from Kṛṣṇa.
- কাকুভাষণ → жалобная мольба / plaintive prayer.
- কৃতিসাধ্যা / সাধ্যভাবা / সাধ্যতা → достижимая действием (крити) / то, чем достигается бхава / достижимость садханой (садхьята) / attainable by action (*kṛti-sādhyā*) / that by which *bhāva* is attained / attainability (*sādhyatā*).
- স্বরূপ-লক্ষণ / তটস্থ-লক্ষণ (бхакти) → сущностный признак (сварупа-лакшана) / сопутствующий признак (татастха-лакшана) / the essential / the accompanying characteristic.
- বিধি / নিষেধ → предписание (видхи) / запрет (нишедха) / injunction (*vidhi*) / prohibition (*niṣedha*).
- ব্যতিরেকভাবে (অনুষ্ঠান) → от противного (вьятирекой) / negatively (*vyatireka*).
- কলাভ্যাস → изучение понемногу («кала», частично) / piecemeal study (*kalā*); ব্যাখ্যাবাদ → толкования ради спора / explanations for argument's sake.
- গ্রাম্যবার্ত্তা → грамья-варта (мирские, домашние разговоры) / *grāmya-vārtā* (mundane household talk).
- ব্যবহারে অকার্পণ্য / মহারম্ভের অনুদ্যম → отсутствие скупости в делах (акарпанья) / отказ от больших начинаний / freedom from miserliness in dealings (*akārpaṇya*) / not undertaking great enterprises.
- ধাত্রী, অশ্বত্থ → дхатри (амалаки), ашваттха / the *dhātrī* (*āmalakī*), the *aśvattha*.
- বিজ্ঞপ্তি, অভ্যুত্থান, অনুব্রজ্যা → вигьяпти (открывать сердце), абхьюттхана, анувраджья / *vijñapti*, *abhyutthāna*, *anuvrajyā*.
- নির্ম্মাল্য, চরণামৃত → нирмалья (остатки подношений), чаранамрита / *nirmālya*, *caraṇāmṛta*.
- তদীয় → тадия (принадлежащее Ему) / *tadīya*.
- দৈব-বর্ণাশ্রম-ধর্ম্ম → дайва-варнашрама-дхарма / *daiva-varṇāśrama-dharma*.
- দ্বিতীয়াভিনিবেশ → поглощённость «вторым», иным / absorption in the “second,” in what is other.
- স্নিগ্ধ (সাধু) / সজাতীয়াশয় → полный любви (снигдха) / с желаниями того же рода / full of affection (*snigdha*) / with desires of the same kind (*sajātīyāśaya*).
- রসিক → садху-расики, сведущие в служении Кришне / *rasika* sādhus.
- বৈয়াকরণ, শাব্দিক, বেষোপজীবী, মন্ত্রজীবী, ভাগবতজীবী → вайякарана (грамматист), шабдика (знаток одних слов), живущий облачением, живущий мантрами, живущий “Бхагаватам” / a grammarian, a *śābdika*, one who lives by his garb, by mantras, by the *Bhāgavatam*.
- দাক্ষিণাত্য → юг (Дакшинатья) / the South (Dākṣiṇātya); শ্রীক্ষেত্র → Шри Кшетра / Śrī Kṣetra.
- বিষ্ণুরাত / ব্রহ্মরাত → Вишнурата (Парикшит) / Брахмарата (Шукадева) / Viṣṇurāta / Brahmarāta.
- পঞ্চযজ্ঞ → пять жертвоприношений (панча-ягья) / the five sacrifices (*pañca-yajña*).
- নিষ্কিঞ্চন → нишкинчана (тот, у кого нет ничего, кроме Кришны) / *niṣkiñcana*.
- বিকর্ম্ম → викарма (грех, запретное действие) / *vikarma* (sin, forbidden act).
- দেব-, ঋষি-, পিতৃ-, ভূত-, মনুষ্য-ঋণ; দেব-, ব্রহ্ম- (ঋষি-), পিতৃ-, ভূত-, নৃ-যজ্ঞ → долг богам, риши, предкам, существам, людям; дэва-, брахма- (риши-), питри-, бхута-, нри-ягья / the debts to the gods, sages, ancestors, beings, men; *deva-*, *brahma-* (*ṛṣi-*), *pitṛ-*, *bhūta-*, *nṛ-yajña*.
- নবযোগেন্দ্র → девять Йогендр / the nine Yogendras; করভাজন → Карабхаджана / Karabhājana.
- মনোধর্ম্ম / আত্মধর্ম্ম → свойство ума / свойство души / a property of the mind / of the soul.
- কর্ম্মজ বিরাগ / বৈরাগ্য → отрешённость, рождённая кармой / detachment born of *karma*.
- ভেদবুদ্ধি → чувство разделённости / the sense of separateness.
- রাগাত্মিকা ভক্তি — «главная» (মুখ্যা) → главная (мукхья) / principal (*mukhyā*); তন্ময়ী → танмайи (исполненная [раги]) / *tanmayī*.
- গাঢ়তৃষ্ণা / আবিষ্টতা → глубокая жажда / поглощённость / deep thirst / absorption.
- জাতরুচি / অজাতরুচি → в ком пробудился вкус (джата-ручи) / лишённые пробудившегося вкуса (аджата-ручи) / *jāta-ruci* / *ajāta-ruci*.
- প্রাকৃত-সহজিয়া → пракрита-сахаджии / *prākṛta-sahajiyās*; শ্রীরূপানুগ পথ → путь, следующий Шри Рупе / the path that follows Śrī Rūpa.
- লোভোৎপত্তিলক্ষণ → признак рождения жажды (лобхи) / the sign that greed (*lobha*) has arisen.
- সাধকরূপ / সিদ্ধরূপ (সিদ্ধদেহ) → облик (тело) садхаки / облик сиддхи (сиддха-деха) / the form (body) of a *sādhaka* / of a *siddha* (*siddha-deha*); স্বরূপসিদ্ধি → сварупа-сиддхи / *svarūpa-siddhi*.
- নিরস্তানর্থ → избавившийся от анартх / freed from *anarthas*; গুর্ব্বানুগত্য → следование гуру / allegiance to the guru.
- অন্তর্ম্মনা → обратив ум внутрь / with the mind turned within.
- শান্তরূপে (Бхаг. 3.25.38): APB — звательный («о мать с умиротворённым обликом»), Ану — местный («во Мне… или в Вайкунтхе») / vocative in APB, locative in the *Anubhāṣya*.
- ভগবান্ মৈত্রেয় ঋষি → Бхагаван (почтенный) Майтрея-риши / the venerable (*bhagavān*) sage Maitreya.
- প্রীত্যঙ্কুর → росток прити (любви) / the sprout of *prīti*; অস্ফুটাবস্থা (প্রেমের) → неразвившееся состояние / the unblossomed state.
- কৃষ্ণপ্রেমসেবা → служение Кришне в любви (кришна-према-сева) / loving service to Kṛṣṇa (*kṛṣṇa-prema-sevā*).
- গুরুশাসন-বলে (বৈধী) → силой наставлений гуру / by the force of the guru's instructions (о вайдхи-бхакти; рагануга идёт силой пробудившегося вкуса, но — по подзаголовкам 154, 159 — всякий миг следуя гуру).
