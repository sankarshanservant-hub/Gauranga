# Новые термины — Антья 18, комментарии, часть 1 (стихи 0–55; RU / EN)

#### Термины
- জলকেলি; জলক্রীড়া → водные игры (джала-кели) / water pastimes (*jala-keli*).
- প্রেমাবেশ (о рыбаке, АПБ 0) → охватила божественная любовь (премавеша) / overcome by divine love (*premāveśa*).
- ওঝা → знахарь (как в переводе стихов) / exorcist.
- কৃষ্ণনামের চাপড় → хлопок имени Кришны / a slap of Kṛṣṇa's name.
- লোক-ধর্ম্মাতীত; অতিক্রান্তলোকমর্য্যাদ (о Кришне, 25) → стоящий выше мирских законов; преступивший пределы мирских правил / beyond worldly codes; having transgressed the bounds of worldly convention.
- গন্ধর্ব্বপ (গন্ধর্ব্বপতি) → цари гандхарвов / the lords of the Gandharvas.
- ভিন্নসেতু (বিদারিতবপ্র) → прорвавший насыпь / having broken through the embankment.
- কুন্দমালা → гирлянда из цветов кунды / a garland of *kunda* flowers.
- হর্ষ / বিষাদ (Ану 9) → радость / скорбь / joy / sorrow; সম্ভোগ-লীলা / বিপ্রলম্ভ-লীলা → игры единения (самбхоги) / игры разлуки (випраламбхи) / pastimes of union (*sambhoga*) / of separation (*vipralambha*).
- উদ্দীপন (подзаг. 4) → пробуждает (уддипана) / awakens (*uddīpana*).
- চিৎপরমাণু-কণ → крупица, духовный атом (чит-параману) / a particle, a spiritual atom (*cit-paramāṇu*).
- কৃষ্ণশক্তিবর্গ → сонм энергий Кришны / the host of Kṛṣṇa's potencies.
- গোপী-কিঙ্করী-অভিমানী → считающий Себя служанкой гопи / thinking Himself a maidservant of the gopīs.
- উদ্ঘূর্ণা → удгхурна / *udghūrṇā* (как в общем глоссарии).
- নিরঙ্কুশ ইচ্ছাশক্তি → ничем не скованная энергия воли / unrestrained power of will.
- অন্তর্দ্ধান (подзаг. 38) → «ушёл» (антардхана), не «сокрылся» / departed (*antardhāna*).
- গ্রহাবিষ্ট ধীবর → рыбак, «одержимый духом» (в кавычках: домысел рыбака) / the fisherman, “possessed by a spirit.”
- ধীবর, জালিয়া → рыбак / fisherman.
- জীবে (55) → будет жить / will live.

#### Имена, места, источники
- কোণার্ক → Конарк / Koṇārka; অর্কতীর্থ → Арка-тиртха / Arka-tīrtha; কণারক → «Канарак» / “Kaṇārak.”
- চিরায়ু-পর্ব্বত → Чираю-парват (= Чатака-Парват) / Cirāyu-parvata (= Caṭaka-parvata).
- আইটোটা → Айтота / Āiṭoṭā (как в общем глоссарии).
- অভিজ্ঞানশকুন্তল-নাটক, ৪র্থ অঙ্ক; প্রিয়ম্বদা → “Абхигьяна-шакунтала”, действие 4; Приямвада / *Abhijñāna-śakuntala*, Act 4; Priyaṁvadā.
- রামরায় (подзаг. 22) → Рама Рай / Rāma Rāya.
- শ্রীশুকদেব; পরীক্ষিৎ → Шри Шукадева; Парикшит / Śrī Śukadeva; Parīkṣit.

#### Оформление
