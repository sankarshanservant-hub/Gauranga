# Новые термины — Мадхья 24, часть 3 (комментарии, стихи 231–350)

Согласовано с `glossary-Madhya24-p1.md` и `glossary-Madhya24-p2.md` (Мригари, мудрец Парвата, самуччая, авадхарана, итаретара, экашеша).

## Виды атмарам (32 вида, Ану 278–286)
- বৈধভক্ত / রাগভক্ত → вайдха-бхакта / рага-бхакта / *vaidha-bhakta* / *rāga-bhakta*; বৈধী / রাগময়ী ভক্তি → вайдхи- / рагамайи-бхакти / *vaidhī-* / *rāgamayī-bhakti*.
- নিত্যসিদ্ধ পারিষদ, সাধনসিদ্ধ, জাতরতি সাধক, অজাতরতি সাধক → нитья-сиддха паршада (вечно совершенный спутник), садхана-сиддха, джата-рати-садхака (садхака, в котором пробудилась рати), аджата-рати-садхака / the eternally perfect *pārṣada*, the *sādhana-siddha*, the *jāta-rati sādhaka*, the *ajāta-rati sādhaka*.
- দাস, সখা, পিত্রাদি গুরু, কান্তা → слуга (даса), друг (сакха), старший — отец и другие (гуру), возлюбленная (канта) / servant (*dāsa*), friend (*sakhā*), elder — a father and the like (*guru*), beloved (*kāntā*).
- স্থূলে / সূক্ষ্মে → в общих чертах / в тонкостях, при подробном счёте / broadly / in finer detail.
- প্রতীতি (ভগবৎ-প্রতীতি) → представление (пратити) о Бхагаване / a conception (*pratīti*) of Bhagavān; স্বয়ংস্বরূপ → изначальный облик (сваям-сварупа) / the original form (*svayaṁ-svarūpa*).
- ক্ষেত্রজ্ঞ (জীব), ক্ষেত্রজ্ঞা শক্তি → кшетрагья, энергия кшетрагья / *kṣetrajña*, the *kṣetrajña* potency.

## «Бхагаватам» (Ану 314–316)
- পারমহংসী-সংহিতা → «Парамахамси-самхита» / the *Pāramahaṁsī-saṁhitā*; উদ্ধর্ম্ম → недхарма / irreligion; ধর্ম্মজ্ঞানাদি = ষড়ৈশ্বর্য্য → шесть достояний / the six opulences.

## «Вайшнава-смрити» («Хари-бхакти-виласа»; Ану 319–337)
- বৈষ্ণবস্মৃতি → «Вайшнава-смрити» (= «Хари-бхакти-виласа») / the *Vaiṣṇava-smṛti*; ব্যবহারশাস্ত্র → свод правил поведения / code of conduct.
- জাতি: শৌক্র, সাবিত্র, দৈক্ষ → джати: шаукра (по семени), савитра (по Савитри), дайкша (по посвящению) / *śaukra*, *sāvitra*, *daikṣa*.
- পঞ্চসংস্কার: তাপ, পুণ্ড্র, নাম, মন্ত্র, উপাসনা → пять самскар: тапа, пундра, имя, мантра, упасана / the five *saṁskāras*; নবেজ্যা → девять видов поклонения (наведжья) / the nine kinds of worship (*navejyā*); অর্থপঞ্চক → пять предметов (артха-панчака) / the five subjects (*artha-pañcaka*).
- গুরুব্রুব; বঞ্চক / বঞ্চিত → гуру-брува; «обманщики» / «обманутые» / *guru-bruva*; “cheaters” / “the cheated”; যোষা → «йоша» (предмет наслаждения) / *yoṣā*.
- পঞ্চোপাস্য → пять божеств (панча-упасья) / the five deities (*pañca-upāsya*); পাষণ্ডী → пашанди (безбожник) / *pāṣaṇḍī*.
- ভাগবত বৈদিক অধিকার / পাঞ্চরাত্রিক তান্ত্রিক অধিকার → ведическое право бхагаваты / тантрическое право панчаратрики / the Vedic right of the *bhāgavata* / the Tantric right of the *pāñcarātrika*.
- সিদ্ধ, সাধ্য, সুসিদ্ধ, অরি (мантры) → сиддха, садхья, сусиддха, ари / *siddha*, *sādhya*, *susiddha*, *ari*; শাত্রব দোষ → изъяны вражды / faults of enmity.
- মন্ত্রসংস্কার: জনন, জীবন, তাড়ন, রোধন, অভিষেক, বিমলীকরণ, আপ্যায়ন, তর্পণ, দীপন, গুপ্তি → обряды очищения мантры: джанана, дживана, тадана, родхана, абхишека, вималикарана, апьяяна, тарпана, дипана, гупти / the purificatory rites of a mantra.
- মৈত্রকৃত্য → естественные отправления / answering the calls of nature; আপোমার্জন → окропление водой с мантрами / sprinkling with water and mantras.
- ঊর্দ্ধ্বপুণ্ড্র, গোপীচন্দন, পদ্মাক্ষ → урдхва-пундра, гопи-чандана, падмакша (бусы из семян лотоса; не кости и не рудракша) / *ūrdhva-puṇḍra*, *gopī-candana*, *padmākṣa*.
- উপচার: পঞ্চ, দশ, ষোড়শ, পঞ্চাশ, চতুঃষষ্টি (চৌঘন) → подношения: пять, десять, шестнадцать, пятьдесят, шестьдесят четыре («чоу-гхана») / offerings: five, ten, sixteen, fifty, sixty-four (*cau-ghana*).
- পঞ্চকাল: অরুণোদয়, প্রাতঃ, মধ্যাহ্ন, সায়াহ্ন, প্রদোষ → пять времён: арунодая (предрассветный час), утро, полдень, вечер, прадоша (начало ночи) / *aruṇodaya*, morning, midday, evening, *pradoṣa*.
- সেবাপরাধ (৩২) → оскорбления в служении / offenses in service; নামাপরাধ → оскорбления имени / offenses against the name.
- বিদ্ধা / অবিদ্ধা (ব্রত, একাদশী) → «пронзённый» (виддха) / непронзённый / “pierced” (*viddhā*) / unpierced.
- দিনকৃত্য, পক্ষকৃত্য, মাসকৃত্য → ежедневные, обязанности пакши, ежемесячные / daily, fortnightly, monthly duties.
- সাত্বত-পুরাণ → саттвата-пураны / the Sātvata Purāṇas.

## Прочее
- প্রয়াণ-পথ / প্রমাণ-পথ → «праяна-патха» / «прамана-патха» (обычная дорога) / the common road.
- আত্মপ্রসাদ → безмятежность души / serenity of the self; অবধূত → авадхута / *avadhūta*.
- হসেনসাহ পাৎসাহা → падишах Хусейн Шах / the emperor Husain Shāh (как в глоссарии).
- Имена: Шри Ганганараяна, Рамакришна (брахманы по рождению, ученики Нароттамы); Шьямананда; Нилакантха (комментатор «Махабхараты») / Śrī Gaṅgānārāyaṇa, Rāmakṛṣṇa; Śyāmānanda; Nīlakaṇṭha.
- Источники: «Таттва-сагара» / *Tattva-sāgara*; «Двараки-махатмья» / *Dvārakā-māhātmya*; «Сканда-пурана», «Аванти-кханда» / *Skanda Purāṇa*, *Avantī-khaṇḍa*; «Брихат-сахасранама-стотра» («Падма-пурана») / *Bṛhat-sahasra-nāma-stotra*; «Туласи-става» / *Tulasī-stava*.
