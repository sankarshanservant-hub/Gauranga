# Новые термины, имена, места — комментарии к Мадхье 3 (RU / EN)

Формат: бенг./санскр. → RU / EN.

## Оформление
- Колофоны: «ইতি অমৃতপ্রবাহভাষ্যে তৃতীয় পরিচ্ছেদ» → *Так заканчивается третья глава “Амрита-праваха-бхашьи”.* / *Thus ends the third chapter of the “Amṛta-pravāha-bhāṣya.”*; «ইতি অনুভাষ্যে তৃতীয় পরিচ্ছেদ» → *Так заканчивается третья глава “Анубхашьи”.* / *Thus ends the third chapter of the “Anubhāṣya.”*
- «যথা পদ—[ধানশ্রী-রাগ]» и «(ধ্রু)» над стихом 114 — часть стиха, в комментарий не переносятся.
- Номер «১৯৪» перед абзацем о служении (Ану) — опечатка издания, отнесено к стиху 185 со сноской.

## Санньяса
- ত্রিদণ্ডী ভিক্ষু, আবন্তিক → нищий-триданди из Аванти / the *tridaṇḍī* mendicant of Avantī.
- পরাত্মনিষ্ঠা / জড়াত্মনিষ্ঠা → верность Высшей Душе (паратма-ништха) / привязанность к материальному «я» (джадатма-ништха) / fidelity to the Supreme Self (*parātma-niṣṭhā*) / attachment to the material self (*jaḍātma-niṣṭhā*).
- তুর্য্যাশ্রম → четвёртый ашрам (турья-ашрама) / the fourth *āśrama* (*turyāśrama*).
- ত্রিদণ্ড / একদণ্ড / জীবদণ্ড; ত্রিদণ্ড-সন্ন্যাস / একদণ্ড-সন্ন্যাস → триданда / экаданда / джива-данда; триданда-, экаданда-санньяса / *tridaṇḍa* / *ekadaṇḍa* / *jīva-daṇḍa*; *tridaṇḍa-*, *ekadaṇḍa-sannyāsa*. একদণ্ডী → экадандин / *ekadaṇḍī*.
- ঐকান্তিকী ভক্তি → беспримесная (айкантики) бхакти / exclusive (*aikāntikī*) devotion.
- অষ্টোত্তরশতনামী / দশনামী সন্ন্যাসী → санньясины ста восьми имён / система десяти имён / *sannyāsīs* of the hundred and eight names / the system of ten names.
- শিবস্বামী → Шивасвами / Śivasvāmīs. কেবলাদ্বৈতবাদী → кевала-адвайтавадины / *kevalādvaita-vādīs*. শুদ্ধাদ্বৈত → чистая адвайта (шуддха-адвайта) / pure nondualism (*śuddhādvaita*).
- শিখা-সূত্র → шикха и священный шнур (сутра) / the *śikhā* and the sacred thread (*sūtra*).
- বহিঃপ্রজ্ঞ → чья мудрость обращена вовне (бахих-прагья) / whose wisdom faces outward (*bahiḥ-prajña*). অতদ্ধর্ম্ম → дхарма, чуждая Ему (атад-дхарма) / a *dharma* alien to Him (*atad-dharma*).
- দৈব / আসুর বর্ণাশ্রম → дайва- / асура-варнашрама / *daiva-* / *āsura-varṇāśrama*.
- বৈষ্ণবস্মৃত্যাচার্য্য → смрити-ачарья гаудия-вайшнавов / the *smṛti-ācārya* of the Gauḍīya Vaiṣṇavas. ত্রিদণ্ডিপাদ → Триданди-пада / Tridaṇḍipāda.
- পারমহংস্য, অবধূতত্ব → парамахамсья, авадхутатва / *pāramahaṁsya*, *avadhūtatva*. বহূদক → бахудака-санньясин / *bahūdaka-sannyāsī*. তৈর্থিক → тайтхика (странствующий по тиртхам) / *taithika*.
- কৌলাবধূতাচার → поведение каула-авадхуты (у шактов) / the conduct of a *kaula-avadhūta*. স্বরূপ-ব্রহ্মচারী → сварупа-брахмачари (брахмачари с именем «Сварупа») / *svarūpa-brahmacārī*.
- বান্তাশী → ванташи («тот, кто ест извергнутое») / *vāntāśī*. ফল্গুবৈরাগ্য → ложное отречение (пхалгу-вайрагья) / false renunciation (*phalgu-vairāgya*).
- নিরপেক্ষ → нирапекша, ни от чего не зависящий / *nirapekṣa*, dependent on nothing. সুনীতি → благая мораль (сунити) / good morality (*sunīti*). নিরীশ্বর নীতিবাদী → безбожные моралисты / godless moralists.

## Прасад и кухня (транслитерация + пояснение при первом упоминании)
- শুখারুখা ব্যঞ্জন → шукха-рукха вьянджана / *śukhārukhā vyañjana*; চচ্চড়ি → чаччари (бенгальское сухое тушёное овощное блюдо; «(?)» — в издании) / *caccaḍi*; রসা → раса (жидкое блюдо, похлёбка) / *rasā* (a liquid dish, a broth); সূপ → супа / *sūpa*.
- বত্তিশা-আঠিয়া-কলার আঙ্গটিয়া → баттиша-атхия-калара ангатия (атхия — сорт банана, гроздь в 32 кисти; ангатия — цельный лист) / *battiśā-āṭhiyā-kalāra āṅgaṭiyā*.
- দোনা / ডোঙ্গা → дона / донга (чашечка из листа) / *donā* / *ḍoṅgā* (leaf cup).
- উপকরণ → упакарана (дал, овощи и прочее — то, с чем едят рис) / *upakaraṇa*.
- মান → мана (мерка-катха в четыре сера) / *māna* (a *kāṭhā* measure of four seers).
- রসবাস → расаваса (благоухание, исполненное вкуса) / *rasavāsa*. তাম্বূল → тамбула / *tāmbūla*.
- মহাপ্রসাদ, মহামহাপ্রসাদ → маха-прасад, маха-маха-прасад / *mahā-prasāda*, *mahā-mahā-prasāda*. উচ্ছিষ্ট, ঝুট(া) → остатки (уччхишта), джхута / remnants (*ucchiṣṭa*), *jhuṭā*.
- আচমন → ачамана / *ācamana*.
