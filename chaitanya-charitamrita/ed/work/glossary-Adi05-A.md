# Новые термины — Ади 5, часть A (комментарии к 0–48)

Формат: бенг./санскр. → RU / EN.

## Термины
- বিলাসমূর্ত্তি → виласа-мурти / *vilāsa-mūrti*; দ্বিতীয় দেহ → второе тело / second body.
- মূল-সঙ্কর্ষণ / মহাসঙ্কর্ষণ → мула-Санкаршана (изначальный Санкаршана) / Маха-Санкаршана; *mūla-Saṅkarṣaṇa* / Mahā-Saṅkarṣaṇa.
- আদিচতুর্ব্যূহ / দ্বিতীয় চতুর্ব্যূহ → изначальная / вторая чатур-вьюха / the original / the second *catur-vyūha*; দ্বিতীয় কায়ব্যূহ → вторая кайа-вьюха.
- অংশ / কলা → часть (амша) / доля (кала) / part (*aṁśa*) / portion (*kalā*).
- ঈক্ষণ → взгляд (икшана) / glance (*īkṣaṇa*); অঙ্গাভাস → подобие тела (анга-абхаса) / semblance of His body (*aṅgābhāsa*).
- উপাদান-কারণ / নিমিত্ত-কারণ → материальная (упадана-карана) / действующая причина (нимитта-карана) / material / efficient cause; গৌণনিমিত্ত কারণ → второстепенная действующая причина / secondary efficient cause.
- সমষ্টি জগৎ → совокупный мир / the aggregate universe; সমষ্টিবিষ্ণু / ব্যষ্টিবিষ্ণু → совокупный / индивидуальный Вишну / the aggregate / the individual Viṣṇu.
- কারণাব্ধিশায়ী, গর্ভোদশায়ী, পয়োব্ধিশায়ী, ক্ষীরোদশায়ী → Каранабдхишайи, Гарбходашайи, Пайобдхишайи, Кширодашайи (как в издании) / Kāraṇābdhiśāyī, Garbhodaśāyī, Payobdhiśāyī, Kṣīrodaśāyī.
- শেষ-শয্যা → ложе-Шеша / the bed of Śeṣa; পরিশিষ্টলীলা → дополнительные игры / supplementary pastimes.
- স্বকীয়ভাব → свакия-бхава / the mood of *svakīyā*.
- মহান্তঃপুর → великие внутренние покои / the great inner palace; আবরণ (গোকুলের) → оболочки / coverings.
- পাদবিভূতি / একপাদবিভূতি → пада-вибхути / эка-пада-вибхути (материальный мир) / *pāda-vibhūti* / *eka-pāda-vibhūti*.
- মহাবস্থা → «Махавастха» (название четырёх вьюх) / “Mahāvasthā”.
- অধিদৈবত, অধিষ্ঠাতৃদেবতা → владыка (адхидайвата) / presiding deity (*adhidaivata*).
- আধারশক্তি → опорная сила (адхара-шакти) / supporting potency (*ādhāra-śakti*).
- তটস্থা জীবশক্তি → пограничная (татастха) джива-шакти / the marginal (*taṭastha*) *jīva-śakti*; চিৎকণ → частица духа / particle of spirit.
- ব্রহ্মসাযুজ্য → мукти слияния с Брахманом (брахма-саюджья) / *brahma-sāyujya*; সাযুজ্য-লয় → слияние (саюджья-лая) / merging (*sāyujya-laya*).
- নির্ব্বিশেষ / সবিশেষ → лишённый признаков (нирвишеша) / имеющий признаки (савишеша) / without features (*nirviśeṣa*) / with features (*saviśeṣa*).
- প্রতিকূল / অনুকূল অনুশীলন → враждебное / благоприятное служение (пратикула- / анукула-анушилана) / hostile / favorable cultivation (*pratikūla- / anukūla-anuśīlana*).
- আলম্বন (о Боге) → опора (аламбана) / support (*ālambana*).
- তারতম্য → различие в степени (таратамья) / gradation (*tāratamya*); অতিশয় → превосходство (атишая) / pre-eminence (*atiśaya*).
- অচিন্ত্যশক্তি → непостижимая энергия / inconceivable potency; ইন্দ্রজাল → колдовство (индраджала) / sorcery (*indra-jāla*).
- কারিকা → карика / *kārikā*; মর্ম্মানুবাদ → пересказ смысла / paraphrase of the meaning; ভাষ্যার্থ → смысл комментария / the meaning of the commentary.
- সিদ্ধান্তহানি → крушение собственного учения (сиддханта-хани) / *siddhānta-hāni*.
- বিভুচৈতন্য / অণুচৈতন্য → всепроникающее / крошечное сознание (вибху- / ану-чайтанья) / *vibhu-caitanya* / *aṇu-caitanya*.
- চিদচিৎসমন্বয়বাদী → учащие о слиянии духа и материи / those who teach the merging of spirit and matter (*cid-acit-samanvaya*).
- সূক্ষ্ম, ব্যূহ, বিভব → сукшма, вьюха, вибхава / *sūkṣma*, *vyūha*, *vibhava*; চাতুরাত্ম্য → чатуратмья / *cāturātmya*.
- দিব্যসূরি → божественные мудрецы (дивья-сури) / divine sages (*divya-sūris*); আলবার → альвары / the Āḻvārs.
- তন্ত্রেণ (грамм.) → «при двояком прочтении» / “read in a double sense” (со сноской).
