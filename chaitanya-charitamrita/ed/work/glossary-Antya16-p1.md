# Новые термины — Антья 16, комментарии, часть 1 (стихи 0–75; RU / EN)

#### Термины
- অধরামৃত (о остатках вайшнавов, АПБ 0, 60) → нектар уст (адхарамрита) — остатки трапезы / the nectar of the lips (*adharāmṛta*), the remnants.
- ফেলামৃত → пхеламрита (нектарные остатки) / *phelāmṛta* (nectarean remnants).
- বল্লভভোগ → валлабха-бхога / *vallabha-bhoga*.
- জ্ঞাতি-খুড়া → дядя по роду / a kinsman of [his] father's generation.
- প্রেম-দীক্ষা → посвящение в любовь (према-дикша); у Бхактисиддханты — путь служения, основанный на чистой любви / initiation into love (*prema-dīkṣā*); in the *Anubhāṣya*, the method of worship rooted in pure love.
- উন্নতোজ্জ্বলরস → возвышенная, сияющая раса (уннатоджджвала-раса) / the elevated, radiant *rasa* (*unnatojjvala-rasa*).
- কৃষ্ণনাম-সঙ্কেত → имя Кришны как условный знак (санкета) / the name of Kṛṣṇa as a sign (*saṅketa*).
- বঞ্চন-লীলা (Калидаса, Ану 7) → игра, вводящая в заблуждение / misleading pastime.
- পাশা, দ্যূত → игра в кости (паша, дьюта) / playing dice (*pāśā*, *dyūta*).
- ভুঁইমালী → бхуинмали (каста, подобная хадди, «ха̐ри») / *Bhũimālī* (a caste similar to the Haḍḍī, “Hā̃ḍi”).
- ব্রাহ্মণ-বৈষ্ণব / শূদ্র-বৈষ্ণব → брахман-вайшнав / шудра-вайшнав (рождённые в семьях шаукра-брахманов / шаукра-шудр) / *brāhmaṇa-Vaiṣṇava* / *śūdra-Vaiṣṇava*.
- মনোময়ী অর্চ্চা; মানস-পূজা → Божество, явленное в уме (маномайи-арча); поклонение в уме / the Deity manifest in the mind (*manomayī arcā*); worship in the mind.
- অপ্রাকৃত-ব্রাহ্মণতা → трансцендентное брахманство / transcendental *brāhmaṇa* nature.
- দেহাত্মবুদ্ধি → отождествление себя с телом / identifying the self with the body.
- অমানিত্ব / মানদত্ব → свобода от гордости (амани) / почитание других (манада) / freedom from pride (*amānī*) / honoring others (*mānada*).
- নিষ্কপট মহাকৃপা → бескорыстная (нелицемерная) великая милость / great mercy without reserve.
- পহাচ (ория) → пахач, ступень лестницы; বাইশ পহাচ → двадцать две ступени (у Львиных врат) / *pahāca*, a step; *bāiśa pahāca*, the twenty-two steps.
- পাটুয়া-খোলা → патуя-кхола: листья и кора [банана] / *pāṭuyā-kholā*: leaves and bark (в переводе стиха — «обёртки из банановых листьев»).
- চোকলা → чокла, кожура / *cokalā*, peel; আড়ে → за прикрытием / behind a screen; গাড়ে → в яме / in the pit; ঠারে → знаком / by a sign; এতাবতা → до сих пор / this far; অনুব্রজি → идя следом / walking behind.
- টঙ্ক → т̣ан̇ка, резец (орудие, раскалывающее камень) / *ṭaṅka*, a chisel (a tool for splitting stone).
- সাধনের বল (তিন) → сила трёх средств садханы (пыль со стоп, вода со стоп и нектар уст преданного) / the strength of the three practices.
- পরমপুরুষার্থ → высшая цель жизни (парама-пурушартха) / the supreme aim of life (*parama-puruṣārtha*).
- মহেন্দ্রমণিদাম (ইন্দ্রনীলমণিমালা) → ожерелье из сапфиров (махендра-мани, индранила) / a necklace of sapphires (*mahendra-maṇi*, *indranīla*).
- কুবলয় (নীলোৎপল); কজ্জল → голубой лотос (нилотпала); сурьма (каджала) / blue lotus (*nīlotpala*); collyrium (*kajjala*).

#### Имена и места
- ঝড়ু ঠাকুর → Джхаду Тхакур / Jhaḍu Ṭhākura; কালিদাস → Калидас / Kālidāsa.
- পুরীদাস, পরমানন্দপুরীদাস → Пури дас, Парамананда Пури дас (= Кави-карнапура) / Purī dāsa, Paramānanda Purī dāsa (= Kavi-karṇapūra).
- আর্য্যাশতক → “Арья-шатака” / *Āryā-śataka*; তত্ত্বসাগর → “Таттва-сагара” / *Tattva-sāgara*; নৃসিংহ-পুরাণ → “Нрисимха-пурана” / *Nṛsiṁha Purāṇa*.
- ভেদো / ভদুয়া → Бхедо / Бхадуя / Bhedo / Bhaduyā; কৃষ্ণপুর → Кришнапур / Kṛṣṇapura; দেবানন্দপুর → Деванандапур / Devānandapura; ব্যাণ্ডেল্-জংসন → узловая станция Бандел / Bandel Junction.
- শঙ্খ-নগর → Шанкха-нагар / Śaṅkha-nagara; সরস্বতী নদী → река Сарасвати / the Sarasvatī River; ত্রিবেণী → Тривени / Triveṇī.
- শ্রীমদনগোপাল → Шри Мадана-гопала / Śrī Madana-gopāla; রামপ্রসাদ দাস → Рамапрасад дас / Rāmaprasāda dāsa; মতিলাল চট্টোপাধ্যায় → Мотилал Чаттопадхьяя / Motilal Caṭṭopādhyāya.
