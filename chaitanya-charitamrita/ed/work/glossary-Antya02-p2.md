# Глоссарий: Антья 2, часть 2 (стихи 96–172) — новые термины (RU / EN)

- ছোট-হরিদাস → Чхота Харидас (как в общем глоссарии; в стихах ВЧД — «Младший Харидас») / Choṭa Haridāsa; মাধবী-দেবী → Мадхави-деви / Mādhavī-devī.
- বৈরাগী → вайраги (отрёкшийся) / *vairāgī* (renunciant); বৈরাগিব্রুব (অনধিকারী) → неподготовленный мнимый вайраги / unqualified pseudo-*vairāgī*.
- ভেক, ভেকধারী → бхек (одеяние отрёкшегося), носящий бхек / *bhek* (the renunciant's dress), wearing the *bhek*.
- প্রকৃতি (о женщине), প্রকৃতি-সম্ভাষণ, স্ত্রী-সম্ভাষণ → пракрити (женщина), беседа с пракрити, стри-самбхашана / *prakṛti* (a woman), conversing with *prakṛti*, *strī-sambhāṣaṇa*.
- ধর্ম্মধ্বজী → дхармадхваджи (выставляющие дхарму напоказ) / *dharma-dhvajīs* (those who make a show of *dharma*).
- শাল্যন্ন → шальянна (белый тонкий рис) / *śālyanna* (fine white rice); আরোয়া চাউল → «ароя чаул» (рис шали сорта «ароя») / *āroyā cāul*; দেউল-প্রসাদ → деула-прасад / *deula-prasāda*.
- সরলতা / কপটতা → простота / неискренность / simplicity / duplicity.
- বিবিৎসা (= বিবিদিষা?), ধীর; বিদ্বৎ, নরোত্তম (санньясины) → вивидиша (со сноской), дхира; видват, нароттама / *vividiṣā* (with a note), *dhīra*; *vidvat*, *narottama*.
- অক্ষজ-জ্ঞানী → акшаджа-гьяни (чьё знание опирается на чувства) / *akṣaja-jñānī* (one whose knowledge rests on the senses).
- অষ্টপ্রকার স্ত্রীসংসর্গ → восемь видов общения с женщиной / the eight kinds of contact with women.
- জিহ্বোদরোপস্থ-লাম্পট্য → распущенность языка, желудка и гениталий / indulgence of the tongue, the belly and the genitals.
- উপধর্ম্ম / অপধর্ম্ম → упадхарма / ападхарма (побочные / ложные религии) / *upadharma* / *apadharma* (side / false religions); বিদ্ধ প্রাকৃত-সহজিয়া → «смешанные» (виддха) пракрита-сахаджии / “mixed” (*viddha*) *prākṛta-sahajiyās*.
- অমন্দোদয়া দয়া → щедрая милость / bountiful mercy; ধর্ম্মসেতু ধর্ম্মবর্ম্ম → оплот и щит дхармы / the bulwark and armor of *dharma*; বজ্রাদপি কঠোরতা → строгость твёрже ваджры / sternness harder than a thunderbolt; সদ্ধর্ম্মগোপ্তা → хранитель истинной дхармы / protector of true *dharma*.
- দেহত্যাগ (Харидаса) → оставил тело / gave up his body (не «самоубийство»); আত্মঘাত, আত্মহত্যা (только в догадке преданных, 156) → покончил с собой / killed himself.
- দিব্য-দেহ, গন্ধর্ব্ব-দেহ → божественное тело, тело гандхарвы / divine body, the body of a Gandharva; ব্রহ্মরাক্ষস → брахма-ракшас / *brahma-rākṣasa*.
- শ্রৌতপথ / তর্কপন্থা → путь слушания (шраута-патха) / путь логики / the path of hearing (*śrauta-patha*) / the path of argument.
- গৌরকৈঙ্কর্য্য → служение Гауре / service to Gaura; গাঢ় অনুরাগ → глубокая любовь (анурага) / deep love (*anurāga*).
- Имена и места: Праяга, Тривени / Prayāga, Triveṇī; Алаланатха / Ālālanātha; Яяти, Деваяни / Yayāti, Devayānī.
- Источник в подзаголовке: (Шримад-Бхагаватам, 9.19.17, и Ману-самхита, 2.215) / (*Śrīmad-Bhāgavatam* 9.19.17 and *Manu-saṁhitā* 2.215).
