# Новые термины — Мадхья 8, часть 2 (стихи 93–192; RU / EN)

#### Оформление
- Подзаголовки с буквами раздела «(গ)», «(ঘ)» → «(в)», «(г)» / “(c)”, “(d)”; с цифрами «(১)…» → «(1)…».
- Комментарии к группам: APB «১০১-১০২», «১০৯-১১০», «১৩৭-১৩৮» → `## 101–102` и т. д.; Ану «৯৭-১১৫» → `## 97–115` после `## 115`; «১১২-১১৩» → `## 112–113` после `## 111`.
- Строки-источники над шлоками («(শ্রীগীতগোবিন্দে ৩য় সর্গে ১ম শ্লোকে)», «লঘুভাগবতামৃতে—(২।৪৫) (পদ্মপুরাণ-বাক্য)» и т. п.) — часть стиха, в комментарий не переносятся.

#### Термины
- অসমোর্দ্ধ্ব → «которой (которому) нет равного и нет выше» (асамордхва) / “with no equal and none above” (*asamordhva*).
- সাধ্যাবধি / সাধ্যশিরোমণি / সাধ্যসার → предел цели (садхьи) / венец всех целей (садхья-широмани) / суть цели / the limit of the goal / the crest jewel of all goals (*sādhya-śiromaṇi*) / the essence of the goal.
- ব্রজদেবী → девы Враджа (враджа-деви) / the goddesses of Vraja (*vraja-devīs*); গোপীজনবল্লভ → Гопиджана-валлабха, Возлюбленный гопи / Gopījana-vallabha, the beloved of the gopīs.
- নিরপেক্ষ প্রেম → независимая [от других] любовь (нирапекша) / independent love (*nirapekṣa*); অন্যাপেক্ষা → оглядка на других / regard for others.
- বামতা / কৌটিল্য / কুটিল প্রেম → строптивость (вамата) / извилистость (каутилья) / извилистая любовь / contrariness (*vāmatā*) / crookedness (*kauṭilya*) / crooked love; মমতা → привязанность (мамата) / attachment (*mamatā*).
- অহেতু / সহেতু মান → «беспричинная» / «имеющая причину» мана / *māna* “without cause” / “with cause”.
- যন্ত্র / যন্ত্রী → «инструмент» / «Тот, Кто на нём играет» / “instrument” / “the One who plays it”; সূত্রধার → сутрадхара (главный актёр, открывающий представление) / *sūtradhāra*.
- নিঃশ্রেয়স → высшее благо (нихшреяс) / the highest good (*niḥśreyas*); ঐশ্বর্য্য, শ্রুত, শ্রী (অভিমান) → гордость богатством, учёностью, красотой / pride of wealth, learning, beauty; প্রণিপাত, পরিপ্রশ্ন, সেবা → поклон, искренние вопросы, служение / obeisance, sincere inquiry, service.
- বর্ত্মপ্রদর্শক গুরু → гуру, указывающий путь / the guru who shows the path; শ্রবণগুরু, ভজন-শিক্ষাগুরু → шравана-гуру, шикша-гуру в бхаджане / *śravaṇa-guru*, *śikṣā-guru* in *bhajana*; পাঞ্চরাত্রিক দীক্ষা → панчаратрика-дикша / *pāñcarātrika* initiation.
- বৃত্ত-ব্রাহ্মণতা → брахманство по поведению (вритта-) / brāhmaṇa status by conduct (*vṛtta-*); অচ্যুতব্রাহ্মণ → «брахманы Ачьюты» / “brāhmaṇas of Acyuta”; একায়ন-শাখী দৈক্ষ্যব্রাহ্মণ → дайкшья-брахманы ветви Экаяна / *daikṣya* brāhmaṇas of the Ekāyana branch; বাজসনেয় শাখা → ветвь Ваджасанейи / the Vājasaneya branch; ভজনানন্দী → бхаджанананди / *bhajanānandī*.
- শুদ্ধাত্মবৃত্তি → природное свойство чистой души / the natural function of the pure self.
