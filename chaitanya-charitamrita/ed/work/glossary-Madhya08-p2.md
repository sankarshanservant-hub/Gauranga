# Новые термины — Мадхья 8, часть 2 (стихи 93–192; RU / EN)

#### Оформление
- Подзаголовки с буквами раздела «(গ)», «(ঘ)» → «(в)», «(г)» / “(c)”, “(d)”; с цифрами «(১)…» → «(1)…».
- Комментарии к группам: APB «১০১-১০২», «১০৯-১১০», «১৩৭-১৩৮» → `## 101–102` и т. д.; Ану «৯৭-১১৫» → `## 97–115` после `## 115`; «১১২-১১৩» → `## 112–113` после `## 111`.
- Строки-источники над шлоками («(শ্রীগীতগোবিন্দে ৩য় সর্গে ১ম শ্লোকে)», «লঘুভাগবতামৃতে—(২।৪৫) (পদ্মপুরাণ-বাক্য)» и т. п.) — часть стиха, в комментарий не переносятся.

#### Термины
- অসমোর্দ্ধ্ব → «которой (которому) нет равного и нет выше» (асамордхва) / “with no equal and none above” (*asamordhva*).
- সাধ্যাবধি / সাধ্যশিরোমণি / সাধ্যসার → предел цели (садхьи) / венец всех целей (садхья-широмани) / суть цели / the limit of the goal / the crest jewel of all goals (*sādhya-śiromaṇi*) / the essence of the goal.
- ব্রজদেবী → девы Враджа (враджа-деви) / the goddesses of Vraja (*vraja-devīs*); গোপীজনবল্লভ → Гопиджана-валлабха, Возлюбленный гопи / Gopījana-vallabha, the beloved of the gopīs.
- নিরপেক্ষ প্রেম → независимая [от других] любовь (нирапекша) / independent love (*nirapekṣa*); অন্যাপেক্ষা → оглядка на других / regard for others.
- বামতা / কৌটিল্য / কুটিল প্রেম → строптивость (вамата) / извилистость (каутилья) / извилистая любовь / contrariness (*vāmatā*) / crookedness (*kauṭilya*) / crooked love; মমতা → привязанность (мамата) / attachment (*mamatā*).
- অহেতু / সহেতু মান → «беспричинная» / «имеющая причину» мана / *māna* “without cause” / “with cause”.
- যন্ত্র / যন্ত্রী → «инструмент» / «Тот, Кто на нём играет» / “instrument” / “the One who plays it”; সূত্রধার → сутрадхара (главный актёр, открывающий представление) / *sūtradhāra*.
- নিঃশ্রেয়স → высшее благо (нихшреяс) / the highest good (*niḥśreyas*); ঐশ্বর্য্য, শ্রুত, শ্রী (অভিমান) → гордость богатством, учёностью, красотой / pride of wealth, learning, beauty; প্রণিপাত, পরিপ্রশ্ন, সেবা → поклон, искренние вопросы, служение / obeisance, sincere inquiry, service.
- বর্ত্মপ্রদর্শক গুরু → гуру, указывающий путь / the guru who shows the path; শ্রবণগুরু, ভজন-শিক্ষাগুরু → шравана-гуру, шикша-гуру в бхаджане / *śravaṇa-guru*, *śikṣā-guru* in *bhajana*; পাঞ্চরাত্রিক দীক্ষা → панчаратрика-дикша / *pāñcarātrika* initiation.
- বৃত্ত-ব্রাহ্মণতা → брахманство по поведению (вритта-) / brāhmaṇa status by conduct (*vṛtta-*); অচ্যুতব্রাহ্মণ → «брахманы Ачьюты» / “brāhmaṇas of Acyuta”; একায়ন-শাখী দৈক্ষ্যব্রাহ্মণ → дайкшья-брахманы ветви Экаяна / *daikṣya* brāhmaṇas of the Ekāyana branch; বাজসনেয় শাখা → ветвь Ваджасанейи / the Vājasaneya branch; ভজনানন্দী → бхаджанананди / *bhajanānandī*.
- শুদ্ধাত্মবৃত্তি → природное свойство чистой души / the natural function of the pure self.

- স্বরূপগত / বস্তুগত (অবস্থিতি) → «сварупа-гата» (в своей истинной природе) / «васту-гата» (в действительности); স্বরূপতঃ / বস্তুতঃ → «в своей истинной природе» / «в действительности» / *svarūpa-gata* (in one's own true nature) / *vastu-gata* (in actual fact).
- অভিনব-মদন, অপ্রাকৃত নবীন মদন → вечно новый Мадана / the ever-new Madana; মন্মথমন্মথ → Манматха-манматха, Купидон для Купидона / Manmatha-manmatha, the Cupid of Cupid; কামতত্ত্ব (মাংসপিণ্ডের আকর্ষী) → кама (влечение комков плоти) — только о мирской каме, противопоставленной немирскому Мадане.
- কামগায়ত্রী / কামবীজ (ক্লীং) → кама-гаятри / кама-биджа («клим») / *kāma-gāyatrī* / *kāma-bīja* (*klīṁ*); সম্বন্ধাধিদেবতা, অভিধেয়াধিদেবতা, প্রয়োজনাধিদেবতা → Владыка самбандхи / абхидхеи / прайоджаны / the Lord of *sambandha* / *abhidheya* / *prayojana*; রসন → «расана», поклонение, которое Его радует / *rasana*, worship that pleases Him; ত্রি-অষ্টাক্ষরী → трижды восьмисложная / of three times eight syllables.
- উদ্বর্ত্তন, আবাটা → натирание (удвартана), паста (абата) / unguent (*udvartana*), paste (*ābāṭā*); অভিরূপতা → привлекательность (абхирупата) / comeliness (*abhirūpatā*); মার্দ্দব → мягкость (мардава) / softness (*mārdava*); রূপ / সৌন্দর্য্য / লাবণ্য / মাধুর্য্য → облик / красота / прелесть / сладость / form / beauty / loveliness / sweetness.
- কিলকিঞ্চিতাদি বিংশতি ভাব: অঙ্গজ (ভাব, হাব, হেলা), আত্মজ (শোভা, কান্তি, দীপ্তি, মাধুর্য্য, প্রগল্ভতা, ঔদার্য্য, ধৈর্য্য), স্বভাবজ (কিলকিঞ্চিত, লীলা, বিলাস, বিচ্ছিত্তি, বিভ্রম, মোট্টায়িত, কুট্টমিত, বিব্বোক, ললিত, বিকৃত) → ангаджа, атмаджа, свабхаваджа; транслитерацией / *aṅgaja*, *ātmaja*, *svabhāvaja*; *bibboka* — как в издании.
- পঞ্চবিংশতি গুণ শ্রীরাধার: অঙ্গস্থ, উক্তিস্থ, মনস্থ, পরসম্বন্ধগ → пребывающие в теле (ангастха), в речи (уктистха), в уме (манастха), связанные с другими (пара-самбандхага) / *aṅgastha*, *uktistha*, *manastha*, *para-sambandhaga*; названия качеств — транслитерацией с переводом.
- ধীরাধীরা, প্রগল্ভা, মধ্যা, মুগ্ধা → дхира-адхира, прагалбха, мадхья, мугдха / *dhīrādhīrā*, *pragalbhā*, *madhyā*, *mugdhā*; প্রচ্ছন্নমান → скрытая мана / hidden *māna*; ধম্মিল্ল → дхаммилла, узел волос (кхопа) / *dhammilla* (*khõpā*); পট্টবাস / পটবাস → паттаваса / патаваса / *paṭṭavāsa* / *paṭavāsa*.
- প্রেমবৈচিত্ত্য → према-вайчиттья / *prema-vaicittya*; তরল → тарала, подвеска (дхукдхуки) / *tarala*, pendant; অবতংস → аватамса (украшение для ушей) / *avataṁsa*; শ্যামরস → шьяма-раса (= мадхура-раса) / *śyāma-rasa*; মনোবৃত্তি-সখী → сакхи — Её мысли / the *sakhīs*, Her thoughts; মঞ্জরী → манджари / *mañjarīs*.
- প্রেমবিলাস-বিবর্ত্ত / বিলাস-বিবর্ত্ত / জড়বিবর্ত্ত → према-виласа-виварта / виласа-виварта / материальная виварта / *prema-vilāsa-vivarta* / *vilāsa-vivarta* / material *vivarta*; স্ফূর্ত্তি → является (спхурти) / is manifest (*sphūrti*); বিবর্ত্তবাদী → виварта-вадин / *vivarta-vādī*.
- অস্মিতাভাস → подобие «я» (асмитабхаса) / semblance of selfhood (*asmitābhāsa*); অতন্নিরস্ত → «где лишь отброшено „не то“» (атан-нираста) / *atan-nirasta*; দৃগ্দৃশ্যবাদী → дриг-дришья-вадин (учащий о видящем и видимом) / *dṛg-dṛśya-vādī*; আরোহবাদী → ароха-вадин (приверженец восходящего пути) / *āroha-vādī*; ভাবনাবর্ত্ম → путь воображения (бхаваны) / the path of imagination (*bhāvanā*).
- চিন্ত্যদ্বৈতাদ্বৈত → чинтья-двайта-адвайта / *cintya-dvaitādvaita*; অপ্রাকৃত-সাহজিক / অপ্রাকৃত-সহজ-ধর্ম্ম → немирской сахаджика / немирская сахаджа-дхарма / transcendental *sahajika* / *sahaja-dharma*; বাউল (в Ану 191 вместо বাতুল стиха 290) → баул / *bāul* (со сноской).
- ব্যত্যয় → «словно меняются сознанием своей сварупы» (вьятьяя) / *vyatyaya*; ঔদার্য্য-প্রকোষ্ঠ → покой щедрости (аударьи) на Голоке / the chamber of magnanimity (*audārya*).
- পরাবিদ্যামন্দির / প্রাকৃত-বিদ্যামন্দির → «храм высшего знания» (пара-видьи) / «храм материальной учёности» / the “temple of higher knowledge” / the “temple of material learning”.
- ভূমা পুরুষ → Бхума-пуруша / the Bhūmā-puruṣa; শেষশায়ী → Шешашайи / Śeṣaśāyī; পরমেষ্ঠীপতি → Владыка Парамештхи / the Lord of Parameṣṭhī; মহাকালপুর → Махакалапура / Mahākālapura; শ্বেতদ্বীপ (= Голока, БС 5.56) → Шветадвипа / Śvetadvīpa.
