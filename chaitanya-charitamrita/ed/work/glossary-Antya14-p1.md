# Рабочий глоссарий: Антья 14, часть 1 (разделы 0–60; RU и EN)

## Термины
- রাগোদয় (АПБ 0) → «исполнился раги» (неясно: рага-любовь или обиходное «гнев»; см. сноску) / “was filled with *rāga*” (unclear; see note).
- সূত্রকর্ত্তা / বৃত্তিকার → автор сутр / автор толкования (вритти) / the author of the *sūtras* / the author of the explanation (*vṛtti*).
- পাঁজি-টীকা, পঞ্জি-টীকা → па̐джи-тика, панджи-тика (вводное толкование; «распушает», как хлопок, доводы первоисточника) / *pā̃ji-ṭīkā*, *pañji-ṭīkā* (an introductory commentary).
- নিদর্শনজ্ঞাপিকা টিপ্পনী → заметки (типпани), которые служат ориентиром / notes (*ṭippanī*) that serve as guides.
- 'রংবেরং'মত → пёстрые учения всех мастей / motley doctrines of every kind.
- রঙ্গিণ 'নদীয়া-নাগরী'ভাব; 'রঙ্গের নদীয়ানাগরী' → пёстрое настроение «надия-нагари»; «забавные нагари из Надии» / the fanciful mood of “Nadīyā-nāgarī”; “playful *nāgarīs* of Nadīyā”.
- গৌরনাগরবাদ → учение «гаура-нагара» / the “Gaura-nāgara” doctrine.
- নব্য ভক্তাভিমানী → новоявленные люди, мнящие себя преданными / people of a new stamp who consider themselves devotees.
- গম্ভীরলীলা → сокровенные игры (гамбхира-лила) / profound pastimes (*gambhīra-līlā*).
- অভিমান (Уджвала-ниламани) → абхимана / *abhimāna*; সেবকাভিমান → самоощущение слуги (севака-абхимана) / the self-conception of a servant (*sevaka-abhimāna*).
- শ্রীরাধার কিঙ্করী-অভিমান → ощущение Себя служанкой (кинкари) Шри Радхи / feeling Himself a maidservant (*kiṅkarī*) of Śrī Rādhā.
- বৈচিত্রী (УН 14.190) → вайчитри (дивное проявление) / *vaicitrī* (the wondrous).
- আর্ত্তি → рвение, горячее желание увидеть (арти) / eagerness, an ardent wish to see (*ārti*).
- উত্তমাঙ্গ → высшая часть тела (уттаманга) / the highest part of the body (*uttamāṅga*).
- কার্ষ্ণ → принадлежащий Кришне / belonging to Kṛṣṇa.
- অক্ষজজ্ঞানে 'স্ত্রী-পুরুষাদি' বাহ্য পরিচয় → чувственным знанием, по внешним признакам — «женщина», «мужчина» / with sense-born knowledge, by external marks such as “woman” or “man”.
- গোস্বামিপাদোক্ত শ্লোক → шлока, сказанная Госвамипадой / a verse spoken by Gosvāmipāda.
- কাপালিক → капалика (йог, странствующий с человеческим черепом; не вайшнав) / *kāpālika* (a yogī who wanders with a human skull; not a Vaiṣṇava).
- উপমালঙ্কার → сравнение (упама-аланкара) / simile (*upamā-alaṅkāra*).
- শঙ্খকুণ্ডল; শঙ্খারি → серьги из раковины; мастера по раковинам / conch-shell earrings; conch-shell craftsmen.
- স্থালী (ভিক্ষাপাত্র) → чаша для подаяния (стхали) / begging bowl (*sthālī*).
- মহা-বাউল; বাউল যোগী → Маха-баул; йоги-баулы / Mahā-bāul; Bāul yogīs.
- ঝুলনী → джхулни (ткань, которой покрывают голову) / *jhulnī* (a cloth to cover the head).
- তরজা (তর্জ্জা, Ану 46) → тарджа (песенное состязание двух групп; сродни кави-гану и джхумуру) / *tarjā* (a song contest; akin to *kavi-gān* and *jhumur*).
- প্রলয়াবস্থা → состояние пралаи (обморока) / the state of *pralaya* (fainting).
- প্রোষিতভর্তৃকা → [гопи,] чей возлюбленный уехал в далёкие края (прошита-бхартрика) / [a *gopī*] whose beloved has gone abroad (*proṣita-bhartṛkā*).
- প্রবাসাখ্য বিপ্রলম্ভ → разлука, называемая «праваса» (отъезд возлюбленного) / the separation called *pravāsa* (the beloved's absence abroad).
- [যথা রাগঃ] → [мелодия — любая подходящая] (как в общем глоссарии).

## Источники
- হংসদূত → «Хамсадута» / *Haṁsadūta*; পদ্যাবলী → «Падьявали» / *Padyāvalī*; ললিতমাধব → «Лалита-мадхава» / *Lalita-mādhava*; অমর (ইত্যমরঃ) → «Амара-коша» / *Amara-kośa*; ভ্রমরগীতা → «Бхрамара-гита» / *Bhramara-gītā*.
