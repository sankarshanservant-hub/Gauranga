# Новые термины — Антья 18, часть 2 (стихи 56–121)

- স্বরূপ (в подзаголовках) → Сварупа / Svarūpa (как в издании; в тексте стихов — Сварупа Дамодара).
- জালিয়া, ধীবর → рыбак / fisherman; ওঝা → знахарь / exorcist (*ojhā*).
- যথার্থানুমান → верная догадка / correct inference; বুদ্ধিবিভ্রম → замешательство ума / confusion of mind.
- দশাত্রয় → три состояния / the three states; অন্তর্দ্দশা, বাহ্যদশা, অর্দ্ধবাহ্য → внутреннее состояние, внешнее сознание, полувнешнее сознание / internal state, external consciousness, half-external consciousness.
- গোপীর কিঙ্করী → служанка гопи / maidservant of the *gopīs*; যূথেশ্বরী → предводительница (ютхешвари) / group leader (*yūtheśvarī*); লাল্যা কিঙ্করী (মঞ্জরীগণ) → любимые служанки (манджари) / cherished maidservants (*mañjarīs*).
- আত্মেন্দ্রিয়সম্ভোগ-বাঞ্ছা → желание наслаждать собственные чувства / the desire to gratify one's own senses; অহংগ্রহোপাসনা → ахамграхопасана (почитание Богом себя) / *ahaṅgrahopāsanā* (worshipping oneself as God) — как в общем глоссарии.
- করপুষ্কর → руки-лотосы; по другому мнению — кончик хобота (শুণ্ডাগ্র) / lotus hands; another opinion: the tip of the trunk.
- তড়িৎ, নবঘন → молния, новая туча / lightning, fresh cloud.
- পদ্মিনীপত্র → лист лотоса / lotus leaf; অধোবসন → нижняя одежда / lower garment; কঞ্চুলী, কাঁচুলী → корсаж (канчули) / bodice (*kañculī*, *kā̃culī*); স্বস্তিক → свастика (руки, скрещённые на груди) / *svastika* (arms crossed over the breast).
- হেমাব্জ / নীলাব্জ → золотой / синий лотос (хемабджа / нилабджа) / golden / blue lotus (*hemābja* / *nīlābja*); রক্তোৎপল → красная кувшинка (рактотпала) / red water lily (*raktotpala*); উৎপল = কুমুদ → утпала, кумуда (ночная кувшинка) / *utpala*, *kumuda* (night water lily); চক্রবাক → птица чакравака / the *cakravāka* bird.
- বিরোধ, বিরোধাভাস, অতিশয়োক্তি → виродха (противоречие), виродхабхаса (кажущееся противоречие), атишайокти (преувеличение) / *virodha* (contradiction), *virodhābhāsa* (apparent contradiction), *atiśayokti* (hyperbole).
- উপমেয় / উপমান → упамея (то, что сравнивают) / упамана (образ сравнения) / *upameya* (the thing compared) / *upamāna* (the standard of comparison); অধ্যবসায় → адхьявасая (отождествление) / *adhyavasāya* (identification).
- জাতি, গুণ, ক্রিয়া, দ্রব্য (в «Кавья-пракаше») → род (джати), качество (гуна), действие (крия), вещество (дравья) / genus (*jāti*), quality (*guṇa*), action (*kriyā*), substance (*dravya*); উল্লাস → ульласа / *ullāsa*; কারিকা → карика / *kārikā*.
- উদ্বর্তন, আবাটা → удвартана, абата (паста) / *udvartana*, *ābāṭā* (paste) — как в общем глоссарии; সম্ভার → подношения (упаяна) / offerings (*upāyana*); সংস্কার (плодов) → подготовка / preparing.
- Плоды (Ану 104–105): কোলি = কুল, বদরী → ююба / jujube; পনস = কাঁটাল → джекфрут / jackfruit; নারঙ্গ → цитрус из рода апельсинов (камала-лебу) / citrus of the orange kind; দ্রাক্ষা = আঙ্গুর → виноград / grapes; সান্তারা → крупный цитрус из рода помело (батаби-лебу) / large citrus of the pomelo kind; মেওয়া → отборные плоды холодных стран (фисташки, миндаль) / choice fruits of cold countries; খরমুজা → плод, родственный арбузу (пхути, банги) / fruit related to the watermelon (*phuṭi*, *bāṅgī*); ক্ষীরিকা = ক্ষীরাই → огурец кхираи / the *khirāi* cucumber; তাল = তালশাঁস, ফোপল → мякоть пальмового плода (тал-шас), пхопал / palm-fruit flesh (*tāl-śā̃s*), *phopal*; কেশুর = কশেরু, কসেরু → корень травы вроде сыти (мутхи) / nut-grass root; পানীফল = শৃঙ্গাটক → шрингатака (водяной орех) / *śṛṅgāṭaka*; শৈবাল → тина (шайвала) / weed (*śaivāla*); মৃণাল → стебель (корень) лотоса / lotus stalk (root); দাড়িম্ব = ডালিম; মস্কট, বেদানা → гранат (далим); маскат, бедана / pomegranate (*ḍālim*); *maskaṭ*, *bedānā*.
- নাড়ু → сладкие шарики (нару) / sweet balls (*nāḍu*); পিষ্টক → лепёшки (пиштака) / cake-like foods (*piṣṭaka*); ছানা → творог (чхана) / curd (*chānā*); খণ্ডক্ষীরিসার → кханда-кширисара (сладости в форме деревьев из сахара) / *khaṇḍa-kṣīrisāra* (tree-shaped sugar sweets).
- কৃষ্ণসুখবাঞ্ছা → жажда счастья Кришны / longing for Kṛṣṇa's happiness.
- অচৈতন্য / চৈতন্য (игра слов) → лишённый сознания (ачайтанья) / сознание (чайтанья) / bereft of consciousness (*acaitanya*) / consciousness (*caitanya*); কৃষ্ণোন্মুখতা → обращённость к Кришне / being turned toward Kṛṣṇa.
- রদা-রদি (разночтение к বাদাবাদি) → «рада-ради» (рада — зуб) / *radā-radi* (*rada*, tooth).
