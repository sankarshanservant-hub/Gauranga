# Новые термины: Антья 3, часть 1 (стихи 0–136)

Термин → RU / EN.

- নামাভাস → намабхаса, «отблеск имени» (как в выверенной Мадхье 25) / *nāmābhāsa*, the semblance (reflection) of the Name; শুদ্ধনাম → чистое имя / the pure Name.
- সাঙ্কেত্য / সঙ্কেত → намёк (санкета) / indication (*saṅketa*).
- দংষ্ট্রী → кабан (дамштри, «клыкастый») / a boar (*daṁṣṭrī*).
- অরিন্দা (Гопала Чакраварти) → сборщик податей (аринда) / a tax collector (*arindā*).
- ব্রহ্মবন্ধু, পাষণ্ড → брахма-бандху (недостойный брахман), пашанда (безбожник) / *brahma-bandhu*, *pāṣaṇḍa*.
- স্ফূর্ত্তি → видение (спхурти) / a vision (*sphūrti*).
- নিরপেক্ষ → беспристрастный (нирапекша) / impartial (*nirapekṣa*).
- রাণ্ডী → вдова / a widow.
- সূক্ষ্মজীব → тонкие (непроявленные) дживы, сукшма-джива / subtle *jīvas* (*sūkṣma-jīva*).
- কারণোদশায়ী মহাবিষ্ণু → Маха-Вишну Каранодашайи / Mahā-Viṣṇu Kāraṇodaśāyī.
- রাসপূর্ণিমা → Раса-пурнима / the Rāsa full moon.
- স্বয়ং ভগবান কৃষ্ণ → Сам Бхагаван Кришна / Bhagavān Himself, Kṛṣṇa.
- গূঢ়লীলা → сокровенная игра / the confidential pastime.
- আলবন্দারু (শ্রীযামুনাচার্য্য), স্তোত্ররত্ন → Алавандару (Шри Ямуначарья), “Стотра-ратна” / Ālavandāru (Śrī Yāmunācārya), *Stotra-ratna*.
- রামায়ণ (বঙ্গবাসী সংস্করণ) → “Рамаяна” (издание «Бангабаси») / the *Rāmāyaṇa* (Baṅgavāsī edition).
- বেনাপোল, যশোহর, বনগাঁ-জংসন, খুলনা → Бенапол, округ Яшохар, узловая станция Бонгаон, Кхулна / Benāpola, Yaśohara district, Bongaon Junction, Khulnā.
- উসিমিসি / উস্‌খুস্ করা → ёрзать (ус-хус каре) / to fidget (*us-khus kare*).
- নামগ্রহণ-যজ্ঞ, নামযজ্ঞ → ягья повторения имени, нама-ягья / the sacrifice of chanting the Name, *nāma-yajña*; নামিস্বরূপ ভগবান → Бхагаван — Носитель имени (нами) / Bhagavān, the Bearer of the Name (*nāmī*).
- শৌক্র / সাবিত্র যজ্ঞাধিকারী → имеющий право на ягью по рождению (шаукра) / по посвящению Савитри / entitled to sacrifice by birth (*śaukra*) / by Sāvitrī initiation.
- বৈদিক একায়নশাখী দৈক্ষব্রাহ্মণ → ведический брахман по посвящению (дайкша-брахман) из ветви Экаяна / a Vedic *brāhmaṇa* by initiation (*daikṣa-brāhmaṇa*) of the Ekāyana branch; দৈক্ষ-ব্রাহ্মণতা → брахман по посвящению / a *brāhmaṇa* by initiation.
- অপ্রাকৃত যাজ্ঞিকব্রাহ্মণ → трансцендентный брахман-жрец (яджника) / a transcendental *brāhmaṇa* priest (*yājñika*).
- নির্ব্বেদ → отрешённость (нирведа) / detachment (*nirveda*).
- প্রয়োজন-সিদ্ধি → достижение цели (прайоджаны) / attaining the goal (*prayojana*).
