# Глоссарий: Антья 3, часть 2 (стихи 137–270) — новые термины (RU / EN)

- গৃহবিত্ত / গৃহবৃত্তি (разночтение) → грихавитта (домашнее имущество) / грихаврити / *gṛha-vitta* (household wealth) / *gṛha-vṛtti*; বৃত্তি → занятие, ремесло (вритти) / occupation (*vṛtti*).
- দক্ষিণা, দক্ষিণ পথ / উত্তর পথ → дакшина (дар жрецу), южный путь (в обитель Ямы) / северный путь / *dakṣiṇā* (the priest's fee), the southern path / the northern path.
- প্রস্তাব → праства (повод, связь с рассказом, прасанга) / *prastāva* (occasion, connection with the story, *prasaṅga*).
- দুর্গামণ্ডপ / চণ্ডীমণ্ডপ → дурга-мандапа / чанди-мандапа / *durgā-maṇḍapa* / *caṇḍī-maṇḍapa*.
- মজুমদার (মজমু-আদার) → Маджумдар («маджму-адар», хранитель счетов госдоходов) / Majumadāra (*majmu-ādār*, keeper of the revenue accounts).
- মুলুক → мулук (область) / *muluk* (district); আরিন্দা → аринда (пеший сборщик податей) / *ārindā*; তহশীল → тахшил / *tahśīl*; পেয়াদা → пеяда (посыльный) / *peyādā* (runner).
- নামাভাস → намабхаса (отблеск имени) / *nāmābhāsa* (the semblance of the Name); শুদ্ধনাম → чистое имя / the pure Name.
- অর্থবাদ → преувеличение (артхавада) / exaggeration (*arthavāda*); ব্রহ্মবন্ধু → брахмабандху / *brahma-bandhu*; হেতুবাদী → безбожник-спорщик (хетувади) / mere logician (*hetuvādī*).
- ঘটপটিয়া → гхата-патия (наияйика, спорящий о «горшке» и «ткани») / *ghaṭa-paṭiyā* (a *naiyāyika* arguing about “the pot” and “the cloth”).
- রক্ষা (в стихе 218) → ракша (защита положения в обществе) / *rakṣā* (protection of one's standing).
- শ্রাদ্ধপাত্র → шраддха-патра / *śrāddha-pātra*.
- সত্রযাজী, একান্তী, শ্বপচ (цитата «Гаруда-пураны» в «Бхакти-сандарбхе» 117) → совершающий жертвоприношения-сатры, всецело преданный (экантин), псоед / *satra* performer, one wholly devoted (*ekāntī*), dog-eater.
- সংখ্যা-নামকীর্ত্তন-যজ্ঞ → жертвоприношение — киртан имени по счёту / a sacrifice of chanting the Name by a fixed count.
- দ্বিতীয়াভিনিবেশজ ভোক্তৃভাব → чувство «я наслаждающийся», рождённое погружением во «второе» / the sense of being an enjoyer, which arises from absorption in a “second”.
- আব্রহ্মস্তম্ব → от Брахмы до былинки (абрахма-стамба) / from Brahmā down to a blade of grass (*ābrahma-stamba*); তির্য্যক্ → прочие твари (тирьяк) / other creatures (*tiryak*).
- ভোক্তা / ভোগ্যা (о Майе) → «наслаждающийся» (бхокта) / «предмет наслаждения» (бхогья) / “enjoyer” (*bhoktā*) / “object of enjoyment” (*bhogyā*); নিত্যকৃষ্ণভোগ্য → вечно служащий наслаждению Кришны / eternally existing for Kṛṣṇa's enjoyment.
- কোটিকল্প → коти-кальпа (срок в коти — десять миллионов — кальп) / *koṭi-kalpa*.
- মদনজয়ী শম্ভু → Шамбху, победитель Мадана / Śambhu, the conqueror of Madana.
- নামাচার্য্য → ачарья святого имени / the *ācārya* of the holy Name.
- Имена и места: Чандапур (Кришнапур) близ Тривени, округ Хугли / Cā̃dapura (Kṛṣṇapura), near Triveṇī, Hugalī district; Ядунандана Ачарья / Yadunandana Ācārya; Гопала Чакраварти / Gopāla Cakravartī; Вишрава / Viśravā.
