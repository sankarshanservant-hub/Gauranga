# Новые термины — Ади 17, часть 2 (комментарии к стихам 126–336; RU / EN)

## Термины
- শরিয়ৎ, তরিকৎ, মারফৎ → «шариат», «тарикат», «марифат» (три вида пути) / *śarīʿat*, *ṭarīqat*, *maʿrifat* (three kinds of path).
- প্রবৃত্তি / নিবৃত্তি মার্গ → путь правритти (деятельности) / нивритти (отречения) / the path of *pravṛtti* (engagement) / *nivṛtti* (renunciation).
- জরদ্গব → джарадгава (очень старая корова) / *jaradgava* (a very old cow).
- গোমেধ, পলপৈতৃক → гомедха; шраддха предкам с мясом / *gomedha*; a *śrāddha* to the forefathers with meat. দেবর → деверь, младший брат мужа / the husband's younger brother.
- অপৌরুষেয় → апаурушея (не созданное человеком) / *apauruṣeya* (not of human authorship).
- দ্বিতীয়াভিনিবেশ → поглощённость «вторым» (двитийа-абхинивеша) / absorption in a “second” (*dvitīyābhiniveśa*).
- পিয়াদা, চাপরাসী → пиада (слуга-посыльный), «чапраси» / *piyādā* (a servant-messenger), *cāprāsī*. পাতসাহ → падишах / the Pādśāh.
- ম্লেচ্ছ → млеччха / *mleccha*. যবন → яван / *yavana*.
- নামাভাস (সাঙ্কেত্য, পারিহাস্য, স্তোভ, হেলন) → нама-абхаса (намёк на другое, насмешка, напев, пренебрежение) / *nāmābhāsa* (indication of something else, mockery, musical filler, disregard).
- পাষণ্ডী (কর্ম্মজড়, বহ্বীশ্বরবাদী, পৌত্তলিক) → пашанди (погрязший в карме, многобожник, идолопоклонник) / *pāṣaṇḍī* (sunk in *karma*, polytheist, idolater). বহ্বীশ্বরবাদী → многобожник (бахв-ишвара-вадин) / polytheist (*bahv-īśvara-vādī*).
- কর্ম্মাঙ্গ → «часть кармы» (карманга) / “a part of *karma*” (*karmāṅga*). অক্ষজ-হেতুবাদী → спорщик, чьи доводы опираются на чувственное знание (акшаджа-хетувадин) / an arguer whose reasoning rests on sense knowledge (*akṣaja-hetuvādī*).
- ব্রাহ্মণব্রুব → лжебрахман (брахмана-брува) / so-called brāhmaṇa (*brāhmaṇa-bruva*).
- সদাচার → благочестивый обычай (садачара) / proper conduct (*sadācāra*).
- তালাক → торжественное обещание («талак») / a solemn vow (*tālāka*).
- গোলক (смрити) → голака (сын, рождённый вдовой; сноска: Ману 3.174) / *golaka* (a son born to a widow; note: *Manu-saṁhitā* 3.174).
- পরবিদ্যাবধূজীবন → жизнь невесты высшего знания (о Вишну) / the life of the bride of transcendental knowledge (of Viṣṇu).
- উত্তরায়ণ, সংক্রমণ → уттараяна, санкрамана (переход Солнца) / *uttarāyaṇa*, *saṅkramaṇa* (the sun's passage into a new sign).
- (এক) দণ্ড → (одна) данда / (one) *daṇḍa*. কর্ম্মাঙ্গ (সন্ন্যাসের) → обрядовые части санньясы / the ritual parts of *sannyāsa*.
- লম্পট নাগর → «распутный нагара» / a “lecherous *nāgara*”. গৌরনাগরী বাদ → учение «гаура-нагари» / the “Gaura-nāgarī” doctrine (как в общем глоссарии).
- বিষয় / আশ্রয়জাতীয় → вишая / ашрая (поведение вишаи; настроение ашраи) / the *viṣaya* / *āśraya* (the conduct of the *viṣaya*; the mood of the *āśraya*).
- কুম্ভীপাক → Кумбхипака (ад; кумбхи — сосуд) / Kumbhīpāka (a hell; *kumbhī*, a vessel).
- প্রবন্ধ; মুখবন্ধ, উপক্রমণিকা → прабандха (раздел); предисловие, вступление / *prabandha* (section); preface, introduction. প্রতিসংক্রমণ → краткий пересказ / summary recapitulation.
- জন্ম, বাল্য, পৌগণ্ড, কৈশোর, যুবা → «рождение», «детство» (балья), «отрочество» (пауганда), «юность» (кайшора), «молодость» (юва) / “birth,” “childhood” (*bālya*), “boyhood” (*paugaṇḍa*), “youth” (*kaiśora*), “young manhood” (*yuvā*).
- ভক্তরূপ, ভক্তস্বরূপ, ভক্তাবতার, ভক্তাখ্য, ভক্তশক্তি (ГГД 11–16) → в облике преданного; преданный по природе; аватара преданного; зовущиеся преданными; энергия преданного / in the form of a devotee; a devotee by nature; the *avatāra* of a devotee; called devotees; the potency of a devotee.
