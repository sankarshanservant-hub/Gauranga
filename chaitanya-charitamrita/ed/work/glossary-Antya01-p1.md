# Глоссарий: Антья 1, часть 1 (стихи 0–139) — новые термины (RU / EN)

- নান্দী, নান্দী-শ্লোক → нанди, шлока «нанди» (благословляющая шлока в начале драмы) / *nāndī*, the *nāndī* verse (the auspicious opening verse of a play).
- প্রস্তাবনা / আমুখ → праставана (пролог) / амукха / *prastāvanā* (prologue) / *āmukha*.
- সূত্রধার → сутрадхара (руководитель труппы) / *sūtradhāra* (stage manager); নটী → актриса (нати) / actress (*naṭī*); বিদূষক → шут (видушака) / jester (*vidūṣaka*); পারিপার্শ্বিক → помощник (парипаршвика) / assistant (*pāripārśvika*).
- পাত্র (в драме) → патра (персонаж, исполнитель роли) / *pātra* (character, actor playing a role); সন্নিধান → появление на сцене / appearance on stage.
- উদ্ঘাত্যক, কথোদ্ঘাত, প্রয়োগাতিশয়, প্রবর্ত্তক, অবলগিত → удгхатьяка, катходгхата, прайогатишая, правартака (выход на сцену), авалагита / *udghātyaka*, *kathodghāta*, *prayogātiśaya*, *pravartaka* (entrance onto the stage), *avalagita*.
- প্ররোচনা → прарочана / *prarocanā*; বীথী → вити / *vīthī*; প্রহসন → прахасана / *prahasana*.
- বস্তু, বীজ, মুখ (в драме) → васту (предмет), биджа (семя), мукха (завязка) / *vastu* (subject), *bīja* (seed), *mukha* (opening).
- স্বভাবোক্তি → свабхавокти (описание природы вещей) / *svabhāvokti* (description of things as they are).
- অঙ্ক (драмы) → действие / Act (как в общем глоссарии: “Лалита-Мадхава”, действие 5).
- শিখরিণী, রসালা → шикхарини, расала (сладкое питьё) / *śikhariṇī*, *rasālā* (a sweet drink); ঘনসার → гханасара (камфара) / *ghanasāra* (camphor).
- প্রণয় (Радхи и гопи) → любовь (пранайя) / love (*praṇaya*); নবানুরাগ → новая любовь (анурага) / fresh love (*anurāga*) — не «страсть».
- গঙ্গাপ্রাপ্তি → уход из этого мира на берегу Ганги / departure from this world on the bank of the Ganges (не «смерть»).
- কড়চা (о рукописи) → кадача (набросок, черновая рукопись) / *kaḍacā* (a draft).
- ভক্তবাৎসল্য → любовь Бхагавана к Своим преданным / Bhagavān's love for His devotees.
- আত্মপর্য্যন্ত প্রসাদ → милость вплоть до того, что отдаёт Самого Себя / mercy to the point of giving Himself.
- স্ফূর্ত্তি → явление (спхурти) / manifestation (*sphūrti*); ধ্বনি → подразумеваемый смысл (дхвани) / the suggested meaning (*dhvani*).
- Имена и места: Анупама / Anupama; Сатьябхамапур / Satyabhāmāpura; Джанкадеипур / Jānkādeipura; округ Каттак / Cuttack district; Нандимукхи / Nāndīmukhī; Бхагавати Паурнамаси / Bhagavatī Paurṇamāsī; Дамаянти / Damayantī; пулинда / Pulinda; Намачарья (Харидас) / the Nāmācārya; Нитай / Nitāi.
- Источники: “Натака-чандрика”, “Сахитья-дарпана”, “Кавья-пракаша”, “Найшадхия”, «Ямала» / *Nāṭaka-candrikā*, *Sāhitya-darpaṇa*, *Kāvya-prakāśa*, *Naiṣadhīya*, the *Yāmala*.
- Источник в подзаголовке «(বিদগ্ধমাধবে ১ম অঙ্কে ১৫শ শ্লোকে)» → (“Видагдха-мадхава”, действие 1, шлока 15) / (*Vidagdha-mādhava*, Act 1, verse 15); «তস্যোদাহরণং যথা—» → «Пример этого —» / “An example of this —”.
