# Новые термины и имена: Мадхья 16, комментарии, часть 2 (стихи 151–290)

RU / EN.

## Места
- রেমুণা → Ремуна / Remuṇā; ভদ্রক → Бхадрака / Bhadraka; বালেশ্বর → Балешвар / Bāleśvara (как в общем глоссарии).
- পিছলদা → Пичхалада / Pichaladā (деревня на реке Рупанараяне); রূপনারায়ণ-নদ → река Рупанараяна / the Rūpanārāyaṇa river; তমলুক → Тамлук / Tamluk.
- ওঢ্রদেশ → Одра-деша / Oḍra-deśa; সুবর্ণরেখা → Суварнарекха / the Suvarṇarekhā; শ্রীপাট গোপীবল্লভপুর → шрипат Гопиваллабхапур / the *śrīpāṭa* of Gopīvallabhapura.
- ওড়িয়া-কটক → одия-катака (войсковой лагерь, сайнья-катака, на границе Уткалы) / the Oṛiyā *kaṭaka* (army camp, *sainya-kaṭaka*).
- মন্ত্রেশ্বর (নদ) → река Мантрешвар / the Mantreśvara river; ডায়মণ্ডহারবার → Даймонд-Харбор / Diamond Harbour; দুষ্টনদ → опасная река (душта-нада) / dangerous river (*duṣṭa-nada*).
- খড়দহ → Кхардаха / Khaḍadaha; পানিহাটী → Панихати / Pāṇihāṭī; কুমারহট্ট → Кумарахатта (Халисахар) / Kumārahaṭṭa (Hālisahara); কাঞ্চনপল্লী → Канчанапалли (= Канчарапара) / Kāñcanapallī (= Kāñcaḍāpāḍā).
- জহ্নুদ্বীপ → Джахну-двипа / Jahnu-dvīpa; কুলিয়া-পাহাড়পুর, পাড়পুর → Кулия-Пахарпур, Парпур / Kuliyā-Pāhāḍapura, Pāḍapura; কোলদ্বীপ-পর্ব্বত → Коладвипа-парвата / Koladvīpa-parvata; কুলিয়ার পাট → «Кулияр пат» / “Kuliyār Pāṭ”; কোলের গঞ্জ, কোল-আমাদ, কোলের দহ, গদখালি → Колер-гандж, Кола-амада, Колер-дах, Гадакхали / Koler Gañj, Kola-āmāda, Koler Daha, Gadakhāli.
- খানাযোড়া, বড়গাছি, দো-গাছিয়া → Кханайора, Барагачхи, До-гачхия / Khānāyoḍā, Baḍagāchi, Do-gāchiyā; রাঢ়-দেশ → Радха-деш / Rāḍha-deśa.
- বিল্বগ্রাম, পাটুলি, বাঘনাপাড়া, বৈঁচী → Билва-грама, Патули, Багхнапара, Байнчи / Bilva-grāma, Pāṭuli, Bāghnāpāḍā, Baiṁci.
- সপ্তগ্রাম, শ্রীকৃষ্ণপুর, ত্রিশবিঘা → Саптаграм, Шри Кришнапур, станция «Тришабигха» / Saptagrāma, Śrī Kṛṣṇapura, Triśabighā station (как в общем глоссарии).
- খেতরি, যাজিগ্রাম, কালনা → Кхетури, Яджиграм, Кална / Kheturi, Yājigrāma, Kālnā; টোটা → Тота / Ṭoṭā.

## Люди
- শ্রীকর চট্টোপাধ্যায়, যুধিষ্ঠির চট্টোপাধ্যায় → Шрикара Чаттопадхьяя, Юдхиштхира Чаттопадхьяя / Śrīkara Caṭṭopādhyāya, Yudhiṣṭhira Caṭṭopādhyāya; মাধবদাস, হরিদাস, কৃষ্ণসম্পতি → Мадхава дас, Харидас, Кришнасампати / Mādhava dāsa, Haridāsa, Kṛṣṇasampati; ছকড়ি, তিনকড়ি, দুকড়ি → Чхакари, Тинкари, Дукари / Chakaḍi, Tinakaḍi, Dukaḍi; বংশীবদন, রামচন্দ্র → Вамшивадана, Рамачандра / Vaṁśīvadana, Rāmacandra.
- হিরণ্য মজুমদার, গোবর্দ্ধন মজুমদার → Хиранья Маджумдар, Говардхана Маджумдар / Hiraṇya Majumadāra, Govardhana Majumadāra; বলরাম আচার্য্য (পুরোহিত), যদুনন্দন আচার্য্য (গুরু-পুরোহিত) → Баларама Ачарья (пурохита), Ядунандана Ачарья (гуру-пурохита) / Balarāma Ācārya (*purohita*), Yadunandana Ācārya (*guru-purohita*).
- প্রেমদাস → Премадас / Premadāsa (его бенгальское переложение «Чайтанья-чандродаи» — «бхаша»); ঘনশ্যাম দাস (= নরহরি চক্রবর্ত্তী) → Ганашьяма дас / Ghanaśyāma dāsa; ভগবান্ দাস (কালনা) → Бхагаван дас / Bhagavān dāsa.

## Термины
- বিশ্বাস, বিশ্বাসখানা, দপ্তর → вишваса (доверенный чиновник-каястха), «вишваса-кхана», ведомство (даптар) / *viśvāsa*, *viśvāsa-khānā*, department (*daptar*).
- চর → чара (соглядатай) / *cara* (spy); মিতালি → митали (дружба, скреплённая подарками) / *mitāli*.
- সবন → савана (жертвоприношение сомы) / *savana* (*soma* sacrifice).
- মর্কট-বৈরাগ্য, মর্কট-বৈরাগী → марката-вайрагья (обезьянье отречение), «марката-вайраги» / *markaṭa-vairāgya* (monkey renunciation), *markaṭa-vairāgī*; শ্মশান-বৈরাগ্য → шмашана-вайрагья (отречение на месте сожжения) / *śmaśāna-vairāgya*; যুক্তবৈরাগ্য → юкта-вайрагья (истинное отречение) / *yukta-vairāgya*.
- বেষ্টন (আবরণ) → заслон (вештана) / cordon (*veṣṭana*); পাইক, পদাতিক → пеший стражник / foot guard.
- প্রহেলী, প্রহেলিকা, তর্জ্জা → прахели, прахелика, загадка (тарджа) / *prahelī*, *prahelikā*, riddle (*tarjā*); বাদিয়া, বেদে → бадии, беде (бродячие фокусники) / *bādiyās*, *bedes* (itinerant conjurers).
- ভৌম-বৃন্দাবন → земной (бхаума) Вриндаван / the earthly (*bhauma*) Vṛndāvana; ধামবাসী → дхамаваси / *dhāma-vāsī*.
- দক্ষিণা-ভাব → кроткое (дакшина) чувство / gentle (*dakṣiṇa*) feeling.
- “দুর্গমসঙ্গমনী” → “Дургама-сангамани” (комментарий Шри Дживы к БРС) / *Durgama-saṅgamanī*; “নবদ্বীপ-পরিক্রমা” (Нарахари) → “Навадвипа-парикрама” / *Navadvīpa-parikramā*; “শ্রীচৈতন্যচরিত-মহাকাব্য” / “-কাব্য” → “Шри Чайтанья-чарита-махакавья” / “-кавья” / *Śrī Caitanya-carita-mahākāvya* / *-kāvya*.
