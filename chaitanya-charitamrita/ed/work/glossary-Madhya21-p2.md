# Новые термины — Мадхья 21, комментарии, часть 2 (стихи 92–149)

### Madhya21-p2

#### Термины
- স্বারাজ্যলক্ষ্মী → свараджья-лакшми (у ВЧД в стихе 97 — «Свараджйа-шакти») / *svārājya-lakṣmī*.
- ষড়ৈশ্বর্য্য (Ану 96, 104) → шесть достояний (шад-айшварья) / the six opulences (*ṣaḍ-aiśvarya*); в Ану 104 перечень: красота, знание, богатство, сила, слава, отрешённость / beauty, knowledge, wealth, strength, fame, renunciation.
- ভগবত্তা → бхагаватта (природа Бхагавана) / *bhagavattā* (the nature of Bhagavān); ঐশ্বর্য্যপ্রধান / মাধুর্য্যপ্রধান ভগবত্তা → бхагаватта, где главенствует величие / сладость / *bhagavattā* predominated by majesty / by sweetness.
- নরলীলা, নরবপু → игры в облике человека (нара-лила), тело человека / pastimes in human form (*nara-līlā*), a human body; নবকিশোর → свежая юность (нава-кишора) / fresh youth (*nava-kiśora*); নটবর → лучший из танцоров (натавара) / the finest of dancers (*naṭavara*).
- নৈমিত্তিক অবতার → аватары, приходящие по особому поводу (наймиттика) / avatāras who come for a particular occasion (*naimittika*); সবিশেষ / নির্ব্বিশেষ → наделённый качествами (савишеша) / безличный (нирвишеша) / with attributes (*saviśeṣa*) / impersonal (*nirviśeṣa*).
- অন্তঃপুর / মধ্যমাবাস / বাহ্যাবাস → внутренняя / средняя / внешняя обитель / the inner / middle / outer abode.
- সন্ধিনী (যোগমায়ার) → сандхини (йогамайи) / the *sandhinī* (of Yogamāyā); বিশুদ্ধসত্ত্ব-পরিণতি → преображение вишуддха-саттвы / the transformation of *viśuddha-sattva*.
- লাবণ্য → прелесть (лаванья) / loveliness (*lāvaṇya*); তারুণ্য → юность / youth.
- মদনমোহন → Мадана-мохана / Madana-mohana; নবকন্দর্প → нава-кандарпа (новый, надмирный Мадана Враджа) / *nava-kandarpa* (the new, transcendental Madana of Vraja); পঞ্চশর → пять стрел (облик, вкус, запах, звук, прикосновение) / five arrows.
- অনন্যসিদ্ধ / স্বয়ংসিদ্ধ → ананья-сиддха / сваям-сиддха (совершенная сама по себе) / *ananya-siddha* / *svayaṁ-siddha* (perfect by itself).
- বৈভবসত্তা → величественное бытие (вайбхава-сатта) / glorious existence (*vaibhava-sattā*).
- কামগায়ত্রী, কামবীজ → Кама-гаятри, кама-биджа / Kāma-gāyatrī, *kāma-bīja*; সার্দ্ধ-চব্বিশ (২৪॥০) → двадцать четыре с половиной / twenty-four and a half.
- দ্বিজরাজ(-রাজ) → луна, двиджараджа (царь лун) / the moon, *dvija-rāja* (the king of the moons); অষ্টমী-ইন্দু → полумесяц (аштами-инду) / the half-moon (*aṣṭamī-indu*).
- ঠাট / নাট → тхата (пребывание, стхити) / ната (танец, натья) / *ṭhāṭa* (abiding, *sthiti*) / *nāṭa* (dance, *nāṭya*); বিলাসী রাজা → царь, предающийся играм (виласи) / a king given to play (*vilāsī*).
- পক্ষ্ম → веко (пакшма) / eyelid (*pakṣma*); নিমিষে নিন্দন → упрёк морганию / reproaching the blink.
- রসজ্ঞ → «знаток вкуса» (расагья) / a knower of *rasa* (*rasajña*); বিধি → Видхи (Творец) / Vidhi (the Creator).
- সন্নিপাত; ত্রিদোষ; ধাতু → саннипата; три расстройства (доши); составы тела (дхату) / *sannipāta*; the three disorders (*doṣas*); the bodily constituents (*dhātus*).
- চক্রবাত → чакравата (круговой вихрь) / *cakravāta* (a whirlwind); ঘূর্ণী → водоворот / whirlpool.
- বক → цапли (у ВЧД в стихе 109 — «утки») / cranes.
- নীবি, ঘাগ্‌রা → ниви (шнур на поясе), гхагра (юбка) / *nīvi* (waist-cord), *ghāgrā* (skirt).
- অমানী / মানদ → амани (не ищущий почёта) / манада (оказывающий почёт) / *amānī* / *mānada*.
- রসসন্দর্ভ → повествование о расе (раса-сандарбха) / a composition on *rasa* (*rasa-sandarbha*).
- ভক্তুন্মুখী সুকৃতি → сукрити, обращающая к бхакти / *sukṛti* that turns one toward *bhakti*.
- বিপ্রলম্ভ-রস → раса разлуки (випраламбха) / the *rasa* of separation (*vipralambha*).
