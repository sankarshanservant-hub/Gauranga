# Глоссарий комментариев к Мадхье 5 (новые термины, имена, места) — RU / EN

Формат: бенг./санскр. → RU / EN.

## Термины
- অর্চ্চাশ্রিত বিগ্রহ → виграха, явленный в арче (Божестве) / the form manifest as the *arcā*, the Deity.
- ব্রহ্মণ্যদেব → Брахманья-дева / Brahmaṇya-deva; ব্রহ্মণ্য → брахманство (брахманья) / brahminhood (*brahmaṇya*).
- প্রেমকলহ → любовная ссора (према-калаха) / loving quarrel (*prema-kalaha*).
- পাকা মন্দির → прочный каменный храм / solidly built temple.
- মহকুমা → подокруг / subdivision; প্রাদেশিক রাজধানী → провинциальная столица / provincial capital; প্রাদেশিক শাসনকর্ত্তা → наместник / provincial governor.
- পৌত্তলিক → идолопоклонник (паутталика) / idolater (*pauttalika*); শিলাকাষ্ঠবুদ্ধি → видеть в Божестве камень и дерево / regarding the Deity as stone and wood; ভৌমবুদ্ধি → видеть лишь земную материю / regarding as mere earth.
- নাস্তিক → безбожник (настика) / godless (*nāstika*); স্মার্ত্ত → смарта / *smārta*; দেহারামী → живущий ради тела / one who lives for the body.
- ছল → чхала (уловка) / *chala* (quibbling); বাক্যছল → словесная уловка / verbal quibbling; ন্যায় (в стихе) → ньяя — довод (тарка) / *nyāya* — argument (*tarka*); কুতর্ক → кутарка (ложные доводы) / *kutarka*.
- মহাজন (в стихе 76) → Божество (девата) / the Deity (*devatā*).
- রাজমার্গ → раджа-марга (царская дорога) / *rāja-mārga* (the royal road); দেউল → деула (храм) / *deula* (temple).
- উপলভোগের মন্দির, ভোগবর্দ্ধন খণ্ড → храм упала-бхоги, зал бхога-вардханы / the hall of *upala-bhoga*, the *bhoga-vardhana* hall.
- বৈধসন্ন্যাস → вайдха-санньяса (санньяса по предписаниям) / *vaidha-sannyāsa*; বিদ্বৎসন্ন্যাস → видват-санньяса (санньяса познавших) / *vidvat-sannyāsa*; বিবিৎসা-সন্ন্যাস (так в издании) → вивитса-санньяса (санньяса ради стремления к знанию) / *vivitsā-sannyāsa*.
- কুটীচক, বহূদক, হংস, পরমহংস → кутичака, бахудака, хамса, парамахамса / *kuṭīcaka*, *bahūdaka*, *haṁsa*, *paramahaṁsa*; দণ্ডী → дандины / *daṇḍīs*.
- নিত্যসত্য বিগ্রহ → вечно истинная виграха / the eternally true *vigraha*; স্বয়ংসত্য-বিগ্রহ → Сама Истина во плоти / Truth Himself embodied.

## Имена и места
- সাক্ষিগোপাল → Сакши-Гопала / Sākṣi-gopāla; বিদ্যানগর → Видьянагар / Vidyānagara; সত্যবাদী → Сатьявади / Satyavādī.
- যাজপুর → Яджапур / Yājapura; নাভিগয়া → Набхи-гая / Nābhi-gayā; বিরজাক্ষেত্র → Вираджа-кшетра / Virajā-kṣetra; বৈতরণী → Вайтарани / the Vaitaraṇī; ব্রাহ্মণনগর → Брахманнагар / Brāhmaṇanagara; বরাহদেব → Вараха-дева / Varāha-deva.
- কটক → Катак / Kaṭaka; মহানদী → Маханади / the Mahānadī.
- Двенадцать лесов: ভদ্র, বিল্ব, লৌহ, ভাণ্ডীর, মহাবন; মধু, তাল, কুমুদ, বহুলা, কাম্য, খদির, বৃন্দাবন → Бхадра, Бильва, Лауха, Бхандира, Махавана; Мадху, Тала, Кумуда, Бахула, Камья, Кхадира, Вриндаван / Bhadra, Bilva, Lauha, Bhāṇḍīra, Mahāvana; Madhu, Tāla, Kumuda, Bahulā, Kāmya, Khadira, Vṛndāvana; পঞ্চক্রোশী বৃন্দাবন → Панчакроши Вриндаван / Pañcakrośī Vṛndāvana; নন্দগ্রাম, বর্ষাণ → Нандаграм, Варшана / Nandagrāma, Varṣāṇa.
- ভীষ্মক, রুক্মী, রুক্মিণী, বিদর্ভ, চৈদ্য → Бхишмака, Рукми, Рукмини, Видарбха, Чайдья / Bhīṣmaka, Rukmī, Rukmiṇī, Vidarbha, Caidya; যুধিষ্ঠির, অশ্বত্থামা → Юдхиштхира, Ашваттхама / Yudhiṣṭhira, Aśvatthāmā.

- ত্রৈলঙ্গদেশ → страна Траиланга / the land of Trailaṅga; কোটদেশ → Котадеша / Koṭadeśa; গোদাবরী → Годавари / the Godāvarī; রাজমহেন্দ্রী → Раджамахендри / Rājamahendrī; ভিজিয়ানগরম্, ভিজিয়ানা-গ্রাম, বিজয়নগর → Бхиджиянагарам, деревня Бхиджияна, Виджаянагар / Bhijiyānagaram, Bhijiyānā, Vijayanagara.

- কমলপুর → Камалапур / Kamalapura; ভার্গীনদী → река Бхарги / the Bhārgī River; দণ্ডভাঙ্গা → Дандабханга / Daṇḍabhāṅgā; কপোতেশ্বর → Капотешвара / Kapoteśvara; আঠারনালা → Атхаранала / Āṭhāranālā; কাটোয়া → Катва / Kāṭoyā.
