# Новые термины — Мадхья 22, часть 1 (стихи 0–90)

## Термины (RU / EN)
- মায়াপিশাচী → ведьма-майя / the witch Māyā; ষড়ূর্ম্মি (কামক্রোধাদি) → шесть волн (вожделение, гнев и прочие) / the six waves (lust, anger and the rest); সাধুবৈদ্য → врач-садху / a *sādhu*-physician.
- স্থূল ও লিঙ্গ আবরণ → грубая и тонкая оболочки (стхула и линга) / the gross and subtle coverings (*sthūla* and *liṅga*).
- সাক্ষাৎ / গৌণ অভিধেয় → «прямое» / «второстепенное» средство (абхидхея) / the “direct” / “secondary” means (*abhidheya*); নিত্য অভিধেয় → вечная абхидхея / the eternal *abhidheya*.
- অদ্বয়জ্ঞান-তত্ত্ব / অভেদ-তত্ত্ব → истина недвойственного знания (адвая-гьяна-таттва) / истина неразличия (абхеда-таттва) / *advaya-jñāna-tattva* / *abheda-tattva*; স্বরূপাবরণী মায়াশক্তি → майя-шакти, скрывающая истинную природу дживы / the *māyā-śakti*, which covers the *jīva*'s true nature.
- সম্বিদ্বৃত্তি → энергия сознания (самвит) / the potency of consciousness (*saṁvit*); অতন্নিরসন → отвержение всего, что не есть Истина (атат-нирасана) / *atat-nirasana*; অহংগ্রহোপাসনা → поклонение себе как Богу (ахан̇граха-упасана) / *ahaṅgraha-upāsanā*.
- আরোহবাদী → (идущий путём логики) восходящего метода (ароха-вада) / the ascending process (*āroha-vāda*); নির্ভেদ-ব্রহ্মবাদী → брахмавади, не признающий различий / *brahmavādīs* who admit no distinctions.
- আত্মপ্রসাদ → удовлетворение в душе (атма-прасада) / satisfaction of the self (*ātma-prasāda*); অন্তর্য্যামী গুরুদেব → гурудева, знающий сердце / the *gurudeva* who knew his heart; অন্তর্য্যামি-গুরু → гуру в сердце (антарьями-гуру) / the *guru* within the heart (*antaryāmī-guru*).
- ভক্ত্যুন্মুখী / ভোগোন্মুখী / মোক্ষোন্মুখী সুকৃতি → сукрити, обращённая к бхакти / к наслаждению / к освобождению / *sukṛti* turned toward *bhakti* / enjoyment / liberation.
- চেতন (о садху) → пробуждённый (четана) / an awakened soul (*cetana*); লব → лава (11¼ лавы = 1 секунда) / *lava*.
- ফল্গু বৈরাগ্য → ложное (пхалгу) отречение / false (*phalgu*) renunciation; অসদবগ্রহ → дурная привязанность (асад-авограха) / evil attachment (*asad-avagraha*); অসম্ভাবনা → неверие (асамбхавана) / disbelief (*asambhāvanā*).
- দৈব- / অদৈব-বর্ণাশ্রম → дайва- / не-дайва-варнашрама / *daiva* / non-*daiva varṇāśrama*; গোদাস → раб чувств (годаса) / slave of the senses (*godāsa*).
- প্রৌঢ়শ্রদ্ধ / কোমলশ্রদ্ধ → (человек) зрелой веры / некрепкой веры (комала) / of mature faith / of tender faith (*komala*); প্রাকৃতভক্ত, ভক্তপ্রায়, বৈষ্ণবাভাস → пракрита-бхакта, «почти преданный» (бхакта-прая), «тень вайшнава» (вайшнава-абхаса) / *prākṛta-bhakta*, “almost a devotee” (*bhakta-prāya*), “a semblance of a Vaiṣṇava” (*vaiṣṇava-ābhāsa*).
- তটস্থ- / স্বরূপ-লক্ষণ → косвенный (татастха) / сущностный (сварупа) признак / marginal (*taṭastha*) / essential (*svarūpa*) characteristic; কৃষ্ণৈকশরণত্ব → то, что Кришна — единственное прибежище / having Kṛṣṇa as one's only refuge.
- অন্বয় / ব্যতিরেক (বৈষ্ণব-আচার) → «прямое» (анвая) / «обратное» (вьятирека) вайшнавское поведение / Vaiṣṇava conduct in its “direct” (*anvaya*) / “indirect” (*vyatireka*) form.
- মায়াবাদী / মায়াবিলাসী → майявади / майя-виласи (наслаждающийся майей) / *māyāvādī* / *māyā-vilāsī* (enjoyer of *māyā*); মুমুক্ষু / বুভুক্ষু → мумукшу / бубхукшу / *mumukṣu* / *bubhukṣu*; যোষিৎ-ক্রীড়া-মৃগ → «забавный олень» женщин / a “pet deer” of women; মহদ্ব্যবসায়ী → (люди) великой решимости / of great resolve.
- দ্বিজবন্ধুলিঙ্গ → с внешними признаками брахмана лишь по рождению (двиджа-бандху) / bearing the outward marks of a *brāhmaṇa* by birth only (*dvija-bandhu*); ব্রাহ্মণবেষী → в облике брахмана / in the guise of a *brāhmaṇa*.
- পাঠান্তর → другое чтение / another reading; গর্ভস্তোত্র → «Гарбха-стотра» / the “Garbha-stotra”; চতুঃশ্লোকী → «Чатух-шлоки» / the “Catuḥ-ślokī.”
- শ্রীসনাতন শিক্ষা—(২) → Наставления Шри Санатане — (2) … / The instructions to Śrī Sanātana — (2) …

- চমস, হবি (নবযোগেন্দ্র) → риши Чамаса, риши Хави (из девяти Йогендр) / the sage Camasa, the sage Havi (of the nine Yogendras); ভদ্রশ্রবা → Бхадрашрава / Bhadraśravā; প্রচেতোগণ → Прачеты / the Pracetās; সুভদ্রশ্রবা → Субхадрашрава / Subhadraśravā.
