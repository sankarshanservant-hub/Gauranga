# Новые термины: Антья 10, часть 1 (стихи 0–85)

- ঝালি → джхали (мешок, короб с угощениями) / *jhāli* (bag, hamper); রাঘবের ঝালি → «джхали Рагхавы» / “Rāghava's *jhālis*”.
- মুন্সিব্ → мунсиб (смотритель) / *munsib* (steward).
- জগমোহন-পরিমুণ্ডা (песня/киртан) → «Джагамохана-паримунда» / “Jagamohana-parimuṇḍā”.
- পুরাণ শুক্তা → пурана шукта (высушенная горькая зелень) / *purāṇa śuktā* (dried bitter greens); পাটশাক → паташака (зелень джута) / *pāṭa-śāka* (jute greens).
- তৈলাম্র → тайламра (манговый ачар в горчичном масле) / *tailāmra* (mango pickle in mustard oil); গুণ্ডা → гунда (порошок) / *guṇḍā* (powder).
- মনুষ্য-বুদ্ধি → манушья-буддхи (видеть в Нём человека) / *manuṣya-buddhi* (regarding Him as a human being).
- আম (болезнь) → ама / *āma*; অম্লপিত্ত → амла-питта (кислотно-желчная болезнь) / *amla-pitta* (acid-bile disease).
- কোটি-সুখ-পোষ → коти-сукха-пош / *koṭi-sukha-poṣa*.
- অপরাধের আভাস → тень оскорбления / the shadow of an offense.
