#### Термины
- সাধ্য / সাধ্যবস্তু / সাধ্যসার / সাধ্যাবধি → цель (садхья) / предмет цели (садхья-васту) / суть цели (садхья-сара) / предел цели (садхья-авадхи) / the goal (*sādhya*) / the object of the goal (*sādhya-vastu*) / the essence of the goal (*sādhya-sāra*) / the limit of the goal (*sādhya-avadhi*).
- কর্ম্মার্পণ → посвящение деятельности Кришне (кармарпана) / offering one's actions (*karmārpaṇa*); আসক্তিশূন্য কর্ম্ম → деятельность без привязанности / action free from attachment; জ্ঞানমিশ্রা ভক্তি → бхакти, смешанная со знанием / devotion mixed with knowledge; জ্ঞানশূন্যা শুদ্ধভক্তি → чистая бхакти, свободная от знания / pure devotion free from knowledge.
- দাস্যপ্রেম, সখ্যপ্রেম, বাৎসল্যপ্রেম, কান্তপ্রেম → према слуги, према друга, према родителей, према возлюбленной / the *prema* of a servant, of a friend, of parents, of the beloved.
- প্রেমবিলাস-বিবর্ত্ত → «према-виласа-виварта» / *prema-vilāsa-vivarta*.
- ব্রজসখীর আনুগত্য → следование за подругами (сакхи) Враджа / following the *sakhīs* of Vraja.
- মূলতত্ত্ব → изначальная истина (мула-таттва) / original truth (*mūla-tattva*).
- বিজয়মূর্ত্তি → виджая-мурти (Божество для выездов) / the *vijaya-mūrti* (the festival Deity).
- বিজাতীয় / স্বজাতীয় (আশ্রয়) → виджатия («иного рода»), сваджатия (прибежище того же рода) / *vijātīya* (“of another kind”), *svajātīya* (a shelter of the same kind).
- শৌক্রবিপ্র → брахман по рождению (шаукра-випра) / brāhmaṇa by birth (*śaukra-vipra*); দৈক্ষ-ব্রাহ্মণ → брахман по посвящению (дайкша-брахман) / brāhmaṇa by initiation (*daikṣa-brāhmaṇa*); বৈদিক-একায়ন-শাখা → ведическая ветвь Экаяна / the Vedic Ekāyana branch.
- নিন্দ্যকর্ম্ম → ниндья-карма (порицаемый поступок) / *nindya-karma* (a blameworthy act).
- ত্রিসবন স্নান → омовение трижды в день (три-савана) / bathing three times a day (*tri-savana*).
- তাপাদিপঞ্চসংস্কার, নবেজ্যা, অর্থপঞ্চক → пять санскар, начиная с тапы; девятеричное поклонение; пять смыслов (артха-панчака) / the five *saṁskāras* beginning with *tāpa*; the ninefold worship; the five meanings (*artha-pañcaka*).
- অর্চ্চনমার্গ / ভাবমার্গ → путь арчаны / путь бхавы / the path of *arcana* / the path of *bhāva*.
