#### Философия (Веданта, майявада)
- মুখ্যবৃত্তি / অভিধাবৃত্তি / লক্ষণা(-বৃত্তি) / রূঢ়িবৃত্তি → прямое значение (абхидха-вритти) / переносное значение (лакшана-вритти) / рудхи-вритти (= мукхья-вритти) / primary meaning (*abhidhā-vṛtti*) / secondary sense (*lakṣaṇā-vṛtti*) / *rūḍhi-vṛtti* (= *mukhya-vṛtti*).
- সবিশেষ / নির্ব্বিশেষ(ত্ব); বিশেষবাদ → наделённый признаками (савишеша) / отсутствие признаков (нирвишеша); учение о признаках / *saviśeṣa* / featurelessness (*nirviśeṣatva*); the doctrine of features.
- নিঃশক্তিক → лишённый энергий / without potency (*niḥśaktika*); নিরাকার → бесформенный / formless.
- অধ্যারোপবাদ → учение о наложении (адхьяропа-вада) / the doctrine of superimposition (*adhyāropa-vāda*).
- চিদ্বিলাস / নির্ব্বিলাস → духовная игра / отсутствие игры / spiritual play / absence of play.
- কেবল-অভেদবাদ → учение о полном тождестве (кевала-абхеда-вада) / the doctrine of sheer nondifference (*kevala-abheda-vāda*).
- শক্তিপরিণামবাদ → учение о преобразовании энергии (шакти-паринама-вада) / the doctrine of the transformation of potency (*śakti-pariṇāma-vāda*); বিকারী → подверженный изменению (викари) / subject to change (*vikārī*); বিবর্ত্তবুদ্ধি → виварта-буддхи / *vivarta-buddhi*.
- দুষ্টসূত্র → «порочная сутра» / “faulty *sūtra*”; প্রাদেশিক বাক্য → частное изречение (прадешика) / limited statement (*prādeśika*); নামবিগ্রহ → образ в имени (нама-виграха) / form in the name (*nāma-vigraha*).
- চয়স্ত্বিষাম্ (ন্যায়) → правило «чаяс твишам» («скопление лучей») / the maxim *cayas tviṣām* (“a mass of rays”); চিৎপুঞ্জ → скопление духа / mass of spirit; চিৎপরমাণু → атомарная частица духа / atomic particle of spirit.
- চিৎসাহিত্যবাদ / চিদ্রাহিত্যবাদ → учение о «чистом духе» / учение об отсутствии духа / the doctrine of “pure spirit” / the doctrine of the absence of spirit.
- নৈষ্কর্ম্ম্য (প্রাকৃত) → (материальная) найшкармья, свобода от деятельности / (material) *naiṣkarmya*, freedom from action.
- নির্ব্বোধ → лишённый сознания / devoid of consciousness; খণ্ডজ্ঞান → частичное знание / partial knowledge.
- বিতণ্ডা, ছল, নিগ্রহ → витанда, чхала, ниграха (определения — по Ану 177) / *vitaṇḍā*, *chala*, *nigraha*.
- আশ্লিষ্য-দোষ → ашлишья-доша (изъян двусмысленности) / *āśliṣya-doṣa* (the defect of ambiguity).
- ব্রহ্মসাযুজ্য / ঈশ্বরসাযুজ্য; কৈবল্য → брахма-саюджья / ишвара-саюджья; кайвалья / *brahma-sāyujya* / *īśvara-sāyujya*; *kaivalya*; যোগমার্গ → йога-марга / the path of *yoga*; পাতঞ্জল → учение Патанджали, “Йога-сутра” / Patañjali's teaching, the *Yoga-sūtra*; কৈবল্যপাদ → “Кайвалья-пада” / *Kaivalya-pāda*.
- দায়ভাক্ → наследник (дайа-бхак) / heir (*dāya-bhāk*).

#### Энергии и джива
- ক্ষেত্রজ্ঞশক্তি → кшетрагья-шакти (= джива-шакти) / *kṣetrajña-śakti*; কুণ্ঠাবৃত → покрытая и стеснённая / covered and cramped.
- তটস্থত্ব → пограничность (татастхатва) / marginality (*taṭasthatva*); নির্ম্মায়িক সত্তা → бытие, свободное от майи / existence free from *māyā*.
- গুণমায়া / জীবমায়া (подзаголовок 164) → гуна-майя / джива-майя / *guṇa-māyā* / *jīva-māyā*.
- কারাকর্ত্রী (মায়া) → тюремщица / jailer.
- পাষণ্ডী / যমদণ্ড্য → пашанди / достойный кары Ямы / *pāṣaṇḍī* / liable to Yama's punishment; কৈঙ্কর্য্য → кайнкарья (служение) / *kaiṅkarya*.
- শৌক্র-বিচার → суждение по рождению (шаукра) / judgment by birth (*śaukra*).

#### Прасад и быт
- অরুণোদয়-কাল → арунодая-кала (четыре данды перед восходом) / *aruṇodaya-kāla*; শিষ্ট → достойные люди (шишты) / the cultured (*śiṣṭa*).
- ফলশ্রুতি → пхала-шрути (обещание плода) / *phala-śruti* (promise of reward).
