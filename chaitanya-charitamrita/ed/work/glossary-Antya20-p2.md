# Новые термины — Антья 20, комментарии, часть 2 (стихи 71–158 и колофоны; RU / EN)

## Термины
- মহাসুকৃতি → великие благие заслуги (сукрити) / great pious merit (*sukṛti*).
- প্রেম-চেষ্টা → проявления любви / actions of love.
- দৈন্যোক্তি; পুনর্দৈন্যোক্তি → слова смирения; снова слова смирения / words of humility; words of humility once more.
- আদিব্যাস → изначальный Вьяса (ади-вьяса) / the original Vyāsa (*ādi-vyāsa*).
- পরম-প্রমাণ, সর্ব্বশ্রেষ্ঠ প্রমাণ → высшее доказательство (прамана) / the highest authority (*pramāṇa*).
- উচ্ছিষ্টভোজি → тот, кто ест остатки / one who eats the remnants.
- রাঙ্গাটুনি; টুন্টুনী (АПБ 90) → ранга-туни; птичка тунтуни (птица-портниха) / *rāṅgā-ṭuni*; the *ṭunṭunī* bird (tailorbird).
- অপ্রাকৃত কবিসম্রাট → царь трансцендентных поэтов / the emperor of transcendental poets; অহঙ্কার-বিমূঢ়াত্মা → сбитый с толку ложным «я» / bewildered by false ego.
- যন্ত্র-জ্ঞানে → считая себя орудием / regarding himself as an instrument.
- উপাস্য-বিগ্রহ → упасья-виграхи (почитаемые) / *upāsya-vigrahas* (those one worships).
- অনুবাদ (стих 102, подзаг. 140) → повторение (анувада), обзор, пересказ / recapitulation (*anuvāda*).
- সম্বন্ধাভিধেয়-প্রয়োজনাধিদেব → Божества-владыки самбандхи, абхидхеи и прайоджаны / the presiding Deities of *sambandha*, *abhidheya* and *prayojana*; গৌড়ীয়েশ্বর → Владыки гаудиев / the Lords of the Gauḍīyas.
- পঞ্চতত্ত্বাত্মক গৌর → Гаура, который есть Панча-таттва / Gaura, who is the Pañca-tattva.
- রাগমার্গীয় → идущий путём раги / who follows the path of *rāga*; গৌরশক্তিস্বরূপ গুরুবর্গ → гуру — воплощения энергии Гауры / the gurus, embodiments of Gaura's potency.
- চৈতন্যময়ী (о милости Нитьянанды) → исполненная Чайтаньи (сознания) / full of Caitanya (consciousness).
- উপাধ্যায়ী → учитель (упадхьяя), учитель искусств (кала-видьи) / teacher (*upādhyāya*), teacher of the arts (*kalā-vidyā*).
- প্রেমমাধ্বীক; প্রেমমদিরা → хмельной мёд премы; пьянящий напиток премы / the intoxicating honey (drink) of *prema*.
- রসজ্ঞ-রোলম্ব → пчёлы — знатоки расы / bees who know *rasa*.
- প্রপত্তি → предание себя (прапатти) / surrender, taking refuge (*prapatti*).
- কৃষ্ণপঞ্চমী, অসিতপঞ্চমী → кришна-панчами (пятый день тёмной половины месяца) / *kṛṣṇa-pañcamī* (the fifth day of the dark fortnight).
- অঙ্কস্য বামা গতিঃ → «цифры идут справа налево» / “numerals run from right to left”.
- পাঠ (১৫৬–১৫৮ অনেক পাঠে দৃষ্ট হয় না) → списки / manuscripts.
- চৈতন্যাব্দ; গৌর[াব্দ] → эра Чайтаньи; эра Гауры (Гаурабда) / the Caitanya era; the Gaura era (Gaurābda).
- ত্রিবিক্রম (মাস) → месяц Тривикрама / the month of Trivikrama; মেষ → месяц Меша / the month of Meṣa.
- যুগল-পীরিতি → любовь к Божественной Чете / love for the Divine Couple.
- অপ্রকাশ্য কথা → тайна, о которой не говорят где придётся / a secret not spoken of just anywhere.

## Имена, места, источники
- শেষখণ্ড (Чайтанья-бхагаваты) → Шеша-кханда / the Śeṣa-khaṇḍa.
- মনু-সংহিতা (Ану 147) → Ману-самхита, 2.141 / *Manu-saṁhitā* 2.141.
- বিপিনবিহারী (প্রভু) → Випина-вихари / Vipina-vihārī; শ্রীগুরুগোস্বামী → Шри Гуру Госвами / Śrī Guru Gosvāmī.
- শ্রীগোদ্রুম → Шри Годрума / Śrī Godruma; শ্রীসুরভিকুঞ্জ → Шри Сурабхи-кунджа / Śrī Surabhi-kuñja.
- শ্রীব্রজপত্তন → Шри Враджа-паттана / Śrī Vraja-pattana; নবদ্বীপ মায়াপুর → Навадвип, Майяпур / Navadvīpa, Māyāpura; কুলিয়া → Кулия / Kuliyā.
- দয়িতদাসিয়া → Дайита-дасия (форма имени Дайита дас; Бхактисиддханта) / Dayita-dāsiyā.
- শ্রীগৌরকিশোর দাস → Шри Гауракишора дас / Śrī Gaurakiśora dāsa.
- শ্রীমন্মদনগোপাল, গোবিন্দদেব → Шриман Мадана-Гопала, Говинда-дева / Śrīman Madana-Gopāla, Govinda-deva (как в Мадхья 25).
