# Новые термины — Антья 20, комментарии, часть 1 (стихи 0–70; RU / EN)

#### Термины
- লীলা সমাপ্ত করেন (АПБ 0) → «завершил Свои игры» / “concluded His pastimes” (не «умер»).
- বিলাপ (АПБ 1) → сетования (вилапа) / lamentations (*vilāpa*); লপিত, প্রলাপ → бессвязные речи / incoherent words.
- চিত্তোল্লাস, অসহিষ্ণুতা, অস্থিরতা, নিজক্ষুদ্রমননতা, কাতরতা (Ану 1) → радость сердца, нетерпимость, беспокойство, сознание собственной ничтожности, страдание / elation of heart, intolerance, restlessness, the sense of one's own smallness, anguish.
- আটটী সাত্ত্বিক ও তেত্রিশটী ব্যভিচারী (подзаг. 5) → восемь саттвика-бхав и тридцать три вьябхичари-бхавы / the eight *sāttvika* and thirty-three *vyabhicārī bhāvas*.
- সাধ্য-সাধন, উপেয়-উপায় (подзаг. 8) → садхья и садхана, упея и упая (цель и средство) / *sādhya* and *sādhana*, *upeya* and *upāya* (goal and means).
- শাব্দিকাবতার (শ্রীনাম) → аватара в звуке (шабдика-аватара) / the *avatāra* in sound (*śābdika-avatāra*).
- শিক্ষাষ্টক → “Шикшаштака” / the *Śikṣāṣṭaka*; শ্রীভাগবত-নির্য্যাস → суть “Шри Бхагаватам” / the essence of the *Śrī Bhāgavatam*; শ্রীমদ্ভাগবত-ফল-নির্য্যাস → выжатая суть плода “Шримад-Бхагаватам” / the distilled essence of the fruit of *Śrīmad-Bhāgavatam*.
- পদ্যাবলীতে N অঙ্কে ধৃত শিক্ষাষ্টকের Mম শ্লোক → `> (M-я шлока “Шикшаштаки”, приведённая в “Падьявали” под номером N)` / `> (The M-th verse of the *Śikṣāṣṭaka*, cited in the *Padyāvalī* as number N)`.
- শ্লোকার্থ-ব্যাখ্যা → Объяснение смысла шлоки / Explanation of the verse.
- কৈরব, কুমুদ → белые кувшинки (кайрава, кумуда) / white lilies (*kairava*, *kumuda*); বিদ্যাবধূ → невеста-знание (видья) / the bride Knowledge (*vidyā*); সর্ব্বস্বরূপের শীতলকারী → освежает прохладой истинное «я» (сварупу) каждого / bathes the true self (*svarūpa*) of everyone in coolness.
- দেহাত্মবুদ্ধি → отождествление себя с телом / identifying oneself with the body; নৈরন্তর্য্য → непрерывность / uninterruptedness.
- অপৌনর্ভব → апаунарбхава (избавление от новых рождений) / *apaunarbhava* (freedom from further births); ত্রিবর্গ → триварга / *trivarga*; কৈতবাত্মক → обманный по природе / deceitful by nature.
- অহৈতুকী (নিষ্কামা ব্যবধানরহিতা) → беспричинная (лишённая желаний, ничем не прерываемая) / causeless (free from desires, uninterrupted).
- সাধ্যভক্তি → садхья-бхакти / *sādhya-bhakti*; বাহ্যলক্ষণ / অন্তর্লক্ষণ → внешние / внутренние признаки / external / inner signs.
- ত্রুটি, লব → трути, лава (мельчайшие доли времени) / *truṭi*, *lava*.
- একান্ত কৃষ্ণপরতন্ত্রতা → безраздельная зависимость от Кришны / exclusive dependence on Kṛṣṇa; কৃষ্ণপরতন্ত্রা-শিরোমণি → венец тех, кто всецело во власти Кришны / the crown jewel of those wholly in Kṛṣṇa's power.
- পিনষ্টু (АПБ 47: পেষণ করুন; Ану: আত্মসাৎ করোতু) → «стиснет в объятиях» (АПБ) / «пусть сделает Своей» (Ану) / “crush in His arms” / “let Him make His own.”
- লম্পট, লম্পটপুরুষ (о Кришне в словах Радхи, 47) → распутник (лампата) / libertine (*lampaṭa*).
- মদীয়ত্ব / তদীয়ত্ব স্নেহ; মধু / ঘৃত স্নেহ → снеха «моё» (мадиятва) / «Его» (тадиятва); снеха, подобная мёду / топлёному маслу / the *sneha* of “mine” (*madīyatva*) / “His” (*tadīyatva*); *sneha* like honey / like ghee.
- কৃষ্ণেন্দ্রিয়তর্পণ, কৃষ্ণেন্দ্রিয়প্রীতিবাঞ্ছা → желание порадовать (усладить) чувства Кришны / the desire to please Kṛṣṇa's senses; আত্মেন্দ্রিয়প্রীতিবাঞ্ছা → желание усладить собственные чувства / the desire to please one's own senses.
- কৃষ্ণের সম্ভোগ-কামিনী → та, что жаждет наслаждения (самбхоги) с Кришной / the woman who craves enjoyment (*sambhoga*) with Kṛṣṇa.
- পাতিব্রত্য, পতিব্রতা → верность мужу (пативратья), верная жена (пативрата) / faithfulness (*pātivratya*), faithful wife (*pativratā*); বিপ্রবন্ধু → брахман лишь по рождению (випра-бандху) / a brahmin in name only (*vipra-bandhu*).
- কেবল-প্রেম → чистая любовь (кевала-према) / pure love (*kevala-prema*).
- স্বভজন-বিভজন-প্রয়োজনাবতার → аватара, явившаяся, чтобы Самому вкушать служение Себе и раздавать его / the *avatāra* who came to relish worship of Himself and to distribute it.
- দার্শনিক পণ্ডিতপ্রবর, তত্ত্ববিৎ, সূক্ষ্মদর্শী (прозвища, Ану 28) → «учёный философ», «знаток таттвы», «тонкий мыслитель» / “learned philosopher,” “knower of *tattva*,” “subtle thinker”; রসিক, ভজনানন্দী, ভাগবতোত্তম, লীলারসপানোন্মত্ত, রাগানুগীয়-সাধকাগ্রগণ্য, রসজ্ঞ, রসিকচূড়ামণি → «расика», «блаженствующий в бхаджане», «лучший из бхагават», «опьянённый питьём расы лилы», «первый среди садхаков раганугической бхакти», «знаток расы», «венец расиков».
- বৈরস্যাত্মক প্রাকৃত-সম্ভোগ → мирская самбхога, по сути лишённая вкуса / material *sambhoga*, at heart tasteless.
- অষ্টপদী → ашта-пади / *aṣṭa-padīs*.

#### Имена, места, источники
- শ্রীগীতগোবিন্দ (জয়দেব-কৃত), শ্রীজগন্নাথবল্লভনাটক (শ্রীরায়-রামানন্দ-কৃত), শ্রীকর্ণামৃত (শ্রীবিল্বমঙ্গল-কৃত) → “Шри Гита-Говинда” (Джаядевы), “Шри Джаганнатха-валлабха-натака” (Шри Рамананды Рая), “Шри Карнамрита” (Шри Бильвамангалы) / *Śrī Gīta-govinda* (Jayadeva), *Śrī Jagannātha-vallabha-nāṭaka* (Śrī Rāmānanda Rāya), *Śrī Karṇāmṛta* (Śrī Bilvamaṅgala).
- পদ্যাবলী → “Падьявали” / the *Padyāvalī*; ভক্তিসন্দর্ভ ৬৯ সংখ্যা → “Бхакти-сандарбха” (раздел 69) / *Bhakti-sandarbha* (section 69).
- আদিত্য-পুরাণ, মার্কণ্ডেয়-পুরাণ, পদ্মপুরাণ → “Адитья-пурана”, “Маркандея-пурана”, “Падма-пурана” / *Āditya Purāṇa*, *Mārkaṇḍeya Purāṇa*, *Padma Purāṇa*; মাণ্ডব্য ঋষি → мудрец Мандавья / the sage Māṇḍavya.
- শেষ-বিষ্ণু → Шеша-Вишну / Śeṣa-Viṣṇu; জগন্নাথ (глосса к জগদীশ) → Джаганнатха / Jagannātha.

#### Оформление
- Ссылка на «Падьявали» над шлокой «Шикшаштаки» — отдельной строкой `> (…)` после подзаголовка.
- Добавления издания перед анваей без слова стиха (напр. «হে প্রভো») — в скобках не жирным: «(О Господь,)».
