# Новые термины — Антья 19, комментарии, часть 2 (стихи 56–112; RU / EN)

#### Термины
- নামসঙ্কীর্ত্তনে রাত্রি-যাপন → ночь в киртане святых имён / the night spent in *kīrtana* of the holy names.
- মুখসংঘর্ষণ → трение лица о стены / rubbing the face against the walls; উদ্‌ঘূর্ণা → удгхурна / *udghūrṇā* (как в общем глоссарии).
- প্রভু-পাদোপাধান; চরণোপধান → подушка для стоп Господа / the pillow for the Lord's feet.
- নিমগ্নোন্মগ্ন দশা → то погружается, то всплывает / now sinks, now surfaces.
- দশপ্রকার চিত্রজল্প → читра-джалпа десяти видов / the ten kinds of *citra-jalpa*.
- নটনগুরু (নৃত্য-শিক্ষক) → учитель танца (натана-гуру) / dance teacher (*naṭana-guru*).
- অষ্টাঙ্গ (দুই চক্ষু, নাভি, মুখ, দুই হস্ত, দুই পদ) → восемь частей тела / the eight limbs.
- চর্চ্চা → умащение / anointing; হেমকীলিত → оправленный в золото / set in gold; চুরি (АПБ 95) → сокрытие (утаивание) / concealment; বাউরী → обезумевшая / maddened.
- অধোক্ষজ → недоступный чувствам (адхокшаджа) / beyond the senses (*adhokṣaja*); কার্ষ্ণলীলা → игры, связанные с Кришной (каршна-лила) / the pastimes connected with Kṛṣṇa (*kārṣṇa-līlā*).
- অক্ষজজ্ঞানী → тот, чьё знание добыто чувствами / one whose knowledge comes from the senses; পণ্ডিতম্মন্য, পণ্ডিতাভিমানী → мнящий себя учёным / one who thinks himself learned; জড়বিদ্যা-মত্ত → опьянённый мирской учёностью / intoxicated with material learning; তর্কপন্থী → идущий путём рассуждений / one who follows the path of argument.
- মন্ত্র-শিষ্য (АПБ 101) → ученик, получивший мантру / a disciple who received *mantra*.
- অনঙ্গ-বেদনা → боль Ананги / the pain of Anaṅga; ত্রিবর্গ → три цели жизни (триварга) / the three aims of life (*trivarga*).
- কুররী, চক্রবাকী → курари, чакраваки / *kurarī*, *cakravākī*.
- [ যথা রাগঃ ] → [Напев — любая рага (ятха-рага)] / [Any *rāga* as suits (*yathā-rāga*)] (как в Антья 16–17).

#### Имена, источники
- মৈত্রেয়, বিদুর, স্বায়ম্ভুব মনু, শতরূপা → Майтрея, Видура, Сваямбхува Ману, Шатарупа / Maitreya, Vidura, Svāyambhuva Manu, Śatarūpā.
- সারার্থদর্শিনী টীকা → комментарий «Сарартха-даршини» / the *Sārārtha-darśinī* commentary.
- স্তবাবলী, চৈতন্যস্তবকল্পবৃক্ষ → Стававали: “Чайтанья-става-калпаврикша” / *Stavāvalī*: *Caitanya-stava-kalpavṛkṣa*.
- ভঃ রঃ সিঃ পূঃ বিঃ প্রেমভক্তিলহরী → Бхакти-расамрита-синдху, Пурва-вибхага, Према-бхакти-лахари / *Bhakti-rasāmṛta-sindhu*, Pūrva-vibhāga, Prema-bhakti-laharī.
- ভ্রমরগীতা (Бхаг. 10.47.12–21); মহিষীগণের গীত (Бхаг. 10.90.15–24) → «Бхрамара-гита»; песни цариц / the *Bhramara-gītā*; the songs of the queens.
- বালি, শূর্পণখা, বলি, বামন → Вали, Шурпанакха, Бали, Вамана / Vāli, Śūrpaṇakhā, Bali, Vāmana.
- স্বরূপ, রায় (подзаголовки) → Сварупа, Рай / Svarūpa, Rāya.
