# Новые термины — Мадхья 18, часть 1 (стихи 0–100)

Формат: бенг./санскр. → RU / EN.

## Места
- আরিট্-গ্রাম, অরিষ্ট(-গ্রাম), অরিঙ্গ → Арит-грама, «Аришта», ныне «Аринг» / Āriṭ-grāma, “Ariṣṭa,” now “Ariṅg”.
- রাধাকুণ্ড, শ্যামকুণ্ড → Радха-кунда, Шьяма-кунда / Rādhā-kuṇḍa, Śyāma-kuṇḍa; তদীয়-সরসী (ГЛ 7.102) → Радха-кунда, «Её озеро» / Rādhā-kuṇḍa (не «пруд» в мирском смысле).
- সুমনঃ-সরোবর = কুসুম-সরোবর → Суманах-саровара = Кусума-саровара / Sumanaḥ-sarovara = Kusuma-sarovara.
- গোবর্দ্ধন-গ্রাম; হরিদেব → деревня Говардхана; Харидева (у ВЧД «Харидэв») / the village of Govardhana; Harideva.
- ব্রহ্মকুণ্ড → Брахма-кунда / Brahma-kuṇḍa; মানসগঙ্গা → Манаса-Ганга / Mānasa-gaṅgā; গোবিন্দকুণ্ড → Говинда-кунда / Govinda-kuṇḍa.
- অন্নকূট(-গ্রাম); আনিয়োর; পৈঠা-গ্রাম → Аннакута(-грама); «Анийор»; деревня Пайтха / Annakūṭa(-grāma); “Āniyor”; Paiṭhā.
- গাঠোলী / গাঁঠোলী (стих: গাঙ্ঠুলি) → Гатхоли (как у ВЧД); в народной этимологии от গাঁঠি «узел» — «Гантхоли» / Gāṭholī; “Gā̃ṭholī”.
- গোপালপুর, বিলছু → Гопалпур, Билчху / Gopālapura, Bilchu.
- কাম্যবন / কাম্যকবন → Камьяван (как у ВЧД) / лес Камьяка / Kāmyavana / Kāmyaka-vana.
- নন্দীশ্বর; পাবন-সরোবর (পাবন-কুণ্ড) → Нандишвара (у ВЧД «Нандишвар»); Павана-саровара / Nandīśvara; Pāvana-sarovara.
- খদিরবন, শেষশায়ী, খেলা-তীর্থ / খেলনবন, ভাণ্ডীরবন (ভাণ্ডীরক; অক্ষয়বট), ভদ্রবন, শ্রীবন (বিল্ববন), লোহবন (লোহজঙ্ঘ-বন), মহাবন → Кхадираван, Шешашайи, Кхела-тиртха / Кхелана-ван, Бхандираван (Бхандирака; «Акшая-вата»), Бхадраван, Шриван (Бильваван), Лохаван (Лохаджангха-ван), Махаван / Khadiravana, Śeṣaśāyī, Khelā-tīrtha / Khelana-vana, Bhāṇḍīravana (Bhāṇḍīraka; “Akṣaya-vaṭa”), Bhadravana, Śrīvana (Bilvavana), Lohavana (Lohajaṅgha-vana), Mahāvana.
- যমলার্জ্জুন-তীর্থ → Ямаларджуна-тиртха / Yamalārjuna-tīrtha; যোগপীঠ → Йогапитха / the Yogapīṭha.
- অক্রূর-ঘাট / অক্রূর-তীর্থ / অক্রূর-গ্রাম → Акрура-гхат / Акрура-тиртха / деревня Акрура / Akrūra-ghāṭa / Akrūra-tīrtha / the village of Akrūra.
- কালীয়-হ্রদ / কালীয়-তীর্থ, প্রস্কন্দন, দ্বাদশাদিত্য(-ঘাট / -তীর্থ), কেশীঘাট / কেশীতীর্থ, রাসস্থলী, চীরঘাট, আম্লিতলা / তেঁতুলতলা → Калия-храда / Калия-тиртха, Праскандана, Двадашадитья(-гхат / -тиртха), Кеши-гхат / Кеши-тиртха, Раса-стхали, Чира-гхат, Амли-тала / Тентул-тала / Kālīya-hrada / Kālīya-tīrtha, Praskandana, Dvādaśāditya(-ghāṭa / -tīrtha), Keśī-ghāṭa / Keśī-tīrtha, Rāsa-sthalī, Cīra-ghāṭa, Āmli-talā / Tẽtula-talā.
- তালখড়ি, কাচনাপাড়া, সোনাখালি, খেজুরা; যশোহর; ই, বি, আর → Талкхади, Качнапара, Сонакхали, Кхеджура; Яшохар; Восточно-Бенгальская железная дорога / Tālakhaḍi, Kācanāpāḍā, Sonākhāli, Khejurā; Yaśohara; the Eastern Bengal Railway.
- সোরোক্ষেত্র, সোরো; ত্রিবেণী → Соро-кшетра, Соро; Тривени / Soro-kṣetra, Soro; Triveṇī (как в ч. 2).

## Имена
- বিজলী খাঁ (в «Кратком содержании») → Биджули Хан (как в ч. 2) / Bijulī Khān.
- বিঠ্ঠলেশ্বর, বিঠ্ঠলনাথ, বিঠ্ঠল দীক্ষিত; বল্লভ ভট্ট → Виттхалешвара, Виттхаланатха, Виттхала Дикшита; Валлабха Бхатта / Viṭhṭhaleśvara, Viṭhṭhalanātha, Viṭhṭhala Dīkṣita; Vallabha Bhaṭṭa.
- Сыновья Валлабхи и Виттхалы: গোপীনাথ; গিরিধর, গোবিন্দ, বালকৃষ্ণ, গোকুলেশ, রঘুনাথ, যদুনাথ, ঘনশ্যাম → Гопинатха; Гиридхара, Говинда, Балакришна, Гокулеша, Рагхунатха, Ядунатха, Ганашьяма / Gopīnātha; Giridhara, Govinda, Bālakṛṣṇa, Gokuleśa, Raghunātha, Yadunātha, Ghanaśyāma.
- লোকনাথ (গোস্বামী); পদ্মনাভ; প্রগল্ভ; «তালখড়ির ভট্টাচার্য্য» → Локанатха (Госвами); Падманабха; Прагалбха; «Бхаттачарьи из Талкхади» / Lokanātha (Gosvāmī); Padmanābha; Pragalbha; “the Bhaṭṭācāryas of Tālakhaḍi”.
- লঘু-হরিদাস (ছোট-হরিদাস) → Лагху-Харидас (Чхота Харидас) / Laghu-haridāsa (Choṭa Haridāsa); লঘু, মধ্যম → «лагху» (младший), «мадхьяма» (средний) / “Laghu” (junior), “Madhyama” (middle).
- Из «Бхакти-ратнакары» (6-я волна): মধু-পণ্ডিত, পরমানন্দ-ভট্টাচার্য্য, কৃষ্ণদাস ব্রহ্মচারী, দ্বিজ-হরিদাস → Мадху Пандит, Парамананда Бхаттачарья, Кришнадас Брахмачари, Двиджа Харидас / Madhu Paṇḍita, Paramānanda Bhaṭṭācārya, Kṛṣṇadāsa Brahmacārī, Dvija Haridāsa.
- রাণী পদ্মাবতী → царица Падмавати / Queen Padmāvatī; লোহজঙ্ঘাসুর → асура Лохаджангха / the demon Lohajaṅgha; অঘারি; বকভিৎ → враг Агхи; Убийца Баки / the enemy of Agha; the slayer of Baka; মঘবা → Магхаван / Maghavān; বৃন্দা → Вринда / Vṛndā; সূর্য্যকন্যা → дочь Солнца (Ямуна) / the daughter of the Sun.

## Термины
- ছল (ম্লেচ্ছভয়-চ্ছল) → предлог («чхала») / pretext (*chala*).
- বিবর্ত্তবুদ্ধি; কৃষ্ণস্ফূর্ত্তি → ошибочное представление (виварта-буддхи); «явился Кришна» / mistaken notion (*vivarta-buddhi*); “Kṛṣṇa was revealed.”
- চিৎকণ (জীব) → частица духа (чит-кана) / particle of spirit (*cit-kaṇa*).
- ম্লেচ্ছাচার্য্য → мусульманский наставник (млеччха-ачарья) / Muslim teacher (*mleccha-ācārya*); পাঠান ঘোড়সোয়ার → всадники-патханы / Paṭhān horsemen; ধুতুরা → дурман (дхутура) / *dhuturā*.
- তুরুক; তুরুকধারী; গ্রামী → турука (мусульманское войско: турки или патханы); турука-дхари (конные воины в турецкой одежде); грами (житель деревни) / *turuka*; *turuka-dhārī*; *grāmī*.
- লুপ্ত (তীর্থ) → «утрачена» (лупта) / “lost” (*lupta*).
- পাক / অন্নপাক → пака (анна-пака, приготовление пищи) / *pāka* (*anna-pāka*, cooking).
- ভক্তাভিমানী → считающий Себя преданным, слугой / who regards Himself as a devotee, a servant; স্বরূপবিগ্রহ → Свой собственный облик / His own form.
- ভগবন্মূর্ত্তি (о Говардхане) → непосредственно облик Бхагавана / directly the form of Bhagavān.
- অভিষেক → абхишека / *abhiṣeka*; ফাগুয়া → пхагуя (праздничный дар на Холи) / *phaguā* (a festive gift).
- প্রণয়গ্রন্থি-বন্ধন → узел любви / the knot of love.
- সংখ্যা-নাম(-কীর্ত্তন) → повторение имени по счёту / chanting the name by count.
- পরতেক → паратека («пратьякша», «сакшат», воочию) / *parateka* (*pratyakṣa*, *sākṣāt*, before one's eyes).
- কমণ্ডলু → камандалу / *kamaṇḍalu*; বাতুল-চেষ্টা → ведёт Себя как безумный / behaves like a madman.
- সেবা-অধিকারী → распорядитель служения / the one in charge of the service; টিপ্পনী → примечания (типпани) / notes (*ṭippanī*).
