# Глоссарий Ади 5, часть B (стихи 49–120), комментарии — новые термины (RU / EN)

- উপাদান-কারণ / নিমিত্ত-কারণ → материальная причина (упадана-карана) / действующая причина (нимитта-карана) —
  material cause (*upādāna-kāraṇa*) / efficient cause (*nimitta-kāraṇa*); উপাদানাংশ / নিমিত্তাংশ → материальная /
  действующая часть — material / efficient portion. (Как в части A, «Краткое содержание».)
- গৌণ কারণ / মুখ্য কারণ → второстепенная / главная причина — secondary / chief cause.
- অঙ্গাভাস → анга-абхаса (подобие тела) — *aṅgābhāsa* (a semblance of His body).
- ঈক্ষণ → взгляд (икшана) — glance (*īkṣaṇa*).
- কারণ-সমুদ্র, কারণার্ণব, কারণবারি → Причинный океан (Карана-самудра), Причинные воды — the Causal Ocean
  (*Kāraṇa-samudra*), the Causal Waters.
- কারণাব্ধিশায়ী / কারণার্ণবশায়ী / কারণোদকশায়ী → Каранабдхишайи / Каранарнавашайи / Каранодакашайи (как в оригинале).
- অজাগলস্তন → сосцы на шее козла (козы) — the nipples (teats) on a goat's neck.
- ত্রসরেণু / পরমাণু → трасарену / параману (мельчайшая частица) — *trasareṇu* / *paramāṇu* (the finest particle).
- অব্যক্ত / অব্যাকৃত → непроявленное / авьякрита (неразвёрнутое) — the unmanifest / *avyākṛta*, the undeveloped.
- নিষেধাবধিভূত তত্ত্ব → Истина — предел отрицания — the Truth at which all is negated (the limit of negation).
- আবরণী / বিক্ষেপাত্মিকা (শক্তি) → покрывающая / отбрасывающая — covering (*āvaraṇī*) / projecting (*vikṣepātmikā*).
- অনুপাদেয়তা → нежеланность — undesirability.
- সেবোন্মুখতা / সেবাবিমুখ → обращённость к служению / отвернувшийся от служения — readiness to serve / averse to service.
- চিদ্ভাবাভাস → подобие духовного бытия — a semblance of spiritual being.
