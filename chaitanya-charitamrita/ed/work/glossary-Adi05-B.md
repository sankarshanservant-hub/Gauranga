# Глоссарий Ади 5, часть B (стихи 49–120), комментарии — новые термины (RU / EN)

- উপাদান-কারণ / নিমিত্ত-কারণ → материальная причина (упадана-карана) / действующая причина (нимитта-карана) —
  material cause (*upādāna-kāraṇa*) / efficient cause (*nimitta-kāraṇa*); উপাদানাংশ / নিমিত্তাংশ → материальная /
  действующая часть — material / efficient portion. (Как в части A, «Краткое содержание».)
- গৌণ কারণ / মুখ্য কারণ → второстепенная / главная причина — secondary / chief cause.
- অঙ্গাভাস → анга-абхаса (подобие тела) — *aṅgābhāsa* (a semblance of His body).
- ঈক্ষণ → взгляд (икшана) — glance (*īkṣaṇa*).
- কারণ-সমুদ্র, কারণার্ণব, কারণবারি → Причинный океан (Карана-самудра), Причинные воды — the Causal Ocean
  (*Kāraṇa-samudra*), the Causal Waters.
- কারণাব্ধিশায়ী / কারণার্ণবশায়ী / কারণোদকশায়ী → Каранабдхишайи / Каранарнавашайи / Каранодакашайи (как в оригинале).
- অজাগলস্তন → сосцы на шее козла (козы) — the nipples (teats) on a goat's neck.
- ত্রসরেণু / পরমাণু → трасарену / параману (мельчайшая частица) — *trasareṇu* / *paramāṇu* (the finest particle).
- অব্যক্ত / অব্যাকৃত → непроявленное / авьякрита (неразвёрнутое) — the unmanifest / *avyākṛta*, the undeveloped.
- নিষেধাবধিভূত তত্ত্ব → Истина — предел отрицания — the Truth at which all is negated (the limit of negation).
- আবরণী / বিক্ষেপাত্মিকা (শক্তি) → покрывающая / отбрасывающая — covering (*āvaraṇī*) / projecting (*vikṣepātmikā*).
- অনুপাদেয়তা → нежеланность — undesirability.
- সেবোন্মুখতা / সেবাবিমুখ → обращённость к служению / отвернувшийся от служения — readiness to serve / averse to service.
- চিদ্ভাবাভাস → подобие духовного бытия — a semblance of spiritual being.
- শক্তিমত্তত্ত্ব → Обладатель силы (шактиман-таттва) — the Possessor of potency (*śaktimat-tattva*).
- পঙ্গ্বন্ধন্যায় → правило хромого и слепого — the maxim of the lame and the blind.
- তদেকাত্মরূপ / দ্বার → тад-экатма-рупа / посредник — *tad-ekātma-rupa* / medium.
- অপ্রপঞ্চ / প্রপঞ্চ → то, что за пределами мира / мир, прапанча — what lies beyond the world / the world (*prapañca*).
- ষোড়শকল → наделённый шестнадцатью калами — endowed with sixteen *kalās*; имена шакти (Шри, Бху, Кирти, Ила, Лила, Канти,
  Видья, Вимала, Уткаршини, Гьяна, Крия, Йога, Прахви, Сатья, Ишана, Ануграха…) — транслитерацией без перевода.
- সত্ত্বতনু → саттва-тану — *sattva-tanu*; নির্গুণ → ниргуна (вне гун) — *nirguṇa* (beyond the *guṇas*).
- ঈশ্বরকোটি / জীবকোটি → разряд Ишвары / разряд джив — the category of the Lord / of *jīvas*; শক্ত্যাবিষ্ট জীব →
  шактьявеша-джива — empowered *jīva* (*śaktyāviṣṭa*); আবেশাবতার → авеша-аватара — *āveśa-avatāra*.
- শয্যারূপ শেষ / ভূধারী শেষ → Шеша-ложе / Шеша, держащий землю — Śeṣa the bed / the earth-bearing Śeṣa.
- প্রাদেশমাত্র → размером в пядь — the size of a span; সপ্তবিতস্তি → семь пядей — seven spans.
- বিভূতি → достояние (вибхути) — opulence (*vibhūti*); বিকলা → викала — *vikalā*.
- Источники: “Параматма-сандарбха”, “Шри Кришна-сандарбха”, “Сиддханта-широмани”, “Вишну-дхармоттара”, “Брахманда-пурана”,
  “Вамана-пурана”, “Сканда-пурана” (“Айодхья-махатмья”), “Махабхарата” (“Мокша-дхарма”, “Шанти-парва”), “Шрутапракашика”
  (Сударшаначарьи) / *Paramātma-sandarbha*, *Śrī Kṛṣṇa-sandarbha*, *Siddhānta-śiromaṇi*, *Viṣṇu-dharmottara*,
  *Brahmāṇḍa Purāṇa*, *Vāmana Purāṇa*, *Skanda Purāṇa* (*Ayodhyā-māhātmya*), *Mahābhārata* (*Mokṣa-dharma*,
  *Śānti-parva*); «Бхагавата-татпарья» Мадхвы / *Bhāgavata-tātparya*; «Татхья» (раздел «Гаудия-бхашьи») / *Tathya*.
- Места/имена: Вираджа, Шветадвипа, Шубхраварна, Маха-Вишнулока, Сумеру/Меру, Джамбудвипа, Вадаванала, Друмила (один из
  девяти Йогендр), Шарнги / Virajā, Śvetadvīpa, Śubhravarṇā, Mahā-Viṣṇuloka, Sumeru/Meru, Jambudvīpa, Vaḍavānala, Drumila, Śārṅgī.
