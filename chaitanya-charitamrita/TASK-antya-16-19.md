# Задание: перевод недостающих глав Антья-лилы ЧЧ (16, 17, 18, 19) в стиле Вриндавана Чандры даса

У пользователя есть русский перевод «Шри Чайтанья-чаритамриты» Кришнадаса Кавираджа, выполненный Вриндаваном Чандрой
дасом (Google Drive пользователя; текстовые выгрузки .doc → `vcd/txt/CC_*.txt`, antiword). В Антья-лиле нет глав
**16–19**. Их нужно перевести так, чтобы они не отличались от глав переводчика: тот же формат, та же транслитерация,
тот же пословный перевод, та же лексика и тон.

## Образцы (прочитать до начала, внимательно)
- `vcd/txt/CC_Antya13.txt`, `CC_Antya14.txt`, `CC_Antya15.txt`, `CC_Antya20.txt` — прозаическая версия (главный образец).
- `vcd/txt/CC_Antya13poetry.txt` … `CC_Antya15poetry.txt` — стихотворная версия (тот же пословный, перевод — стихами).
- Глоссарий переводчика собрать самому по образцам: как он передаёт имена (Сваруп Дамодар / Сварупа Дамодара?),
  «према», «бхава», «Махапрабху», «Господь Чайтанья», обращения, кавычки “…”, «Шри Чайтанья-чаритамрита» и т. д.
  Записать его в `GLOSSARY-vcd.md` (сначала, потом пополнять). Транслитерация — его кириллица с диакритикой
  (а̄, ӣ, ӯ, р̣, ш́, ш̣, н̣, т̣, д̣, н̇, н̃, х̣, м̇ …), строчными, по образцу; разбор правил — тоже в глоссарий.

## Исходный текст
- Бенгальский текст стихов: vedabase.io (`https://vedabase.io/en/library/cc/antya/16/1/` и т. д., бенгальский
  текст в JSON страницы) — использовать **только текст стиха** (он в общественном достоянии). Переводы и комментарии
  BBT не воспроизводить и не пересказывать (правило CLAUDE.md); можно заглядывать только в сомнительных местах.
- Сверка: издание 1915 г. (DLI, `src/antya_1915_dli_djvu.txt`; скан `https://archive.org/details/in.ernet.dli.2015.477853`).
- Нумерация стихов — как у переводчика (он следует изданию Гаудия Матха / BBT; проверить по главе 15/20, совпадает ли
  нумерация с vedabase; расхождения отметить в PLAN).
- Заголовки разделов (подзаголовки «Анубхашьи» Бхактисиддханты: бенгальский + транслитерация + русский) — давать,
  только если переводчик даёт их в Антья 13–15/20, в том же виде. Вводное резюме главы из «Амрита-праваха-бхашьи»
  **не** давать (пользователь просил убрать комментарии из книги).

## Формат вывода
- `vcd/new/CC_Antya16.md` … `CC_Antya19.md` — прозаическая версия, повторяющая структуру образца:
  шапка (“Шри Чайтанья-чаритамрита” / Антья-лила / Глава N / название / (перевод Вриндавана Чандры даса) — **нет**:
  вместо имени переводчика писать «(перевод выполнен в стиле Вриндавана Чандры даса, 2026)» — чтобы не приписывать ему
  чужой работы); затем для каждого стиха: бенгальский текст с «॥ N ॥», строки транслитерации, под каждой — пословный
  (в md: строка транслитерации, следующая строка — пословный; слова пословного разделять двумя пробелами), затем
  «(N) перевод». Санскритские шлоки — так же, как у переводчика.
- Стихотворную версию (`CC_Antya16poetry.md` …) — вторым проходом, после всех четырёх глав прозой.
- Сноски (только где нужно: расхождения изданий, неясные места) — `[^n]` в конце файла, кратко.

## Богословие
Глазами гаудия-вайшнава, авторитет — Бхактисиддханта: ни майявадского, ни мирского прочтения (Антья 16–19 — высшие
переживания разлуки: «безумие» — божественное, према гопи — не мирская страсть; Божество — не «статуя»).

## Порядок и сохранность
- Писать по ~30–40 стихов, после каждой порции — коммит своих файлов (`git commit -- <файлы>`) и пуш
  (`git pull -q --rebase --autostash origin claude/book-translation-tesseract-bengali-yaygag && git push -q -u origin claude/book-translation-tesseract-bengali-yaygag`).
- Статус — в `chaitanya-charitamrita/PLAN.md` (раздел «Антья 16–19»): сколько стихов готово в каждой главе.
- База лил по ЧЧ — **не** в этом задании (будет отдельный проход по всей ЧЧ).
