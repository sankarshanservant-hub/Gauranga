# Художественное (иллюстрированное) издание ЧЧ — образец: Ади-лила, глава 1

Альбомная книга A4 (210×297, вертикальная), **две колонки** на странице — по образцу русского издания
«Чайтанья-бхагаваты» (Ади-кханда, PDF пользователя на Диске, id `1b7fWpYLahOZ_Eavlp7nA3lQBS6QzFOPa`).
Результат: `Adi-01-illustrated.pdf`.

## Состав страницы и порядок чтения
1. **Открытие главы** (стр. 1, правая): верхняя половина — ночная сцена санкиртаны (вырезанные фигуры на небе),
   название главы; ниже на той же странице сразу начинается текст в две колонки: «Краткое содержание главы»
   (резюме «Амрита-праваха-бхашьи») с буквицей, затем стихи. Отдельной пустой титульной страницы нет.
2. **Стих** — один блок: заголовок раздела «Анубхашьи» (если есть, курсивом) → «СТИХ N» → бенгальский текст →
   транслитерация курсивом → перевод ВЧД полужирным. Сразу за стихом — комментарии с вводными метками
   **«Амрита-праваха-бхашья.»**, **«Анубхашья.»** (и, где есть, **«Шрила Б. Р. Шридхар Махарадж.»**).
3. Перевод стиха и абзацы комментария переносятся из колонки в колонку (не менее 2 строк с каждой стороны);
   бенгальский текст стиха и транслитерация не разрываются. Колонки выравниваются по нижнему краю (добавочный
   интервал между стихами, не более 12 мм).

## Иллюстрации: правило «стих и картинка на одном развороте»

проходов: если после вставки панорамы стих «уехал», панорама переносится, пока стих и иллюстрация не совпадут
(отчёт `_report.json`, строки «якорь …»).

## Сборка
```
python3 -I prepare_art.py <папка с исходниками с Диска>   # один раз: art/ (PNG без фона, панорамы, profiles.json)
python3 -I build.py                                          # _book.html → Adi-01-illustrated.pdf (+ _report.json)
python3 -I preview.py 55                                     # превью разворотов в _prev/ (не коммитится)
```
Нужны: `psd-tools`, `pyphen`, `scipy`, Node-Playwright (Chromium). Шрифты (OFL) — `fonts/`: Gentium Book Plus
(текст, транслитерация), Cormorant Garamond (заголовки), Noto Serif Bengali.

Исходники иллюстраций — папка пользователя «Gauralila new» на Google Диске
(`1ibjxGtmHD6bnCtQzMK-HG32QGhwgAdKb`; подпапки Nabadweep, KK CC, Puri, Characters, Vrindavan, Govardhan,
sampradaya, …). PSD: нижний слой «Фон» (чёрный) отбрасывается, остальные слои дают фигуру на прозрачном фоне;
листы с несколькими фигурами режутся на отдельные фигуры.
