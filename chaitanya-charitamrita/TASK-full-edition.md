Для отдельного чата. Цель — русское издание ЧЧ, где:
- к каждому стиху даётся перевод Вриндавана Чандры даса (далее ВЧД; главы Антья 16–19 сделаны «в его стиле»);

  Сарасвати в нашем переводе.

Это пп. 2 и 13 общего `PLAN.md` (п. 3, ЧЧ → база лил, сюда не входит).

**Стихи уже переведены**, их не переводить заново. Работа: подготовить главы, перевести оба комментария и собрать книгу.
**Богословских сносок от себя не давать.** Толкование даёт сам комментарий. Сноски допустимы только редакторские и
короткие: неясное место скана, разночтение изданий, ссылка на источник цитаты, если она не указана.

## 2. Этап А. Подготовка глав ВЧД (пп. 2 общего плана)
Скрипт `tools/prep_vcd.py`: читает `vcd/txt/CC_*.txt` и пишет `ed/vcd/CC_<Лила><NN>.md` в формате `vcd/new/*.md`.
1. **Шапка:**
   - `“Шри Чайтанья-чаритамрита”` / лила / `Глава N` / `**название**` / `(перевод Вриндавана Чандры даса)`;
   - для Антья 16–19 оставить свою пометку «(перевод выполнен в стиле…)».
2. **Стих:**
   - бенгальский текст с `॥ N ॥`;
   - транслитерация, под каждой строкой пословный (если он есть в главе), слова разделены двумя пробелами;
   - `(N) перевод`;
   - в md переносы строк внутри блока — двумя пробелами в конце строки, как в `vcd/new`.
3. **Убрать все комментарии** (решение пользователя). Под это попадают:
   - вводное резюме главы с подписью `(“Амр̣та-права̄ха-бха̄ш̣йа”, комментарий Шрилы Бхактивинода Тхакура)`;
   - подзаголовки «Анубхашьи»: русская строка, бенгальская строка и транслитерация перед стихом, например
     «Описание безграничного великодушия…» + «শ্রীকৃষ্ণচৈতন্যের মহাবদান্যতা-বর্ণন, ш́рӣ…»;
   - **вставки современных комментариев**, не PD: «Шрила Говинда Махарадж: …», цитаты Шридхара Махараджа,
     Прабхупады и подобные. Найти так:
     `grep -n -i 'Говинда Махарадж\|Шридхар\|Прабхупад\|Махарадж:' vcd/txt/*.txt`. Они есть в Ади 1, 2, 7, 8, 10, 11,
     12, 14, 17, Мадхья 3, 8, 10, 11, 17–20, 22, 24, 25, Антья 1, 5, 7;
   - пояснения переводчика к словам после пословного (например, Ади 7.1 «агатй — беспомощный…»);
   - любые другие абзацы, которые не являются стихом, пословным или переводом.

   Всё удалённое дословно записывать в `ed/review/removed-<глава>.md` с номером стиха: ничего не теряется, и
   пользователь может проверить. Сначала обработать **одну главу** (Ади 7, в ней все виды вставок) и показать
   пользователю результат и список удалённого. Массово — только после его согласия.

   Перевод цитат внутри самого стиха (в «(N) …») — это текст ВЧД, не комментарий, его не трогать. Ссылка вида
   «(ШБ, 2.3.24)» после перевода шлоки остаётся.
4. **Опечатки и техника:**
   - мусорные символы Word: U+3000, U+FFA0, U+3164, табуляции-выравнивания пословного; привести к двум пробелам;
   - номера страниц, попавшие в текст (например, «1143»);
   - сбои нумерации: сравнить последовательность `॥ N ॥` и `(N)`. Пример — Антья 3: «॥ ১৭০ ॥» вместо ২৭০;
   - орфография и пунктуация RU (например, «исполненно» → «исполнено»), ё по образцу ВЧД; правки не стилистические,
     **текст переводчика не переписывать**;
   - разнобой транслитерации: привести к таблице `GLOSSARY-vcd.md`, где ВЧД сам непоследователен; где он
     последователен, его вариант сохранять;
   - **бенгальский текст:** автоматически сравнить с vedabase. Расхождения проверить по изображению `CC_SS.pdf`
     (`pdftoppm -f P -l P -r 150`), исправлять в пользу Гаудия Матха (как `vcd/new/work/overrides.txt`).

   Все правки — в журнал `ed/review/fixes-<глава>.md` (было → стало, причина).
   - **Издание Гаудия Матха (Бхактисиддханта) авторитетнее vedabase** (решение пользователя 2026-10-10): текст — по
     нему, но все расхождения с vedabase перечислять в отдельном файле `ed/review/vedabase-diff-<глава>.md`
     (создаётся автоматически `tools/prep_vcd.py` → `tools/cmp_bn.py`).
   - Сверять с vedabase мало: ВЧД местами набрал чтение vedabase, а не ГМ (Ади 7.5, 7.82, 7.85, 7.123…). Каждый стих
     сравнивать с OCR скана (`tools/ocr_verses.py`), сомнительные строки смотреть по изображению.
5. **Нумерация стихов** — по `CC_SS.pdf`. Где ВЧД разошёлся с ней (пропуск, сдвоение), отметить в журнале. Стих
   без перевода у ВЧД не досочинять, а внести в список `ed/review/missing.md` для пользователя.
6. **Проверка главы** (скрипт `tools/check_ed.py`):
   - у каждого стиха есть бенгальский текст, транслитерация и перевод;
   - номера идут подряд;
   - нет мусорных символов;
   - число стихов совпадает с `CC_SS.pdf`/vedabase.
   Итоговая таблица — в `chaitanya-charitamrita/PLAN.md`.

Прогноз: 2–3 сессии.

## 3. Этап Б. Текст комментариев (бенгальский)
1. **Карта скана:** `src/CC_SS-pages.md` — лила, глава → диапазон страниц; номер первого стиха на каждой странице.
   Взять по колонтитулам «আদিলীলা — প্রথম পরিচ্ছেদ» через OCR верхней полосы страницы.
2. **Вёрстка страницы.** Сверху стихи в одну колонку. Ниже — «অমৃতপ্রবাহ ভাষ্য» (две колонки, абзацы с номерами
   стихов «১৩৩।»), затем «অনুভাষ্য» (тоже по номерам стихов).
3. **OCR:**
   - `pdftoppm -r 300 -gray`;
   - разрезать на зоны: стихи, левая колонка, правая колонка; искать по белым промежуткам или по заголовкам
     «অমৃতপ্রবাহ ভাষ্য» / «অনুভাষ্য»;
   - `tesseract <зона> - -l ben --psm 4` (или `--psm 6`);
   - склеить колонки в порядке чтения: левая, затем правая, затем следующая страница.
4. **Выверка по изображению** — обязательна. OCR даёт ошибки в сочетаниях согласных (ত্রী вместо শ্রী, অস্থত вместо
   অমৃত, «1১৩২।» вместо «॥১৩২॥»). Каждый абзац сверять с картинкой зоны: читать её прямо, Read по .png.
   Исправлять по картинке, не «по догадке». Неразборчивое помечать `{?…}`.
5. **Файлы (PD, коммитятся):**
   - `ed/bn/<Лила><NN>-apb.md` («Амрита-праваха-бхашья»);
   - `ed/bn/<Лила><NN>-anu.md` («Анубхашья»).

   Внутри — разделы `## N` (номер стиха или диапазон «N–M»), как в издании. Вводный абзац главы — `## 0`.

   Санскритские цитаты в комментариях сохранять. Источник цитаты указан в издании — оставить, не указан — не
   додумывать.
6. Порции — по 8–10 страниц; после каждой коммит и пуш.

## 4. Этап В. Перевод комментариев на русский
**Принципы:**
- **Точность важнее гладкости.** Переводить полностью, без пропусков и пересказа. Каждая мысль оригинала должна
  быть в переводе, лишнего не добавлять.
- Где синтаксис Бхактисиддханты плотный, можно разбить длинный период на 2–3 предложения, но не терять связи
  («поэтому», «ибо», «то есть»).
- **Стиль — как у ВЧД:** ясный, литературный, почтительный русский.

  Брать из `GLOSSARY-vcd.md`:
  - имена: «Шри Чайтанья», «Махапрабху», «Сваруп Дамодар»… — как в главе ВЧД;
  - термины: «према», «бхава», «божественная любовь»;
  - обращения и кавычки.

  Термины, которых нет в глоссарии (их много у Бхактисиддханты: адхокшаджа, вивартавада, ачинтья-бхедабхеда,
  абхидхея, прайоджана, сварупа-шакти, татастха…), — транслитерация без диакритики в тексте, при первом
  появлении в главе краткое пояснение в скобках. Вести `ed/GLOSSARY-commentary.md` и придерживаться его во
  всех главах.
- **Цитаты из шастр** внутри комментария: перевод в “лапках” и ссылка в скобках, как у ВЧД. Если та же шлока есть в
  ЧЧ, взять перевод ВЧД этого стиха дословно (найти grep-ом по транслитерации) и указать «(ЧЧ, Ади 1.5)». Стихи
  ЧЧ, которые комментатор цитирует или пересказывает, тоже сверять с переводом ВЧД, чтобы не было двух разных
  переводов одного места.
- **«Амрита-праваха-бхашья».** Это в основном пересказ-разъяснение стихов простым бенгальским. Переводить так, чтобы
  он не дублировал перевод стиха ВЧД дословно, но и не расходился с ним по смыслу.

  Если Бхактивинода понимает стих иначе, чем ВЧД, переводить Бхактивиноду точно и дать **редакторскую** сноску:
  «В переводе стиха — иначе: …». Это не богословская сноска, а сверка.
- **«Анубхашья»** — глоссы к словам, толкования, полемика (с майявадой, смартами, пракрита-сахаджиями), ссылки на
  шастры. Глоссы к отдельным словам: `**бенг. слово** (транслит.) — пояснение`.
- **Богословие.** Переводить глазами гаудия-вайшнава. Комментарий сам и есть богословие: не смягчать резкие места
  Бхактисиддханты и не добавлять от себя. Ни одна формулировка в переводе не должна допускать майявадского или мирского
  прочтения:
  - Божество — не «статуя»;
  - йогамайя — не «иллюзия»;
  - према — не «страсть»;
  - уход Господа — «сокрытие».
- **Без сносок от себя**, кроме редакторских (§ 0).

**Файлы:** `ed/ru/<Лила><NN>-apb.md`, `ed/ru/<Лила><NN>-anu.md`, разделы `## N` — один к одному с `ed/bn/`. Порции по
~30–40 разделов, после каждой коммит и пуш.

**Перепроверка** (каждая глава, **другим исполнителем**, не тем, кто переводил):
1. Абзац к абзацу bn ↔ ru: нет пропусков (сравнить число предложений и цитат), нет добавлений, верны числа,
   имена, номера стихов, ссылки на шастры.
2. Сверка терминов с `GLOSSARY-commentary.md` и `GLOSSARY-vcd.md`; цитаты ЧЧ совпадают с переводом ВЧД.
3. Богословская вычитка по списку выше.
4. Чтение русского текста целиком: стиль, ясность, опечатки.

Замечания — в `ed/review/check-<глава>.md` (было → стало, причина). Исправления вносит переводчик или проверяющий;
спорное выносится пользователю.

## 5. Этап Г. Сборка книги
- **Сводный md по лилам:** `Chaitanya-Charitamrita-full-ru-{adi,madhya,antya}.md`, или единый файл, если позволит
  размер.

  Порядок внутри главы:
  1. шапка;
  2. вводный абзац «Амрита-праваха-бхашьи» (`## 0`) под заголовком «Амрита-праваха-бхашья»;
  3. стихи по порядку — блок ВЧД, затем «**Амрита-праваха-бхашья.**» и «**Анубхашья.**» для этого стиха (если есть).

  Подзаголовки разделов издания («Анубхашья»), убранные на этапе А, вернуть на место из `ed/bn`/`ed/ru` и перевести.
- **Отдельно лёгкое издание без комментариев:** `Chaitanya-Charitamrita-ru.md`, только ВЧД.
- **Стихотворная версия ВЧД** (где есть) — отдельная книга `…-poetry`, без комментариев.
- Сборка DOCX/PDF — движком `govinda-kadacha/build.py`: бенгальский — Noto Serif Bengali, сноски — настоящие
  (не цифры в тексте).
- **Предисловие** (своими словами):
  - о Кришнадасе Кавирадже, ВЧД, обоих комментаторах и издании-источнике;
  - что Антья 16–19 переведены в стиле ВЧД (2026);
  - что комментарии переведены впервые для этого издания.

## 6. Порядок, объём, сохранность
- **Порядок:** этап А для всех глав → Б+В по главам (Ади 1, 2, … — сначала одна глава целиком: bn → ru → проверка,
  показать пользователю образец, потом остальные) → Г.

  Исполнителей можно вести параллельно по разным главам, по `lila-db/PARALLEL.md`. Каждый пишет только свои
  файлы; `PLAN.md` правит только координатор.
- **Объём:**
  - этап А — 2–3 сессии;
  - комментарии — около 700 двухколоночных страниц OCR и выверки плюс перевод, ~15–25 сессий. Скорректировать
    после первой главы;
  - сборка — 1 сессия.
- **Сохранность:** писать порциями; после каждой порции:
  ```
  git commit -- <свои файлы>
  git pull -q --rebase --autostash origin claude/book-translation-tesseract-bengali-yaygag
  git push -q -u origin claude/book-translation-tesseract-bengali-yaygag
  ```
  Ни одной несохранённой порции. В корень репозитория ничего не класть.
- **Статус** — таблица в `chaitanya-charitamrita/PLAN.md`: глава | этап А | bn-apb | bn-anu | ru-apb | ru-anu |
  проверка.
- `CC_SS.pdf` и страничные картинки не коммитить; вырезки отдельных страниц для спорных мест — можно, < 20 МБ.

## Решения пользователя (2026-10-10, по образцу Ади 7)
