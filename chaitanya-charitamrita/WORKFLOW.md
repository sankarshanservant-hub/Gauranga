# Организация работы над «Шри Чайтанья-чаритамритой» (экономно по токенам, без потери качества)

Дополняет `TASK-full-edition.md` (что делать) — здесь *как*: кто, за сколько проходов, какими средствами.
Черновик 2026-10-10; уточнить после пилота (Ади 1).

## 1. Принципы экономии
1. **Всё механическое — скриптами.** Разбор .doc, OCR, выравнивание двух сканов, сверка с vedabase, поиск
   расхождений, подстановка перевода ВЧД для цитат из ЧЧ, проверка нумерации/чисел/ссылок, вёрстка PDF, сборка книги.
   Модель не читает то, что можно проверить кодом, и получает только список «подозрительных» мест.
2. **Один проход по фрагменту — все задачи по нему.** Кто читает перевод главы ради опечаток, тот же за этот проход
   дописывает пословный и вносит лилы в базу. Кто смотрит изображение страницы комментария, тот же сразу правит OCR
   и переводит этот абзац.
3. **Не перепечатывать бенгальский.** Бенгальский текст очень «дорогой» по токенам. Исправления OCR — правками
   «было → стало» (как `ed/fixes/`), а чистый текст `ed/bn/` собирает скрипт из OCR + правок.
4. **Изображения — только нужные зоны.** Для стихов — вырезки строк, где OCR разошёлся с текстом (как в Ади 7: ≈45 строк
   вместо 28 страниц). Для комментариев — колонка целиком (качество важнее: OCR бенгальского ненадёжен).
5. **Модель по задаче.** Opus — перевод «Анубхашьи» и «Амрита-праваха-бхашьи», спорные богословские места.
   Sonnet — этап А (опечатки, пословный, база лил), проверка полноты перевода, сравнительный анализ по готовому
   русскому тексту. (Другая модель на проверке — заодно и независимый взгляд.)
6. **Короткие поручения.** Постоянные правила — в файлах (`TASK-*.md`, глоссарии); исполнителю — 5–10 строк:
   глава, этап, файлы. Не пересказывать правила в каждом поручении.
7. **Без лишних отчётов.** Исполнитель отвечает итогом в 5–10 строк; подробности — в журналах `ed/review/`.
8. **Параллельно 2–3 главы** (`lila-db/PARALLEL.md`), каждая — свой исполнитель и свои файлы.

## 3. Перевод комментариев: как обеспечить качество экономно
- **OCR дважды:** наш `CC_SS.pdf` (извлекать исходные 600-ppi картинки `pdfimages`, не рендерить) и CCBSST
  (другая вёрстка того же текста). Скрипт выравнивает их и помечает места, где они расходятся, — переводчик видит, где
  OCR сомнителен, и смотрит изображение внимательнее (изображение смотрится всегда).
- Перевод сразу «набело» по правилам `TASK-full-edition.md` § 4; цитаты из ЧЧ скрипт заранее подставляет из перевода ВЧД.
- **Глоссарий комментариев** (`ed/GLOSSARY-commentary.md`) — растёт по ходу; его читают все переводчики (дешевле, чем
  каждый раз согласовывать термины в проверке).
- **Богословие (решение пользователя 2026-10-10):** содержание комментариев Бхактисиддханты и Бхактивиноды —
  авторитет, его не «вычитываем» и не оцениваем. Проверяется только **точность передачи**: чтобы русское слово не
  внесло чужого смысла (Божество — не «статуя», йогамайя — не «иллюзия», према — не «страсть», уход — «сокрытие»).
  Это делает скрипт по стоп-списку (`ed/GLOSSARY-commentary.md`, раздел «Нельзя») + сверка смысла в проходе 3;
  отдельного богословского прохода нет.
- **Стиль:** перевод — литературный, а не подстрочник; период Бхактисиддханты можно делить на 2–3 предложения с
  сохранением связей. Проверка (проход 3) отдельно оценивает читаемость.

## 4. Сравнение комментариев Бхактиведанты Свами (англ.) с «Анубхашьей»
Цель: какая доля комментариев Бхактиведанты — переработка «Анубхашьи», что уникально, что спорно.
- **Единица анализа — смысл, а не слова.** Комментарий Бхактиведанты к стиху делится на смысловые единицы (тезисы);
  каждый тезис относится к одной категории:
  `=` повторяет мысль «Анубхашьи» (близкий пересказ/перевод) · `+` развивает её (дополнения, примеры) ·
  `new` нет у Бхактисиддханты (свои объяснения, современные примеры, проповедь Запада) ·
  `−` есть у Бхактисиддханты, но опущено · `≠` иное толкование/расхождение (с пояснением) · `?` спорное.
- Итог по главе: доли тезисов и примерная доля объёма по категориям; список `≠` и `?` с короткими пояснениями своими
  словами. Цитаты из английского — не воспроизводить (только ссылки «Ади 1.12, абз. 2»).
- Делается **после** проверенного перевода «Анубхашьи» главы (чтобы наш перевод не был под влиянием английского текста)
  и по готовому русскому тексту — так не нужно второй раз читать бенгальский.
- Английский текст комментариев скрипт извлекает с vedabase во временную папку (в репозиторий не коммитится).
- **Пилот — Ади 1**, затем оценка объёма и решение пользователя, делать ли все главы.
