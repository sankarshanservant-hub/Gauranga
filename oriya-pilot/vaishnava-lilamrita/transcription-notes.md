# Транскрипция: сверка проходов A и B (гл. 4, ст. 28–81)

Скан: `sources/oriya/madhava-chaitanya-vilasa/Madhava_Vaishnava-Lilamrita_ed-Acharya_1986_IA-baishnaba-lilamruta-1986.pdf`,
листы 66–69 (печ. с. 22–25; номер листа = номер страницы PDF, считая с 0, как в `pdfimages`). Изображения в PDF —
двухцветные 300 dpi (JBIG2), извлечены без пересжатия (`pdfimages -png`). Работали только с областью стихов (над
чертой); примечания редактора не транскрибировались.

## Проходы

- **A (OCR):** tesseract 5, модель tessdata_best `ori`, `--psm 6`, изображение ×2 (Lanczos). Сырой результат — в
  scratchpad (в репо не кладём: это шум). Время: ≈11–12 мин процессорного времени на страницу (машина была сильно
  загружена — 4 страницы шли ≈35 мин). **Точность сырого OCR на этих 54 строках: 17 % слов совпали точно, ≈69 %
  символов** (по сравнению с итоговым текстом). Типичные ошибки: матра «େ» (в этом шрифте — отдельный знак слева)
  читается как ବ/ଚ (ବଦଖିଲ = ଦେଖିଲ, ବସ = ସେ); ଭ/ଉ/ତ; ର/ଗ୍ବ; конъюнкты рассыпаются (କ୍ଷେତ୍ରେ → ଚଷବନ, କିନୈ).
- **B (по изображению):** чтение строк при увеличении ×2–×4 без заглядывания в OCR; записано до сверки. Совпадение
  B с итоговым текстом — 97 % слов (364 из 377); 13 слов исправлены после сверки (см. таблицу).
- **Сверка:** для каждого расхождения — повторное чтение при ×4, сравнение формы знака с тем же знаком в
  надёжных словах той же страницы, рифма (двустишия рифмуются по последнему слогу), размер (навакшари — 9 слогов в
  полустишии, с отклонениями ±1), словари (Brooks 1874; Sutton 1843 — не понадобился для этих мест).

## Особенности шрифта издания 1986 г. (важно для дальнейшей работы)

1. Матра «େ» — отдельный знак перед согласной, похожий на ଚ/ବ без верха; «ୋ» = «େ» + согласная + «ା».
2. **ସ, ଯ и ଜ очень похожи** в полужирном начертании; различаются мелкими деталями петли. Решали по контексту и рифме
   (ст. 31 ଯେ, 39 ଯେତେ, 60 ଯେବେ ଯିବ, 70/72 ଜ).
3. **«ରି» выглядит почти как ଶ** (флажок «ି» сливается с ର): ср. ସରି (68а), отсюда чтения ଉଭରିଲ (50), ଉଭରି (68).
4. Две формы ତ (обычная и «ଢ»-подобная) — ମତ, ଭଗତ; ନ и ବ различаются открытостью петли (ст. 44 ଠାନ).
5. ଲ и ଳ различаются слабо; где не ясно — оставлено, как в общепринятом написании слова.
6. Флажок «ି» иногда теряется при печати (ст. 70 ବଜେ, 72 ବଜେକ — вероятно, ବିଜେ).

бы 5 верных чтений (≈1,3 % слов). Вывод для метода — в `../METHOD.md`.
