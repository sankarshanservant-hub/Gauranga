# Пилот перевода с ория: метод, затраты, уверенность, прогноз

Пилот выполнен 2026-10-08 по плану, одобренному пользователем: носителей ория в проекте нет, поэтому качество
обеспечивается методом — двойной независимой транскрипцией, сверкой по скану/рифме/размеру/словарям, пословным
переводом с явными пометками сомнений и списком вопросов к будущему специалисту.

Текст пилота: Мадхава Паттанаяк, **«Вайшнава-лиламрита»** (≈1535), гл. 4, **ст. 28–81** (54 двустишия = 108 полустиший,
377 слов), скан изд. Б. Ч. Ачарьи (1986), листы 66–69 (печ. с. 22–25). Эпизод: приход Шри Чайтаньи в Пури,
обморок перед Джаганнатхой, Сарвабхаума, встреча с Джаганнатхой Дасом у Бата-Ганеши, споры с Сарвабхаумой и его
прозрение, совет идти к Рамананде, встреча с Раманандой Раем на Годавари. Файлы: `vaishnava-lilamrita/src.md`
(текст ория), `full.md` (ория + транслитерация + пословный RU/EN + уверенность), `ru.md`, `en.md` (литературный
перевод со сносками), `transcription-notes.md` (сверка A/B), `QUESTIONS.md`.

## 1. Порядок работы (на страницу скана)

1. **Изображение.** `pdfimages -png` — извлечь исходное 300 dpi изображение страницы без пересжатия (рендер
   `pdftoppm` не нужен: в PDF уже двухцветные 300 dpi). Обрезать область стихов над чертой примечаний.
2. **Проход A (OCR):** tesseract 5 + `ori.traineddata` (tessdata_best), `--psm 6`, увеличение ×2. Запускать в фоне
   сразу для нескольких страниц. Результат не смотреть до окончания прохода B.
3. **Проход B (чтение по изображению):** строки по 5–6, увеличение ×2; записать чтение в файл.
4. **Нарезка строк** (по столбцу разделителя «॥») и **сверка** каждого расхождения при ×2,5–×4: форма знака
   сравнивается с тем же знаком в надёжных словах страницы; проверяется рифма (двустишие рифмуется по последнему
   слогу), размер (навакшари — 9 слогов в полустишии ±1), словарь. Решения — в `transcription-notes.md`.
5. **Словари** для каждого неясного слова: Brooks (быстро, по колонтитулам) → «Пурначандра» (по изображению,
   бинарный поиск по колонтитулам тома) → грамматики Саттона/Молтби для форм глагола.
6. **Пословный перевод** RU/EN (транслитерация — автоматически, скриптом по таблице § 3), пометки `(?)`/`(??)`,
   оценка уверенности двустишия A/B/C.
7. **Литературный перевод** RU/EN, сноски: реалии, лица, параллели с ЧЧ/ЧБ, богословие (по Бхактисиддханте; где автор
   расходится с гаудия-вайшнавским взглядом — точный перевод + сноска), неясные чтения.
8. **Вопросы** — в `QUESTIONS.md` с номерами строк.

| Этап | Время |

## 3. Транслитерация ория (IAST-подобная)

Буква в букву, по написанию (не по произношению); автоматически — скрипт (таблица ниже).

- Гласные: ଅ a, ଆ ā, ଇ i, ଈ ī, ଉ u, ଊ ū, ଋ ṛ, ଏ e, ଐ ai, ଓ o, ଔ au; матры так же. Присущее «a» пишется всегда, в т. ч.
  в конце слова (в ория оно произносится, [ɔ]): *nāma, bhāba*.
- Хиатус: отдельная буква ଇ/ଉ после согласной с присущим «a» — ï/ü (*caïtanya* ଚଇତନ୍ୟ, *gaüra* ଗଉର), чтобы не
  спутать с матрами ୈ ai / ୌ au.
- Согласные: କ k, ଖ kh, ଗ g, ଘ gh, ଙ ṅ; ଚ c, ଛ ch, ଜ j, ଝ jh, ଞ ñ; ଟ ṭ, ଠ ṭh, ଡ ḍ, ଢ ḍh, ଣ ṇ; ତ t, ଥ th, ଦ d, ଧ dh,
  ନ n; ପ p, ଫ ph, **ବ b** (в ория одна буква для b/v), ଭ bh, ମ m; **ଯ y** (произносится [dʒ]), **ୟ ẏ**
  (антахстха; после вирамы, т. е. я-пхала ୍ୟ, — y), ର r, ଲ l, **ଳ ḷ**, ଶ ś, ଷ ṣ, ସ s, ହ h; ଡ଼ ṛ, ଢ଼ ṛh; ୱ w.
- Знаки: ଂ ṁ, ଃ ḥ, ଁ (чандрабинду) — надстрочный ̐ над предыдущей гласной: *mu̐, duhe̐*.
- В пословном переводе сложные слова делятся дефисом (*bhakta-meḷe*); квадратные скобки — предлагаемое исправление
  печатного текста.

## 5. Главные трудности ория (по пилоту)

1. **Шрифт издания 1986 г.**: отдельно стоящая матра «େ», почти одинаковые ସ/ଯ/ଜ, «ରି» ≈ ଶ, две формы ତ, слабое
   различие ଲ/ଳ, теряющиеся «ି» и пятна краски. Это главный источник ошибок OCR и первого чтения.
2. **Опечатки издания** (ст. 44 ଠାନ вм. ଠାବ, ст. 81 ପଦ୍ମରେ вм. ପଦ୍ୟରେ?, ст. 70/72 ବଜେ вм. ବିଜେ?) — выявляются
   только рифмой и смыслом; без рукописей не проверить.
3. **Средневековая морфология**: прош. вр. на ‑ila/‑ile/‑ilā, «‑eka/‑ka» (କଲେକ, ହେଲେକ, ବଜେକ), буд. ‑iba для
   1-го и 2-го лица, деепричастия ‑iṇa/‑i, необычное ‑achu (ହୋଇଅଛୁ); архаичные падежные формы (‑eṇa: ଅଙ୍ଗେଣ, କୂଳେଣ).
4. **Почтительная и придворная лексика** (ବିଜେ, ଟମକ, ନିଶାଣ, ହାଣ୍ଡୋଳା?) и местные реалии Пури (Бата-Ганеша,
   рахаса).
5. **Смена говорящего не обозначена** (ст. 59–63, 76) — решается параллелями с ЧЧ.
6. Сквозная орийская (не гаудия) традиция: эпизод с Джаганнатхой Дасом, взаимные «свами»/«прабху» — переводится
   точно, со сносками.

## 6. Словари: оценка пригодности

- **Brooks 1874** (в репо): быстрый, чёткая печать, удобный по колонтитулам; книжная и бытовая лексика XIX в.; нет
  глагольных форм и многих средневековых слов (ସାଷ୍ଟାମ, ଉଭରିବା нет). Помог: ଠାବ, ଟମକ, ମାଜିବା, ଉଦନ୍ତ, ଉଛଳନ.
- **«Пурначандра» (Прахарадж)** — лучший: толкования на ория/англ., **цитаты из средневековой поэзии (в т. ч. из
  «Бхагаваты» Джаганнатхи Даса)**, областные слова. Решил ଉଭାରିବା и показал, что «ହାଣ୍ଡୋଳା» читается/понимается
  неверно. Но тома по 80–110 МБ (не в репо), а текстовый слой IA бесполезен (ория распознано как латиница) — поиск
  только по изображениям, 4–8 мин на слово.
- **Sutton 1843 / грамматики Саттона и Молтби** (в репо) — в пилоте не понадобились; ценны для систематики
  глагольных форм при больших объёмах.
- Рекомендация: **один раз построить индекс колонтитулов «Пурначандры»** (≈ 9 000 страниц, OCR только крупных
  направляющих слов вверху страницы → таблица «том, лист, первое–последнее слово»). Это сократит поиск до ≈ 1 мин на
  слово.

## 8. Вывод

Метод работает: смысл всех 54 двустиший установлен, ошибки печати и OCR выявляются, сомнения явно помечены и
сведены в вопросы. Без носителя текст пригоден как **рабочий перевод с аппаратом сомнений**, но не как окончательный:
≈ 40 % двустиший содержат хотя бы одно место для проверки специалистом. Рекомендуется продолжать «Вайшнава-лиламриту»
этим методом (с индексом «Пурначандры» и пакетным фоновым OCR всей книги), накапливая `QUESTIONS.md` для разовой
консультации со специалистом по средневековому ория (≈ 1–2 часа на 100 вопросов).
