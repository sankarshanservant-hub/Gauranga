# Мурари Гупта, «Шри Кришна-чайтанья-чаритамрита» («Кадача») — перевод на русский и английский

- `Murari-Gupta-Kadacha-ru.*` / `-en.*` — перевод (MD, DOCX, PDF).
- `Murari-Gupta-Kadacha-ru-full.*` / `-en-full.*` — полная версия: санскрит (деванагари), IAST, пословный перевод, перевод.
- `skt/P.SS.md` — выверенный санскрит (по трём OCR-свидетелям), разночтения (VAR), пословный перевод RU/EN.
- `ru/`, `en/` — перевод по саргам (4 пракрамы, 78 сарг, 1925 шлок по нумерации изданий).
- `TASK.md` — правила перевода; `REVIEW.md` и `review/1–4.md` — сквозная (в т.ч. богословская) выверка и её протокол.
- `GLOSSARY.md` — единые написания; `check.py` — проверка нумерации и сносок; `build.py` — сборка.
- Источники: `../sources/murari-gupta/` (см. README там), нарезка по саргам — `src/`.

Сарга 3.14 дана в связном порядке бенгальского издания 1945 г. (см. сноску к ней).
