# Кави Карнапура. «Шри Кришна-Чайтанья-чаритамрита» (махакавья) — оглавление

Поэма в 20 саргах, 1912 стихов по нашему изданию (Харидас Шастри, 1983; издатель в конце поэмы называет 1911 стихов). Завершена в 1464 г. Шака (1542 г. н. э.), в месяц ашадха (20.49). Основной источник автора — записи Мурари Гупты (20.42–43).

Название сарги дано там, где оно есть в колофоне издания; в остальных колофон даёт только номер. «Содержание» — краткая тема сарги своими словами. Страницы — печатные страницы издания.

### Сарга двадцатая — Бенгалия, Шантипур, возвращение; сокрытие Господа; заключение автора

- **1–10** — Путь через Ориссу; Рамананда возвращается от Бхадры
- **11–19** — Гауда: у Рагхавы Пандита, Шривасы, Васудевы и Шивананды
- **20–25** — Шантипур: встреча с Адвайтой и Шачи
- **26–30** — К западу от Навадвипы: толпы жителей Надии
- **31–34** — Поворот с пути к Ямуне; возвращение в Пури
- **35–37** — Второй поход к Ямуне; Рамананда оставляет тело в разлуке
- **38–41** — Итог: сорок семь лет игр; Господь уходит в Свою обитель
- **42–49** — Заключение автора: источник — записи Мурари; дата завершения поэмы
