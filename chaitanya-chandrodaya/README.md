# «Шри Чайтанья-чандродая» Кави Карнапуры — перевод на русский

  сверка — по изданию Kāvyamālā № 87 (1917), см. `../sources/chaitanya-chandrodaya/`.
- `TASK.md` — правила перевода; `GLOSSARY.md` — имена; `build.py` — сборка (использует `../govinda-kadacha/build.py`).
