# «Шри Чайтанья-чандродая» Кави Карнапуры — перевод на русский и английский

- `Chaitanya-Chandrodaya-ru.*` (.md / .docx / .pdf) — итоговые файлы (10 актов, ок. 480 стихов, 164 с.).
- `Chaitanya-Chandrodaya-en.*` (.md / .docx / .pdf) — английская версия (с санскрита и пракрита; нумерация стихов и
  примечания — как в RU, 161 с.).
- `ru/01–10.md` — перевод по актам с примечаниями переводчика; `en/01–10.md` — английский перевод с теми же разделами и примечаниями.
- `src/act01–10.txt` — источник: электронный текст Gaudiya Grantha Mandira (по изд. М. Гухи 1971 и Р. Мишры 1966), разбитый по актам;
  сверка — по изданию Kāvyamālā № 87 (1917), см. `../sources/chaitanya-chandrodaya/`.
- `TASK.md` — правила перевода; `GLOSSARY.md` — имена; `build.py` — сборка RU и EN: `python3 build.py [ru|en]`
  (использует `../govinda-kadacha/build.py`).
- `review/en-pass.md` — исправления русского текста, найденные при переводе на английский.
