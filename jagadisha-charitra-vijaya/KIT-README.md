# «Джагадиша-чаритра-виджая» Ананды Даса — комплект для перевода в отдельном чате (без доступа к GitHub)

Ты переводишь бенгальскую поэму **Ананды Даса «Шри Джагадиша-чаритра-виджая»** («Победа жития Джагадиши») —
житие **Джагадиши Пандита** из Ятры (Яшоды, совр. Яшара), спутника Шри Чайтаньи и Нитьянанды, «танцора»
(«нритья-винодӣ»), — на **русский и английский**. Поэма в 12 «варнах» (главах); автор — шестой в линии учеников
от Джагадиши (Джагадиша → Рагхунатха Ачарья → Бхагаватананда → Премананда → Радхачарана → Ананда Дас); писал,
по его словам, по велению Бхагаватананды, явившегося во сне. Время — XVIII в. (рукопись-основа издания
переписана в 1737 г. Шаки = 1815 г.). Готовые порции ты отдаёшь файлами; пользователь кладёт их в папку Google Диска,
Claude в основном чате проверяет, вносит в репозиторий и ведёт базу лил.

Прочитай этот файл целиком перед началом и перечитывай § 4–7 перед каждой порцией.

## 2. Что переводится, что — нет
- **Только текст поэмы**: паяры, трипади, санскритские шлоки и цитаты («তথাহি…»), подписи автора, колофоны варн
  («ইতি শ্রীজগদীশ পণ্ডিতস্য চরিত্র বিজয়ে … নাম … বর্ণঃ»), заключительная шлока и дата рукописи (pdf 79).
- **Только перевод** (RU и EN параллельно, одинаковая нумерация и сноски); бенгальского оригинала и пословного в
  выходных файлах нет.
- **Не переводить и не пересказывать** аппарат издания 1996 г.: предисловие и обзор редактора (pdf 1–12),
  **сноски редактора внизу страниц** (набраны мелко, начинаются с «১—», «২—» и т. п.: справки о лицах, станциях,
  дорогах — «হাওড়া হইতে…», «শিয়ালদহ ষ্টেশন…»), рекламу, последние страницы (pdf 80–82).
  Pdf 80 («শ্রীশ্রীজগদীশ পণ্ডিতের শাখা বর্ণন») — поздняя сиддха-пранали из другой рукописи, **не переводится**.
- Современные переводы и пересказы не использовать.

## 3. Как читать текст
- Основа — наш OCR; **каждую строку сверяй с изображением**, если в OCR что-то странное (শ্রী → «জী», «প্রী», «ভ্রী»;
  «৷৷» вместо «॥»; разорванные конъюнкты; перепутанные колонки). Второе чтение — OCR archive.org.
- **Нумерации в издании нет.** Нумеруй сам, **внутри каждой варны с 1**: единица — паяр-двустишие (две строки:
  «… ।» + «… ॥»), строфа трипади (6 полустрок до «॥») или санскритская шлока. Заголовок варны, «তথাহি…»-вводы,
  ссылки на источник цитаты и колофон — без номера.
- Неясное: наиболее вероятное чтение + сноска «чтение неясно» с бенгальским словом латиницей. **Никогда не угадывай
  молча** имя, число, дату, название места.
- Язык — бенгальский XVIII в.: формы করিলা, আইলা, হৈল, কৈল, মুঞি — нормальны.

## 4. Формат файла (как в `sample/ru.md`)
```
# Варна 1. <название по колофону варны>        ← только в первой порции варны

*<одна курсивная строка краткого содержания — своими словами>*

**1.** Первая строка двустишия.
Вторая строка двустишия.

*Тата хи (Бхагавата, 11.14.21):*                ← ввод цитаты курсивом, без номера

**2.** *Санскритская шлока — курсивом.*[^1]
```
- Номер — `**N.**`; пустая строка между единицами. Трипади — одной единицей, три строки по смыслу (или шесть
  коротких), как удобнее читать; санскрит — курсивом.
- **Подпись автора** (обычно «প্রভু ভাগবতানন্দ পদে করি আশ। জগদীশ লীলা কহে এ আনন্দ দাস ॥» и варианты) —
  обычное двустишие, всегда одной формулой:
  RU: «Уповая на стопы Прабху Бхагаватананды, / Ананда Дас повествует об играх Джагадиши.»
  EN: "Placing hope in the feet of Prabhu Bhagavatananda, / Ananda Dasa tells of Jagadisha's pastimes."
  (другие варианты подписи — переводить по тексту, близко к формуле).
- **Колофон** варны — курсивом отдельным абзацем.
- **Сноски** `[^N]` — сквозная нумерация **внутри варны** (с 1 в каждой); определения — в конце файла порции.

## 5. Стиль, имена, богословие
- Перевод **точный, построчный, без рифмы, без пересказа**; каждое слово оригинала должно отразиться. Ясный
  литературный язык без архаизмов и без просторечия. EN — естественный литературный английский.
- **Имена** — по `GLOSSARY.md`, затем `ref/PERSONS.md`, `ref/PLACES.md`: Джагадиша Пандит, Камалакша (отец),
  Бхагьявати (мать), Махеша Пандит (брат), Духкхини (жена Джагадиши; «Духкхини-мата»), Тапана (тесть),
  Рамабхадра (сын), Расаманджари (дочь), Гопала-валлабха (зять, сын Гангадеви, дочери Нитьянанды), Рагхунатха
  Ачарья (сын Бхагавана Ачарьи «Кханджа»), Камалаканта из Дургапура, Яшода (бенг. «যশোড়া», совр. Ятра близ Чакдахи; в `PLACES.md` пока нет — «Яшода» / "Yashoda",
  при первом упоминании «Яшода (Ятра)» / "Yashoda (Jatra)", и в список «Новые имена»), Гаура-
  Гопала (Божество Махапрабху у Духкхини), Джаганнатха из Ятры. Новое имя — по тем же правилам, в список «Новые имена».
- **Местоимения**: о Господе, Нитьянанде, Адвайте, Джаганнатхе — с заглавной; о Джагадише и других спутниках —
  строчными.
- **Богословие** (глазами гаудия-вайшнава; авторитет — Шрила Бхактисиддханта Сарасвати). Божество — «Божество» /
  "Deity" (никогда «статуя», «изваяние», «идол», "idol", "statue"); «মূর্তি / শ্রীমূর্তি» — «облик», «Божество»,
  «шри-мурти»; уход Господа и спутников — «уход», «сокрытие» / "disappearance" (не «смерть», "death");
  Господь не подвластен майе — «йогамайя»; према — не «страсть». Где автор расходится с «Чайтанья-бхагаватой»,
  «Чайтанья-чаритамритой» или «Гаура-ганоддеша-дипикой» — **точный перевод** и короткая сноска (не исправлять автора
  в тексте). Заранее известные места:
  - автор, видимо, сливает двух Джагадиш: «танцора» Джагадишу Пандита (ГГД 143, Чандрахаса) и Джагадишу из пары
    «Джагадиша-Хираньи» (ГГД 192; ЧБ: у них маленький Нимай съел подношение в экадаши) — сноска при первом таком месте;
  - чудеса (Джаганнатха, принесённый на спине; Божество, изваянное неведомым мастером; совместная трапеза Гауры,
    Нитьянанды и Божества) — переводить как есть, без «смягчений» и без мирских слов;
  - вамша, даты, родство с потомками Нитьянанды — переводить точно; расхождения с «Нитьянанда-вамша-вистарой» /
    «Бхакти-ратнакарой» — в сноску, если уверен.
- **Сноски** — кратко: лица, места, реалии, источники шлок (если уверен), расхождения с ЧБ/ЧЧ/ГГД, неясные чтения.
  Ссылки на ЧЧ/ЧБ — главой.
