# «Шри Гаура-ганоддеша-дипика» Кави Карнапуры — перевод на русский

- `Gaura-Ganoddesha-Dipika-ru.md` / `.docx` / `.pdf` — итоговые файлы.
- `Gaura-Ganoddesha-Dipika-ru-full.md` / `.docx` / `.pdf` — полная версия: выверенный санскрит (деванагари), IAST, пословный перевод и перевод.
- `skt/s01–s04.md` — выверенный санскрит, исправления конвертера, пословный перевод и протокол сверки перевода; `skt/TASK.md` — правила.
- `ru/01.md`–`ru/03.md` — перевод по частям (шлоки 1–57, 58–123, 124–215) с примечаниями.
- `build.py` — сборка итоговых файлов (использует `../govinda-kadacha/build.py`).

Источник: `../gaura-ganoddesha-dipika_hindi.pdf` (Gaudiya Vedanta Publications, 2008). Переведён
только санскритский текст Кави Карнапуры (1576 г.); хинди-перевод издания не использовался.
Английские переводы этой книги существуют, поэтому, по договорённости, сделан только русский.
