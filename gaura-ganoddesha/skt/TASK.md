- Типичные ошибки конвертера: «ञच» вместо «ञ्च» (पञचतत्त्व → पञ्चतत्त्व), лишние «ा»/«ि» в связках
  (निारवकर → निरवकर, निाशम्य → निशम्य), висячие вирамы (तदेवात्र् → तदेवात्र), смещённая «ि», перепутанные
  реф/связки, пропавшие слова или строки. Иногда строки в выборке неполные.
- Если строку не удаётся восстановить по тексту, **посмотри изображение страницы**: найди страницу
  (`pdftotext -f N -l N` по PDF и поиск по хинди/санскриту), отрендерь её `pdftoppm -f N -l N -r 110 -png <pdf> /tmp/ggd_pN`
  и прочти изображение инструментом Read. Это надёжный способ для мест, отмеченных в переводе как неполные
  (шлоки 165, 167, 182, 190) и для любых сомнительных мест.
- Хинди-перевод издания используй только для понимания (не переводить, не цитировать).
- Готовый русский перевод: `/home/user/Gauranga/gaura-ganoddesha/ru/01.md` (1–57), `02.md` (58–123), `03.md` (124–215).
  Нумерация — по изданию (группы 10–22 и 194–207 там объединены; в выходном файле используй ту же нумерацию
  и тот же номер-заголовок, что у абзаца перевода, напр. «### 10–22» если перевод начинается с «**10–22.**»;
  проверь, как именно оформлено в ru-файлах).

Для каждой шлоки (или группы) своего диапазона:
1. **Выверенный санскритский текст деванагари**: исправь ошибки конвертера по метру (обычно ануштубх: 4 пады по 8
   слогов; есть и другие размеры), грамматике и смыслу; при сомнении — по изображению страницы. Деление на строки —
   как в издании (обычно по полустишию на строку). Не выдумывай: если не восстановить, «[…]».
2. **Пословный перевод на русский**: все слова по порядку, в упрощённой русской транскрипции без диакритики
   (имена — как в переводе: Шивананда Сена, Сварупа, Радха, Лалита…), «слово — значение; …».
3. **Сверь готовый русский перевод** с текстом: OK / МЕЛОЧЬ / ОШИБКА (как и где), для МЕЛОЧЬ и ОШИБКА — полный
   исправленный перевод (в стиле существующего, без номера, сохраняя ссылки на сноски [^N], если они там уместны).
   Особое внимание — к отождествлениям «кто есть кто» (имя в Гаура-лиле ↔ имя во Врадже): ошибка в них — ОШИБКА.
   Если сноска о неполноте больше не нужна — напиши.

Формат выходного файла (строго):
```
### 12
SKT:
<строки деванагари>
VAR: <исправления конвертера, важные для смысла, или восстановление по изображению; иначе опусти>
WFW: <пословный перевод>
CHECK: OK
```
или `CHECK: МЕЛОЧЬ — …` / `CHECK: ОШИБКА — …` + `FIX: <полный перевод>` (+ `NOTE: …`).
Пиши файл постепенно. В конце — сводка OK / МЕЛОЧЬ / ОШИБКА и список ОШИБОК.
