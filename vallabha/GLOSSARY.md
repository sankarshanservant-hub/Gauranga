# Глоссарий — валлабхские тексты

Имена, общие с другими переводами проекта, — по их глоссариям (Шри Кришна-Чайтанья / Sri Krishna-Chaitanya,
Мадхавендра Пури / Madhavendra Puri, Рупа и Санатана / Rupa and Sanatana, Джива Госвами / Jiva Gosvami, Вриндаван /
Vrindavana, Говардхан / Govardhana). Здесь — новые. Местоимения о Господе (Чайтанье, Джаганнатхе, Шринатхаджи,
Кришне) — с заглавной; о Валлабхе и прочих — со строчной.
