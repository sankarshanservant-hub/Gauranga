# Шри Чайтанья в преданиях валлабхской традиции — перевод на русский и английский

- `Vallabha-Episodes-ru.*`, `Vallabha-Episodes-en.*` (.md / .docx / .pdf) — итоговые файлы.
- `ru/00.md` — предисловие; `ru/01.md` — варты (12 эпизодов: Нидж-варта, Байтхак-чаритра, Чаураси вайшнаван ки варта); `ru/02.md` — «Валлабха-дигвиджая» Ядунатхи (1 эпизод). То же в `en/`, с одинаковой нумерацией абзацев и сносок.
- `CATALOG.md` — каталог всех мест о Чайтанье (переведённые, краткие упоминания, тупики), состояние источников, проверка года издания вартт (самват 1959 = 1902/03).
- `GLOSSARY.md` — имена и термины RU/EN; `TASK.md` — задание; `build.py` — сборка (движок `../govinda-kadacha/build.py`).
- Источники — `../sources/vallabha/` (варты, изд. 1902/03; «Валлабха-дигвиджая» Кришнашастри 1908); санскритский текст Ядунатхи — по изд. 1985 г. на IA (издание ©, файл не хранится; переведён только текст 1610 г.).
- База лил: источник `vallabha-varta` (категория D), записи `../lila-db/lilas/vallabha-varta.yaml` (vlb-0001…0013).

Все тексты — предание валлабхской традиции, позднее и сектантское; перевод верен автору, гаудийская позиция и
расхождения с «Чайтанья-чаритамритой» — в примечаниях.
