# Правила работы в этом репозитории

## Сохранность работы (требование пользователя, всегда)
- Никогда не оставлять работу несохранённой. Каждый промежуточный результат сразу записывать в файлы репозитория
  и коммитить + пушить (`git pull -q --rebase --autostash origin <branch> && git push -q -u origin <branch>`).
- Исполнители (субагенты) пишут результаты в файлы порциями по ходу работы (переводы — каждые ~30–40 двустиший,
  поиск — README/журнал поиска и скачанные файлы сразу, даже для тупиков), с настоящими заголовками и сносками,
  чтобы при обрыве (лимиты, перезапуск) ничего не терялось.
- После каждого уведомления исполнителя и перед паузой — коммит и пуш; при обрыве — сначала сохранить, что есть,
  затем продолжить с места остановки.
- Не допускать файлов в корне не по делу (мусор поиска удалять).

## Переводы
- Переводить только оригиналы в общественном достоянии; современные переводы и примечания редакторов не
  воспроизводить и не пересказывать (можно лишь для понимания смысла, своими словами).
- Бенгальские поэмы: без оригинала и пословного перевода, только перевод (RU и EN параллельно, единая нумерация).
- Исполнители — по очереди, по одному (не параллельно), с автоматическим продолжением до исчерпания лимитов.
- Авторитет в толковании — Шрила Бхактисиддханта Сарасвати.
- Переводить и проверять глазами гаудия-вайшнава: ни одна формулировка не должна допускать майявадского или мирского
  прочтения (Господь не подвластен майе — «йогамайя»; Божество — не «статуя»; према гопи — не мирская страсть и т.п.).
  Такие места отлавливать сразу, при приёме каждой порции, а не только при итоговой выверке.
- Верность автору: переводить текст оригинала как он есть, не подправляя под позднейшее богословие; где автор
  расходится с гаудия-вайшнавским богословием (Бхактисиддханта) — точный перевод + сноска с пояснением.
- Современные английские переводы — только для сомнительных мест; расхождения с ними можно кратко отмечать в сносках
  (без цитирования); пользователю отдельно не выводить.

## База лил
- `lila-db/` — сводная база лил Шри Чайтаньи по всем источникам (временная шкала, источник и место в нём, теги
  спутников `@…` и мест `#…`, авторитетность A–D). Формат — `lila-db/README.md`. При переводе житий вести записи
  параллельно, по порядку изложения; проверка — `python3 lila-db/build.py`.
