# Задание: перевод «Гаудия-бхашьи» Бхактисиддханты Сарасвати к «Шри Чайтанья-чандрамрите»

Источник: `/home/user/Gauranga/sources/chaitanya_chandramrita_bss_bengali_djvu.txt` — OCR (с ошибками) бенгальского
издания «Шри Чайтанья-чандрамритам» с «Гаудия-бхашьей» и бенгальским переводом Бхактисиддханты Сарасвати
(Гаудия Матх, Калькутта, 1-е изд.). Бхактисиддханта умер в 1937 г.; его текст — общественное достояние.

Для каждой шлоки в издании идут:
1. Заголовок-резюме (одна-две строки, кончаются «__» или «—»), напр. «দর্শন-স্পর্শনাদিমাত্রে পরম-প্রেম্দ শ্রীচৈতন্তের স্ততি__».
2. Санскритская шлока (бенгальским письмом), кончается «॥ N ॥».
3. «অন্বয়» — пословное толкование: санскритские слова с бенгальскими пояснениями в скобках (OCR часто портит слово «অন্বয়»).
4. «অনুবাদ» — связный бенгальский перевод-толкование с пояснениями, кончается «॥ N ॥».

Что нужно сделать для каждой шлоки твоего диапазона (нумерация — по этому бенгальскому изданию):
- перевести на русский заголовок-резюме;
- перевести на русский **полностью** «অনুবাদ» (это и есть комментарий; сохраняй все пояснения в скобках,
  цитаты из других писаний, ссылки — цитаты из бенгальских/санскритских текстов тоже переводи);
- из «অন্বয়» добавить только те толкования, которых нет в «অনুবাদ» и которые несут смысл (напр. «"Шри" — это
  Шримати Радхика, "Хари" — Кришна»), одной строкой «Из пословного толкования: …». Если таких нет — строку опусти.
- Самих шлок НЕ переводить (они уже переведены, см. ниже).
