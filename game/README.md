# Игра по Гаура-лиле (изометрическая RPG)

- `DESIGN.md` — концепция: герой-гандхарва, два плана, главы по периодам базы лил, кодекс, принципы содержания,
  открытые вопросы к пользователю.
- `TECH.md` — как добиться красивой графики бесплатно: пререндер фонов в Blender/Cycles + 3D-персонажи в Godot 4,
  ассеты CC0, конвейер персонажей, данные из `lila-db/export`.
- `VERTICAL-SLICE.md` — тестовый уровень «Ночь пхалгуна-пурнимы» (Явление, 1486): карты, эпизоды по событиям базы,
  шаги работ, что нужно от пользователя (промпты GPT).
- `research/TASK-material-culture.md` — задание для отдельного чата: историческая база быта эпохи.
- `ref/` — эталонные картинки (концепты GPT, портреты), `probe/` — пробные рендеры.
