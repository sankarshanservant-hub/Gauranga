# Техника и графика: как добиться красивой картинки без художника и без платных инструментов

## 1. Главный вывод: делать как Baldur's Gate, но современными средствами
Baldur's Gate и Icewind Dale красивы не потому, что их фоны рисовали вручную: их фоны — **3D-сцены, отрендеренные
заранее** (offline-рендер с киношным светом), а поверх — маленькие персонажи. Тот же приём у Pillars of Eternity,
Pathfinder, Disco Elysium (у последнего — ещё и живописная дорисовка).

Наш вариант этого приёма:
1. **Фоны** — сцены в Blender из бесплатных фотограмметрических ассетов (CC0) и моих процедурных моделей
   бенгальских построек, рендер **Cycles** (физически точный свет, глобальное освещение, мягкие тени, туман,
   свет лампад, затмение) в высоком разрешении. Рендер идёт на CPU в облачном контейнере — медленно (минуты–час
   на кадр), но бесплатно, а фон рендерится один раз.
2. **Из той же сцены** автоматически выгружаются: карта глубины, упрощённая «прокси-геометрия» (по ней ходят
   персонажи, она их загораживает, отбрасывает на них тени), маски воды/огня/листвы для анимации (рябь Ганги,
   пламя, качание листьев, дым очага, летучие мыши, светлячки).
3. **Персонажи — настоящие 3D-модели в Godot**, освещённые так же, как фон (направление и цвет света берутся из
   сцены Blender). Это даёт плавное движение во все стороны, жесты, танец киртана — то, что спрайтами не сделать.
4. **Портреты для диалогов** — живописные картины (как в BG), их делает пользователь через GPT по готовым
   промптам (`VERTICAL-SLICE.md`). Именно портреты несут лица и чувство; на карте персонаж ~150 px.
5. **Живописная дорисовка** фонов (по желанию): рендер → GPT/«img2img» в едином стиле. Нюанс: GPT слегка сдвигает
   геометрию, тогда прокси-маски перестают совпадать. Поэтому основной путь — сам рендер Cycles; дорисовку
   применяем к небу, дальним планам, небесному плану (где точная геометрия не нужна) и к концептам стиля.
   Если у пользователя есть ПК с видеокартой NVIDIA ≥ 8 ГБ — можно Stable Diffusion + ControlNet по глубине: тогда
   живописность без сдвига геометрии (бесплатно, локально).

Почему не «нарисую кодом»: прошлый опыт (картинка «из кода») так и выглядит. Здесь код только **собирает сцену** из
фотореалистичных материалов и считает свет — как это делает 3D-художник, только руками скриптов. Качество
определяют ассеты, свет и рендер, а не рисование.

## 2. Движок: Godot 4 (бесплатно, MIT)
- Камера — ортографическая изометрическая, совпадает с камерой Blender (параметры экспортируются скриптом).
- Фон = картинка; прокси-меши фона **рисуют сами пиксели фона** (шейдер берёт цвет из рендера по экранным
  координатам) — поэтому персонаж, зашедший за колонну или под навес, загораживается точно по силуэту.
- Ходьба — навигационная сетка из прокси-геометрии, клик-для-движения, как в BG.
- Рендерер Compatibility (WebGL2) — игра запускается **прямо в браузере на сайте**; также сборки для Windows /
  macOS / Linux, позже Android. Пререндер фона делает игру лёгкой даже для слабых машин.
- Диалоги — своя простая система на JSON (или плагин Dialogic, MIT); тексты RU/EN в отдельных файлах.

## 3. Где брать ассеты (законно и бесплатно)
| Что | Откуда | Лицензия |
|---|---|---|
| Фотограмметрия: деревья, камни, корзины, горшки, дерево, ткани; HDRI-небо | Poly Haven | CC0 |
| PBR-материалы: глина, штукатурка, солома, бамбук, кирпич, земля, вода | ambientCG, Poly Haven | CC0 |
| Растительность: пальмы, бананы, бамбук, ним, травы | Poly Haven; Sketchfab (только CC0/CC-BY, с указанием авторов); недостающее — собираю сам из CC0-текстур (листья на плоскостях, как в играх) | CC0 / CC-BY |
| Базовые тела людей, риг | MPFB2 (MakeHuman для Blender) | готовые модели — CC0 |
| Анимации (ходьба, стойка, жесты) | Quaternius Universal Animation Library, CMU Mocap; Mixamo (нужен бесплатный аккаунт пользователя) | CC0 / свободно |
| Звуки природы, улица, вода | Freesound (CC0/CC-BY), Sonniss GDC (бесплатно) | CC0 / роялти-фри |
| Бенгальская специфика (хижины чала, туласи-манча, дхеки, шил-нора, ханди, банановые листья, алпана, тхакур-гхар) | **моделирую сам** (скрипты Blender + CC0-текстуры); ткани, узоры сари, алпана — текстуры по промптам GPT | наше |

**Ассеты из старых RPG брать нельзя**: графика Baldur's Gate/Icewind Dale и других коммерческих игр — чужая
собственность, и для сайта миссии это прямой риск. Да и стилистически она «европейское фэнтези» — нам не подходит.

## 4. Персонажи — конвейер
1. Пользователь делает в GPT **лист персонажа**: вид спереди/сбоку/сзади в нейтральной позе + живописный портрет
   (промпты в `VERTICAL-SLICE.md`). Это эталон облика.
2. Я делаю тело в MPFB2 (пропорции, лицо, тон кожи по эталону), одежду моделирую в Blender (дхоти, уттарья, сари,
   чаддар; симуляция ткани), шикха, тилак, мала, украшения; риг; анимации — CC0-библиотеки + свои ключевые
   (поклон, киртан с поднятыми руками, качание младенца).
3. Запасной путь для сложных лиц/фигур — генерация 3D по картинке (TRELLIS, MIT; бесплатный Space на Hugging Face)
   с последующей чисткой; качество неровное, поэтому основной путь — MPFB2.
4. Уникальных героев много, но на карте важны силуэт, одежда, цвет, походка; лица — на портретах. Толпы (гхат,
   киртан, рынок) — вариации одного тела: одежда, цвет, рост, анимации со сдвигом.

## 5. Данные
- `game/tools/export_lila.py` (будет): из `lila-db/export/*.json` собирает `game/data/chapters/*.json` — для каждой
  главы: события, краткое изложение, источники, стихи и ссылки на сайт, участники, места.
- Главы описываются в `game/data/chapters.yaml` (вручную): какая карта, какие события, порядок сцен, точки кодекса.
- Быт — из исторической базы `material-culture/` (готовит отдельный чат по `game/research/TASK-material-culture.md`).
