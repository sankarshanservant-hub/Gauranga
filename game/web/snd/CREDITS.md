# Звуки игры — источники и лицензии

Все записи свободные: **CC0** (общественное достояние), атрибуция не обязательна, но мы её даём.
Большинство взято из набора приложения «Нада-янтра» (репозиторий HareKrishna, `public/apps/nada-yantra/app/s/`),
где они уже отобраны и сведены.

| Файл | Что | Источник |
|---|---|---|
| `tanpura.mp3` | тампура (дрон музыки), первые 120 с | Freesound, Kaczinski (CC0) |
| `harp-*.mp3` | ноты арфы для мелодии | VCSL — Versilian Community Sample Library (CC0) |
| `kartal.mp3` | караталы (Finger Cymbals) | VCSL (CC0) |
| `bell1–3.mp3` | ручной колокольчик (Hand Bells, Nepalese) — звон при подношении | VCSL (CC0) |
| `shimmer.mp3` | отзвук небесного зрения (отрывок «колокольчиков») | Freesound, Littleboot (CC0) |
| `amb_day.mp3` | лес днём | Freesound, sonidosreales245 (CC0) |
| `amb_dusk.mp3` | утро в джунглях (птицы) — для сумерек | Freesound, kyles / Selector (CC0) |
| `amb_night.mp3` | тропическая ночь (сверчки), первые 120 с | Freesound, kyles / Selector (CC0) |
| `fire.mp3` | огонь в очаге-чуле | Freesound, cagancelik (CC0) |
| `grass_1–2.mp3` | шаг по траве (leaves) | OpenGameArt, «Different steps on wood, stone, leaves, gravel and mud» — [kdd] (CC0) |
| `creak1–2.mp3`, `doorOpen_1.mp3` | деревянная дверь | OpenGameArt, «50 RPG sound effects» — Kenney (CC0) |
| `bookFlip1–2.mp3`, `bookOpen.mp3` | карточка и журнал | там же, Kenney (CC0) |

Шаги босыми ногами по земле, глиняному полу и тропе не записаны, а синтезируются в `audio.js`.
Музыка генерируется прямо в игре и поэтому не повторяется. Под ней звучит тампура, поверх раз в 8–18 с идут короткие фразы арфы
в раге по времени суток: днём Бхупали, в сумерках Ямань, ночью Малькаунс. Изредка звучит тихий перебор (как на сварамандале)
или одиночный звон каратал.
