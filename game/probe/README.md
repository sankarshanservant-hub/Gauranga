# Пробный рендер стиля: двор дома Джаганнатхи Мишры

`build_courtyard.py` — сцена целиком из кода: бенгальские хижины-чала (изогнутые соломенные кровли, глиняные
стены, веранды на бамбуковых столбах, цоколи), туласи-манча с алпаной, пруд с гхатом, кокосовые пальмы, бананы,
бамбук, стога соломы, кизяк на стенах, дрова, сари на верёвке, лампады; трава — geometry nodes. Материалы, деревья,
латунные и глиняные предметы, небо — Poly Haven (CC0). Рендер — Cycles, CPU.

Запуск (нужны Blender 4.5 и ассеты Poly Haven — скачиваются скриптом `ph_get.py` по списку внутри):
```
blender -b -P build_courtyard.py -- --assets <ассеты> --out frame.png --res 100 --samples 160 \
  --sky 0.5 --moon 0.8 --exposure 0.3 --hdri qwantani_moonrise --hdri_rot 120
```
Кадры: `frame-dusk.jpg` — вечер пхалгуна-пурнимы перед восходом луны.
