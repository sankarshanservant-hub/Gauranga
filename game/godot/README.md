# Серый уровень: «Брахман-паломник» (Godot 4.5)

Пробный играбельный уровень: двор дома Джаганнатхи Мишры, лила из «Шри Чайтанья-бхагаваты», Ади 5.16–166.
«Серый» — значит, персонажи пока условные фигуры, портреты — цветные плашки; фон и механики — настоящие.

## Как запустить
1. Скачать **Godot 4.5** (бесплатно, один файл): https://godotengine.org/download — «Godot Engine» (не .NET).
2. Скачать папку `game/godot` из репозитория (на GitHub: Code → Download ZIP, распаковать).
3. Запустить Godot → «Импорт» → выбрать файл `game/godot/project.godot` → «Импортировать и редактировать».
4. Нажать **F5** (или ▶ вверху справа). Первый запуск импортирует ресурсы (≈ 1 мин).

## Управление
- Левая кнопка мыши — идти; на предмет — подойти и открыть карточку; на человека — карточка лица.
- Пробел — подсветить все предметы; Tab — небесное зрение; J — журнал; Esc — закрыть окна.
- В диалоге — щелчок / Пробел / Enter — дальше; 1–3 — выбор.

## Что показывает уровень
- пререндеренный фон (Blender/Cycles) + невидимая прокси-геометрия: персонажи заходят за кровли и столбы;
- навигация по двору и верандам (поиск пути);
- 20 кликабельных предметов быта с карточками «Как это было» (черновые тексты до исторической базы) и журнал;
- лилу в 4 сценах: днём, вечером, ночью; реплики — дословно из перевода ЧБ, у каждой — источник и стих;
- выбор героя в диалоге (внутренний отклик гандхарвы — игровой рассказ);
- небесное зрение: видны наставник-гандхарва и Нидра-деви, у предметов открывается «небесный» слой описания;
- ощутимость: незримый гость не должен подходить близко — иначе Шачи заметит тень, а Нимай… увидит.

## Для разработчика
- `scripts/main.gd` — мир, ввод, режиссёр сценария; `figure.gd` — фигуры; `ui.gd` — интерфейс.
- `data/scenario.json` — сценарий (шаги: place, walk, say, narrate, choice, time, vision…), `codex.json`, `characters.json`.
- Фон и прокси — из `game/probe/build_courtyard.py` (`--export` пишет `assets/proxy/`).
- Автотест со скриншотами: `godot --path . -- --autoplay --shots=/папка`.
