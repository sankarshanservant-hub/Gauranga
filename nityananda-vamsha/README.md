# «Нитьянанда-вамша-вистара» — перевод на русский и английский

- `Nityananda-Vamsha-Vistara-ru.*`, `Nityananda-Vamsha-Vistara-en.*` (.md / .docx / .pdf) — итоговые файлы.
- `ru/01–10.md`, `en/01–10.md` — перевод по главам (2251 двустишие, нумерация внутри глав) с примечаниями переводчика.
- `src/ch01–ch10.txt` — источник: две OCR-копии издания Кишори Даса Бабаджи (2-е изд., 1991), разложенные по колонкам, постранично.
- `GLOSSARY.md` — имена RU/EN; `TASK.md` — правила перевода; `build.py` — сборка (использует `../govinda-kadacha/build.py`).

Переведён только текст поэмы (приписывается Вриндавану Дасу Тхакуру); предисловие, примечания и приложения
издателя не переводились. Бенгальские слова в примечаниях даны в транслитерации IAST.
