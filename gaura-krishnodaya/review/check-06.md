# Выверка: сарга 6

Санскрит — скан, с. 28–32.

- 6.9: восстановлен конец стиха: «ты зажжена Творцом мира для мира, как светильник» (оговорка о порче снята).
- 6.14: «вспоминая Его слова, о Владыка» → «вспоминая слова Владыки» (*vibhoḥ* — род. п., не обращение).
- 6.16: «как закрывшийся бутон лотоса» → «словно [отложенную] чашечку с остатками подношения (*нирмальей*)» + сноска.
- 6.43: «рис, дал» → «кислый суп» (*amla-sūpa*; лишний «рис»).
- 6.45: «гроздья бананов, кокосы» → «гроздьями, молодые манго, бананы» (*bālāmra-rambhā-panasa*; кокосов в тексте нет).
- 6.46: «трижды» → «на три доли» (*tridhā pūrya*).
- 6.48: «Ты… — единый» → «единственный Вкушающий» (*eka evāttā*; намёк на Брахма-сутру 1.2.9) + сноска.
- 6.55: «[Ачарья-ратна]» → «[Ачарья-мани]» — единообразие со ст. 18, 26–28.
- 6.56: «заполнили [город]…» → «достигли той [обители], где пребывал…» + сноска (*vayasi*/*vasati*).
- 6.57: добавлено «долго… измождённого» (*tāntaṃ … ciriṇam*).
- 6.59: «мудрецов, горожан-мусульман» → «Буддхиманту Хана и прочих» — **существенная правка** (имя спутника вместо «мусульман»); сноска 14 переписана.

Сверено без замечаний: остальные шлоки. RU и EN совпадают (сноски перенумерованы синхронно).
Богословие: без замечаний; «застыли, как изваяния» (6.40) — о людях, не о Божестве.
