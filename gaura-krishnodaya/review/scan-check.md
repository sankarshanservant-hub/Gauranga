# Сверка неясных мест по скану

Скан: archive.org `sri-gaura-krsnodayah`, PDF 122 МБ (`src/Gaura-krsnodaya_scan.pdf`, в git не входит).
PDF-страница N = книжная страница N−5; страницы повёрнуты, текстовая полоса — правая половина разворота.
Метод: изображение страницы (300 dpi, поворот 270°) → чтение санскрита глазами → сравнение с OCR и переводом.
