# Задание: Говинда-дева, «Шри Гаура-кришнодая» — перевод на русский и английский

**Текст.** «Шри-шри Гаура-кришнодая» (*Śrī-śrī Gaura-kṛṣṇodayaḥ*, «Восход Гаура-Кришны») — санскритская
махакавья в 18 саргах. Автор — Говинда-дева (Говинда Кави), ориец, из семейства (линии) Вакрешвары Пандита;
поэма завершена в 1680 г. Шака (1758 г. н. э.), в месяц ашвина, на второй титхи тёмной половины (так в предисловии
издателя). Источник: изд. Бхактисиддханты Сарасвати (Шри Вималапрасад Сиддханта Сарасвати; 1-е изд. — 427 г.
Чайтанья-эры, т. е. 1913 г.), 4-е изд., Майяпур, Шри Чайтанья-матх, 2002 (IA `sri-gaura-krsnodayah`).
Рукопись, по словам издателя, получена из княжества Наягарх (Орисса) через Рай-сахиба Гаурашьяма Маханти.

**Что в издании от Бхактисиддханты.** Только краткое предисловие (бенг., 1 с.: характеристика поэмы, сведения об
авторе и дате, история рукописи) и оглавление. **Комментария и подстрочных примечаний нет** — печатается только
текст поэмы с колофонами сарг. Переводится **только поэма**; предисловие издателя не переводится (о нём — своими
словами в нашем предисловии).

**Объём** (по последним номерам шлок в саргах): 62 + 62 + 71 + 50 + 51 + 61 + 61 + 62 + 58 + 63 + 63 + 44 + 61 + 71 +
60 + 68 + 74 + 64 = **1106 шлок** (уточняется при переводе: нумерация издания местами сбита OCR).

**Файлы источника** (`src/`): `Gaura-krsnodaya_text.pdf` (IA, текстовый PDF 15 МБ), `Gaura-krsnodaya_djvu.txt`
(OCR IA, tesseract asm+ben). Полный скан (PDF 122 МБ) в репозиторий не кладётся — только ссылка:
https://archive.org/details/sri-gaura-krsnodayah. Текст набран бенгальским шрифтом. Собственный OCR не делался (машина перегружена); испорченные места OCR IA
сверяются по изображениям страниц скана (PDF-страница N = книжная страница N−5; страницы в скане повёрнуты на 90°).

**Принципы перевода.**
- Только перевод (без оригинала и пословного), RU и EN параллельно, одна нумерация: `ru/NN.md`, `en/NN.md`
  (NN — номер сарги), метки **N.** — номера шлок издания.
- Перевод точный, прозой, по шлокам; поэтические фигуры (шлеша, утпрекша) — раскрывать в сносках.
- Сноски: параллели с «Чайтанья-чаритамритой» (поэма в основном пересказывает ЧЧ — отмечать, где следует, где
  добавляет своё), богословие — по Бхактисиддханте; расхождения с ЧЧ и «Гаура-ганоддеша-дипикой» — оговаривать.
- Испорченные OCR места сверять по скану (страницы PDF); невосстановимое — «[…]» и сноска.
- Маркер `*[с. N]*` / `*[p. N]*` — страница PDF скана перед первой шлокой новой страницы.
- Имена — по `../murari-gupta/GLOSSARY.md` и `../karnapura-mahakavya`.

**Книга:** `build.py` (по образцу `../nityananda-vamsha/build.py`, движок `../govinda-kadacha/build.py`) →
`Gaura-Krishnodaya-{ru,en}.{md,docx,pdf}` с предисловиями.
