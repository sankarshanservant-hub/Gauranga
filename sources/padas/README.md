# Пады современников Махапрабху — источники (антологии и падавали)

Поиск начат 2026-10-07 (этап 1 плана `../../padas/PLAN.md`). Здесь — антологии бенгальских пад, где находятся пады
спутников Чайтаньи о Гауре, и журнал поиска (включая тупики). Каталог пад — `../../padas/CATALOG.md`; выписка из Маджумдара —
`../../padas/majumdar-ch2.md`.

Правило: берём только общественное достояние (средневековые тексты; издания до ~1930 или издания, редакторы которых умерли
более 60 лет назад — индийское законодательство: 60 лет p.m.a.). «djvu.txt» = OCR archive.org (Bengali, качество среднее:
цифры номеров пад часто искажены, двухколоночная вёрстка местами перемешана). PDF не скачивались, если OCR пригоден.

- IA metadata по идентификаторам из плана: `in.ernet.dli.2015.22783` — **не ПК** (это «Despatches… Marquess Wellesley», 1836) — ошибка в плане; т. 5 = `477950`/`513341`.
