# Распознавание tesseract (ben), этап 1б

Заново распознанные (tesseract, язык `ben`) сканы изданий в общественном достоянии (см. таблицу в `../README.md`):
`pk_v1…pk_v4.txt` — «Падакалпатару», изд. С. Рая, тт. 1–4; `ps.txt` — «Падамрита-самудра» (1878);
`kgc.txt` — «Кшанада-гита-чинтамани» (1925); `gpt1.txt` — «Гаура-пада-тарангини», 1-е изд. (1903).
`pk-index.json` — привязка сквозных номеров ПК к тексту (≈2180 из 3101 пад). `scripts/` — вспомогательные
скрипты разбора (пути внутри — временные папки сессии; при повторном использовании поправить).
OCR лучше, чем у archive.org, но не безошибочен: чтения для перевода сверять по сканам PDF.
Порция 16: `scripts/sweep_pk.py` — сплошная сверка ПК (tesseract `pk_v1…v4.txt`) по подписям поэтов-современников со словами гаура-лилы в окне
пады; печатает том, PDF-страницу, номер ПК (по меткам) и пометку NEW (номера нет в каталоге и переводах).
