# «Шри Чайтанья-упанишад» — поиск изданий (журнал)

Для книги `chaitanya-upanishad/` (п. 14 `PLAN.md`): «Шри Чайтаньопанишад» (атхарваведийская) с санскритским
комментарием Бхактивиноды Тхакура «Шри Чайтанья-чаранамрита» (первое изд. — Калькутта, 1887). Дата поиска: 2026-10-11.
