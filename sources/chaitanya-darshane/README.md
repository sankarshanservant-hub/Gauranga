# «Шри Чайтанья-даршане Прабхупада Шрила Бхактисиддханта Сарасвати Тхакур» (бенг.)

*Śrī Caitanya-darśane Prabhupāda Śrīla Bhaktisiddhānta Sarasvatī Ṭhākura* — «Прабхупада Шрила Бхактисиддханта
Сарасвати Тхакур в свете учения Шри Чайтаньи».

- Сборник статей, лекций, писем и бесед Бхактисиддханты Сарасвати (из «Гаудии», «Саджджана-тошани», «Надии-пракаши» и др.), на бенгали.
- Составитель — Тридандисвами Бхакти Виласа Тиртха Госвами Махарадж (Шри Чайтанья Матх). Первое издание — в нескольких томах к столетию Бхактисиддханты (1974).
- Здесь — 2-е изд., Шри Чайтанья Матх, Маяпур, 14.02.2009 (изд. Бхакти Праджняна Яти Махарадж), тома 1–2 в одном файле, 730 с.
- Разделы озаглавлены изречениями: *mūḍhaḥ kartāham iti manyate*, *satyaṁ paraṁ dhīmahi*, *vedyaṁ vāstavam atra vastu śivadam*, *śrī-caitanya dayānidhe, tava dayā bhūyād amandodayā*, *dhyeyaṁ sadā śrī-caitanya-caraṇāravindam*, *atha upadeśāmṛta-sāram*, *sadā hṛdaya-kandare sphuratu naḥ śacīnandanaḥ*, «Гаудия-даршана — ачинтья-бхедабхеда-вада», *vidyā bhāgavatāvadhi*, *bhaktir hi bhūtānām*, *harer nāmaiva kevalam*, *raso vai saḥ*, *hari-sambandhi-vastunaḥ*.
