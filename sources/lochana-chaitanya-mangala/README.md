# Лочан Дас, «Шри Чайтанья-мангала» — источники

- `bss1922_djvu.txt` — OCR (DLI `in.ernet.dli.2015.357655`): **издание Шрилы Бхактисиддханты Сарасвати** (Шри Чайтанья Матх,
  Майяпур, 1329 Бенг. = 1922). Основной текст (A). Содержит также: гуру-парампару, список цитируемых писаний, предисловие
  Бхактисиддханты («ভূমিকা», строки ~95–500), его краткое изложение по частям («খণ্ড বিবরণ», ~514–~1000), указатель
  имён и слов (до ~12190) и прозаические изложения перед разделами. Текст поэмы: Сутра-кханда 12192, Ади 16106,
  Мадхья 23325, Шеша 30330 — конец 32492.
- `hs1983_devanagari_djvu.txt` — OCR изд. Харидаса Шастри (Вриндаван, 1983), бенгальский текст деванагари (archive.org
  `chaitanya_mangala_devanagari`). Второй свидетель (B), распознан хорошо.
- `atul1903_djvu.txt` — OCR изд. Атулкришны Госвами (1903; DLI `in.ernet.dli.2015.453358`). Третий свидетель (C), OCR плохой.
- Английский перевод (современный, защищён; только для сомнительных мест, не копировать):
  https://www.wisdomlib.org/hinduism/book/chaitanya-mangala
