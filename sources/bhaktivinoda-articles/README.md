## Авторское право
Статьи Тхакура (ум. 1914) — общественное достояние. Предисловия, подзаголовки-«шираномы» и примечания редакторов
сборников (1950, 2004/2015) и переводы BVI — современные, не воспроизводить (только для ориентира).
В `EN-bhaktivinodainstitute.tsv` — лишь библиографические данные (заглавия, ссылки, выходные данные), без текста.
