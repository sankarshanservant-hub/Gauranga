## Не в репозитории (> 50 МБ) — только ссылки

- **Г. Ч. Прахарадж, *Purnachandra Odia Bhashakosha*** (ପୂର୍ଣ୍ଣଚନ୍ଦ୍ର ଓଡ଼ିଆ ଭାଷାକୋଷ), Cuttack 1931–1940, 7 тт. (ория → ория/англ./бенг./хинди),
  главный словарь ория, с цитатами из средневековой поэзии. IA `Purnachandra.Odia.Bhashakosha.Complete`
  (`https://archive.org/details/Purnachandra.Odia.Bhashakosha.Complete`): тома по 80–111 МБ (PDF), jp2-архивы по
  170–240 МБ. Т. 4 отдельно: IA `dli.language.1517` (311 МБ).
  Тома: 1 — гласные; 2 — ka…ṅa; 3 — ca…ṭha(?)/tha; 4 — da…pa; 5 — pha…ma; 6 — ja(ya)…śa; 7 — sa…ha.
  **Текстовый слой IA (djvu.txt) для поиска непригоден**: орийские заголовки распознаны как латиница («G9. 9- QQQI…»);
  читаемы только английские толкования. Поиск слова — по изображению страницы (бинарный поиск по алфавиту:
  скачать том в scratchpad, `pdftoppm -f N -l N`). Т. 4 и др. скачивались в scratchpad пилота; в репо — только
  выдержки, использованные в сносках/`oriya-pilot/vaishnava-lilamrita/transcription-notes.md`.
  Найдено в пилоте: т. 1, лист PDF 1045 — ଉଭା, ଉଭାରିବା «поднимать(ся), вставать» (с цитатой из «Бхагаваты»
  Джаганнатхи Даса); т. 7, лист PDF 1171 — ହାଣ୍ଡୋଳା «маленький глиняный храм деревенских божеств». Нумерация листов
  PDF ≈ печатным страницам (т. 1: лист 1000 = с. 1000; т. 7: лист 1163 = с. 1067). Оценка — `oriya-pilot/METHOD.md`, § 6.
- Pramod Chandra Deb, *Pramoda Abhidhana* (ориясский словарь), 1942 — IA `PramodaAvidhanaByPramodChandraDeb-OdiaDictionary.pdf`
  (235 МБ; автор — проверить даты жизни перед использованием).
- Для средневекового ория полезны глоссарии к изданиям Сарала-Махабхараты (А. Б. Моханти) — на IA не найдены
  (не искались подробно).
