## Рекомендация: с чего начинать перевод

1. **«Вайшнава-лиламрита» Мадхавы Паттанаяка** (≈1535, ученик Гададхары, очевидец Пури; ≈80 стр. двустиший) — самый
   ранний и надёжный орийский текст, который реально доступен целиком (скан 1986). Переводить с ория напрямую, по скану;
   примечания Ачарьи не воспроизводить.
2. **«Чайтанья-виласа»** — пока перевести только выдержки, приведённые Маджумдаром (≈30 строк, 10 чханд по пересказу);
   параллельно запросить копию рукописи Odisha State Museum (Ol./616(C), Ol./945).
3. **Дивакар Дас** — по PD-изданию 1927 г., гл. 1–7 (о Чайтанье в Ориссе) и 23; сектантские места — точный перевод + сноски.
4. **Ишвара Дас** — выборочно (гл. 2, 46–49, 64–65: Рамананда, путь в Пури, Пратапарудра, Панчасакха, уход); много
   богословски чуждого (Чайтанья как Будда-Джаганнатха) — сноски по Бхактисиддханте.
5. «Махабхава-пракаша» Канаи Кхунтии (52 стр., неполная) — небольшая, ценная (спутник Чайтаньи), можно сразу после п. 1.

Помощь при переводе: орийский словарь *Purnachandra Odia Bhashakosha* (Г. Ч. Прахарадж, 1931–40, 7 т.; IA `Purnachandra.Odia.Bhashakosha.Complete`); для средневекового ория полезны
словари к изданиям А. Б. Моханти (Сарала-Махабхарата). Желательна сверка спорных мест с носителем ория.
