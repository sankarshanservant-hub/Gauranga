# Джаянанда, «Чайтанья-мангала» (Jayānanda, Caitanya-maṅgala) — источники

Поиск выполнен 2026-10-03, дополнен 2026-10-05 (второй проход: изд. 1905 г. + все цитаты в PD-антологиях и исследованиях). **Полный текст Джаянанды (ни изд. 1905 г., ни изд. 1971 г.) в открытом доступе не найден.** Ниже — всё, что удалось достать: фрагменты оригинала (бенг.) и английские переводы фрагментов, первые статьи-публикации Н. Васу (1897–98) с обширными цитатами, исследования Б. Маджумдара.

Структура поэмы (для проверки): Ādi, Nadīyā, Vairāgya, Sannyāsa, Utkala, Prakāśa, Tīrtha, Vijaya, Uttara khaṇḍa; колофон «চিন্তিয়া চৈতন্য-গদাধর-পদদ্বন্দ্ব … গাএ জয়ানন্দ».
