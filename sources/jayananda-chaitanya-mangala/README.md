# Джаянанда, «Чайтанья-мангала» (Jayānanda, Caitanya-maṅgala) — источники

Поиск выполнен 2026-10-03. **Полный текст Джаянанды (ни изд. 1905 г., ни изд. 1971 г.) в открытом доступе не найден.** Ниже — всё, что удалось достать: фрагменты оригинала (бенг.) и английские переводы фрагментов, первые статьи-публикации Н. Васу (1897–98) с обширными цитатами, исследования Б. Маджумдара.

Структура поэмы (для проверки): Ādi, Nadīyā, Vairāgya, Sannyāsa, Utkala, Prakāśa, Tīrtha, Vijaya, Uttara khaṇḍa; колофон «চিন্তিয়া চৈতন্য-গদাধর-পদদ্বন্দ্ব … গাএ জয়ানন্দ».

## Найдено, но не скачано

**Издания самого текста (полные):**

Public domain, но **скана в сети не найдено**: проверены archive.org (advancedsearch по всем вариантам написания, полнотекстовый поиск FTS по «জয়ানন্দ», по колофонам «গাএ জয়ানন্দ», по строкам текста), зеркала DLI (in.ernet.dli.2015.*, dli.bengal.*, dli.calcutta.*), все тома/ежегодники Sahitya Parishat 1904–1907 на archive.org, Google/Bing.
