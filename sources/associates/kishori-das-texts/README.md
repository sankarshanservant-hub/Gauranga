# Старые тексты в изданиях Кишори Даса Бабаджи: что внутри и что переводить

Составлено 2026-11-19. Кто такой Кишори Дас и все его издания — `../KISHORI-DAS-BABAJI.md`.
Скачано с archive.org: PDF + OCR архива (`*-ocr_djvu.txt`); где OCR архива плох или без деления на страницы —
наш OCR (tesseract 5, `ben`) по страницам (`*_tesseract-pages.txt`, метки `=== pdf NNN ===`).
PDF > 20 МБ — вне git (`.gitignore`); скачать заново по идентификатору archive.org из таблицы.

**Правила.** Издания современные (1976–2010-е) и под охраной: предисловия, примечания, реконструкции и сочинения
самого Кишори Даса не воспроизводятся и не пересказываются. Ниже — только факты (автор, дата, рукопись, объём) и
содержание по самим старым текстам. Переводится только старый текст. Авторитет в толковании — Бхактисиддханта
Сарасвати; оценки подлинности — по Маджумдару («Шри Чайтанья-чаритер упадан», 2-е изд., 1959, `dli.calcutta.10939`,
OCR — `sources/jayananda-chaitanya-mangala/Majumdar_*`). «Гаудия-вайшнава-абхидхана» Харидаса Даса в проекте нет —
не сверялось.

Достоверность (как в `lila-db`): **B** — поздний, но добросовестный источник; **C** — поздняя местная/семейная
традиция, много чудесного; **D** — подделка или ложная атрибуция (по Маджумдару), использовать только с оговоркой.

## Рекомендации: порядок перевода
1. **«Шакха-нирнаямрита»** (59 шлок) — коротко, санскрит, B; закрывает гададхара-шакху для `parshadas/` и
   `lila-db`. Комплект: `shakha-nirnayamrita/` (одна-две порции).
2. **«Пата-нирная» + «Пата-парьятана» + «Шакха-нирная Абхирамы»** (≈135 двустиший) — перечни шрипатов XVII в.
   для тегов мест; PP и ASN — по изданию 1911 г. (PD). Комплект: `pata-nirnaya/`.
3. **«Джагадиша-чаритра-виджая»** (≈1250 единиц, 12 варн) — единственное житие Джагадиши Пандита, C; сноски о
   слиянии двух Джагадиш. Комплект: `jagadisha-charitra-vijaya/`.
4. «Дхананджая-Гопала-чарита» и «Шьямачандродая» (≈55 + 129 строф) — малые местные жития, C; комплект можно
   собрать по образцу (PDF в git).
5. По остаточному принципу и только с оговоркой о подложности (D): «Сита-чаритра» (лучше искать изд. 1926),
   «Сита-гуна-кадамба», «Абхирама-патала»; из «Нитьянанда-чаритамриты» — разве что Антья 12–14 по изд. 1902/1903.
   В «Сите» и «Абхирама-патале» — сахаджийские мотивы (мужчины в женском облике, отождествления с манджари):
   переводить только точно и со сносками по Бхактисиддханте.
6. «Шриниваса-рачанавали» — не переводить целиком; стотры о Шринивасе — при работе над `stotras/`.
