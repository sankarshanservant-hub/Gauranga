# Мурари Гупта, «Шри Кришна-чайтанья-чаритамрита» — источники санскритского текста

- `hs_upft_djvu.txt` — OCR (archive.org, `upfT_shri-shri-krishna-chaitanya-charit-amritam-of-shriman-murari-gupta-edited-by-shr`):
  изд. Харидаса Шастри (Шри Харидас Шастри Го-сева Санстхан, Вриндаван), санскрит + хинди. Основной свидетель (A).
- `hs_kcc_djvu.txt` — OCR другого скана того же издания (archive.org `kcc_murarigupta`; это же издание — epub в корне репозитория). Свидетель B.
- `hdd1945_djvu.txt` — OCR изд. Харидаса Даса Бабаджи, бенгальское письмо, Калькутта (изд. Мриналканти Гхоша), 4-е изд., 1945
  (archive.org `phys_shri-shri-krishna-chaitanya-charitamritam-by-murari-gupta-haridas-das-babaj`). Свидетель C.
  То же издание (1943/1944) есть на archive.org: `shri-shri-krishnachaitanya-charitamrim`, `Krishnachaitanya_charitamritam`.
- `ggm_kcc.pdf` — Gaudiya Grantha Mandira (grantha.jiva.org, e_no=515), набор пракрамы 1, сарг 1–6 (2003), шрифт devnag (TeX);
  для сверки начала.
- Не использовались: англ. перевод на gaudiya.redzambala.com (современный, защищён); хинди-переводы изданий.
