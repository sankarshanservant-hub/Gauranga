# Шрила Бхактивинода Тхакур, «Шри Навадвипа-дхама-махатмья» и «Шри Навадвипа-бхава-таранга»

Внесено 2026-10-26 по просьбе пользователя (издание Шри Чайтанья Сарасват Матха).

## Сочинения

- **«Шри Навадвипа-дхама-махатмья»** (бенг., 1890) — прославление Навадвипа-дхамы: Нитьянанда Прабху ведёт
  Дживу Госвами по девяти островам Навадвипы (Антардвипа, Симантадвипа, Годрумадвипа, Мадхьядвипа, Коладвипа,
  Ритудвипа, Джахнудвипа, Модадрумадвипа, Рудрадвипа) и рассказывает о лилах Махапрабху и Его спутников на
  каждом месте, о прошлых и будущих лилах и о значении дхамы. 18 глав («Парикрама-кханда»). Отдельно
  Бхактивинода составил «Прамана-кханду» — свод шастрических свидетельств о дхаме (в этом издании её нет).
- **«Шри Навадвипа-бхава-таранга»** (бенг., 1899) — песни-парикрама самого Бхактивиноды по Навадвипе: что он
  видит духовным зрением на каждом месте, в своём сиддха-облике.

Оригиналы Бхактивиноды (1890, 1899) — в общественном достоянии.
