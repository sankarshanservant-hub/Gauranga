## Проверено при переводе (2026-10-08)
- **Год издания вартт:** титул (с. PDF 4) — «संवत् १९५९» = самват 1959 = **1902/03 г. н. э.** Изд. Ядувамшия

  чаритра», «Чаураси вайшнаван ки варта», «Аштасакха ки варта». В скане есть дублированные листы (PDF 157=159,
  158=160, 182=184).

  (титул — с. PDF 6; «अन्तिम सूचना» — с. PDF 512). Название файла сохранено для истории, см. `vallabha/CATALOG.md`.

  Встреча с Чайтаньей — печ. с. 52 (PDF 88). Переведён только санскритский текст Ядунатхи (общественное достояние);
