## Бенгальский оригинал «Амрита-вани» — найден (2026-11-19)
«শ্রীল প্রভুপাদের উপদেশামৃত» («Шрила Прабхупадер упадешамрита») — по предисловию английского издания, это и есть
оригинал «Amṛta Vāṇī» (Touchstone Media сменила заглавие и добавила заголовки глав, которых в бенгальском нет).
Собрал Тридандисвами Бхакти Маюкха Бхагават Госвами Тхакур (ученик Бхактисиддханты), издал его преемник;
Гаудия-самити, Шри Гауранга-матх (Раипур, Бирбхум). Наш экземпляр — 5-е изд., 1417 г. Б. С. (≈2010),
«все права защищены» (относится к изданию/подборке; сами слова Бхактисиддханты — общественное достояние).
Устройство: вопросы и ответы — сотни пронумерованных вопросов («Кто может знать тайну бхаджана?», «Что такое
анйабхилаша?», «Шри-виграха — Сам Господь?», «Где найти гуру?»…), ответы — слова Прабхупады из бесед, статей
и писем (источники ответов в издании, по-видимому, не указаны — проверить).
