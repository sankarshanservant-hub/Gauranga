## Ядунандана Дас, «Карнананда» (কর্ণানন্দ)

Поэма в 7 «нирьясах» (নির্যাস, «выжимка») о Шринивасе Ачарье, его семье, учениках и ветви; автор —
Ядунандана Дас, ученик Хемалаты Тхакурани (дочери Шринивасы). Датировка в колофоне (1529 шака = 1607 г.)
не согласуется с описанными событиями; текст содержит поздние вставки (см. `../karnananda/TASK.md`).
