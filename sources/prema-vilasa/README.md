# «Према-виласа» Нитьянанды Даса (бенг.)

- `prema_vilasa_nityananda_dasa_djvu.txt` — OCR издания 1913 г. (Калькутта, Багбазар, 1320 г. Б. Э.; общественное достояние),
  с Google Drive пользователя (`prema_vilasa_-_nityananda_dasa_djvu.txt`).
- Состав: предисловие издателя (≈11 тыс. бенг. слов, не переводится), вилас 1–23 (≈82 тыс.), вилас 24 (≈26 тыс., генеалогии; считается поздней вставкой),
  приложение — письма Шринивасы и Дживы Госвами и пр. (≈13 тыс.).
- `ocr_A_1913_columns.txt` — то же изд. 1913 г. (archive.org `premavilasa`), заново собранное из hOCR с разделением двух колонок
  по координатам (левая, `<!-- col -->`, правая); маркеры `=== PDF page N ===`.
- `ocr_B_1999_columns.txt` — изд. «Махеш лайбрери», Калькутта, 1999 (ред. Биджан Госвами; перепечатка текста 1913 г.),
  archive.org `CjbY_prema-vilasa-bengali-nityananda-das`, так же из hOCR. OCR заметно чище, но местами повреждён;
  используется только для чтения текста поэмы (предисловие и примечания редактора 1999 г. защищены и не используются).
