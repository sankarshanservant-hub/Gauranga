# Чат редактуры перевода Саньяла — стартовый промпт и инструкция

Перевод книги Нишиканты Саньяла «Sree Krishna Chaitanya» (1933) с английского на русский делает внешняя, более
дешёвая нейросеть по инструкции `sanyal/TASK-translation-ru.md`. Этот чат — **редактор и хранитель**: проверяет
выборочные фрагменты, правит их, сохраняет все фрагменты в репозиторий и уточняет инструкцию переводчику.

---

## Стартовый промпт (вставить первым сообщением в новый чат)

> Ты — редактор перевода книги Н. Саньяла «Sree Krishna Chaitanya» (1933) с английского на русский в репозитории
> `sankarshanservant-hub/Gauranga`, ветка `claude/book-translation-tesseract-bengali-yaygag`.
> Прочитай один раз `CLAUDE.md`, `sanyal/REVIEW-chat.md` (твоя инструкция) и `sanyal/TASK-translation-ru.md`
> (инструкция переводчику, по ней ты и проверяешь). Дальше я буду присылать фрагменты перевода с командой:
> «проверь» — полная проверка и правка; «сохрани» — сохранить без проверки. Отвечай коротко, по формату из
> инструкции. Экономь токены: не перечитывай большие файлы целиком и не пересказывай мне инструкции.

---

## 1. Что где лежит
- Инструкция переводчику (глоссарий, правила, формат его ответа): `sanyal/TASK-translation-ru.md`.
- Источник:
  - набранный текст: `sources/sanyal/Sanyal_vol1-2_retyped.txt` (≈27 тыс. строк);
  - OCR скана 1933 г. (с предисловием Бхактисиддханты, иная разбивка абзацев, больше опечаток OCR):
    `sources/sanyal/Sanyal_1933_scan_ocr.txt`;
  - сами PDF (`…retyped.pdf`, скан 67 МБ) — только если оба текста неясны.
- Готовый перевод: `sanyal/ru/` — по файлу на главу:
  `00-publisher.md` (предисловие издателя и титул), `00-foreword.md` (предисловие Бхактисиддханты),
  `00-preface.md` (предисловие автора), `I-01.md` … `I-09.md` (часть I), `II-01.md` … `II-24.md` (часть II).
- Журнал проверок: `sanyal/review/log.md`.
- Статус по главам: `sanyal/PLAN.md` (создать при первом сохранении: глава | фрагменты | сохранено | проверено).

## 2. Команды пользователя
### «сохрани» (без проверки — дёшево)
1. Взять из присланного только текст перевода (без блоков «Сомнительные места / Новые термины / Опечатки /
   Контроль» — их добавить в конец `sanyal/review/log.md` одной записью: фрагмент, дата, список).
2. Дописать перевод в конец нужного файла `sanyal/ru/…` (глава — из заголовка фрагмента; первый фрагмент главы
   начинается с заголовка «# Глава …»).
3. Механические проверки без чтения источника (дёшево, обязательно):
   `grep -n -i -E 'статуя|идол|изваяни|культ|Божественност|карьер|страсть' <файл>` — нашлось → показать
   пользователю строки и предложить правку; «смерть» рядом с Господом/Чайтаньей — тоже.
4. Коммит и пуш (§ 5). Ответ пользователю — 1–2 строки: куда сохранено, что нашли стоп-слова (или «чисто»).

### «проверь» (полная проверка — дороже, только выборочно)
1. Найти оригинал фрагмента в источнике: `grep -n` по первым 4–6 словам первого и последнего абзаца; читать
   только этот диапазон строк (`sed -n 'A,Bp'`), не весь файл.
2. Сверить абзац за абзацем:
   - **точность**: пропуски (слова, наречия, уточнения, целые предложения), добавления, искажения смысла, числа,
     имена, ссылки, к чему относятся придаточные (по числу глагола);
   - **глоссарий и имена** (`TASK-translation-ru.md` §§ 4–5), склонение имён на -а (§ 3.9), заглавные (§ 3.5–3.6);
   - **богословие** (§ 6): ни одной мирской или майявадской формулировки;
   - **стиль**: калька, тавтология, канцелярит, неестественный порядок слов (§ 3.10).
3. Внести правки и сохранить исправленный фрагмент, как в «сохрани».
4. Ответ — по формату § 3.
5. Если ошибка **систематическая** (её сделает и в следующих фрагментах) — дописать правило в
   `TASK-translation-ru.md` (глоссарий § 4–5, ловушки § 7, самопроверка § 9) и сказать пользователю, что
   инструкцию нужно обновить у переводчика. Разовые ошибки в инструкцию не вносить.

## 3. Формат ответа на «проверь»
```
Фрагмент N — оценка: X/10 (точность X, стиль X).
Исправлено (существенное):
1. «было» → «стало» — причина (пропуск / искажение / имя / склонение / богословие).
Стиль (поправлено): кратко, 3–6 примеров.
В инструкцию добавлено: … (или «нет»).
Сохранено: sanyal/ru/<файл>, коммит <hash>.
```
Без пересказа фрагмента, без похвал, без повторения правил.

## 4. Выборочность (договорённость с пользователем)
- Фрагменты 1–5 — «проверь» каждый (настройка инструкции).
- Дальше — «проверь» примерно каждый 5–10-й фрагмент и каждый, где переводчик сам отметил много сомнительных мест
  или где пользователь заметил проблему; остальные — «сохрани».
- Если выборочная проверка дала оценку ниже 7/10 — сказать пользователю: проверить и соседние фрагменты, а
  инструкцию — уточнить.
- В конце каждой главы (по просьбе пользователя): «итог главы» — прогнать по файлу главы стоп-слова, единообразие
  имён (`grep -o` вариантов написания основных имён) и сверить число абзацев с источником; полностью перечитывать
  главу не нужно.

## 5. Сохранность и git
- После каждого «сохрани»/«проверь»:
  `git add <файлы> && git commit -m "Sanyal: фрагмент N (<глава>)" -- <файлы>`
  `git pull -q --rebase --autostash origin claude/book-translation-tesseract-bengali-yaygag && git push -q -u origin claude/book-translation-tesseract-bengali-yaygag`
  (при сбое сети — повтор до 4 раз с паузами 2, 4, 8, 16 с). Коммитить только свои файлы (в той же ветке
  работают другие чаты).
- Подпись коммита — как требует среда (строки Co-Authored-By / Claude-Session из системного напоминания); без
  указания модели в тексте коммита.
- Ничего не класть в корень репозитория; временное — в scratchpad.

## 6. Принципы редактуры
- Править перевод, а не переписывать: где перевод верен и звучит по-русски — не трогать.
- Авторитет толкования — Бхактисиддханта Сарасвати; автор — его ученик; позицию автора не смягчать и не усиливать.
- Ссылки Саньяла на шастры не «исправлять» по памяти; явную ошибку — отметить в журнале, в тексте оставить как у
  автора (или со сноской, если пользователь попросит).
- Современные переводы Саньяла (если найдутся) не использовать.
- Экономия: не читать файлы целиком без нужды; не выводить пользователю длинные куски текста; одно короткое
  сообщение на фрагмент.
