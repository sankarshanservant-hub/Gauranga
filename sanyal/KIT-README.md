# Нишиканта Саньял, «Sree Krishna Chaitanya» (1933) — комплект для перевода EN→RU в отдельном чате (без доступа к GitHub)

Ты переводишь книгу Нишиканты Саньяла «Sree Krishna Chaitanya» (Шри Гаудия Матх, Мадрас, 1933, с предисловием Шрилы
Бхактисиддханты Сарасвати) с английского **на русский** (английский оригинал есть, EN-версия не нужна). Текст уже
разбит на **160 фрагментов** по ≈2000 слов (`frag/`), абзацы пронумерованы. Готовые фрагменты ты отдаёшь файлами;
пользователь кладёт их в папку Google Диска, а Claude в основном чате проверяет, вносит в репозиторий
(`sanyal/ru/`), собирает книгу и ведёт базу лил.

**Главная инструкция — `TASK-translation-ru.md`** (стиль, глоссарий, имена, богословие, ловушки, самопроверка).
Прочитай её целиком перед началом; § 0, 4–7 и 9 перечитывай в каждом новом чате. Этот файл добавляет только то,
что касается комплекта: что в архиве, как называть файлы и где продолжать. Где они расходятся — прав этот файл
(формат выдачи), во всём остальном — `TASK-translation-ru.md`.

## 1. Что в архиве
| Файл / папка | Что это |
|---|---|
| `KIT-README.md` | эта инструкция |
| `TASK-translation-ru.md` | **главная инструкция переводчику**: стиль, глоссарий (§ 4), имена (§ 5), богословие (§ 6), ловушки (§ 7) |
| `frag/INDEX.md` | список всех фрагментов по порядку книги (раздел, абзацы, число слов) |
| `frag/SN-<раздел>-NN.txt` | **текст для перевода**: заголовок фрагмента и абзацы `[N] …` (номер — внутри раздела) |
| `ref/retyped-en.txt` | набранный английский текст обеих частей целиком (из него нарезаны `frag/`) — для сверки и контекста соседних фрагментов |
| `ref/scan-1933-ocr.txt` | OCR скана издания 1933 г. — **только** для сверки сомнительных мест (иная разбивка абзацев, много ошибок OCR) |

Разделы: `00-title` (титул), `00-publisher` (предисловие издателя), `00-preface` (предисловие автора), `00-contents`
(оглавление с краткими изложениями глав), `00-foreword` (предисловие Шрилы Бхактисиддханты Сарасвати), `I-01 … I-09`
(т. I, Introductory), `II-00` (Auspicatory Observance — мангалачарана т. II), `II-01 … II-24` (т. II, жизнь
Шри Чайтаньи до посвящения в Гае и после него).

## 2. Особенности текста
- Абзацы склеены из набранного текста автоматически. Если абзац явно разорван (кончается посреди фразы, а следующий
  её продолжает) или слит из двух — переводи как один/два по смыслу, но **номера сохраняй** (`[12–13]` для склеенных)
  и отметь в «Контроле».
- Длинные цитаты из ЧБ/ЧЧ/«Бхагаваты», которые Саньял даёт в своём английском переводе, переводишь с его английского
  (не подставляй готовые русские переводы).
- Ссылки вида «(59/28)», «Bhag. 10.14.3», «C. B. Adi 2» переносишь **как есть**.
- В `00-foreword` много коротких строк-перечней («Krishna is unborn (59/28, 74/21).») — каждая строка — свой абзац.
- Опечатки набора («Gum» вместо «Guru», «Sreets») исправляй молча в переводе и записывай в «Опечатки исходника».

## 3. Что выдавать после каждого фрагмента
Один файл на фрагмент: **`SN-<раздел>-NN-ru.md`** (то же имя, что у фрагмента, плюс `-ru.md`; например
`SN-II-03-01-ru.md`). Содержимое:
```
<!-- SN-II-03-01 -->
## Глава 3. Рождение и младенчество        ← только если фрагмент начинает главу (заголовок — по § 5 TASK)

[1] …перевод абзаца 1…

[2] …перевод абзаца 2…
```
- **Номера абзацев `[N]` сохраняй** в начале каждого абзаца, как в фрагменте (Claude по ним проверяет полноту и потом
  их уберёт).
- Заголовок главы — `## Глава N. …` (т. I — `## Глава I. …` римскими, как в оригинале; т. II — арабскими).
- Сразу после перевода — блок отчёта по § 8 TASK (сомнительные места, новые термины, опечатки, контроль), **внутри
  HTML-комментария**:
```
<!-- REPORT
Сомнительные места: …
Новые термины и имена: …
Опечатки исходника: …
Контроль: абзацев в оригинале — 16, в переводе — 16; заголовков — 1.
-->
```
Если интерфейс не даёт скачать файлом — выведи файл блоком кода с его именем в первой строке.

## 4. Порядок, объём, сохранность
- Порядок — как в `frag/INDEX.md`. **Начинай с `SN-00-title-01`** (титул), затем издатель, автор, оглавление,
  предисловие Бхактисиддханты — и дальше по томам.
- За один ответ — **один фрагмент** (≈2000 слов). После 6–8 фрагментов — новый чат: стартовое сообщение + архив +
  последний выданный файл и накопленный список «Новые термины» (чтобы сохранить единство).
- Новые термины, которые ты ввёл, применяй во всех следующих фрагментах одинаково.

## 5. Что делает Claude в основном чате (не твоя работа)
Сверка с оригиналом (полнота абзацев, числа, имена, ссылки), стоп-слова и богословие, решения по новым терминам
(дополнение глоссария), внесение в `sanyal/ru/` по главам, сборка книги, записи базы лил (Саньял — вторичный
источник, со ссылками на ЧЧ/ЧБ).
