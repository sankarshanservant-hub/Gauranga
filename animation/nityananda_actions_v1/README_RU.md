# Нитьянанда: тест повторно используемых действий v1

13 октября 2026. Техническая проверка, не художественное утверждение и не канонический сюжет.
Эпизод: персонаж стоит в правом профиле, держит простой сосуд; поднимает его к нижней части груди, слегка
склоняет голову, останавливается и возвращается. Ноги неподвижны. Походка v0.7 не менялась
(`../nityananda_v07/` — без изменений).

Обозначения статусов: **[Godot]** — проверено запуском Godot; **[запись]** — видно в записи/кадре;
**[код]** — вывод по коду; **[гипотеза]**.

## 2. Устройство (повторное использование)

- **Части** (`project/parts.json`, `project/assets/`) — жёсткие Sprite2D без деформаций сетки:
  `body` → `head` → контур плеча и предплечья → `vessel` → контур кисти → заливки плеча, кисти,
  предплечья → `band`. Порядок перекрытий задан явно в `main.gd` (`_build`).
- **Рука в два прохода.** Сначала части с контуром, затем их заливки без внешнего контура: стык в локте и
  у браслета не виден, внешний контур остаётся. Локоть — поворот части вокруг шарнира, а не растяжение.
- **Сосуд — дочерний кисти** (`M.vessel = M.hand_grip`): не скользит и не проходит сквозь пальцы
  **[код]**; в журнале координата точки хвата в системе кисти неизменна во всех кадрах **[Godot]**.
  Кисть поверх сосуда, браслет поверх кисти.
- **Три параметра персонажа:** `raise_amount` (плечо, локоть, запястье между двумя ключевыми позами),
  `incline_amount` (голова), `idle_phase` (дыхание руки).
- **Три независимых действия** — отдельные `Animation` на отдельных `AnimationPlayer`, каждое меняет только
  свой параметр: `hold_idle` (цикл 2,4 с), `raise_object` (1,4 с вверх, 1,0 с удержание, 1,4 с вниз),
  `head_incline` (0,9 с, 1,2 с, 0,9 с). Сохраняются в `project/actions/*.tres`.
  Эпизод = `hold_idle` + `raise_object` с 0,6 с + `head_incline` с 1,0 с (голова начинает позже руки
  и возвращается раньше). Одиночные действия запускаются тем же кодом без пересборки **[Godot]**.

**Что можно использовать снова:** разбиение и порядок слоёв, корпус, голову (наклон в пределах ~10°),
плечо и предплечье с накладками локтя, двухпроходную схему руки, параметры и действия `head_incline`,
`hold_idle`, механизм «предмет — дочерний кисти». **Что привязано к этому тесту:** кисть с хватом и сосуд
(один хват под один предмет), ключевые углы руки (`POSE_HOLD`, `POSE_RAISED` под этот размер сосуда и
высоту груди). Перенос на другого персонажа — только с переразметкой точек, частей и пропорций; не обещаю.

## 5. Проверки

- **Дыры в перекрытиях [Godot]:** эпизод отрисован на ярко-зелёном фоне (`--bg=0,1,0`), во всех 162 кадрах —
  49 пикселей фона внутри силуэта, в худшем кадре 4 пикселя (просвет между краем сосуда и пальцами).
  Разрывов плеча и шеи нет.
- **Покой [код]:** сборка частей без кисти и сосуда против исходника: средняя разница 0,81 из 255,
  374 пикселя с разницей > 24 (`project/diagnostics/rest_compare.json`).
- **Лицо [код]:** голова — жёсткий блок, только поворот: лицо не растягивается.
- **Узор [код]:** части не деформируются — узор не плывёт; но в подложке v0.7 за рукой видна «ступенчатая»
  текстура дхоти и шали **[запись]** — это недостающий рисунок, а не скачок узора движения.
- **Журналы поз [Godot]:** `diagnostics/*_pose_log.txt` — углы суставов, наклон сосуда, хват в системе кисти.
- **Не проверено:** художественная оценка; кисть и сосуд глазами художника; согласование с паспортом персонажа.

## 6. Недостающие рисунки (`missing/`)

Прозрачные PNG в координатах холста исходника (1054×1492): смещение `offset` и размер в `missing.json`,
маска `*_mask.png`. Пример сборки — `tools/compose_missing.py` → `missing/example_assembly.png`.
Как подключить доработанный рисунок: заменить PNG тем же размером и смещением, затем
`cd project && python3 -I tools/build_parts.py` — Godot подхватит новые текстуры без правки кода.
Деформированные позы как замена текстур не экспортируются.

| PNG | Что нужно нарисовать | Где видно |
|---|---|---|
| `hand_grip` | кисть, обхватывающая тулово сосуда (тыльная сторона к зрителю, большой палец сверху) | весь эпизод |
| `vessel` | простой сосуд без узора | весь эпизод |
| `elbow_cap_upper`, `elbow_cap_forearm` | скрытые половины локтя (полукруги) | при сгибе локтя |
| `body_behind_arm` | торс, шаль, шнур, пояс и дхоти за рукой (сейчас подложка v0.7, ступенчатая) | подъём руки |
| `shawl_under_shoulder` | шаль под куполом плеча | отведение плеча |
| `shawl_under_hair` | шаль и шея под волосами | наклон головы с поднятой рукой |
| `neck_under_head` | шея над линией разреза | наклон головы |
| (нет PNG) | **сменный глаз со взглядом вниз** | наклон головы: сейчас глаз смотрит горизонтально |

## 7. Запуск

Godot **4.3-stable** (Linux x86_64, рендер Compatibility / OpenGL 3). Проверено в этой среде под xvfb.

```
cd project
godot --headless --path . --import            # первый раз
godot --path . -- --action=episode            # окно; варианты: raise | incline | idle | start | end
# флаги: --debug (кости) --synth (дорисовки пурпуром) --bg=0,1,0 (проверка дыр) --log (журнал поз)
#        --scale=0.62 --ox=-130 --oy=10 (вид) --nohud
# запись: godot --path . --write-movie out.png --fixed-fps 30 --quit-after 162 res://main.tscn -- --action=episode
python3 -I tools/build_parts.py                # пересборка частей из слоёв v0.7 (нужен ../../nityananda_v07)
```

## 8. Журнал

- **Переиспользовано:** слои v0.7 (`body` из шали, дхоти, стоп, торса и их подложек), исходный рисунок,
  точки плеча, локтя, запястья из `planning_landmarks.json`, приём слежения за дорисовками (diag-текстуры).
- **Создано:** разрез головы, полосы шали, плеча и предплечья; накладки локтя; подложки шеи, шали под волосами
  и под куполом плеча; кисть с хватом; сосуд; двухпроходная отрисовка руки; три действия и эпизод; проверка дыр
  на цветном фоне.
- **Попытки:** одна техническая сборка и одна корректирующая итерация. Внутри корректирующей — три пересборки
  частей, чтобы найти одну причину ступеньки у плеча (сначала неверно приписал её корпусу, затем нашёл в куске
  полосы шали). Исправлено в итерации: дрожание руки (кубическая интерполяция зацикленной фазы давала мусорные
  значения), ровный срез полосы шали на заднем контуре плеча, дыра под контуром полосы. Время не замерялось.
- **Осталось непроверенным / известные недостатки:** глаз не смотрит на сосуд (нужен сменный рисунок);
  кисть с хватом грубее стиля рисунка (технический черновик); подложка v0.7 за рукой ступенчатая; в конечной
  позе между волосами и полосой шали видна подложка шали с тёмной полосой контура **[запись]**; исходная поза
  с согнутым на 40° локтем отличается от рисунка (прямая рука); локоть в конечной позе выходит за контур спины
  **[запись]** — анатомически допустимо, художественно не оценено.
