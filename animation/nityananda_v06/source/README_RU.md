# Нитьянанда — тест анимации из одного рисунка v0.2
8 октября 2026.

Это исходный рисунок и техническое задание для Claude, НЕ готовый риг и НЕ готовая анимация. В отличие от старого комплекта здесь нет непроверенной нарезки и демонстрационного скольжения фигуры.

## Как использовать
1. Загрузить Claude этот ZIP (или распакованные файлы, если ZIP не читается).
2. Попросить прочитать CLAUDE_TASK_RU.md, проверить изображение и создать тестовый проект для вашей установленной версии Godot.
3. Первым результатом получить неподвижную сборку рядом с исходником и тест шага на месте, а не сразу фильм.
4. Проверять результат по ACCEPTANCE_RU.md. Затем добавлять продвижение.

## Состав
- Nityananda_Standing_Accepted_Working.png — цельный боковой рисунок, который пользователь принял как рабочую основу. 1054×1492, RGB, кремовый фон НЕ прозрачный.
- Artist_Original_N01.jpg — исходная иллюстрация художницы; референс идентичности, не анимационный слой.
- planning_landmarks.json — приблизительные координаты для начала разметки; не готовая привязка костей.
- CLAUDE_TASK_RU.md — задание и ограничения.
- ACCEPTANCE_RU.md — проверки до принятия результата.

Изображения скопированы без изменения пикселей. Рисунок не перерисован при упаковке. Готовые прозрачные части, восстановленные скрытые области, веса сетки и анимация в комплект не входят. Их создание и проверка — задача следующего теста. Кости под дхоти не обязаны иметь отдельные видимые изображения, если ткань закрывает их во всех фазах.

Этот пакет не заменяет Style Bible и паспорт проекта. Это ограниченный эксперимент по одному действию. Не использовать четыре отклонённые генеративные позы как кадры цикла.

## Основание выбора
Godot поддерживает cutout-анимацию, Polygon2D с текстурой и деформацию через Skeleton2D. Покадровая последовательность не обязательна. Конкретная комбинированная конструкция для Нитьянанды пока не проверена.
