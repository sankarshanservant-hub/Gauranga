# Тест позы: проход ближней ноги мимо опорной (на основе v0.7)

Один неподвижный кадр, а не новая версия ходьбы. v0.7 не менялась (`../nityananda_v07/`); длина шага,
скорость и цикл — как в v0.7. Новая анимация не собиралась.

Поза: q = 0,77 — ближняя нога в переносе проходит мимо опорной (сгиб колена 42°, стопа над землёй 16 px).

## A — исправление рига и весов (`project/`)

Копия проекта v0.7 с правками только ткани ближней ноги:

- `tools/build_rig.py`, `KNEE_A`: ткань ближней штанины у колена переходит на кость бедра (доля 0,8,
  плавно по высоте около колена), ниже колена — на кость `near_hang` (перенос вместе с коленом без поворота:
  ткань свисает с колена, а не уходит назад за голенью), у края штанины у щиколотки — снова голень.
- `main.gd`: компенсация v0.7 (дальняя штанина выдвигается за ближним коленом) отключена — `far_bulge = 0`.
  Вместо неё — остаточная поправка ближней штанины (`_apply_near_follow`): если её передний край на высоте
  колена ближе 14 px к колену, передняя зона плавно сдвигается (в позе — 2,9 px).
- В журнал `--logknees --stretch` добавлено место наибольшего растяжения (`max_at`).

**Исправлено настройкой:** колено ближней ноги внутри своей штанины; дальняя не выдвигается; ширина
ближней штанины сохранена (не брюки, колено не открыто); σ 0,81–1,20 (порог 0,8–1,2, максимум под кистью).

**Не исправляется настройкой:** складки остаются вертикальными складками стоящей фигуры (сетка их только
переносит); за ближней штаниной открывается задняя часть дальней (опорной) штанины, которой нет в рисунке
(подложка с угаданным прямым краем).

## B — схема корректирующей формы ближней дхоти

Эскиз поверх позы A (не текстура): 1 — контур; 2 — складки натяжения от колена к поясу; 3 — провис под
коленом; 4 — свисающие складки от колена к краю; 5 — сжатие у края на голени; 6 — задняя часть дальней
штанины для дорисовки; 7 — перекрытие ближней поверх дальней. По конспекту Хогарта
(`../library/konspekt/Hogarth_Wrinkles_Drapery_RU.md`: натяжение от точки опоры — колена, провис позади
сгиба; изгиб колена больше ±15° — нарисованной формой, а не сеткой).

## Как повторить

```
tools/render_pose.sh <godot> <папка> 0.77
# слои варианта A по отдельности (для схемы B):
cd project && for L in dhoti_near dhoti_far; do xvfb-run -a <godot> --path . --rendering-driver opengl3 \
  --resolution 1054x1500 --write-movie <папка>/only_$L.png --fixed-fps 30 --quit-after 2 res://main.tscn -- \
  --mode=in_place --nohud --start=0.77 --slow=0.00001 --scale=1 --ox=0 --oy=0 --only=$L; done
python3 tools/pose_sheet.py <папка>
```

Замеры — `diagnostics/pose_numbers.txt`. Godot 4.3 запускался (xvfb, OpenGL 3).
