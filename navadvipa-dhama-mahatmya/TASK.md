Решение пользователя (2026-10-26): переводы Шри Чайтанья Сарасват Матха — наши (см. `CLAUDE.md`); книгу выкладываем
на сайте RU + EN, как остальные, **заново не переводя**; из неё извлекаем всё для базы: лилы, спутников, места (с
координатами для карты).

## Источники (`../sources/navadvipa-dhama-mahatmya/`)
- **EN** — изд. ШЧСМ 2015 (пер. с бенг. изд. 1988; бенг. текст, транслитерация, пословный, перевод; стихи
  пронумерованы). Разобрано в `en/NN.md` (`tools/build_en.py` из `src/en_lines.jsonl`): только перевод, по стихам
  `**N.**`; где в издании один перевод на два стиха — метка-диапазон `**15–16.**`. Опечатка издания: гл. 5, второй
  «[41]» = 40 (исправлено). После разбора в `en/` есть ручные правки (объединения стихов — они же в
  `MERGE` разборщика; мелкие опечатки издания, сноска гл. 9) — `en/` из разборщика не перегенерировать вслепую.
- **RU** — изд. ШЧСМ 2001 (пер. Д. Рогозы с англ. — с более раннего англ. перевода), сплошная проза без номеров.
  Извлечено в `src/ru-raw/NN.md` (`tools/build_ru_raw.py`): абзацы, переносы восстановлены автоматически.
- Главы RU и EN соответствуют 1 : 1 (гл. 1–18 «Махатмьи»; 19 — «Бхава-таранга»). Названия глав в RU — по изд. 2001.

## Этап 1. Русский текст по стихам (`ru/NN.md`)
Цель — единая нумерация RU и EN (сайт показывает их параллельно; база лил ссылается на метки).
1. `ru/NN.md`: заголовок `# Глава N. <название по изд. 2001>` (для 19 — `# Навадвипа-бхава-таранга`), затем текст
   изд. 2001, разбитый по стихам: для **каждой** метки `en/NN.md`, в том же порядке, — строка, начинающаяся с той же
   метки (`**N.** …`), с соответствующим ей русским текстом. Пустая строка между стихами. Проверка:
   `python3 tools/check_align.py NN` → OK.
2. **Текст изд. 2001 не переписывать.** Только делить по границам стихов (можно посреди предложения, по смыслу;
   союз/запятая на стыке — как есть). Исправлять лишь ошибки извлечения: слитые при переносе составные слова
   («Навадвипадхама» → «Навадвипа-дхама», «Калиюга» → «Кали-юга», «тогдато» → «тогда-то»), ошибочно разорванные слова,
   порядок слов в первом абзаце главы (буквица), явные опечатки. «ё» не вводить. Имена — как в изд. 2001.
3. Если один русский отрывок неделим на несколько стихов — дать его под меткой-диапазоном `**a–b.**` и **так же**
   объединить эти стихи в `en/NN.md` (одна строка `**a–b.**`, английские переводы подряд через пробел). Делать это
   только при действительной неделимости; каждое объединение записать в `review/ru-NN.md`.
4. Если в изд. 2001 стиха (стихов) нет — перевести их на русский по `en/NN.md` (наш англ. перевод; для сверки смысла —
   транслитерация бенгальского в `src/en_lines.jsonl`, шрифт PalatinoLTStd-Medium 8.0), в стиле изд. 2001, и на
   первом стихе такого отрезка поставить сноску: `[^NN-k]: Стихи a–b в изд. 2001 г. отсутствуют; переведены по англ.
   изд. ШЧСМ 2015 г.` (сноски — в конце файла). Если в RU есть текст, которого нет в EN (вставка редактора, пояснение),
   — оставить на месте и отметить в `review/ru-NN.md`.
5. `review/ru-NN.md` — короткий журнал: объединения, восполненные стихи, вставки; **места, где RU расходится по
   смыслу с EN 2015**; формулировки, допускающие майявадское или мирское прочтение (Господь под властью майи,
   «статуя», мирская страсть и т. п. — см. `CLAUDE.md`), — с предложенной правкой. Сам текст в таких местах **не
   менять** (решает пользователь), кроме ошибок извлечения.
6. Сохраняться порциями (каждые ~30–40 стихов файл уже на диске), по окончании главы — коммит своих файлов.

## Этап 2. Места и карта (`lila-db/PLACES.md`, `lila-db/places-geo.yaml`)
- Все места Навадвипа-мандалы, названные в книге (9 островов, сёла, кунды, тилы, храмы, Божества-места), —
  теги `#…` в конец `PLACES.md` (сначала искать существующие: `#mayapur`, `#simantadvipa`, `#modadrumadvipa`,
  `#champahatti`, `#vidyanagara-bengal`, `#kulia`, `#gadigachha`, `#house-srivasa` …). В примечании: остров,
  соответствие во Врадже (по книге), гл.:стих первого описания (`НДМ 5.12`), совр. название.
- `lila-db/places-geo.yaml` — координаты для карты: `#тег: {lat, lon, precision: точно|примерно|условно, basis: "…"}`
  (OSM/Nominatim — не чаще 1 запроса в секунду, с честным User-Agent; карта книги, с. 2 PDF 2015; общеизвестная
  география). Для всех реальных мест `PLACES.md`, не только навадвипских; духовные/мифические (Голока и т. п.) — не
  включать. `build.py` — добавить `geo` в `export/places.json`.

## Этап 3. База лил (`lila-db/lilas/navadvipa-mahatmya-*.yaml`)
- Источник `navadvipa-mahatmya` (B; см. строку в `SOURCES.md`). Формат — `lila-db/README.md`.
- Записи в порядке изложения, id `nvm-NN-NNN` (глава-номер). Рамка (Нитьянанда ведёт Дживу по Навадвипе; ночлеги,
  переходы, видения Дживы) — свои события; лилы Махапрабху, вспоминаемые на местах, — к существующим событиям
  (`ev-…`), если они есть, иначе новые; лилы прошлых юг (Рама, Притху, Брахма, Индра, семь риши, Шива и Парвати …)
  — `kind: pre-advent`, P00; пророчества (храм в Майяпуре и т. п.) — `prophecy`; наставления — `teaching`.
- `verses` — по меткам `navadvipa-dhama-mahatmya/ru/NN.md` (= метки EN).
- Новые события — в свой `lila-db/events-navadvipa-mahatmya-<буква>.yaml`; новые лица/места — в конец
  `PERSONS.md` / `PLACES.md` (перед добавлением `git pull` и поиск). Проверка: `python3 lila-db/build.py -w`.
