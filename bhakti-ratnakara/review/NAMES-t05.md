## Правила транслитерации мест Враджа
- Санскритная основа, без диакритики. RU: ш (ś, ṣ), кш (kṣ), ч (c), чх (ch), дж (j), ри (ṛ); EN: sh, ksh, ch, chh, j, ri.
- Леса: RU «-вана», EN «-vana»: Мадхувана / Madhuvana, Талавана / Talavana, Кумудавана / Kumudavana,
  Бахулавана / Bahulavana, Камьявана / Kamyavana, Кхадиравана / Khadiravana, Бхадравана / Bhadravana,
  Бхандиравана / Bhandiravana, Бильвавана / Bilvavana, Лохавана / Lohavana, Махавана / Mahavana.
  Исключения (устоявшиеся): Вриндаван / Vrindavana, Нидхуван / Nidhuvana.
- Пруды: «Шьяма-кунда» / "Shyama-kunda", «Радха-кунда» / "Radha-kunda"; озеро — «Кусума-саровара» / "Kusuma-sarovara".
- Гхаты: «X-гхат» / "X-ghat" (Чир-гхат / Chir-ghat); но «гхат Вишрама» / "Vishrama ghat".
- Селения: Нандишвара / Nandishvara (холм и селение Нанды), Нандаграм / Nandagrama, Варшана / Varshana,
  Джават / Javata, Санкета / Sanketa, Гирикунда / Girikunda, Гокула / Gokula, Матхура / Mathura,
  Говардхана / Govardhana, Ямуна / the Yamuna, Раса-стхали / Rasa-sthali, Вамшиват / Vamshivata,
  Дхира-самира / Dhira-samira, Калия-храда / Kaliya-hrada.
- Склонение RU: «во Врадже», «Враджа»; места на -а склоняются (в Мадхуване, у Говардханы).
- Сноска к месту — при ПЕРВОМ упоминании в таранге: что это и чем знаменито, одной фразой. Если место ниже
  отмечено «(сноска: 5.N)», сноску не повторять.

## Решения координатора
- Длинный рассказ Рагхавы о местах — БЕЗ кавычек; в кавычках только короткие реплики и вставные рассказы.
- «Кешава-дева» / "Keshava-deva" (через дефис), «Вишранти-тиртха» / "Vishranti-tirtha".
- Пураны во вводной строке: «*Так [сказано] в «Ади-вараха-пуране»:*» / "*Thus [it is said] in the Adi-varaha Purana:*".
- Номер стиха — только если он есть в тексте изданий.
- Термин সালগ / শালগ (вид пения) — «салага» / "salaga" (не «шалага»); но рага ষালগ в 2779 — «Шалага».
- Подзаголовки самого текста A/B/C в теории музыки («অথ …», «অথ … আহ») — НЕ выбрасывать (это не заголовки изд. 1960 г.):
  курсивная первая строка единицы. «অথ X» → «*Теперь — X:*» / "*Now, X:*"; «অথ X-ম্ আহ» → «*Теперь [говорится] о X:*» /
  "*Now [it is told] of X:*". Сольмизация: «са-ри-га-ма» / "sa-ri-ga-ma". Пример в шлоке («উদাহরণম্») — строкой «Пример: …» / "Example: …".
- Теория музыки (с 5.2490): термины — транслитерацией, без кавычек и курсива, склоняются в RU: нада, шрути, свара, грама,
  мурчхана, тала, рага (рагини), марга и деши, дхату и мату, мандра / мадхья / тара; EN nada, shruti(s), svara(s), grama(s),
  murchhana(s), tala(s), raga(s), marga, deshi, dhatu, matu, mandra / madhya / tara. Пояснение — сноской при первом
  употреблении; если термин уже пояснён в предыдущей порции (см. таблицу ниже), не повторять. Инструмент вина — RU «вина»
  (при первом упоминании в порции: «вина (струнный инструмент)», чтобы не спутать со словом «вина»), EN "vina".
  Перед началом прочитай целиком предыдущую по номерам порцию в /home/user/br-out/t05/ — для единства терминов.
- Пады (песни) в кавычки целиком НЕ берутся. Прямая речь внутри пады и в повествовании — «…», вложенная — „…“, третий уровень — ‚…‘; EN "…", вложенная '…'.
- Обращение к Кришне (Господу) — с заглавной (Ты, Тебя, Твой; EN You, Your); к Радхе — по ref/padas-GLOSSARY; к спутникам, Санатане, Рупе — строчными.
